# Production Engineering — COVER Texture Rescue Runtime

## Failure class
Toy synth, beep-boop, ringtone lead, cute blip, cheap EDM pluck, empty intro, weak drop, old idol/J-pop-rock skin.

## Positive replacements
Use role-based modern club materials:
- processed vocal texture as rhythmic hook
- chopped guitar-resample as low-mid stab
- filtered noise/riser as pressure
- sidechain pressure bed below vocal corridor
- tight offbeat hats and dry clap/snare
- rolling sub with separated kick
- wide backing field, center-forward lead

## Negative lockouts
toy synth, beep-boop synth, ringtone lead, chiptune tone, cute blip lead, cheap EDM pluck, old trance/rave stab, empty first 8 bars, weak drop, dated idol backing, 90s J-pop melody, buried Korean lead.

## Cue pairing
- empty intro → [Cold open: full club bed enters immediately]
- weak drop → [Sudden drop] then [Full drop: kick, sub, chopped vocal texture]
- toy pluck → [Instrumental: processed vocal texture answers hook]
- vocal buried → [Lead vocal center-forward; backing doubles wide only on hook]
