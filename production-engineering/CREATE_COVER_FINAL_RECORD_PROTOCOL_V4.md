# CREATE → COVER Final Record Protocol — V4

## Doctrine
CREATE makes the source audio. COVER transforms or refines that audio. COVER is the final record.

## CREATE owns
- tempo
- key/tonal color
- chord motion
- melody contour
- hook shape
- section arc
- core band identity
- motif

## COVER owns
- target skin/finish
- instrument substitution
- groove replacement/refinement
- vocal treatment while preserving identity
- stereo/depth/quality stack
- final/outro protection

## Transform prompt order
target anchor → preserve map → substitution map → vocal identity → section events → quality stack → final/outro.

## Two-step rule
If the prompt must both transform genre and repair quality, split internally:
1. transform
2. refine/remaster

## Audio Influence
- 70-75: note/topline survival
- 62-68: preserve but allow transform
- 55-61: balanced transform
- 45-54: skin replacement
- 20-40: texture/refine/DNA only

## Quality minimum
Every serious COVER has vocal corridor, low-end separation, low-mid cleanup, high-mid/air control, stereo/depth, dynamics/finish in compressed listener language.
