# Pairing Risk Table — 악기·요소 페어링 리스크
원칙: CREATE 핵심 악기 3-4는 "한 밴드"여야 한다(G4-d). 아래는 충돌·마스킹·정체성 표류를 만드는 위험 페어와 처방.

| 위험 페어 | 증상 | 처방 |
|---|---|---|
| glockenspiel/music box + 키즈·인디 무드 | 장난감 동요화(F-005) | muted guitar pickup melody + rim-click으로 대체, EXCLUDE: toy chimes, music box, xylophone |
| 두꺼운 패드 + 보컬 코리더 | 보컬 매몰 | pad를 verse 한정·thin tail로, corridor 줄 필수 |
| 808 sub + 어쿠스틱 밴드 결 | 시대 정체성 분열 | 둘 중 하나 — era 앵커가 결정 |
| crash 과다 + 질주 BPM | 상단 백색화 | ride 중심, crash는 섹션 전환만 |
| 스트링 섹션 + 미니멀 일렉 | 평균 팝 끌림(centroid) | 스트링을 시그니처 1프레이즈로 한정하거나 제거 |
| 더블링 리드기타 + 신스 리드 | 모티프 소유권 분쟁 | 소유 악기 1개 지정, 나머지는 unison 보조로 명시 |
| 남성 저음 더블 + 여성 mid-high 리드 | 옥타브 진흙 | 더블은 후렴 한정 + low-mid pocket 줄 |
| heavy reverb + 빠른 한국어 가사 | 자음 뭉개짐(이해도 하락) | tight plate/short room, dry-forward lead |

## 밀도 거버너 (요약)
동시 발성 레이어: verse ≤3 / pre ≤4 / chorus ≤5 (보컬 포함). 후렴이 "더 크게"가 아니라 "더 넓게" 들리게 — 추가는 폭(스테레오·옥타브)으로, 두께(동대역 중첩)로 하지 않는다.
