# CUE CALL-RESPONSE GRID — 가사 이벤트 ↔ 큐 응답 표준표
큐 배치의 "호응 기준": 큐는 임의 살포가 아니라 **가사 이벤트에 대한 응답**이다. 가사가 부르면(call) 큐가 받는다(response). 라벨: [운영 재현]=운영자 실곡 검증 / [표준]=cue_device_library 합치.

| 가사 이벤트 (call) | 큐 응답 (response) | 근거/조건 |
|---|---|---|
| 고백·자백 직전 행 | [Band drops out] → 직후 행 노출 | 직후 행이 곡 최강 행일 때만 — 평범 행 노출은 낭비 [표준] |
| 훅 진입 직전 | [Breath] 또는 [Sudden drop] 1박 | 둘 중 1개, 매 후렴 중복 금지 [표준] |
| Final 변이 행(defense-shift 착지) | [Held note]+옥타브 점프 또는 [Harmony enters] | 마리최종4 Final 검증 [운영 재현] |
| 브릿지 인정·항복 순간 | [Pause half bar]+[Held]+microtonal slide 스택 | 설계 순간 과감 스택 합법 [운영 재현] |
| 엔딩 잔향 한 줄 | 드랍/휴지 직후 [Whispered] 짧은 행(≤6음절) | Whispered 작동 조건 그 자체 [표준] |
| 챈트·떼창 구간 | (BGV: …) 콜앤리스폰스 인라인 + ALL CAPS 1회 | 독립 행 금지, CAPS 곡당 1-2 [표준] |
| 콩트 오프닝 | 인트로 보컬 첫 줄 = 식별 애드립(콜·허밍·구호) | 운영자 liked 제목군 패턴 [운영 재현] |
| 질주(150+BPM) 런 직후 | [Breath] 또는 [One-bar rest] | 섹션당 휴지 ≥1 [표준] |

## 행 끝 어미와 호흡 배치 (운영자 코퍼스 실측 — 고 519·데 259·서 238)
- **견인 행**(끝이 -고/-서/-는데/-며 = 다음 행을 당김) 뒤 **[Breath] 금지** — 흐름 절단. 호흡은 **완결 어미 행**(-어/-야/-지/-네/!) 뒤에만.
- ? 반문 행 뒤 = 짧은 무큐 공백(침묵이 응답) 또는 [Pause half bar] — 즉답 큐 금지.
- ! 외침 행(운영자 최빈) 뒤 = 에너지 유지면 무큐, 낙차 설계면 [Sudden drop].

## 운용
- 한 섹션의 큐는 그 섹션 가사의 이벤트 수를 넘지 않는다(이벤트 없는 큐 = 스팸).
- 표에 없는 조합은 cue_device_library의 작동/파괴 조건으로 판정.
