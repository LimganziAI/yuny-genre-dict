# CUE EVENT MAP V4.3

Cue = response to a lyric or arrangement event.

For each important cue:
trigger line/event -> device -> intended render -> risk.

Reliable devices:
- [One-bar rest] before critical shout/answer
- [Sudden drop] before hook return or confession
- [Band drops out] before rupture
- [Drums cut] for bridge reset
- [Harmony enters] when harmony must appear
- [Vocal doubles only on final phrase] for final emphasis
- [Instrumental: motif returns] when band speaks

Weak devices:
asterisk, quotes, bold, vague emotional adjectives. Never use them alone.
