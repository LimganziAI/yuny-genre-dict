# Render Model H1-H4 — 운영 가설 (라벨 규율 적용)
모델 메이저 업데이트 시 전수 재검. 전부 [가설]/[연구-가설] — 단정 금지, 운용 규칙의 근거로만.

- **H1 앞쪽 토큰 가중**: Style 프롬프트 앞부분이 결과를 지배한다 [커뮤+운영 재현]. → Position 1 = 마이크로장르+era 앵커, 핵심 정체성은 첫 150자 안에.
- **H2 분포 중심 회귀**: 일반어·다태그는 학습 분포의 평균으로 끌린다 [연구-가설: 토큰 모델 일반 성질]. → 삭제 패스·off-center 채택·EXCLUDE 차별화가 해독제.
- **H3 가사 직결 실현**: LYRIC 텍스트는 보컬 내용으로 거의 그대로 실현, [ ] 큐는 *렌더 가능 디바이스*일 때 반영률이 뛴다 [운영 재현]. → 큐는 placement/dynamic/breath/event 어휘로; 서사·은유 큐는 무시되거나 노이즈.
- **H4 2-pass 비대칭**: COVER는 소스 오디오의 의미층(멜로디·구조·퍼포먼스)을 Audio Influence 비율로 보존 [공식 정의 정합+가설]. 텍스트 침묵 영역은 타깃 장르 평균으로 채워진다. → preserve/substitution 맵 침묵 금지.
