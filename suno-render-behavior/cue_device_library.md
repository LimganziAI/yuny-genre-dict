# CUE DEVICE LIBRARY — 렌더 제어 디바이스 전체 기준
원칙: 큐는 좋은 가사 위의 보컬·편곡 연출이다 — 가사를 대체 못 한다. 스팸 금지, 그러나 설계된 순간엔 과감하게. 라벨: [운영 재현]=자체 반복 확인 / [커뮤]=커뮤니티 관찰 / [가설].

## Tier-S — 구조 이벤트 (가장 신뢰, 편곡 레벨) [운영 재현]
| 디바이스 | 효과 | 사용 기준 | 깨지는 경우 |
|---|---|---|---|
| [Instrumental: 묘사] | 무보컬 구간+편곡 지시 | 인트로/간주/아웃트로 — 악기·길이 명시("bright piano ostinato, 2 bars") | 묘사가 서사면(악기 언어로만) |
| [Band drops out] | 반주 급감 | Bridge 진입·고백 직전 — 직후 행이 노출되므로 그 행이 곡 최강 행이어야 | 드랍 후 평범한 행(노출 낭비) |
| [Sudden drop] | 1박-1마디 급정지 | 훅 직전 공기 만들기, 156BPM+ 질주곡 특효 | 곡당 3회+(충격 인플레) |
| [One-bar rest] | 보컬 1마디 휴지 | 프리 끝/섹션 경계 — 호흡 설계의 기둥 | 행 중간 삽입 |
| [Harmony enters] | 화음 스택 진입 | 2절 후렴·파이널 점층 — "exactly one lift" 설계와 결합 | 매 섹션 남발(점층 소멸) |
| [Vocal doubles only on final phrase] | 마지막 구만 더블 | 파이널 진화 1개로 최적 | 전 후렴 더블과 병용(차별 소멸) |
| 섹션 태그 [Verse 1 8] 등 | 구조+바카운트 | 전 섹션 의무 — 인트로 자동 확장 차단([Short Instrumental Intro: 2 bars]) | — |

## Tier-A — 보컬 연출 (조건부 강함)
| 디바이스 | 작동 조건 | 깨지는 조건 |
|---|---|---|
| [Singing: …] | 섹션당 1개, 영어 ≤120자, placement/dynamic/mic/phrasing+이벤트 — HOW만 | 서사·은유 삽입("like unsent words"), 감정 형용사만 |
| [Breath] | 훅 직전·긴 런 직후·드랍 후 첫 행 앞 [운영 재현] | 행마다 살포(호흡 인플레) |
| [Whispered] | **드랍/휴지/사일런스 직후 + 짧은 행(≤6음절) + 저밀도 반주** — 엔딩 "달다…"형 최적 [운영 재현] | 고에너지 한복판, 긴 행, 선행 대비 없음 → 무시되거나 어정쩡한 약화 |
| [Held] | **행 끝 열린 모음(ㅏ/ㅗ/ah/oh) + 무받침·ㄴ/ㅁ/ㄹ + 정점 자리, 곡당 1-2회** | 파열 받침(-ㄱ/ㅂ/ㅅ), 행 중간, 매 후렴 반복 |
| (인라인 (whisper:) ) | **무효 — 사용 금지, [Whispered]로** [운영 재현 확정] | — |

## Tier-B — 채색 (메인 제어 금지, 페어링으로 실효)
| 장치 | 효과 | 기준 |
|---|---|---|
| ALL CAPS | 외침/스파이크 | 곡당 1-2 단어 — 문장 전체 CAPS 금지 |
| 모음 늘임 표기(사라져어—/lo-o-ove) | 지속 힌트로 실효 [커뮤+운영 재현] | [Held]와 같은 모음 조건, 표기는 1-2회 |
| *asterisk* | **장식적·미약** [운영 재현] | 단독 과신 금지 — CAPS나 늘임과 페어링 시 보조 효과 |
| (BGV: …)/(애드립) | 응답·메아리 | **인라인만**(독립 행 금지 — 중복 보컬 리스크), 짧게 |
| 발음 표기 오버라이드 | 모호 발음 교정 | 섹션당 ≤1, 꼭 필요할 때만 |

## 배치·수량 법칙
- device ≥4 그리고 ≤가사 행수÷3. 닿는 행 *사이* 실배치 — 섹션 끝 더미는 쿼터 게이밍.
- 섹션당 휴지(Breath/rest/드랍 중 1) ≥1 — anti-쏟아짐.
- **과감함의 자리**: 곡당 2-3개의 설계 순간(훅 진입·브릿지 고백·엔딩)에는 스택 허용([Sudden drop]+[Whispered]+[Held]는 정당한 이벤트). 나머지는 절제.
- 큐-대체 테스트: 큐 전부 지워도 가사가 곡으로 서야 한다 — 안 서면 가사 수리로 회귀.
