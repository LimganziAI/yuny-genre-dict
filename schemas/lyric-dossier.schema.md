# lyric-dossier.schema.md — Pre-Writing Lyric Dossier Schema

Built BEFORE any lyric line is written (card 05). Serious songs require all 16 slots; light requests may run a 6-slot fast dossier (persona/scene/metaphor/object bank/hook thesis/forbidden bank).

```yaml
persona: # who sings — age-band, stance, voice in the world
listener: # who is being sung to (can be self/absent/audience)
scene: # concrete place+time, sensory ground
why_now: # the trigger event — why this song exists today
central_metaphor: # ONE governing image; everything serves it
object_bank: # 8-15 concrete nouns from the persona's world
verb_bank: # strong, physical verbs; weak-verb ban (있다/되다 stacking)
rhyme_vowel_bank: # target vowels for hook openness, rhyme families
forbidden_cliche_bank: # 네온/메아리/그림자/속삭임/벨벳/크리스탈 + genre-specific bans + abstract emotion words
hook_thesis: # the one sentence the song proves; hook embeds it organically
section_image_progression: # V1→PC→C→V2→B→FC image arc
verse2_new_information: # what V2 reveals that V1 couldn't
pre_chorus_pressure: # how tension is built (density/ascent/withholding)
bridge_turn: # the perspective/temporal/harmonic pivot
final_chorus_evolution: # what changes (key/ad-lib/density/lyric variant)
outro_image: # the closing frame; [End] strategy
```

Rule: lyric drafts that violate the dossier (cliché use, metaphor drift, weak verbs) fail review before reaching the Lyrics field.
