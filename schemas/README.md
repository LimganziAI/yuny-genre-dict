# schemas/

Canonical record formats. Every saved artifact must validate against its schema.

- `case.schema.md` — result feedback record (canonical; `case_schema.md` = legacy alias)
- `prompt-pattern.schema.md` — promoted reusable technique (provenance + confidence mandatory)
- `genre-card.schema.md` — genre dictionary entry + lookup ladder
- `lyric-dossier.schema.md` — pre-writing dossier (16 slots / 6-slot fast mode)
- `feedback.schema.md` — diagnosis intake ticket (symptom → layer → prescription)
