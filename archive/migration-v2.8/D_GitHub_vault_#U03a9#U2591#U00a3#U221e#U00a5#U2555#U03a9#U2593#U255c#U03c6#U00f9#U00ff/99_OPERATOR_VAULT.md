## ─── PART A. 시그니처 작사 철학 ───

Limganzi의 작사 DNA. 18+ 케이스에서 일관되게 발견되는 패턴.


### A.1 일본 문학 영향 (Decoupled Domestic Imagery)

**무라카미 하루키 영향**: 일상 사물의 미세한 어긋남으로 감정 전달.
감정을 직접 말하지 않고, 무관해 보이는 풍경·사물의 디테일이 정서 운반.

**핵심 원칙:**
- 디테일 자체가 아니라 *디테일들이 만드는 분위기*
- 마법적 리얼리즘 (현실 안에 미세한 균열)

**작법 절차 (4단계):**
1. 감정을 정의 (외로움 / 권태 / 그리움 / 체념)
2. 그 감정과 *무관해 보이는* 일상 사물 3-5개 떠올림 (냉장고, 리모컨, 커피잔, 신발끈, 빈 의자)
3. 그 사물에서 *미세한 어긋남* 찾음 (두부가 그대로 / 자국이 셋 / 컵이 하나만 / 한쪽만 풀린 / 안장만 식어)
4. 그 어긋남만 가사로 적음. 감정 단어 절대 X.

**요시모토 바나나 영향 (Domestic Surrealism + Healing Tone):**
- "일상에서 하는 말, 일기처럼, 친한 친구에게 말하듯이"
- 거대한 감정(이별/죽음/실패)을 일상 디테일로 우회
- 친구에게 말하듯 자연스러운 어미 ("~지", "~잖아", "~같아")
- 결말은 작은 행동 ("문을 연다", "걸어간다", "차를 마신다")


### A.2 한로로/기형도 영향 (서사적 청춘 일기)

- 청춘의 불완전한 감정·관계를 자신만의 언어로
- 형용사보다 *동사*로 감정 전달
- 자연물 메타포 (청설모, 도토리, 비, 바람, 풀잎)
- 자기 비하 + 자기 정당화 동시 ("어차피", "뭐 어쩌겠어")
- 청춘기 일기 톤 + 시적 압축


### A.3 Show Don't Tell 강박 — Limganzi 핵심 규칙

**규칙**: 감정 단어를 가사에 직접 X.

**금지 단어 카테고리:**
- 직접 감정 단어: 슬프다 / 외롭다 / 그립다 / 행복하다 / 사랑한다
- 추상 단어: 마음 / 심장 / 영혼
- 거창 단어: 운명 / 영원 / 사랑 / 이별

**감정 → 감각/사물 변환 체크리스트** (매 라인):
- 이 라인이 "감정인가, 감각인가?" 검증
- 감정이면 → 일상 사물 또는 신체 감각으로 변환
- 감각이면 → 통과


### A.4 감각 파편화 작법 (Case 14 정립)

신체 감각의 파편으로 감정 전달. 시각·청각·촉각·후각·운동감각.

```
시각: "눈썹 끝에 햇빛이 걸려"
청각: "심장 박동이 귀에 들려"
촉각: "땀이 눈을 찔러"
운동감각: "발 밑이 흔들려"
후각: "어제 입은 셔츠 냄새"
```


### A.5 Don't Show Don't Tell 어법 (Case 23 정립)

**핵심**: 사물도 보여주지 않고, 상태를 *부정문*으로만 묘사.

기존 Show Don't Tell이 감정을 사물로 보여주면, *Don't Show Don't Tell*은
감정 위치를 "긍정"이 아니라 "부정의 부정" 또는 "부정의 누적"으로 정의.

**핵심 구문 (한국어 전용 — 영어 번역 불가):**
- "~지 않다" / "~건 아닌데" / "~다고 ~한 건 아니야"
- "그렇다고 ~" / "별로 안 ~잖아"
- "뭐 그냥 ~" / "어차피 ~" / "뭐 어쩌겠어"
- "~더라" / "~구먼" / "~지" / "~잖아"

**작법 절차:**
1. 화자가 느낄 법한 감정 A 정함 (부러움, 권태, 아쉬움, 슬픔)
2. 그 감정을 직접 묘사 X, 부정함
3. 부정한 다음 "그렇다고 ~한 건 아니다"로 한 번 더 부정
4. 두 번의 부정 끝 "뭐 그냥 그런 거지"로 종결

**예시 (자가복제 X, 패턴만):**
- 부러움: "그렇다고 부럽거나 그런 건 아닌데 / 뭐 그냥 그런 거지"
- 슬픔: "별로 안 슬프잖아 / 어차피 ~"
- 만족: "그렇게까지 좋은 건 아닌데 / 그렇다고 싫은 것도 아니야"
- 권태: "좋아서 하는 게 아니라 / 그냥 있으니까 하는 거지"

**적용 화자**: 직장인 / 소시민 / 무덤덤 화자. 무라카미 + 강풀 일상툰 + 김중혁 단편소설 결합.


### A.6 메타포 엔진 분리 작법 (Case 38 정립)

컨셉 엔진 단어를 가사에 *0회 출현*시키되 동작 패턴만 빌려와 *목적어 치환*.

**작법 절차:**
1. 컨셉 엔진 정의 (예: 대체당 = 가짜 단맛 = 칼로리 0)
2. 동작 어휘 풀 추출 (마시다 / 한 모금 / 라벨 / 성분표 / 칼로리 / 혀끝 / 속 아픔)
3. 목적어 치환 ("당신을 한 모금 마셔요" — 대체당의 동작을 사랑에 적용)
4. 메타포 엔진 단어 0회 출현 검증 (출력 직전 grep으로 가사 검수)
5. 듣는 사람이 후반부에서 "어 이거 사실 [엔진]이었네?" 깨닫는 구조

**확장 가능 컨셉 후보:**
- 에너지드링크 (각성 = 거짓 활력)
- 다이어트 콜라 (단맛 = 다이어트 자기기만)
- 화장품 BB크림 (보정 = 가짜 자신감)
- 항우울제 (행복 = 화학적 우회)
- 비타민제 (건강 = 공복감 회피)

**Show Don't Tell과 차이:**
- Show Don't Tell: 식어버린 커피로 외로움을 *보여줌* (감정의 사물화)
- Don't Show Don't Tell: "그렇다고 외로운 건 아닌데"라고만 *말함* (감정의 부정)
- 메타포 엔진 분리: 가짜 단맛의 *동작*을 사랑에 빌려옴 (엔진의 행위적 차용)


### A.7 가사 ↔ 사운드 매칭 5축 프로토콜 (Case 27 정립)

가사 폴리싱 후 사운드 프롬프트 자동 재검증 절차 (의무).

```
1. 가사 정조 ↔ 악기 매칭 (Bridge stop-time과 walking bass 충돌 등)
2. 보컬 디렉션 ↔ 가사 라인 매칭 ([Singing:] 큐 미세 조정)
3. 키/코드 ↔ 가사 감정 매칭 (Chromatic mediant와 hook line align)
4. BPM/구조 ↔ 호흡 매칭 (음절 밀도 vs 바 수 정합)
5. 사운드 throughput ↔ 가사 텐션 매칭 (Final Chorus / Outro)
```


### A.8 다국어 가사 음운론 체크리스트

비한국어 가사 작업 시 5단계 체크:
1. 음운 단위 확인 (모라/음절/강세) — 1음표 대응 단위?
2. 모음 개방도 × 음고 매칭 — 고음 구간에 닫힌 모음 회피
3. 화자 어미/어체 통일 — 그룹 혼용 시 화자 분열
4. 시점 일관성 — 섹션별 시간 라벨로 검증, Bridge가 시점 이탈 최고 위험
5. 문화권 표현 자연도 — 번역체 표현 회피

**일본어 음운 (Case 25, 26 정립):**
- 모라(拍) 기반 리듬: 1모라 = 1음표 대응. 장음(ー), 촉음(っ), 발음(ん)도 각 1모라
- 고음 구간: 개방 모음 あ(a), え(e), お(o) 권장. 닫힌 모음 い(i), う(u)는 중저음
- 의태어/의성어가 J-pop 고유 무기 (ぐしょぐしょ, ふわっ, きらきら)
- 어미가 캐릭터 정체성 결정. 혼용 시 화자 붕괴
- 받침 없음 → BPM 높아도 딕션 유지 쉬움. ん 연속은 비음 뭉침 회피


### A.9 화자 존재 — Action over Reflection (Case 40 학습)

**원칙**: 화자가 *호소하지 않되 몸으로 존재*해야 함.

```
❌ 화자 완전 증발 (정물화) → 공감 불가
❌ 화자 감정 호소 → "감정선 건드리는 건 리스너지 화자가 아님"
✅ 화자가 *행동/몸*으로 존재 (보는 눈 / 만지는 손 / "맨발" 한 단어)
```

"맨발" 한 단어로 곡이 살아난 사례 — 단어 1개의 신체 진입.
