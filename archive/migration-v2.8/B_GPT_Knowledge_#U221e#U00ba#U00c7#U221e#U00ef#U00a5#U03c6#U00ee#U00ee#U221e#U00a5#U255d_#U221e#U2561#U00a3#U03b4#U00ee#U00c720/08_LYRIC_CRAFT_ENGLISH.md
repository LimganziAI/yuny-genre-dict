## SECTION 1 — FOUNDATIONS

### 1.1 What lyrics are for

Lyrics carry *the message that melody cannot say in words*. Melody
shapes the emotion; lyrics name what the emotion is *about*. When
they work together, you have prosody (§1.5).

Before writing one line, answer five questions:
1. **What is being said?** (theme / central idea)
2. **Who is saying it?** (persona / speaker)
3. **To whom?** (listener)
4. **In what situation?** (scene)
5. **Why now?** (urgency)

Cannot answer five? Do not write line one.

### 1.2 The weight of one word

Good lyrics waste no words. Every syllable lands on a melody note —
*a wasted syllable is a wasted note.*

Check every word:
- Weak verb (is, was, has, get, do) → swap for stronger verb (§5)
- Empty adjective (beautiful, deep, eternal) → swap for concrete noun
  or verb (§6.4)
- Abstract noun (love, sadness, memory) → AID it (§4)
- Filler adverb (really, very, just, so) → cut if not adding meaning

### 1.3 Honesty and distance

Lyrics start in *yourself* but are not *your diary*.
- Too close (diary) → no room for listener to enter
- Too far (abstraction) → no emotional connection
- Optimal: *your truth* in language the *listener can claim as theirs*

Pattison: "Number one: who you are. Number two: craft."

### 1.4 Restraint vs redundancy

Pop and ballad rely on repetition, but repetition ≠ redundancy.

Cut redundancy:
- Saying the same thing twice ("hurt and pain") — pick one
- Synonym strings ("alone and lonely") — pick the stronger
- Adverb + adjective stacks ("really happy") — single stronger word

Repetition is intentional craft:
- Same line, *new context* (after bridge it means something different)
- Same line, *different vocal layering* (single → harmony stack)
- Same line, *escalating instrumentation* (sparse verse → full chorus)

### 1.5 Pat Pattison's Four Tools (NEW v3.0)

Berklee's Pat Pattison — author of *Writing Better Lyrics*, *The
Essential Guide to Rhyming*, *Songwriting Without Boundaries* —
codifies the universal craft tools every serious songwriter learns.
Suno-era writers especially need them: AI models trained on song
data already follow these patterns; conscious use beats accidental.

#### A. Prosody — Aristotle's "Unity"

Definition: *appropriate relationship between elements*. Melody,
harmony, rhythm, lyrics, and structure all *support the central
message*. When they don't, listener attention shifts from *what
you're saying* to *how you're saying it* — emotion deflates.

Practical implication for lyrics:
- Stressed syllables on stressed notes (§9 marriage)
- Stable form for stable message; unstable form for unstable message
- Don't fight the melody — let lyric phrase end when melody phrase
  ends (§9.3 marriage)

#### B. Stable / Unstable — the universal lens

Every craft decision sits on a stable-unstable spectrum:

| Domain | Stable | Unstable |
|---|---|---|
| Syllable count | Uniform per line | Varying |
| Line count per section | Even (2, 4) | Odd (3, 5) |
| Rhyme type | Perfect | Assonance / Consonance / X |
| Line endings | Consistent (cat/hat/sat) | Varied |
| Syntax | Complete sentences | Inversion / fragments |
| Tense | Consistent | Shifts |
| POV | First person locked | POV shifts |

Master principle: *stable message → stable devices / unstable message
→ unstable devices. The emotional arc of a song is the journey
between stability states.*

#### C. Verb Amplifier — verbs as power amp

"The difference between great writers and average writers is almost
always in their verbs." — Pattison

Verbs *drive* language. They set it in motion.

| Wattage | Category | English examples |
|---|---|---|
| 0 W | To-be verbs | is, was, will be, are, am |
| 10 W | Generic action | go, come, see, hear, take, get |
| 50 W | Sensory action | touch, taste, smell, feel, brush |
| 100 W | Physical action | jump, throw, slam, drop, run |
| 200 W | Transformative | break, melt, burn, swell, bloom |
| 500 W | Figurative | seep, awaken, caress, devour, haunt |
| 1000 W | Visceral | shatter, claw, gut, snap, plunder |

Rule: *match wattage to idea*. Too strong = blown speakers. Too weak
= no signal. Circle every verb in your draft. Rank them.

#### D. Object Writing — daily 10-minute sensory practice

Pick a random noun. Write 10 minutes on it using all 7 senses.
No editing, no metaphor pressure — just direct sensory description.

Sense list: sight / sound / smell / taste / touch / organic
(heartbeat, breath, nausea) / kinesthetic (body in space).

Output → raw material for lyrics later. Full protocol §7.

## SECTION 2 — STRUCTURE AND FORM

### 2.1 Standard pop structure

```
[Intro] (4-8 bars, often instrumental)
[Verse 1] (8-16 bars, tells the story)
[Pre-Chorus] (4-8 bars, builds toward chorus)
[Chorus] (8-16 bars, central message + title)
[Verse 2] (8-16 bars, advances the story)
[Pre-Chorus] (4-8 bars, build)
[Chorus] (8-16 bars)
[Bridge] (4-8 bars, contrast / new angle)
[Final Chorus] (8-16 bars, sometimes key-up)
[Outro] (4-8 bars, resolution or fade)
```

Variations: verse-pre-chorus pattern can drop pre on second pass.
Bridge can be replaced with [Instrumental Break] or [Dance Break]
in K-Pop / EDM.

### 2.2 Section function by lyric content

| Section | Function | Lyric content |
|---|---|---|
| Intro | Establish sonic world | Often instrumental, or single phrase |
| Verse | Tell the story | Specific scene, AID-heavy (§4), changing each pass |
| Pre-Chorus | Tension build | Rising imagery, increasing rhyme density |
| Chorus | Central message | Title, hook, repeated payoff, *general* |
| Bridge | Contrast | New angle, shifted POV, surprise |
| Final Chorus | Climax | Same hook, deeper context |
| Outro | Resolution | Echo of central theme, often instrumental fade |

### 2.3 Hook placement

Hooks live in:
- **Chorus** (main hook — title line)
- **Pre-Chorus** (setup hook)
- **Post-Chorus** (release hook, optional)
- **Instrumental hook** (riff, often paired with vocal hook)

Pop tradition: title in first or last line of chorus. Hook should be
*memorable within one listen* — 6-12 syllables, single image, one
verb-noun pair.

### 2.4 Repetition design

Pop relies on repetition — but not every chorus repetition is the
same. Three approaches:

**A. Identical repetition** — same lyric, same delivery
- Function: maximum hammer / brand the hook
- Risk: monotony if no other variation
- Mitigation: vary the *production* (sparse → full / single vocal →
  stacked harmony)

**B. Escalating variation** — same structure, escalating meaning
- Chorus 1: "I'll wait for you tonight"
- Chorus 2: "I'll wait for you forever"
- Final: "I'll wait for you 'til the world ends"
- Function: emotional arc within repetition
- *K-Pop industry standard*

**C. Position-altered repetition** — same lyric, different position
- Hook in verse, then in chorus — recontextualization
- Function: discovery / surprise

## SECTION 3 — RHYME (FULL 5-DEGREE HIERARCHY) — NEW v3.0

### 3.1 The 5 degrees of closure (Andrea Stolpe / Berklee)

Rhyme is not binary. It's a *5-step closure hierarchy*, and the
*degree of closure is itself the emotional device*.

#### A. Perfect Rhyme — strongest closure
- Same stressed vowel + same following consonants + different
  preceding consonants
- Examples: head/dead, fine/mine, night/light, song/long
- Effect: powerful, memorable, conclusive — *finality*
- Use: title lines, chorus closers, single-statement songs
- Risk: overuse → predictable / childish / sing-songy

#### B. Family Rhyme — strong closure
- Same vowel + closing consonants from *same family*
- Consonant families:
  - **Plosives**: p, b, t, d, k, g
  - **Fricatives**: f, v, s, z, sh, zh, th, dh, h
  - **Nasals**: m, n, ng
  - **Liquids**: l, r
  - **Glides**: y, w
- Examples: shame/grain (m → n, both nasals), made/save (d → v,
  both voiced), back/snap (k → p, both plosives)
- Effect: smooth, conversational — *gentle resolution*
- Use: verse interior, conversational pop

#### C. Additive / Subtractive Rhyme — mid closure
- **Additive**: same vowel + *adds* a consonant (stow/hope,
  year/feared, down/found)
- **Subtractive**: same vowel + *drops* a consonant (bake/stay,
  shout/now, roll/know)
- Effect:
  - Additive (short → long): light progression, stable
  - Subtractive (long → short): subtle tension, less stable
- Use: verse-to-pre-chorus transitions

#### D. Assonance Rhyme — weak closure
- Same stressed vowel only / different ending consonant families
- Examples: rope/known (long o + p/n, different families),
  tide/life, straight/fame, still/grip
- Effect: less resolved, modern, opens thousands of word pairs
- Use: modern pop / indie / R&B / hip-hop verses

#### E. Consonance Rhyme — weakest closure
- Different vowels + same ending consonant
- Examples: friend/wind, one/gone, hot/foot, scene/when
- Effect: weakest sonic match, maximum freedom, poetic
- Use: bridge endings, outro fades, intentional surprise

### 3.2 Rhyme as emotional device

Each rhyme type *creates a different feeling*:

| Rhyme | Emotional effect | Best section |
|---|---|---|
| Perfect | Finality, certainty, hammer | Chorus close, title line |
| Family | Warmth, conversation, gentle close | Chorus interior, stable verse |
| Additive | Light forward motion | Verse → pre-chorus |
| Subtractive | Subtle instability | Pre-chorus, bridge entry |
| Assonance | Lingering, modern, unresolved | Verse, contemporary chorus |
| Consonance | Poetic, soft, minimal | Bridge, outro |
| **X (no rhyme)** | *Space, surprise, contrast* | Intentional silence |

### 3.3 Rhyme as Stable/Unstable Tool (NEW v3.0)

Plan rhyme as part of the song's stability arc:

```
Verse 1: mid closure (assonance/family) — invite, don't conclude
   ↓
Pre-Chorus: closure ramping up (additive → family) — building
   ↓
Chorus: strongest closure (perfect / family) — *memory and resolution*
   ↓
Verse 2: same rhyme texture as Verse 1, slight intensification
   ↓
Pre-Chorus: closure ramping ↑↑
   ↓
Chorus: strongest closure
   ↓
Bridge: weakened closure (consonance / X) — *contrast and surprise*
   ↓
Final Chorus: closure maxed + key-up
   ↓
Outro: closure relaxes (family → assonance) — lingering
```

### 3.4 The X line — no rhyme as choice

"X" lines (no rhyme) create:
- Space
- Surprise
- Emotional contrast against rhyming lines

X is not laziness — it's *strategic*. Common patterns:
- AAXA (one X in a 4-line stanza)
- ABCB (lines 1 and 3 don't rhyme — common pop)
- Verse free, chorus rhymed (verse holds attention through imagery,
  chorus through rhyme)

### 3.5 Internal rhyme

Rhymes *inside* a line, not just at endings:

> "I made my way **down**, found the **sound** that meant **how**"

Use for:
- Density / virtuosity (hip-hop)
- Hook reinforcement
- Forward propulsion in verse

Avoid:
- Over-density that obscures meaning
- Forced internal rhyme that hurts prosody

### 3.6 Forced-rhyme gate

Before any rhyme commits, check:
1. Does this rhyme strengthen the line's *meaning*?
2. Is this rhyme word something you'd *naturally* say?
3. Is this a *cliché pair* (§6.3)?
4. Is the line *built around the rhyme word* rather than meaning?

3+ YES → reconsider. An X line is legitimate.

## SECTION 4 — SHOW DON'T TELL + AID (NEW v3.0)

### 4.1 Show vs Tell — the central craft

Telling states the emotion:
> "I'm sad and lonely without you"

Showing creates the experience:
> "The empty chair at the table, the quiet of the room"

Showing wins because:
- Listener *enters* the song (visual / sensory)
- Multiple interpretations possible — broader resonance
- Concrete details are memorable — abstract emotions are not
- *Modern pop / Suno-era lyric demands this*

### 4.2 AID formula (Jason Blume / BMI)

Action / Imagery / Detail — the cleanest Show-Don't-Tell breakdown.

#### A. Action — verbs that show what's happening
Instead of *telling* an emotion, show what a person *does* when they
feel it.

| Emotion | Tell | Show (Action) |
|---|---|---|
| Anxious | "I'm so anxious" | "I keep checking my phone" |
| Heartbroken | "My heart is broken" | "I left the second cup of coffee untouched" |
| Excited | "I'm so excited" | "I can't sit still in this chair" |
| Angry | "I'm so angry" | "I'm pacing in the kitchen" |

#### I. Imagery — sensory details
Engage the 5 senses (+ organic + kinesthetic, §7):

| Sense | Example lyric |
|---|---|
| Sight | "Streetlight catching on the wet pavement" |
| Sound | "The kettle whistling like it's afraid of the dark" |
| Smell | "Your sweater still smells like rain" |
| Taste | "Salt on my lips, didn't know I was crying" |
| Touch | "Cold marble counter, glass dripping with sweat" |

#### D. Detail — concrete specificity
Tangible items, places, brands, named objects:

| Generic | Detailed |
|---|---|
| "He laid flowers on the grave" | "He laid *white lilies from her garden* on the grave" |
| "I drank coffee" | "I drank coffee from the chipped blue mug" |
| "She walked to school" | "She walked the four blocks past the gas station" |

### 4.3 AID by section

- **Verse**: Maximum AID — this is where story / scene lives
- **Pre-Chorus**: A + I (Action + Imagery), less Detail
- **Chorus**: I mainly (Imagery) — general / summary / hammer territory
- **Bridge**: A + I + D revived — twist / new angle / re-engagement

### 4.4 Show vs Tell exceptions

Some songs *win on telling*. Use when:
- The bare statement is so unusual it becomes the hook
  - "I will always love you"
  - "I want it that way"
- Country / blues / soul traditions value direct emotional statement
- The song *is the statement*

But default = Show. Tell only when you've earned it.

### 4.5 Multi-sensory rule

A single sense = ok. Two senses = strong. Three+ in one verse =
immersive.

Strong line example:
> "Cold concrete under my back, smell of rain still in the air,
> the streetlight buzzing"

(touch + smell + sound — 3 senses, 1 scene)

### 4.6 Specificity sells

Specific beats general — every time.

| General | Specific |
|---|---|
| "morning routines" | "the smell of coffee at 6 AM" |
| "we drove around" | "we drove the loop on Sunset til 3 AM" |
| "she wore a dress" | "she wore the blue dress with the broken zipper" |
| "a busy street" | "Houston at rush hour" |
| "feeling alone" | "phone face-down on the kitchen counter" |

Specifics create *believability*. A listener thinks: *I've been
there. This is real.*

## SECTION 5 — VERB WATTAGE AUDIT (NEW v3.0)

### 5.1 The audit procedure

After a draft is written:

**Step 1: Circle every verb.** Include all verb forms (gerunds,
participles, infinitives).

**Step 2: Rank by wattage.** Use §1.5.C scale.

**Step 3: Count weak verbs.** Anything 0-10W. If >30% of total verbs
are weak → rewrite.

**Step 4: Match wattage to idea.** Strong idea + weak verb = mismatch.
Weak idea + 1000W verb = melodrama.

**Step 5: Replace weak verbs.** §5.2 substitution menu.

### 5.2 Common verb upgrades

| Weak (0-10W) | Better (50-200W) | Strongest (500-1000W) |
|---|---|---|
| is sad | aches, weighs heavy | hollows, devours |
| has a thought | wonders, considers | grapples, wrestles |
| says | whispers, mutters | spits, hisses |
| walks | strides, drifts | prowls, lurches |
| looks at | studies, watches | scrutinizes, dissects |
| feels cold | shivers, trembles | quakes, convulses |
| is happy | grins, beams | erupts, blazes |
| moves | shifts, sways | swerves, careens |
| sees | spots, notices | catches, registers |
| is angry | bristles, fumes | seethes, rages |

### 5.3 The "to-be" trap

`is / was / are / were / am / be / been / being / will be / has been`
— all 0W. These verbs are connective tissue. They are not where
emotion lives.

Strategy:
- Replace where possible with action
- Keep in declarative title lines if needed ("I am the storm")
- Cut filler "is" constructions ("There is a feeling that..." → cut)

### 5.4 The "do/have/get" trap

Generic helpers carry no signal:
- "I get tired" → "Sleep won't come" / "My eyes burn"
- "I have a feeling" → "Something hums in my chest"
- "I do this every day" → "I run this same route at sunrise"

### 5.5 Wattage by section

Rough guide:
- Verse: 50-200W (action / sensory / physical)
- Pre-Chorus: 100-200W (transformative / building)
- Chorus: 100-500W (figurative / memorable)
- Bridge: 200-1000W (visceral / shifted)

Avoid 0-10W in chorus unless it's a deliberate *quiet* statement.

## SECTION 6 — AI LYRIC ANTI-PATTERNS (NEW v3.0)

### 6.1 Why this matters

AI lyric tools (ChatGPT, Claude, others) trained on song data
default to the *statistically dominant* lyric patterns. These
patterns are exactly the *clichés* that make lyrics feel generic
and AI-written. Suno field guide §13 documents these failures
across thousands of generations.

Human writers fall into the same traps when reaching for the
obvious. The guard below applies to *all* English lyric writing,
not just AI-assisted.

### 6.2 Banned nouns (25)

Use **sparingly** or replace:

```
crown, throne, kingdom, neon, halo, wings, angels, ghost(s),
chains, shackles, ashes, embers, flames, void, abyss, maze,
armor, sword, canvas, storm, mirror, demons, echoes, ruins,
shadows, silence
```

Why banned: overused symbols that feel cosmic / fantasy-novel /
emotionally inflated. Most usages are *abstract* (= telling).

Replacement strategy: concrete, mundane, specific.
- "crown" → "Costco beanie" / "headache" / nothing
- "ashes" → "cigarette tray" / "Sunday morning"
- "demons" → "the bills on the counter" / "the third drink"
- "shadows" → "Tuesday afternoon" / "the underside of the freeway"

### 6.3 Banned phrases / clichés (16)

Hard-ban:

```
"ghost in the machine"
"rise from the ashes"
"broken wings"
"dance with the devil"
"weight of the world"
"heart of gold"
"lost in the dark"
"find the light"
"walls come crashing down"
"demons inside"
"fire and ice"
"written in the stars"
"against all odds"
"eye of the storm"
"chasing dreams"
"through the fire"
```

These are *signal phrases* — the listener immediately knows they
came from a template. Cut entirely.

### 6.4 Banned lazy rhyme pairs (10)

Cliché rhyme pairs every listener has heard 10,000 times:

```
fire / desire
heart / apart / start
night / light / fight / sight
pain / rain / vain
soul / whole / control
time / mind / blind
breath / death
tears / fears / years
burn / turn / learn
fall / all / wall
```

When you find yourself reaching for one of these:
1. Check if the line *needs* that rhyme word
2. Try assonance / consonance / X instead
3. Look up *family rhymes* or *additive/subtractive* alternatives
4. Restructure the line to put the rhyme elsewhere

### 6.5 Adjective crutches (10)

Empty modifiers that add no information:

```
endless, eternal, hollow, broken, shattered, fading, crimson,
golden, empty, frozen
```

Why bad: they signal emotion *without showing*. Replace with
sensory detail or stronger noun.

| Crutch | Replacement strategy |
|---|---|
| "endless love" | Show duration with detail: "still calling at 4 AM" |
| "broken heart" | Action: "I can't make the bed anymore" |
| "frozen in time" | Specific image: "Polaroid on the fridge" |
| "shattered dreams" | Concrete: "the gym I never opened" |

### 6.6 Empty intensifiers

Cut by default:
- really, very, truly, totally, completely, absolutely, deeply,
  forever, always, never, only

These weaken because they signal *I don't trust the verb / noun to
carry weight*. Strengthen the verb or noun instead.

### 6.7 The "you" trap

English pop overuses "you" — every line addressed to a love interest.
Variety pulls:
- Address yourself
- Address a memory
- Address a place
- Address an object
- No address — describe the scene from outside

### 6.8 Human-sounding lyric signals

Inverse of anti-patterns — what makes lyrics feel lived-in:

- **Concrete sensory imagery**: "cold wind through an open door"
- **Subtle motion verbs**: linger, drift, shift, slip, pull, settle,
  press, brush, ease
- **Temporal/spatial specificity**: "3 AM kitchen light"
- **Earned complexity**: competing emotions in tension
- **Imperfect moments**: small unglamorous detail
- **Subverted expectations**: cliché setup, pivot away
- **Rhythmic variation**: line lengths vary

### 6.9 The cliché-pivot move

When a cliché is the natural reach, set it up — then break it:

> "They said the heart of gold —
> mine's just nicotine and chrome"

Setup the cliché ("heart of gold"), then *replace* with concrete /
specific. The listener feels the surprise.

## SECTION 7 — OBJECT WRITING FOR ENGLISH (NEW v3.0)

### 7.1 The protocol

Pattison's daily practice:

1. Pick a random noun (open a book, point to a word)
2. Set a timer — 10 minutes
3. Write *without editing* using the 7 senses
4. Don't force metaphor — *direct sensory description only*
5. After timer: 5-minute pause
6. Re-read and mark the strongest images
7. Save for later use as raw lyric material

### 7.2 The 7 senses

1. **Sight** — colors, shapes, light, shadow, movement
2. **Sound** — noise, silence, tone, rhythm, echo
3. **Smell** — scent, decay, freshness, smoke, food
4. **Taste** — sweet, salt, bitter, sour, umami, metal
5. **Touch** — temperature, texture, pressure, wet/dry
6. **Organic** — heartbeat, breath, stomach, dizziness, nausea
7. **Kinesthetic** — body in space, balance, motion, reach

Most beginners use sight only. The exercise *forces* the other 6.

### 7.3 Example session

Random noun: **bus stop**

- Sight: A streetlamp throws yellow across the plastic bench, the
  schedule curling at the corner from rain
- Sound: A bus engine three blocks away, the click of someone
  unwrapping gum
- Smell: Wet asphalt, cigarette ash on the curb, somebody's
  laundry detergent on the air
- Taste: Cold coffee bottom, morning mouth, the metal of the
  bench rail
- Touch: Bench cold through jeans, schedule paper soft from damp
- Organic: Stomach hollow — didn't eat, breath visible in the cold
- Kinesthetic: Stepping forward when the bus rounds the corner,
  hand out, weight shifting

### 7.4 Object Writing → lyric pipeline

After a week of daily object writing:
1. Collect strongest images from each session
2. Build a noun bank, verb bank, image bank
3. For next song: pull from banks rather than reaching for clichés
4. Specific images you've already written = ready-made lyric material

This is the *Scene Dossier* method (17 §10) at the raw-input stage.

### 7.5 Random noun list (for quick starts)

```

overhead light / drawer / freeway / cigarette / phone screen /
mailbox / fridge / hospital waiting room / library / borrowed car /
empty house / station wagon / kitchen sink / motel sign / payphone
```

K-Pop / urban contexts:
```

카페 창가 / PC방 / 한밤 다리 / 노래방

## SECTION 8 — GENRE NARRATIVITY PROFILES (NEW v3.0)

### 8.1 Academic finding

Berkeley + ACM 2024 studies analyzed 12,280 songs across 6 genres
for narrative structure. Result: *significant genre differences in
narrativity rate*.

### 8.2 Genre narrativity ranking (highest → lowest)

| Genre | Narrativity | Implication |
|---|---|---|
| **Hip-Hop / Rap** | Highest | Detailed scene, multiple characters, plot |
| **Country** | Very high | Specific time/place, Grammy nominees *more* narrative |
| **Rock** | Increasing | Often narrative protagonist, conflict |
| **Pop** | Moderate, *faster plot* | Quicker emotional payoffs, less stage-setting |
| **R&B / Soul** | Lower | More mood/atmosphere than narrative |
| **EDM / Dance** | Lowest | Often anthem rather than story |

### 8.3 Implications for writing

#### Hip-Hop / Rap
- Detailed scene-setting OK (verse can run 16+ bars)
- Multiple characters, specific names
- Action verbs dense, internal rhyme dense
- Temporal markers: "back in '08," "last Tuesday"

#### Country
- Strong specific place ("Houston," "the river road")
- Conventional gender narratives in tradition (see §8.4)
- Concrete objects: trucks, dogs, bottles, porches
- Linear story, often chronological

#### Rock
- Internal conflict / external struggle
- Building intensity matches lyric escalation
- Strong verbs, declarative statements

#### Pop
- *Get to the hook fast* — 30-45 sec
- Plot moves quickly; less stage-setting
- Emotional state changes within song
- Hook bears most of the meaning

#### R&B / Soul
- Mood over plot
- Sensory imagery > narrative sequence
- Internal monologue often
- Sustained emotional state

#### EDM / Dance
- Hook-based, often single-emotion
- Repetition is feature, not bug
- Build / drop / release structure mirrors emotional arc
- Few words, maximum impact

### 8.4 Genre conventions to know

#### Country gender patterns
1990-2021 Billboard country: predominantly male narrator. Lyrics
*observe* female subjects ("she fell in love," "she came in
looking good"). Not necessarily a rule — but listeners expect it.

#### Hip-hop narrative voice
First-person dominant. Often autobiographical or persona-based.
Place specificity (city, neighborhood) signals authenticity.

#### Indie folk
First-person, introspective, often nature imagery. Specific
mundane detail (cabin, kitchen, particular flower).

#### K-Pop English-hook
See §9 — separate craft for K-Pop's English chorus tradition.

### 8.5 Narrative signal vocabulary

Words that *signal* narrative mode (from academic research):

- Action verbs: said, planned, stole, made, took, kept, threw
- Temporal markers: tonight, yesterday, evening, tomorrow, last week
- Place: downtown, hall, town, mall, street, train, city, lot,
  bridge, station
- Things: coffee, wine, keys, ring, phone, light, door, glass

Use these *intentionally* to dial up narrativity. Cut them to dial
toward mood / atmosphere.

## SECTION 9 — LYRIC-MELODY MARRIAGE (Pattison Inviolable)

### 9.1 The principle

"Lyric phrase ends when melody phrase ends." — Pattison

Phrase boundaries must align. *Enjambment* (a lyric phrase running
across melodic boundaries) is the exception, not the rule. When the
melody phrase ends and the lyric phrase doesn't — listener feels
the *fight*.

### 9.2 Order of operations

#### Lyric first
- Find the *meter* of your lyric (stressed/unstressed pattern)
- Write melody to match that meter exactly
- Don't change the melody to fit syllables — change the syllables

#### Melody first
- Mark melody phrases — where they breathe
- Count syllables / mark stresses
- Write lyric to land *exactly* on melody phrase endings
- Stressed melody notes get stressed lyric syllables

#### Simultaneous
- Work in 4-bar or 8-bar phrases
- Match phrase by phrase
- Match emotional contour (melody rises, lyric intensifies)

### 9.3 Stressed-syllable matching

English is stress-timed. *Word stress matters.*

- "bridegroom" (BRIDE-groom) — strong-weak
- "come back" (come BACK) — weak-strong
- "tomorrow" (to-MOR-row) — weak-strong-weak

Place these on the matching melodic positions. A strong-weak word
on weak-strong notes = misprosody → listener pulled out.

In a 4/4 bar: beat 1 = strongest, beat 3 = next, beats 2 and 4 =
weaker. Place stressed syllables on beats 1 and 3 by default.

### 9.4 Syllable count guides (BPM-aware)

| BPM | Syllables per line | Notes |
|---|---|---|
| 60-80 | 6-9 | Ballad, room to breathe |
| 80-100 | 7-10 | Midtempo |
| 100-120 | 7-11 | Pop / midtempo |
| 120-140 | 6-10 | Dance pop, K-pop main |
| 140-160 | 5-9 | Uptempo dance, hyperpop |
| 160-180 | 4-8 | Punk, drill, hardcore |
| 180+ | 3-7 | Extreme tempos |

These are *guides*, not rules. Sweet spot for most pop: **6-12
syllables per line** (Suno field guide tested).

### 9.5 Singability check

Before commit:
- Read line aloud *at song tempo*
- Clap the syllables
- Check for breath points
- Check for vowel sounds that sing well (long vowels on long notes)

Suno-specific:
- Avoid consonant clusters on held notes ("strength" — sustained
  note swallows the cluster)
- Avoid plosive endings on quiet phrases (p, t, k can pop the mic)
- Long vowels (ah, oh, ee, oo) sing best on sustained notes

## SECTION 10 — HOOK CRAFT

### 10.1 What makes a hook

A hook is the *line / phrase / melodic figure* the listener
remembers after one listen. Pop industry standard: hook in every
song.

Hook characteristics:
- 6-12 syllables (sweet spot for memorability)
- Single image or single statement
- Strong verb + concrete noun OR memorable declarative
- *Title appears in or as the hook* (industry tradition)
- Position: first or last line of chorus

### 10.2 Hook types

#### A. Statement hook
> "I will always love you"
> "I want it that way"
Direct emotional declaration. Risky — must be unusual phrasing or
unusual context.

#### B. Image hook
> "I see fire inside the mountain"
> "Diamonds in the soles of her shoes"
Concrete sensory image — listener carries the picture.

#### C. Action hook
> "Shake it off"
> "Roll up your sleeves"
Verb-driven, instructive or self-directive.

#### D. Question hook
> "How will I know?"
> "Where do broken hearts go?"
Listener leans in to find the answer.

#### E. Wordplay hook
> "I'm a creep"
> "Dancing on my own"
Twist of expectation.

#### F. Onomatopoeic / Vocalization hook
> "Na-na-na-na"
> "Ooh-la-la"
Non-lexical, melody-carried.

### 10.3 Title placement

- **Top of chorus**: title as opener / declarative
- **End of chorus**: title as landing / payoff
- **Middle**: less common, used in country / soul
- **Verse**: title as theme statement, expanded in chorus
- **Bridge**: title recontextualized

### 10.4 Hook density

Pop: hook should be heard at least 3 times per song. Often:
- Chorus = hook 2x per chorus, 3 choruses = 6 hooks
- Pre-chorus may have second hook
- Post-chorus may have third (vocal chops, etc.)

EDM: drop replaces traditional chorus; hook is melodic, not lyrical
necessarily.

## SECTION 11 — META-PATTERNS

### 11.1 One-metaphor rule (Pattison)

Pick *one* central metaphor and explore all its facets.

Bad (metaphor switching):
> Verse 1: water (ocean, drowning, tide)
> Verse 2: fire (burning, ashes)
> Chorus: stars (constellation, light)

Good (single metaphor, deep):
> Verse 1: water (ocean, drowning)
> Verse 2: water (tide pulling back, leaving shells)
> Chorus: water (waves, salt, washing clean)
> Bridge: water (drought, dry riverbed)

Album-level: each song its own metaphor. Variety lives in the
collection.

### 11.2 Emotional arc

A song moves through emotional states. Plan the arc:

```
Verse 1: setup state (where things begin)
   ↓
Pre-Chorus: tension rising
   ↓
Chorus: peak emotional statement
   ↓
Verse 2: state evolves / deepens
   ↓
Chorus: same statement, new context
   ↓
Bridge: shift / surprise / reversal
   ↓
Final Chorus: same statement, transformed meaning
   ↓
Outro: resolution or unresolved drift
```

### 11.3 POV (Point of View)

- **First person ("I")**: intimate, default modern pop
- **Second person ("you")**: addressed, direct
- **First person to second ("I → you")**: relationship songs
- **Third person ("he / she / they")**: narrative, story songs,
  country
- **POV shift mid-song**: powerful when intentional (Bridge often)

### 11.4 Tense

- **Present**: immediate, urgent ("I'm walking down the street")
- **Past**: nostalgia, memory, story ("I walked down the street")
- **Future**: anticipation, threat, promise ("I'll walk down...")
- **Mixed**: complex emotional layering

Tense changes signal shifts in time / state — use intentionally.

## SECTION 13 — K-POP ENGLISH-HOOK COLLABORATION (NEW v3.0)

### 13.1 Why this section

The operator works in bilingual K-Pop. K-Pop industry standard puts
the *hook in English* — even when the rest is Korean. English
lyricists need craft specific to:
- Writing English that sits inside Korean melody
- Persona matching for K-Pop archetypes
- Konglish integration

### 13.2 English-hook constraints

K-Pop English hooks are *constrained* compared to English-language
pop hooks:

- **Pronunciation accessibility**: Korean singers may have accent.
  Avoid words with difficult vowel transitions for Korean speakers
  (e.g., short "i" vs long "ee" — easy to slip)
- **Cultural translation**: avoid English idiom that doesn't survive
  cross-cultural listening (avoid sports metaphors, specific Western
  references)
- **Universal emotion**: K-Pop hooks reach global audiences — emotion
  must be *legibly universal*
- **Repeatability**: hook must work as chant — concert sing-along

### 13.3 Persona-first (from §13 in 07_LYRIC_CRAFT_KOREAN.md)

Before writing the hook, know the persona:

| Persona | English hook vocabulary |
|---|---|
| Cute | Soft consonants, light vowels, repetition (TT TT) |
| Girl Crush | Strong verbs, command form, declarative |
| Dark | Minor-mode imagery, ambiguity, restraint |
| Boyish | Self-affirming, casual, slang OK |
| Retro | 80s/90s vocabulary, polite tone |
| Futuristic | Abstract, tech-adjacent, repetition |
| Antihero | Anti-statement, ironic, casual |
| Shy Romantic | Indirect address, gentle, questioning |
| Troublemaker | Playful destruction, hyperbole, fun |

### 13.4 Konglish integration

Konglish ≠ "English words in Korean song." Konglish = *English
words that fit Korean melodic rhythm as natural syllable units*.

Strong Konglish:
- 1-2 syllable English words (baby, love, mine, dream, run)
- Konglish phrases that have entered Korean: "fighting," "OK"
- Simple grammar — short clauses

Weak Konglish:
- Multisyllabic English ("constellation," "monumental")
- Complex grammar — relative clauses, complex tenses
- Unusual English idioms — listener won't catch

### 13.5 Syllable density matching

Korean has *more syllables per meaning*. English needs to *match
the syllable count* of the Korean melody.

Process:
1. Get Korean topline syllable count (e.g., chorus line = 11 syllables)
2. Write English hook to match (11 syllables, not 6)
3. Korean writers fill in verses around the English hook

Example:
- Korean chorus syllable count: 11 per line
- English hook fitting 11 syllables: "Tell me are you ready for the
  drop tonight" (11 syllables) ✓
- English hook fitting 11 syllables: "I love you" (3 syllables) ✗
  (won't fill the melody)

### 13.6 Industry workflow

Typical K-Pop song:
1. Producer makes track
2. Topliner (Korean or Western) writes English topline with melody
3. Korean lyricist adapts English to Korean verses, keeps English hook
4. Both credited via KOMCA (Korean) and equivalent (Western)

YUNY operating mode: serve as bilingual co-writer. Generate both
the English hook *and* propose Korean adaptation, then refine
based on operator feedback.

## §UE-15. 영어 음운 시스템 (Suno 직격)

### §UE-15.1 영어 = Stress-Timed Language

```
영어는 강세 박자 (stress-timed):
- 강세 음절 간격이 비슷 (시간)
- 약음절은 빠르게 흐름

한국어와 차이:
- 한국어 (syllable-timed): 모든 음절이 동일 시간
- 영어 (stress-timed): 강세 음절만 시간 정렬

Suno 처방:
- 영어 가사는 강세 음절 *비트에 맞춤*
- 약음절 (the/a/of/to) 자유롭게 흐름
- 1바에 10-12 syllable 가능 (한국어 6-8보다 많음)
```

### §UE-15.2 영어 강세 시스템

```
영어 강세 (stress) 위계:
1. Primary stress (´) — 강한 강세
2. Secondary stress (`) — 약한 강세
3. Unstressed — 무강세

처방:
- Hook 자리 1음절 단어 (강세 명확): love / heart / fire / night
- Verse 자리 2-3음절 단어 (운율 다양): forever / always / never
- 강세 자리 *비트 1박* 정렬
```

### §UE-15.3 영어 모음 발음 (Suno 함정)

```
영어 단모음 → 한국어 화자 발음 함정:

함정 1: 단모음 vs 장모음:
- "ship" [ʃɪp] vs "sheep" [ʃiːp]
- "bit" [bɪt] vs "beat" [biːt]
- 한국어 화자 → ㅣ로 통합 (Suno 발음 무너짐)

함정 2: 자음 cluster:
- "strength" [strɛŋkθ] — 4 consonant cluster
- "spring" / "scream" — 3 consonant cluster
- 한국어 화자 → 모음 삽입 (스트렝트)

함정 3: 받침 처리:
- 영어는 final consonant 강하게 발음 (released)
- 한국어 화자 → unreleased 받침 처리
- "cat" → 한국어 화자 [캐ㅌ] (받침처럼)

Suno 처방:
- 영어 hook 자리 단순한 단어 (1-2 syllable)
- 자음 cluster 피하기
- [Vocal: native-like English pronunciation on hooks]
```


## §UE-16. 영어 가사 라임 시스템 풀바디

### §UE-16.1 5-Level Rhyme Hierarchy (Pat Pattison / Berklee)

```
Level 1 — Perfect Rhyme (완벽 라임):
- 동일 강세 모음 + 동일 끝자음
- love / above / dove
- night / light / bright
- 효과: closed / resolved

Level 2 — Family Rhyme (가족 라임):
- 동일 모음 + 비슷한 자음군
- voiced/unvoiced 자음: bag/back, hand/hand
- nasal: rain/rang, time/dime
- 효과: 닫히는 듯 열린

Level 3 — Additive-Subtractive (추가-감소):
- 모음 동일 + 자음 추가/감소
- mine / mind (+d)
- play / plays (+s)
- 효과: 흐름 OK

Level 4 — Assonance (모음운):
- 같은 모음, 다른 자음
- light / mine (i)
- bone / road (o)
- 효과: 열린 / 진행감

Level 5 — Consonance (자음운):
- 같은 자음, 다른 모음
- summer / never (r)
- mother / under (r)
- 효과: 가장 열린 / 미완

원칙 (Pattison):
- Verse 자리: Level 3-5 (열린 — 진행감)
- Pre-Chorus: Level 2-3 (build-up)
- Chorus 자리: Level 1-2 (closed — 메모러블)
- Bridge: Level 4-5 (열린 — 대비)
```

### §UE-16.2 Stable / Unstable Tool (Pattison)

```
Stable rhyme (안정):
- Level 1-2 Perfect / Family
- Closing function — 끝남 / 정리

Unstable rhyme (불안정):
- Level 3-5 Additive / Assonance / Consonance
- Opening function — 진행 / 확장

용법:
- Verse 후반 라인 → Unstable (다음으로 진행)
- Chorus 끝 라인 → Stable (메모러블)
- Bridge 라인 → Unstable (긴장)
- Final Chorus 끝 → Stable (해결)
```

### §UE-17.3 Hip-Hop / Rap 어법

## §UE-27. 5-Level Rhyme Hierarchy 실전 풀바디 (영문)

기존 §3이 *학술 정의*. §UE-27는 *영문 실전 풀*.

### §UE-27.1 Perfect Rhyme 실전 풀

**Pattison 정의:** Same vowel + same following consonants + different preceding

**영문 풀:**
```
night / light / fight / right / sight / bright / flight / kite
song / long / wrong / strong / belong / among / hung
heart / start / part / smart / apart / chart / depart
mine / fine / line / time (X — different vowel) / shine / decline
dream / scheme / cream / team / stream / extreme
love / above / dove / shove / glove
soul / whole / hole / role / stroll / control
fire / desire / wire / inspire / require
```

**사용 자리:**
- Title 라인 (강한 닫기)
- Chorus 마지막 라인
- 단일 statement 곡

**위험:** Overuse → predictable / nursery rhyme

### §UE-27.2 Family Rhyme 실전 풀

**자음 family 매칭:**
- Nasals: m / n / ng
- Stops: p / t / k / b / d / g
- Fricatives: f / v / s / z / sh / th
- Liquids: l / r

**영문 풀:**
```
nasal family:
"sun / song / one / wrong / done"
"home / alone / phone / known"

stop family:
"dark / spark / mark / heart"
"hope / soap / dope / scope"

fricative family:
"miss / kiss / bliss / promise"
"hush / brush / rush / blush"

liquid family:
"hold / cold / told / sold"
"hair / care / pair / despair"
```

**사용 자리:**
- Verse 안 (Setup, 약한 closure)
- Pre-chorus (build-up)

### §UE-27.3 Additive / Subtractive 실전 풀

```
Additive (자음 추가):
night / nights (s)
day / days (s)
hold / holds (s)
sun / sunk (k)
dream / dreamt (t)

Subtractive (자음 제거):
nights / night (s 제거)
days / day
holds / hold
```

### §UE-27.4 Assonance (모음 매칭) 실전 풀

```
"i" 모음:
night / time / mind / find / line / nine / right / kite

"o" 모음:
hope / coat / soap / boat / smoke / over

"ea" 모음:
green / dream / sleep / sheen / leave / believe

"o (open)" 모음:
song / strong / on / dawn / gone / wrong
```

**사용 자리:**
- Verse setup (의도적 open)
- Bridge 새로움 자리

### §UE-27.5 Consonance (자음 매칭) 실전 풀

```
"t" 자음 끝:
night / belt / heart / start / part / about

"p" 자음 끝:
hope / heap / hump / hip / weep / sleep

"ng" 자음 끝:
strong / string / sprung / song / wrong / belong
```

**사용 자리:**
- 가장 열린 closure
- 시적 / 의도적 미해결
- 모던 인디 어법

### §UE-27.6 5-Level 결합 어법 (실전 곡 분석)

**예 — Modern Pop Verse-Pre-Chorus:**

```
[Verse 1]
"I keep walking down this empty street      (assonance: street/me)
 Wondering if you'd ever come back to me     (assonance: me/sleep)
 I can't get a moment's sleep                (consonance: sleep/keep)
 But you keep running through my heart"      (perfect: heart/start
                                              with pre)

[Pre-Chorus]
"But every time I try to start                (perfect with verse)
 You break my fragile little heart            (perfect: start/heart)
 So I will keep my distance from you now"    (family: now/down)

[Chorus]
"I'm holding on, I'm letting go              (perfect: go/know)
 I'm finding out what I don't know            (perfect)
 I'm holding on, I'm setting free             (assonance: free/me)
 The version of myself you'll never see"      (perfect: see/free)
```

**구조 분석:**
- Verse: 약한 closure (assonance / consonance) → 미해결
- Pre-Chorus: 점차 강해짐 (family → perfect) → 빌드업
- Chorus: 최강 closure (perfect throughout) → 페이오프


## §UE-28. 일본어 가사 작법 기초

### §UE-28.1 일본어 어법 특성

**Mora Timing System:**
- 일본어는 *syllable이 아닌 mora*로 카운트
- "Tokyo" = 4 morae (To-kyo-o)
- "Sakana" = 3 morae (Sa-ka-na)
- *모든 mora가 동일 시간*

**시간 분배:**
- 일본어 1 mora ≈ 한국어 1 음절 ≈ 영어 0.7 syllable

**음절 → 음표 자리:**
- 일본어 mora 수 → 음표 수 *직결*
- "Sakura ga" (4 morae) → 4 음표 자리

**Pitch Accent:**
- 일본어는 *높낮이 강세*
- "Hashi" (橋 = 다리) vs "Hashi" (箸 = 젓가락) — pitch만 다름
- *팝송에선 큰 영향 X*, 자연스러운 delivery 위해 알면 좋음

## §UE-30. 다언어 라임 매칭 어법

### §UE-30.1 한영 라임 매칭

**원칙:**
- 한국어 음절 vs 영어 syllable *시간 비율*
- 한국어 받침 vs 영어 ending consonant 매칭

**예시 — Verse 한국어 / Chorus 영어:**

```
[Verse - Korean]
첫째 줄 (음절 7-9)
둘째 줄 (음절 7-9, 받침 family 매칭)

[Chorus - English]
First line (syllable 10-12)
Second line (syllable 10-12, ending consonant family 매칭)

라임 매칭:
한국어 "사랑" (라임) ↔ 영어 "young" (라임) — nasal family
한국어 "마음" (음운) ↔ 영어 "moon" (음운) — m start + nasal end
한국어 "비" (단음) ↔ 영어 "be" (단음) — 모음 매칭
```

### §UE-30.2 일영 라임 매칭

**원칙:**
- 일본어 모라 vs 영어 syllable
- 일본어 vowel ending vs 영어 ending

**예시:**
```
[Verse - Japanese]
"夏の風が吹く" (Natsu no kaze ga fuku) — 7 morae
"君の名前は" (Kimi no namae wa) — 7 morae

[Chorus - English]
"Summer breeze is blowing" — 7 syllables
"Calling out your name" — 5 syllables

라임 매칭:
일본어 "kaze" 끝 e-vowel ↔ 영어 "breeze" 끝 ee-vowel
일본어 "namae" 끝 e-vowel ↔ 영어 "name" 끝 ame-vowel
```

### §UE-30.3 스영 라임 매칭

**원칙:**
- 스페인어 vowel-rich ↔ 영어 syllable
- 스페인어 -ar/-er/-ir endings ↔ 영어 ending

**예시:**
```
[Verse - Spanish]
"Quiero bailar contigo" (4-3-3 syllables)

[Chorus - English]
"Dance with me tonight" (1-1-1-2 syllables)

라임 매칭:
스페인어 "bailar" 끝 -ar ↔ 영어 "far / star / car"
스페인어 "contigo" 끝 -igo ↔ 영어 "go / so / know"
```

### §UE-30.4 다언어 Code-Switching 자리 결정

**룰 (07 §UE-21 + C-67 통합):**

```
1. 섹션 격리 default:
   [Verse - Korean] / [Chorus - English]
   → 안전, 발음 충돌 X

2. Hook 자리 single foreign word:
   [Chorus]
   "지나갈 줄 알았는데 (forever)"
   → 강조 효과 + 발음 안전

3. Bridge 자리 언어 전환:
   [Bridge - English]
   completely English bridge with Korean verse return
   → 대비 강함

4. 위험 자리 회피:
   ❌ 한 라인 안 언어 혼용
   ❌ 매 라인 언어 전환
```


## §UE-31. Suno 프롬프트 ↔ 가사 직결 어법 (운영자 핵심 통찰)

운영자 직격:
> *"결국 Suno 프롬프트로 직결되어 그게 표현되냐가 다 중요하니까.
>  가사 쓸 때 가사라는 게 제일 중요하잖아. 수노에서 그거 따라 음악이
>  끌려가는데."*

### §UE-31.1 가사 키워드 → Style Box 자동 추출 (C-97)

**원칙:** 가사 작성 후 Style Box *수동* 작성 X. 가사 디테일에서 *자동 추출*.

**추출 어법:**

```
가사 디테일 분석:
1. 7-감각 명사 추출
2. Action verb 추출 (강도 50W+)
3. 시간 / 장소 specific 추출
4. 메타포 결 추출
5. 감정 결 추출

→ Style Box 키워드 변환

예시:

가사:
"새벽 세 시 라디오에 너의 목소리
 빈 컵에 식어버린 커피 하나
 손가락이 떨리고 입술이 마르고
 너의 의자 자리만 비어있어"

7-감각 명사: 라디오, 컵, 커피, 손가락, 입술, 의자
Action verb: 떨리고 (200W), 마르고 (100W), 비어있어 (50W)
시간 / 장소: 새벽 세 시, 빈 자리
메타포: 빈 컵 = 빈 사람
감정 결: 그리움, 외로움, 새벽 정서

→ Style Box 자동 추출:
"Late-night intimate ballad, 70 BPM, female alto with breathy
 conversational verses, audible breath texture, 3 AM atmosphere
 with empty room tones, sparse acoustic guitar with sustained
 ambient pad, close-mic dry studio, vinyl warmth, no auto-tune"
```

### §UE-31.2 메타포 결 → 장르 / 악기 매핑

```
가사 메타포 결:
"빈 컵 / 식어버린 커피 / 의자 자리"
→ 일상 사물 + 부재 = 인디 / 어쿠스틱 결
→ 악기: acoustic guitar / piano / minimal drums

"한강 / 마지막 차 / 가로등"
→ 도시 + 밤 + 외로움 = 시티팝 / 인디 발라드
→ 악기: city pop synth / 8th note bass / brushed drums

"별 / 새벽 / 우주"
→ 자연 + 영원 + 광활 = 시네마틱 / 인디 폴크
→ 악기: strings / piano / ambient pad

"비 / 우산 / 흐림"
→ 자연 + 우울 + 회상 = 발라드 / R&B 발라드
→ 악기: piano / brushed drums / 7th chords
```

### §UE-31.3 7-감각 → 프로덕션 텍스쳐 매핑

```

촉각 디테일 강함 (온도 / 질감 / 무게):
→ 프로덕션: tube saturation + analog warmth + tape texture

후각 / 미각 디테일 강함:
→ 프로덕션: organic + analog + vintage

유기적 / 운동 디테일 강함 (심장 / 호흡 / 움직임):
→ 프로덕션: breath preserved + audible body + close-mic + minimal
  processing
