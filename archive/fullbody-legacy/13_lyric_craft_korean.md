## VERSION 3.0 — WHAT CHANGED AND WHY

v2.0 was a strong executable SOP for Korean lyric mechanics — rhyme,
parallelism, translationese, semantic field. It worked. But the
operator's 2026-05-22 session diagnosis surfaced gaps that v2.0
couldn't reach:

1. **No conscious-craft foundation.** v2.0 treated Korean lyric as a
   set of native intuitions to clean up. It missed the universal
   tools — Pat Pattison's 50-year Berklee canon — that apply across
   all languages and that AI music creators *especially* need.
2. **Verbs underweighted.** v2.0 talked about action-verb banks
   abstractly. It never named the central truth: verbs are the
   power amplifier of language; the difference between great and
   mediocre lyrics is almost always in the verbs.
3. **No K-Pop industry practice.** K-Pop topline craft has its own
   ruleset — hook in English, syllable density vs melody speed,
   persona-first, A&R-friendly section length. v2.0 assumed all
   Korean lyric was the same. It is not.
4. **No object writing protocol.** Operator's 17 Thematic Engine
   addressed scene at the *brief* level. Object writing (Pattison's
   daily 10-minute sensory practice) is the *generative* engine
   for concrete imagery. v2.0 had no execution loop for it.

v3.0 keeps every v2.0 strength (§3 rhyme system, §4 parallelism
variation, §5 translationese, §6 semantic field) and adds:

- **§1.5 Pattison's Four Tools** — Prosody, Stable/Unstable, Verb
  Amplifier, Object Writing — universal foundation
- **§3.4 Korean Rhyme as Stable/Unstable Tool** — rhyme types as
  emotional devices, not closure mechanics
- **§7.5 Verb Wattage Audit** — actionable verb-ranking pass
- **§8.5 Object Writing for Korean** — 7-sense protocol adapted
- **§9.3 Lyric-Melody Marriage** — Pattison's "most inviolable"
  principle applied to Korean syllable-timed prosody
- **§13 K-Pop Industry Practice** — hook-in-English, persona-first,
  melody-rhythm syllable density, A&R-friendly conventions

Design principle preserved: **palette + consult, never rigid rule.**
The tools sharpen creative choice; they do not narrow it.

## SECTION 1 — 작사의 근본 원칙

### 1.1 메시지 우선

가사는 *메시지를 담는 그릇*이다. 메시지가 명확하지 않으면 어떤
운율·라임·대구도 빈 껍데기가 된다. 작사 시작은 항상:

1. **무엇을 말할 것인가?** (theme / 중심 idea)
2. **누가 말하는가?** (persona / 화자)
3. **누구에게?** (listener / 청자)
4. **어떤 상황에서?** (scene / 장면)
5. **왜 지금?** (urgency / 절박성)

다섯 질문에 답할 수 없으면 가사 첫 줄도 쓰지 않는다.

### 1.2 단어 하나의 무게

좋은 가사는 *불필요한 단어가 없다*. 한국어는 syllable-timed 언어
이고 음절 의미 밀도가 높다. 음절 하나가 멜로디 노트 하나와 결혼
한다 (§9). 따라서 *낭비된 음절 = 낭비된 노트*.

- 약한 동사 (~이다, ~있다, ~되다) → 강한 동사로 교체 검토
- 빈 형용사 (아름다운, 깊은, 영원한) → 구체 명사·동사로 교체
- 추상 명사 (사랑, 슬픔, 추억) → AID(§7.4)로 구체화
- 부사 (정말, 너무, 매우) → 의미 추가 안 하면 제거

### 1.3 정직과 거리

가사는 *너 자신*에서 출발하되 *너의 일기*가 아니다.
- 너무 가까우면 (일기) → 청자가 들어올 자리 없음
- 너무 멀면 (관념) → 청자가 emotional 연결 못 함
- 적정 거리: *너의 진실*을 *청자가 자기 것처럼 느낄 수 있는 언어*로

Pat Pattison: "Number one: who you are. Number two: craft."

### 1.4 절제와 잉여

K-Pop·발라드는 *반복의 미학*이지만 반복 ≠ 잉여. 똑같이 두 번 박는
거랑 *변형 변주*는 다르다 (§4). 잉여 차단:
- 같은 의미 두 번 말하기 ("아프고 슬퍼") — 하나만
- 동의어 나열 ("쓸쓸하고 외로운") — 더 강한 쪽
- 부사 + 형용사 중첩 ("정말 행복한") — 단어 한 개로 강도

### 1.5 Pat Pattison의 4대 도구 (NEW v3.0)

Berklee Pat Pattison 교수의 50년 연구가 정립한 작사 universal 도구.
*장르·언어를 가로지르는* 기초:

#### A. Prosody (운율) — Aristotle의 "Unity" 응용
정의: *모든 element의 적절한 관계*. 멜로디·하모니·리듬·가사·구조가
*중심 message를 지원*해야 함. 어긋나면 청자가 *무엇을 말하는가*가
아닌 *어떻게 말하는가*에 주의를 빼앗김 → 감정 약화.

한국어 적용: §9 멜로디-가사 매칭에서 syllable-timed 한국어의
*음절 단위 prosody*로 구현.

#### B. Stable / Unstable Tool — 곡 전체를 보는 렌즈
모든 작사 결정은 *안정·불안정 스펙트럼* 안에서 일어남:

| 영역 | Stable (안정) | Unstable (불안정) |
|---|---|---|
| 음절수 | 라인별 일정 | 라인별 변동 |
| 라인 수 | 짝수 (2, 4) | 홀수 (3, 5) |
| 라임 | 완전운 (§3.1) | 모음운/자음운 (§3.4-5) |
| 어미 | 일정 (~다 / ~다 / ~다) | 변동 (~다 / ~지 / ~어) |
| 통사 | 완결문 | 도치·생략·명사 마감 |
| 대구 | 정확 대구 | 변형/무대구 (§4) |

운영 원리: *메시지가 stable한 부분 = 안정 도구 / unstable한 부분
= 불안정 도구.* 매끄러운 전환이 곡의 emotional arc 만듦.

#### C. Verb Amplifier (동사 = 언어의 파워앰프)
"The difference between great writers and average writers is almost
always in their verbs." (Pattison)

한국어 적용: §7.5 동사 와트수 점검 SOP 참조. 핵심:
- 약한 동사 (~이다, ~있다, ~되다, ~하다) → 0 와트
- 보통 동사 (가다, 오다, 보다, 듣다) → 낮은 와트
- 강한 동사 (스며들다, 부서지다, 차오르다, 부풀다) → 높은 와트
- 단, *과도하면 스피커 망가짐* — 아이디어와 와트수 매치

#### D. Object Writing (감각 글쓰기) — 매일 10분
무작위 명사 골라 7감각으로 묘사. *unconscious familiarity*에서
*conscious craft*로 전환하는 훈련. §8.5 한국어 적용 참조.

## SECTION 2 — 한국어 가사의 음운 특성

### 2.1 한국어 = Syllable-Timed Language

음절 단위로 시간이 흐름. 영어 = stress-timed (강세 단위)와 결정적
차이.

함의:
- **강세 유무가 표층 의미 변화 없음** — 영어식 stressed/unstressed
  매칭 원리가 *직접 적용되지 않음*
- 한국어 운율은 *음절수 + 모음·자음 결*로 형성
- 모든 음절이 거의 같은 시간 차지 → BPM × 음절 매핑 정밀해짐
  (§9.1)

### 2.2 모음 시스템

한국어 모음 21자 (단모음 10 + 이중모음 11). 영어 5 모음 + 일본어
5 모음에 비해 훨씬 풍부 → end rhyme 가능성 *영어보다 적지만
일본어보다 훨씬 많음*.

#### 단모음 (10)
ㅏ ㅓ ㅗ ㅜ ㅡ ㅣ ㅐ ㅔ ㅚ ㅟ

#### 이중모음 (11)
ㅑ ㅕ ㅛ ㅠ ㅒ ㅖ ㅘ ㅝ ㅙ ㅞ ㅢ

#### 모음 가족 (라임 family)
| 가족 | 멤버 | 결 |
|---|---|---|
| 양성모음 | ㅏ ㅗ ㅑ ㅛ | 밝음·작음·가벼움·여성적 |
| 음성모음 | ㅓ ㅜ ㅕ ㅠ | 어두움·큼·무거움·남성적 |
| 중성모음 | ㅣ ㅡ ㅔ ㅐ | 중립 |

**모음조화**: 양성 + 양성 / 음성 + 음성 결합이 자연스러움. 의성어·
의태어의 핵심 원리 (반짝반짝 vs 번쩍번쩍, 졸졸 vs 줄줄).

### 2.3 자음 시스템

한국어 자음 19개. 영어와 달리 *어두자음·어말자음 제약 강함*. 받침
(어말자음) 7개로 중화 (ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅇ).

자음 가족:
| 가족 | 멤버 | 결 |
|---|---|---|
| 평음 | ㄱ ㄷ ㅂ ㅈ ㅅ | 약함·일반 |
| 격음 | ㅋ ㅌ ㅍ ㅊ | 강함·격렬 |
| 경음 | ㄲ ㄸ ㅃ ㅉ ㅆ | 단단함·날카로움 |
| 비음 | ㄴ ㅁ ㅇ | 부드러움·여운 |
| 유음 | ㄹ | 흐름·이동 |

### 2.4 받침 (Batchim) — 운율의 결정자

받침 = 멜로디 노트와 가사 음절의 *기억성* 결정.

- **받침 없는 음절** (모음 종결): 부드러움·여운·길게 끌 수 있음
  → 발라드, 긴 노트, 후렴 끝
- **받침 있는 음절** (자음 종결): 단단함·끊김·짧게 끊김
  → 펑크/락, 짧은 노트, 강조 자리

#### 받침 부담 진단 (Suno 가창성)
- 한 라인에 **받침 클러스터 3+** → Suno 발음 무너짐
- "값있는 빛깔" (3 받침 연속) → 회피 / 분산
- BPM 130+ 빠른 곡: 받침 50% 이하 권장
- BPM 80- 느린 곡: 받침 70% 가능

### 2.5 한국어 강세 자유도

영어와 달리 *어디 강세 두어도 의미 보존*. 이게 작사가에게 *축복*:
- 멜로디 stress 어디 떨어져도 한국어는 의미 유지
- 영어처럼 "bridegroom vs come back" 잘못 매칭으로 의미 망가짐 X
- 하지만 *자연스러운 phrasing*에서 벗어나면 *어색함*은 있음
  → §9.2 한국어 자연 phrasing 참조

## SECTION 3 — 한국어 라임 시스템

### 3.1 라임의 5단계 closure (Andrea Stolpe / Berklee)

라임은 *closure 강도 위계*가 있고, *closure 강도 자체가 감정 도구*:

#### A. Perfect Rhyme (완전운) — 가장 강한 closure
- 모음 동일 + 받침 동일 + 초성 다름
- 한국어 예: 사랑/노랑, 마음/걸음, 하늘/오늘
- 효과: 강력하고 *기억에 남음* / 단호한 진술
- *과도 시 predictable / childish 우려*

#### B. Family Rhyme (가족운) — 두 번째
- 모음 동일 + 받침 *같은 가족 자음*
- 한국어 예: 사랑/사랑 (ㅇ-ㅇ), 마음/사람 (ㅁ-ㅁ), 가락/노란 (ㄱ-ㄴ 둘 다 비음 직전)
- 효과: 더 *부드러운 전환* / 대화적

#### C. Additive / Subtractive Rhyme — 세 번째
- Additive: 모음 동일 + 받침 *추가* (가/감, 자/잠, 하/한)
- Subtractive: 모음 동일 + 받침 *제거* (감/가, 잠/자)
- 효과: 짧→긴 stable / 긴→짧 less stable

#### D. Assonance Rhyme (모음운) — 네 번째 / **한국어 base**
- 강세 모음만 동일 / 받침 다른 가족
- 한국어 예: 사랑/마법, 노을/도움, 거울/저물
- 효과: less resolved / 수만 단어 가능 / *모던 K-pop의 표준*

#### E. Consonance Rhyme (자음운) — 가장 약한
- 받침 동일 / 모음 다름
- 한국어 예: 사랑/거룩, 노을/하늘 (모두 ㄹ)
- 효과: 가장 약한 / 최대 자유도 / *시적*

### 3.2 한국어 라임의 base = 모음운

영어 = 완전운 base / 한국어 = **모음운(assonance) base**. 이유:
- 한국어 음절 의미 밀도 ↑ → 의미 우선 시 완전운 부담
- 모음운으로도 *충분한 closure* 형성
- 모던 K-pop·인디·R&B는 *모음운이 표준*
- 완전운 과다 시 *동요풍·올드* 결

### 3.3 라임 타입 = 감정 도구

라임 closure 강도 = 감정 closure 강도:

| 라임 타입 | 감정 결 | 사용 자리 |
|---|---|---|
| Perfect | 완결·해결·종지부 | 후렴 마지막 / 곡 마무리 / 단호한 선언 |
| Family | 따뜻한 closure | 후렴 중간 / 안정된 verse |
| Additive | 가벼운 진행 | verse → pre-chorus 전환 |
| Subtractive | 미세한 긴장 | pre-chorus / bridge 진입 |
| Assonance | 여운·미해결·모던 | verse 일반 / bridge |
| Consonance | 가장 약한·시적 | bridge / outro 페이드 |
| **무라임 (X)** | *공간·놀라움·대조* | 의도적 침묵 자리 |

### 3.4 Stable/Unstable Tool로서의 한국어 라임 (NEW v3.0)

라임 선택은 *closure 강도 + 안정성 결정*. 곡 전체 arc 안에서
계획해야:

- **곡 시작 (Verse 1)**: 중간 closure (assonance/family) — 청자
  유도하되 결말 미리 주지 않음
- **Pre-Chorus**: closure 강도 *상승* (additive → family) —
  후렴으로 빌드업
- **Chorus**: 가장 강한 closure (perfect / family) — *기억*과
  *해결*
- **Verse 2**: Verse 1 라임 결 유지 + 미세 변화 (assonance →
  family로 살짝 강화)
- **Bridge**: closure 약화 (consonance / 무라임 X) — *대조와
  surprise*
- **Final Chorus**: closure 극대화 + 키업 (perfect + 음역 상승)
- **Outro**: closure 완화 (family → assonance) — 여운

### 3.5 억지라임 게이트

라임 위해 의미 희생하지 않음. 점검:
1. 이 라임이 *원래 말하고자 하는 것*을 더 강하게 만드는가?
2. 이 라임 단어가 *내가 자연스럽게 선택할 단어*인가?
3. 이 라임이 *클리셰 쌍* (사랑/마음, 너/나, 하늘/구름)인가?
4. 라인 *의미가 라임 단어 위주로 형성*되어 있지 않은가?

3개 이상 YES면 라임 재고. 한 줄 무라임 (X) 정당함.

### 3.6 라임 회의 — 닫지 말 것

라임 의무 X. 라임 무가능 X. 매 후렴마다 라임 회의:
1. 후렴에 라임 박을 자리 있는가?
2. 어떤 강도가 메시지에 맞는가?
3. 클리셰 쌍 회피 가능한가?
4. 무라임이 더 강할 수 있는가?

운영자에게 옵션 제시. 결정.

## SECTION 4 — 대구(對句) 변형 SOP

### 4.1 대구란

대구 = *동일 구조 / 다른 의미*의 두 구절. 한국 시문학·시조 핵심,
K-pop 후렴 표준 도구.

기본 예: "*하늘은* 푸르고 / *바다는* 깊다" (주제어·서술어 평행)

### 4.2 대구 4-옵션 팔레트

후렴 반복 시 4가지 선택지. 닫지 말 것:

#### ① 정확 대구 (Strict Parallelism)
구조 = 의미 모두 평행 / 단어만 교체
```
태양아 안녕 잘 가렴
공룡도 빠이 했을걸
```
→ 강한 stability / Chorus 1·2 본문 거의 동일

#### ② 점층 변주 (Escalating Variation)
구조 = 평행 / 의미 = *점층* (강도·깊이)
```
Chorus 1: 사랑해 너만큼은
Chorus 2: 사랑해 그 어떤 누구보다
Final: 사랑해 이 세상 끝까지
```
→ emotional arc 만듦 / **K-Pop 산업 표준**

#### ③ 동일 반복 (Identical Repetition)
구조 = 의미 = 동일
```
모든 Chorus 본문 동일
```
→ 강한 hammer / *각인* 최강 / "이 부분이 기억할 부분" 신호
→ 단, *컨텍스트·레이어·딜리버리*는 달라야 (§4.4)

#### ④ 무대구 (No Parallelism)
구조 = 자유 / 후렴마다 완전 다른 라인
```
Verse-like Chorus 1
Different Verse-like Chorus 2
```
→ *예술적 / 모던 / less catchy*
→ 인디·R&B·OST에서 정당 / K-pop에서는 드묾

### 4.3 옵션 선택 가이드

| 장르 | 1순위 | 2순위 | 회피 |
|---|---|---|---|
| K-pop main | ② 점층 변주 | ① 정확 대구 | ④ |
| K-indie | ④ 무대구 | ② 점층 | ① 정확 |
| 발라드 | ③ 동일 반복 | ② 점층 | ④ |
| K-R&B | ② 점층 | ④ 무대구 | ① 정확 |
| K-hip-hop | ② 점층 | ① 정확 | ③ |
| OST | ③ 동일 반복 | ② 점층 | ④ |
| 트로트 | ① 정확 대구 | ③ 동일 반복 | ④ |

### 4.4 동일 반복 시 *반드시* 차별화할 것

가사 본문 동일해도 다음 중 1개 이상 변형:
- **레이어**: Doubled / Harmony +3rd / Stacked vocals
- **딜리버리**: Verse 1 = 단일 보컬 / Verse 2 = 듀엣 합류
- **악기**: 첫 후렴 = sparse / 두 번째 후렴 = full band
- **시간**: behind-beat → locked-grid / locked → ahead-push
- **음역**: Final Chorus = key-up half-step
- **dynamics**: +2dB / 추가 element / b9 stab

운영자가 "대구 반복 심함" 신고 시 → 위 6개 중 미반영 항목 확인.

### 4.5 대구 변형 회의

매 후렴마다:
1. 어느 옵션이 메시지·장르에 맞는가?
2. 어느 차원에서 차별화할 것인가? (가사 / 레이어 / 악기 / 시간 / 음역)
3. 운영자 의도가 ①~④ 중 어디인가?

## SECTION 5 — 번역투 블랙리스트

### 5.1 번역투란

영어식 통사 구조가 한국어로 직역되어 어색해진 표현. 영어 Style
Box를 영어로 박은 *직후*가 최고 위험 시간. 한국어 모드로 의식적
전환 필수.

### 5.2 7대 번역투 패턴

#### ① "~의 ~" 과다
영어 's / of를 무차별 번역.
- ❌ "사랑의 색깔이 변해가" / "이별의 시간이 다가와"
- ✅ "사랑이 변색돼" / "이별이 다가와"

한 라인에 "~의" 1개 이내. 후렴 전체 2개 이내.

#### ② 물주구문 (사물 주어)
영어처럼 사물이 능동 주어. 한국어 어색.
- ❌ "비가 나를 적셨다" (영어식)
- ✅ "비에 젖었다" (한국어식)
- ❌ "시간이 모든 것을 데려갔다"
- ✅ "시간이 가니 다 떠나갔다"

#### ③ 주어 명시 과다
한국어 자연 = 주어 생략. 영어식 "I / you" 매번 박지 마.
- ❌ "나는 너를 사랑해 / 나는 너를 그리워해"
- ✅ "사랑해 / 그리워"

후렴에 "나" 1번 이내 (강조 자리만).

#### ④ 수동태 직역
"~되어진다 / ~지게 된다" 영어 수동 직역.
- ❌ "마음이 무너지게 되었어"
- ✅ "마음이 무너졌어"

#### ⑤ 관계대명사 직역
"~하는 사람 / ~하는 것" 영어 who/that 직역.
- ❌ "내가 사랑했던 사람이 떠난 자리"
- ✅ "사랑했던 자리"

#### ⑥ 시제 과다
한국어 자연 = 시제 자유. 영어식 정확한 시제 의무 X.
- ❌ "어제 나는 너를 보았었다"
- ✅ "어제 너를 봤어"

#### ⑦ 추상명사 의존
영어 추상명사 직역.
- ❌ "행복은 짧은 것이다"
- ✅ "행복은 짧아"

### 5.3 한국어 모드 전환 의식

Style Box → 가사 작성 전 의식적 게이트:
1. *영어 prompt 마지막 줄에서 호흡 한 번*
2. *한국어로 1분 자유 쓰기* (warm-up)
3. *번역투 7종 의식*하고 시작

### 5.4 14번 게이트 (출력 전 검증)

14번 §2.7 번역투 게이트가 자동 검증. 7종 발견 시 자동 보강.

## SECTION 6 — 의미장과 톤의 통일성

### 6.1 의미장 (Semantic Field) 정의

곡 전체에서 *동일 의미 군집*에 속하는 어휘들. 곡의 *통일감*과
*깊이* 만듦.

예시:
- "물 의미장": 바다, 비, 강, 호수, 흐르다, 잠기다, 적시다,
  파도, 출렁이다
- "빛 의미장": 햇빛, 그림자, 반사, 눈부시다, 흐리다, 비추다
- "도시 의미장": 거리, 빌딩, 신호등, 카페, 지하철, 네온

### 6.2 의미장 통일 원칙

#### A. 한 곡 = 5-6개 의미장 (Brief Lock §1.5 항목)
- 너무 적으면 (1-2개) → 단조로움
- 너무 많으면 (7+) → 산만 / *AI lyric soup*

#### B. 의미장 간 *유기적 연결* — 무작위 X
- ❌ 1절: 바다 / 2절: 노트북 / 후렴: 우주 (연결 없음)
- ✅ 1절: 한여름 옥상 / 2절: 캔커피 / 후렴: 태양 (열·도시·여름 결)

#### C. 의미장 = 17 Scene Dossier와 직결
17 §10 Scene Dossier (concrete-noun bank / action-verb bank /
anchor objects)가 의미장 1차 재료.

### 6.3 Pattison "One Metaphor Rule" (NEW v3.0)

"Pick one central metaphor and go deep." (Pattison Writing Better
Lyrics)

곡 하나당 *중심 메타포 하나* 잡고 모든 측면 탐색:
- 물 / 불 / 빛 / 시간 / 건축 / 여행 등 하나 선택
- 메타포 switching (1절 강 → 2절 불 → 후렴 산) = 가장 큰 실패
- 청자에게 *시각적 anchor* 없음 = 곡 흩어짐

앨범 단위는 다른 차원: 각 곡 다른 motif, 다양성은 *컬렉션*에서.

### 6.4 톤 (Tone) — Operator 17 register와 정합

톤 = *화자 페르소나의 어조*. 17 Thematic Engine §4.1 한국 register
와 연동:
- 격식·존중·예의 (~습니다 / ~십시오)
- 일상·친근 (~야 / ~지 / ~네)
- 거친·반항 (~다 / ~야! / ~아!)
- 시적·모던 (어미 생략 / 명사 마감)
- 향수·노스탤직 (~었지 / ~았어)
- 절박·격렬 (생략 / 도치 / 단문 연속)

곡 한 곡 내 톤 일관성 의무. 톤 변화는 *섹션 단위*로 의도적.

### 6.5 Drift Check 6항목

01 §9에서 의미장 / 톤 이탈 자동 감시:
1. Concept (최우선)
2. MUST-HAVE
3. MUST-AVOID
4. BPM/Key
5. Vocal Character
6. **의미장 / 톤** (NEW v2.0 이후)

## SECTION 7 — 한국어 작사 수사법

### 7.1 의성어·의태어

한국어 핵심 강점. 영어가 흉내낼 수 없는 풍부함:
- **의성어**: 쿵쾅쿵쾅, 두근두근, 졸졸, 콸콸, 보글보글, 쨍그랑
- **의태어**: 반짝반짝, 살랑살랑, 뚜벅뚜벅, 사뿐사뿐, 흔들흔들

운용:
- 모음조화 의식 (양성 + 양성 / 음성 + 음성)
- 반복 2회 표준 (반짝반짝 ≠ 반짝)
- 후렴 hook 자리 강력 (NewJeans·NMIXX 후렴 다수)

### 7.2 도치

어순 바꾸기. §3.5 라임 자리 만들기의 핵심 도구.
- 표준: "너를 사랑해"
- 도치: "사랑해, 너를"
- 효과: 강조 / 시적 / 라임 위치 자유

### 7.3 생략

한국어 자연 = 생략 자유. 시적 효과:
- 주어 생략 ("사랑해" — 누가 / 누구를 생략)
- 서술어 생략 ("이 거리에 너" — 동사 생략)
- 조사 생략 ("나 너 사랑해" — 받침 단단)

### 7.4 AID (Action / Imagery / Detail) — NEW v3.0

Jason Blume (BMI) 공식. Show Don't Tell의 *3-요소 분해*:

#### A. Action — 동사
감정 진술 X → 동작으로 보여줌.
- ❌ "그리워" (Tell)
- ✅ "전화기를 들었다 놨다" (Action)

#### I. Imagery — 5감 이미지
- 시각: "옥상 콘크리트가 햇빛에 녹아"
- 청각: "에어컨 실외기가 비명을 질러"
- 후각: "비 온 뒤 아스팔트 냄새"
- 촉각: "땀이 눈에 들어와 따가워"
- 미각: "캔커피의 알루미늄 맛"

#### D. Detail — 구체 명사·형용사
- ❌ "꽃을 들었다"
- ✅ "흰 백합 한 송이를 들었다" (구체 명사 + 수량)
- ❌ "옷을 입었다"
- ✅ "후드티 끈을 씹었다" (구체 명사 + 행위)

#### AID 적용 영역
- **Verse**: AID 최대 — 장면·이야기 영역
- **Pre-Chorus**: A + I (Action + Imagery), Detail 줄임
- **Chorus**: I만 (Imagery), 일반·요약·hammer 영역
- **Bridge**: A + I + D 다시 강화 — 반전·심화 영역

### 7.5 Verb Wattage Audit (NEW v3.0)

Pattison 핵심 도구의 한국어 적용:

#### Step 1: 모든 동사 동그라미
가사 초안에서 모든 동사·서술어 표시.

#### Step 2: 와트수 랭킹

| 와트 | 카테고리 | 한국어 예 |
|---|---|---|
| 0 W | 존재동사 | 이다, 있다, 없다, 되다 |
| 10 W | 일반 동사 | 가다, 오다, 보다, 듣다, 하다 |
| 50 W | 감각 동사 | 느끼다, 만지다, 맛보다, 닿다 |
| 100 W | 운동 동사 | 뛰다, 던지다, 휘두르다, 떨어지다 |
| 200 W | 변형 동사 | 부서지다, 녹다, 타오르다, 차오르다 |
| 500 W | 비유적 동사 | 스며들다, 깨우다, 어루만지다, 부풀다 |
| 1000 W | 충격적 동사 | 으스러뜨리다, 잡아채다, 후벼파다 |

#### Step 3: 와트수 매치 점검
- 약한 메시지에 1000W → 과장
- 강한 메시지에 0W → 미달
- 아이디어 강도와 동사 와트 매칭

#### Step 4: 약한 동사 교체 권유
- ~이다 → 더 구체적 행위 동사
- ~있다 → 위치 / 상태 묘사 동사
- ~되다 → 능동 동사 + 행위자

#### 예시
```
초안: "마음이 아프게 되었다" (이다 / 되다, 0W + 0W)
개선: "마음이 무너져 내렸어" (무너지다 / 내리다, 200W + 100W)
```

### 7.6 메타포 (은유)

Pattison 분류 (4종):
1. **Expressed Identity**: A는 B다 / A의 B / A인 B
   - "여름은 롤스로이스다"
   - "여름의 롤스로이스"
2. **Qualifying Metaphor**: 형용사+명사 / 부사+동사 충돌
   - "성급한 구름"
   - "맹목으로 부르다"
3. **Verbal Metaphor**: 동사·주어/목적어 충돌
   - "구름이 항해한다"
   - "서리가 여름을 삼킨다"
4. **Implied Metaphor**: 함축
   - "그는 가지가 부러지듯 쓰러졌다"

운용 원리: *클리셰 회피*. "사랑은 ~~다" 패턴 피하고 *예상 밖
조합* 만들기.

## SECTION 8 — 섹션별 작법

### 8.1 Verse — 이야기·장면 영역

기능: 청자를 *어디 / 언제 / 누가 / 무엇*으로 안내.

도구:
- AID 풀 활용 (§7.4)
- 구체 명사·동사 우선
- 강한 동사 (50-200W)
- 라임은 *가벼움* (assonance / consonance)
- 음절 7-10 (BPM 따라)

체크:
- 한 장면이 명확한가?
- 추상 감정 직접 진술 없는가?
- 동사 와트 적정한가?

### 8.2 Pre-Chorus — 빌드업 영역

기능: Verse → Chorus *전환·고조*.

도구:
- 음역 *상승* (Pre-Chorus 멜로디 ascending)
- 라임 *강화* (verse assonance → pre additive/family)
- 어휘 *추상화* — Detail 줄이고 Imagery 강화
- 라인 *짧아지거나 길어짐* (변동성 도입)
- 의문문·청유·감탄 어미 활용 ("어떡해" / "가자" / "이런!")

체크:
- 청자를 *후렴으로 끌어당기는가*?
- 멜로디 / 가사 둘 다 *상승*하는가?

### 8.3 Chorus — Hook·기억 영역

기능: 곡의 *중심 message* 박기 + *기억* 만들기.

도구:
- Verse보다 *일반·요약*
- 강한 라임 (perfect / family)
- 반복 *의도적* — 변형 변주 (§4.2 ②) 1순위
- 단일 메타포 (§6.3) 가장 강하게
- 음역 *높음* — belt / shouting
- 음절 *적당* — 빨리 가창 가능해야

체크:
- *3번 듣고 따라 부를 수 있는가*?
- 첫 줄에 *중심 message*가 있는가?
- *시각적 anchor*가 있는가?

### 8.4 Bridge — 대조·반전 영역

기능: Verse-Chorus 반복 깨고 *새 각도 / 감정 shift*.

도구:
- 다른 의미장 (단, 의미적 연결 유지)
- 다른 음역 (높이거나 낮추거나)
- 다른 시제 (현재 → 과거 / 미래)
- 다른 화자 시점 (1인칭 → 3인칭 / 청자에게 직접)
- 라임 *약화* (consonance / 무라임) — surprise 효과
- 호흡 변화 (half-time / [Pause])

체크:
- *새로운 정보 / 감정*이 있는가?
- 단순 reiteration 아닌가?
- Final Chorus를 *더 강하게 만드는가*?

### 8.5 Object Writing for Korean (NEW v3.0)

Pattison Object Writing 한국어 적용. 매일 10분, 무작위 명사 골라
7감각 (한국어 풀):

#### 7감각 + 한국어 어휘
1. **시각**: 빛·그림자·색·움직임·형태·반사
2. **청각**: 소리·정적·울림·진동·메아리·삐걱
3. **후각**: 향·내음·비린내·매캐함·풋내·텁텁
4. **미각**: 단·짠·쓴·신·감칠·떫·고소·매콤
5. **촉각**: 따끔·찐득·미끌·까칠·말랑·끈적·서늘
6. **기관** (organic): 두근거림·숨막힘·메스꺼움·어지러움
7. **운동감각** (kinesthetic): 비틀거림·기울어짐·중심잡기·뻗기

#### Object Writing 실행
1. 무작위 명사 1개 선택 (예: "버스 정류장")
2. 7감각 각 1줄 이상 묘사
3. 검열 없이 빠르게 쓰기
4. *비유 강제 X* — 직접 감각만
5. 끝나면 5분 후 다시 읽고 *시각 디테일* 표시
6. 가사 자료로 보관

#### Object Writing → Scene Dossier 연결
17 §10 Scene Dossier (concrete-noun bank / action-verb bank /
anchor objects) 생성 자료. 매일 1 object → 1주 7개 → Scene Dossier
시드.

#### 한국어 Object Writing 예시
주제어: **버스 정류장**

- 시각: 가로등 빛이 비닐 의자 위에 노랗게 흐르고
- 청각: 멀리서 다가오는 엔진 소리, 시간표가 바람에 펄럭이는 소리
- 후각: 비 온 뒤 아스팔트 냄새, 누군가의 담배 끝
- 미각: 캔커피 알루미늄 맛, 아침의 졸린 입안
- 촉각: 비닐 의자가 차가워 다리에 닿고
- 기관: 늦었나, 숨이 가팔라
- 운동감각: 버스 들어오자 발끝을 들고 손을 든다

## SECTION 9 — 멜로디와 가사의 매칭

### 9.1 한국어 음절 × BPM 표

BPM에 따라 라인당 권장 음절수 (99_OPERATOR_VAULT Part F (BPM × 음절 매트릭스) 연동):

| BPM | 권장 음절 / 라인 | 비고 |
|---|---|---|
| 60-80 | 6-9 | 발라드, 호흡 충분 |
| 80-100 | 7-10 | 미드템포 |
| 100-120 | 7-11 | 미드업·R&B |
| 120-140 | 6-10 | 댄스팝·K-pop main |
| 140-160 | 5-9 | 빠른 댄스·하이퍼팝 |
| 160-180 | 4-8 | 펑크·드릴·하드코어 |
| 180+ | 3-7 | 익스트림 |

*받침 비율*도 BPM에 따라:
- 빠를수록 받침 줄임 (Suno 가창 무너짐 방지)
- 130+ BPM: 받침 50% 이하
- 80- BPM: 받침 70% 가능

### 9.2 한국어 자연 phrasing

한국어는 강세 의미 무관이지만 *자연 phrasing*은 있음:
- 어절 단위로 짧은 호흡 ("나는 / 너를 / 사랑해")
- 한 어절 = 2-4 음절이 자연
- 한 라인 = 2-4 어절이 자연 호흡

위반 시 어색:
- 한 어절 5+ 음절 (한국어 자연 X) — 영어식 긴 단어
- 한 라인 5+ 어절 (호흡 부족) — Suno 보컬 러싱

### 9.3 Lyric-Melody Marriage — Pattison "불가침" 원칙 (NEW v3.0)

Pattison: "Lyric phrase ends when melody phrase ends."

한국어 syllable-timed 적용:
- 멜로디 phrase 마디 끝 = 가사 phrase 마디 끝 의무
- *enjambment* (인 잠 망 — 라인 넘어 의미 연결) *예외적*으로만
- 한 phrase 안에 *완결된 의미 단위* — 라인 끝에 단어 잘리는 거 X

#### 작성 순서별 매칭
- **가사 먼저**: 멜로디 리듬을 가사 어절 / 음절 리듬에 정확 매칭
- **멜로디 먼저**: 가사 음절수 / 어절 경계를 멜로디 마디 끝에 매칭
- **동시**: 4 / 8 마디 단위로 phrase 결정 → 양쪽 매칭

#### Suno 작업에서 멜로디 marriage
Suno는 가사 음절 ↔ 멜로디 마디를 *자동 매칭하려 함*. 따라서:
- 라인 길이 균일 → Suno 안정
- 라인 길이 변동 → Suno 불안정 (의도적이면 OK)
- 라인 끝 어절이 *불완전*하면 Suno 어색하게 끊김

### 9.4 강조 단어 위치

한국어는 강세 의미 무관이지만 *비트 강조 위치*는 있음:
- 4/4 박자: 1박·3박 강 / 2박·4박 약
- 라임 단어 = 강박 위치에 놓기 (§3.5)
- 의미적 핵심 단어 = 강박 위치에 놓기

#### 예시
```
4/4 박자, 라인 8 음절:
| 강 약 강 약 | 강 약 강 약 |
| 콘크리트가  | 녹아내려  |
   ↑ 라임/핵심 단어 강박 위치
```

### 9.5 호흡 마커 — Suno 큐 연동

10번 §1-3 Suno 호흡 / [Pause] 큐와 정합:
- 라인 끝 = 자연 호흡 (큐 없음)
- 섹션 끝 = [Pause 1 bar] 자연 휴식
- 극적 침묵 = [Sudden Absolute Silence: 0.5 seconds]
- 라인 중간 호흡 = [Pause half bar]

작사 시점에 호흡 마커 미리 박으면 멜로디·믹스와 정합 ↑.

## SECTION 10 — 한국 문화권 표현 레이어

### 10.1 한국 register 의식

한국어는 *경어 체계*가 의미를 결정. 가사에서도:
- 반말 (~야 / ~지) — 친밀·동등·일상
- 존댓말 (~요 / ~어요) — 정중·거리
- 존경 (~십니다 / ~십시오) — 격식·신앙·연장자
- 시적 (어미 생략 / 명사 마감) — 모던·예술

곡 1곡 안에 *일관성 의무*. 섹션별 다른 register 가능하지만 의도적.

### 10.2 한국적 정서 어휘

번역 어려운 한국어 특유 정서:
- **한**(恨) — 미해결 슬픔·억울함의 결
- **정**(情) — 관계의 따뜻한 결
- **흥** — 신명·즐거움의 폭발
- **멋** — 우아함·태도의 결
- **눈치** — 사회적 감지
- **은근슬쩍** — 조용한 강도
- **쿵짝** — 트로트 리듬
- **꺾기** — 트로트 보컬 ornament
- **간드러지다** — 부드럽고 매력적인 결

운용 원리: *직접 어휘 사용 시 강함* / *번역 시 약함*.

### 10.3 한국 시문학 운율 도구

- **두운** (alliteration) — 영어보다 한국어에서 강함
  "사랑 같은 슬픔 같은"
- **모음 연쇄** (vowel harmony / 모음조화) — §2.2
- **음절 카운트** (4/3 / 3/4 / 7/5 같은 전통 율격)
  4/3 = "산 너머 / 남쪽에는"
  7/5 = "고향 떠나 십 리도 못 가서 / 발병 나네"
- **대구** (parallelism) — §4
- **반복** (repetition) — 강조·리듬·서정
- **댓구** (대구의 강한 형태) — 한시 영향

### 10.4 의성어·의태어 결 분류

- 양성: 반짝, 살랑, 졸졸, 사뿐 — 밝고 작음
- 음성: 번쩍, 설렁, 줄줄, 성큼 — 어둡고 큼
- 첨가: ~거리다 / ~대다 / ~지다 — 동사화

#### 가사 활용
- 후렴 hook 자리: 의성어·의태어 반복 강력
- Verse 디테일: 1개 정도 양념
- 의태어 + 의성어 결합: "쿵쾅쿵쾅 두근두근" — 과도 회피

### 10.5 한국 음악 용어 (운영자 v2.5 규약)

99_OPERATOR_VAULT Part F (한국 음악 용어 영문 페어)에 따라 한글 단독 박지 말 것. 영문 음역 + 영어 의미
페어:

- **꺾기**: `kkeokgi (melismatic phrase-end bend ornament,
  signature trot vocal technique)`
- **쿵짝**: `kung-jjak (two-beat trot pulse, kick on 1 snare on 2-and)`
- **뽕끼**: `ppongki (old-school K-trot dramatic flair)`
- **아야아야**: `aya-aya (hook chant, signature trot affective
  interjection)`
- **국악**: `gugak (Korean traditional music)`
- **판소리**: `pansori (Korean narrative singing tradition)`
- **사물놀이**: `samul-nori (four-percussion folk ensemble)`

**가사 본문**에는 한국어 그대로 (Suno 부를 단어).
**디렉션 큐 / Style Box**에는 영문 + 의미 페어.

## SECTION 11 — 작사 워크플로 + 체크리스트

### 11.1 작사 전 준비

1. **17 Thematic Engine 발동** (C-26.1)
   - Scene Dossier 생성 (concrete-noun / action-verb / anchor objects)
   - 환경 큐 1개 결정
2. **Brief Lock 항목 확인** (01 §7.3)
   - Concept / MUST-HAVE / MUST-AVOID / Theme / Semantic Field
3. **Persona 결정** (§13.3 K-Pop)
   - 화자가 누구인가? (cute / dark / girl crush / antihero / 등)
4. **장르 narrativity 결정**
   - High (country / rap / 발라드) — 상세 장면 설정
   - Medium (rock / 미드템포) — 균형
   - Low (dance / EDM) — 빠른 plot

### 11.2 작사 워크플로

#### Phase 1: 후렴 먼저
1. 중심 message 1줄 잡기 (= 후렴 hook)
2. AID 분해 — Imagery 1개 / Action 1개
3. 라임 결정 (§3.6 회의)
4. 대구 옵션 선택 (§4.5)
5. 음절·BPM 매칭 검증 (§9.1)

#### Phase 2: Verse 설계
1. Scene Dossier에서 concrete-noun 3-4개
2. Action-verb bank에서 동사 3-4개
3. Verb Wattage Audit (§7.5)
4. 한 어절 = 2-4 음절 / 한 라인 = 2-4 어절 검증
5. 번역투 게이트 통과 (§5.4)

#### Phase 3: Pre-Chorus 빌드업
1. Verse → Chorus *전환 메커니즘* 결정
   - 음역 상승 / 라임 강화 / 어휘 추상화 / 의문문 어미
2. 한 줄 *질문 / 청유 / 외침*

#### Phase 4: Bridge 반전
1. Verse-Chorus와 *다른 element* 결정
   - 음역 / 시제 / 화자 시점 / 의미장 변화
2. 새로운 정보·감정 1개
3. 라임 약화 / 무라임 (X) 가능

#### Phase 5: Final Chorus / Outro
1. 후렴 본문 유지 + 차별화 (§4.4)
2. 음역 상승 / 키업 (half-step)
3. Outro: 마지막 한 줄 *임팩트 라인*

## SECTION 13 — K-Pop Industry Practice (NEW v3.0)

### 13.1 K-Pop 작사 산업 관행

#### A. Hook in English
K-Pop 글로벌 시장 관행:
- 후렴 / 타이틀 = 영어로 강제 권장
- "Dynamite" (BTS) — 전곡 영어 시도
- "Cupid" (FIFTY FIFTY) — 영어 후렴 + 한국어 verse
- 영어 toplines → 한국어 lyricist 재작성 모델

#### B. Korean Syllable Density vs Melody
LinNeya Södahl (NMIXX, TAEYEON 작가) 검증:
- "한국어는 음절수가 많아 → 더 빠른 멜로디 리듬"
- "짧은 노트로 많은 음절 박기"
- "긴 노트 회피" — 한국어 의미 손실
- *멜로디는 영어식이지만 가사는 한국어식*

#### C. Persona-First
가수 페르소나 결정 의무 (작사 전):
- Cute / Dark / Girl Crush / Boyish / Retro / Futuristic
- Antihero / Shy Romantic / Charismatic Troublemaker
- 곡 컨셉 따라 *어휘 / 톤 / register* 일관

#### D. A&R Friendly Section Length
- 곡 길이 2:30 ~ 4:00 / 스트리밍 = 짧을수록 replayability ↑
- 첫 hook 30-45초 안 배치 (attention 캡처)
- Rap line *짧게* + *강한 자음*
- *안무 가능한* 호흡 단위

#### E. Konglish 자연 통합
- 모든 영어 ≠ Konglish
- Konglish = *영어 단어가 한국어 멜로디의 자연 음절 단위로* 통합
- 예: "Baby" (2 음절) / "I'm yours" (2 음절) — 한국어 안에 자연
- 어색한 예: "Configuration" (5 음절) — Konglish 어려움

#### F. KOMCA 등록
- KOMCA = 한국음악저작권협회 (BMI / ASCAP 한국 버전)
- 한국 lyricist 협업 시 등록 필수
- 작사 share = 통상 작곡과 동등 분배

### 13.2 K-Pop 가사 구조 표준

#### 표준 구조 (4분 곡)
```
[Intro 8] (8-16초)
[Verse 1 16] (16-24초)
[Pre-Chorus 8] (8-12초)
[Chorus 16] (16-24초)
[Verse 2 16]
[Pre-Chorus 8]
[Chorus 16]
[Bridge 8-12] (보컬 break / rap)
[Dance Break 8-16] (안무 자리)
[Final Chorus 16-24] (변형 / key-up)
[Outro 8] (8-16초)
```

#### 첫 30초 안 박을 것
- Intro hook melody
- 곡 컨셉 명확화
- Persona 톤 확립
- *첫 hook line* (30-45초 안)

## SECTION 14 — Stable / Unstable 작사 운영 (NEW v3.0)

### 14.1 곡 전체 Stable/Unstable Arc

곡은 *안정·불안정 곡선*. 작사 결정마다 어느 쪽에 둘지 결정:

#### 일반 K-pop Arc
```
Verse 1: 중간 stable (도입·이야기)
   ↓
Pre-Chorus: 불안정 ↑ (긴장 빌드)
   ↓
Chorus: stable 최강 (해결·hammer)
   ↓
Verse 2: 중간 stable (이야기 진행)
   ↓
Pre-Chorus: 불안정 ↑↑
   ↓
Chorus: stable 강
   ↓
Bridge: 불안정 최강 (반전·대조)
   ↓
Final Chorus: stable 최강 + 키업
   ↓
Outro: 안정 점감 (fade)
```

#### 발라드 Arc
```
Verse 1: stable (조용)
Pre: 약간 불안정
Chorus 1: 중간 stable (조용한 hammer)
Verse 2: stable + 디테일 추가
Pre: 불안정 ↑
Chorus 2: stable + 강도 +
Bridge: 불안정 정점 (감정 폭발)
Final Chorus: stable 최강
```

### 14.2 Stable / Unstable 도구 매핑

| 도구 | Stable | Unstable |
|---|---|---|
| 음절수 | 라인별 일정 (예: 모두 8 음절) | 변동 (4-12 혼합) |
| 라인 수 | 짝수 (2, 4, 8) | 홀수 (3, 5, 7) |
| 라임 강도 | Perfect / Family | Assonance / Consonance / 무라임 |
| 어미 | 일정 (~다 반복) | 변동 (~다 / ~지 / ~어) |
| 통사 | 완결문 | 도치 / 생략 / 명사 마감 |
| 화자 시점 | 1인칭 일관 | 시점 변경 |
| 시제 | 현재 일관 | 과거 / 미래 혼재 |
| Imagery | 한 의미장 | 의미장 점프 |
| 어휘 | 일상·구어 | 시적·추상 |
| 톤 | register 일관 | 격식 변경 |

### 14.3 운영자 의도와 Stable/Unstable

운영자 메시지 진단 후 결정:
- "위로받고 싶다 / 안식" → Stable 도구 적극

## SECTION 11. NATURAL KOREAN LYRIC PATTERNS (v2.11 NEW — Case 41 통합)

Operator-discovered patterns from sessions that landed (Case 23
"그냥 그런 거지", Case 34 "남자의 연휴사용사유서", Case 41 "일단 뛰어"
gap-moe 어법). These are *not* clichés — they're the seam between
literary tradition and modern speech.

### 11.1 The "그렇다고~ 아닌데" pattern

Operator signature found in Case 23 / Case 41:
- *"그렇다고 슬픈 건 아닌데"*
- *"그렇다고 멋진 건 아닌데"*
- *"그렇다고 끝난 건 아닌데"*

This is **Don't Show Don't Tell** — the negation softens the emotion
*and* hides it simultaneously. The listener fills in the actual feeling.

**Generalization:**
- `그렇다고 [adjective + ㄴ/은 건] 아닌데`
- Pairs well with `그냥 좀 [adjective] 뿐이지` immediately after

**Use:** Bridge or verse softening. Avoid in chorus (too quiet).

### 11.2 The "일단 ~" pattern

Operator signature Case 41:
- *"일단 뛰어"*
- *"일단 그냥"*
- *"일단 [verb]"*

Korean *"일단"* = "for now / first thing" — defers decision while
forcing action. Perfect for chorus hooks where attitude > meaning.

**Generalization:**
- `일단 [verb stem]어` (command form)
- `일단 [noun]부터`

### 11.3 The "어차피 ~" pattern

Resignation + acceptance:
- *"어차피 내일도 same old song"* (Case 41)
- *"어차피 Monday"* (Case 41)
- *"어차피 그런 거지"*

Pairs trochaic stress: stressed "어" on beat 1.

### 11.4 Daily-detail bilingual code-switch

Operator pattern (Case 41 verses):
- Korean lexical + English emphasis word
- *"카드값 또 뛰어"* (Korean) + *"watch me"* (English ad-lib)
- *"편의점 2+1 — that's my VIP"*
- *"근데 나는 manager — not in charge"*

**Pattern**: Korean carries narrative, English carries emphasis/wit.

### 11.5 The "내가 디져야지" tongue-in-cheek pattern

Operator's own description:
> *"내가 디져야지 라는 장난스러운 느낌은 괜찮겠지만"*

Self-deprecating + hyperbolic + clearly joking:
- *"디져야지"* (말도 안 되는 결심)
- *"I might die (just kidding!)"* — joke marker essential

**Rule:** Tongue-in-cheek death/disaster lines need *joke marker*
nearby ("just kidding" / "농담임" / "ㅋㅋ"). Without marker = real
self-harm trigger.

### 11.6 어절 spacing audit (v2.11 from Case 41)

Korean lyrics must have natural word spacing for Suno to parse 어절
as breath unit.

❌ `어차피내일도same old song` (no spacing — Suno compresses)
✅ `어차피 내일도 same old song` (natural 어절 spacing)

External verification: 10 §21.1 / 14 §2.5.5.

### 11.7 한글 직접 사용 (no romanization)

External verification (HookGenius Korean prompts 2026):
> *"Always use Hangul, never romanized Korean."*

❌ `il-dan ttwi-eo`
✅ `일단 뛰어`

### 11.8 6-10 음절 라인 룰 (Korean)

External verification (HookGenius lyrics 2026 + 14 §2.7.1):
Korean syllable density is higher than English. Lines past 12 음절
→ Suno rushes/smears.

**Safe zone**: 6-10 음절 per line
**Past safe**: break into two lines

❌ `어차피 내일도 카드값 월세도 같은 노래` (14 음절, too dense)
✅ `어차피 내일도 / 카드값 또 뛰어` (7 + 6 음절, two lines)

## §UE-7. 한국어 음운론 심화 (학술 풀바디)

### §UE-7.1 한국어 음절 구조 — Suno 직격

```
한국어 음절 = Onset(C) + Nucleus(V) + Coda(C)
                       (필수)

학술 검증 (CSU Thesis):
- 한국어는 최대 3개 sound per syllable (CV / CVC / 받침 1개)
- 영어는 CCCV / VCCC 같은 복잡 cluster 가능
- 한국어 NO complex onset / NO complex coda
- 따라서 한국어 가사는 *영어보다 음절 밀도 낮음*

Suno 함정:
- 영어 음절 매트릭스 그대로 적용 X
- 한국어는 *받침으로 끝나면* 음절 무게 증가
- 받침 없는 (개음절) 빠른 흐름 OK
- 받침 있는 (폐음절) 느린 흐름 필요
```

### §UE-7.2 받침 (Batchim) — 가사 음운 결정자

**한국어 받침은 unreleased**. 영어와 달리 *강하게 안 발음*.

```
받침 7가지 sound 분류:
1. ㄱ (k) — 닭, 부엌
2. ㄴ (n) — 산, 안
3. ㄷ (t) — 옷, 닷, 곶 (ㄷ/ㅅ/ㅆ/ㅈ/ㅊ/ㅌ 다 t 소리)
4. ㄹ (l) — 달, 발
5. ㅁ (m) — 봄, 김
6. ㅂ (p) — 밥, 입 (ㅂ/ㅍ 다 p 소리)
7. ㅇ (ng) — 강, 정

원칙:
- 받침 ㅇ (-ng) — 가장 노래에 잘 안기는 받침 (sustain OK)
- 받침 ㄴ/ㅁ (n/m) — 부드럽게 흘러감 (sustain OK)
- 받침 ㄹ (l) — 가장 흐르는 받침 (liquid)
- 받침 ㄱ/ㄷ/ㅂ — 짧게 끊김 (stop) — sustain 어려움
```

### §UE-7.3 받침 연음 (Liaison) — Suno 발음 함정

```
받침이 다음 음절 ㅇ 만나면 → 다음 음절로 미끄러짐:

예시 (Suno 박을 때 주의):
- 받침 → 다음 받침 (Suno 발음 무너지기 쉬움):
  "꽃이" [꼬치] — ㅊ이 다음 음절로
  "낮에" [나제] — ㅈ이 다음 음절로
  "옷이" [오시] — ㅅ이 다음 음절로

처방:
- 가사 한 줄에 *받침 연음 자리 3+개* → 발음 무너짐 위험
- Suno 입력 시 [Vocal: clear diction, careful consonant linking]
- IPA-like 표기 권장: [Vocal: pronounce "꽃이" as "ggo-chi"]
```

### §UE-7.4 받침 자음 변동 (Suno 함정 풀바디)

```
1. 비음화 (받침 + ㄴ/ㅁ → 비음):
   "한국말" [한궁말] — ㄱ이 ㄴ 만나 ㅇ으로
   "감사합니다" [감사함니다] — ㅂ이 ㄴ 만나 ㅁ으로

2. 유음화 (받침 + ㄹ → 유음):
   "신라" [실라] — ㄴ이 ㄹ로
   "권력" [궐력]

3. 격음화 (받침 + ㅎ → 거센소리):
   "좋다" [조타]
   "많다" [만타]
   "닫히다" [다치다]

4. 경음화 (받침 + 평음 → 된소리):
   "학교" [학꾜]
   "독서" [독써]

5. 구개음화 (받침 ㄷ/ㅌ + 이 → ㅈ/ㅊ):
   "같이" [가치]
   "굳이" [구지]

Suno 입력 시 처방:
- 자음 변동 자리 → IPA-like 표기로 발음 락
- 또는 변동 적은 단어로 치환 (예: "감사합니다" → "고마워요")
```

### §UE-7.5 한국어 모음 시스템 (Suno 발음 정합)

```
단모음 10개:
ㅏ (a)  / ㅓ (eo) / ㅗ (o) / ㅜ (u) / ㅡ (eu) / ㅣ (i)
ㅐ (ae) / ㅔ (e)  / ㅚ (oe) / ㅟ (wi)

이중모음 11개:
ㅑ (ya) / ㅕ (yeo) / ㅛ (yo) / ㅠ (yu) / ㅒ (yae) / ㅖ (ye)
ㅘ (wa) / ㅝ (wo) / ㅙ (wae) / ㅞ (we) / ㅢ (ui)

가사 음운 처방:
- ㅡ (eu) — sustain 어려움 (입 안에서 닫힘) → chorus hook 자리 X
- ㅣ (i) — sustain OK + bright (chorus 자리 좋음)
- ㅏ (a) — sustain best (가장 열린 모음, vocal 잘 뻗음)
- ㅗ (o) — sustain OK + warm
- ㅢ (ui) — 발음 무너지기 쉬움 (Suno 함정) — 회피 권장
```

### §UE-7.6 모음조화 (Vowel Harmony) — 라임의 기본

```
양성 모음 (밝은 결): ㅏ, ㅗ
음성 모음 (어두운 결): ㅓ, ㅜ, ㅡ
중성 모음: ㅣ

원칙:
- 양성끼리 / 음성끼리 어울림
- 받침 끝자음 맞추는 게 아니라 *모음 맞추는 게 한국어 라임*
- 예: "나라" + "바다" (양성 ㅏ-ㅏ 반복) ✅
- 예: "어두움" + "묻어둠" (음성 ㅓ-ㅜ-ㅜ 반복) ✅

Suno 입력 시:

## §UE-16. 외국 작사 거장 어법 (Berklee Pat Pattison 표준)

### §UE-16.1 Pat Pattison 4-도구 (1,300,000+ 학생)

**4-도구 풀바디**:

```
1. Prosody (운율):
   - 가사 의미 ↔ 음악 리듬 정합
   - Stable rhyme = closed / Unstable = open
   - 라인 시작 자리 (downbeat vs offbeat)

2. Object Writing (7-감각):
   - 시각 / 청각 / 후각 / 미각 / 촉각 / 유기적 / 운동
   - 일상 사물 → 깊은 의미
   - 10분 타이머 / 편집 없이 / 7-감각 누적

3. Stable-Unstable Tool:
   - Stable rhyme (Level 1-2) → closing function
   - Unstable rhyme (Level 3-5) → opening function
   - 운율 위계로 감정 흐름 제어

4. Verb Amplifier:
   - 약한 동사 (be / get / have) X
   - 강한 동사 (slam / shatter / glow) ✓
   - Verb Wattage Audit 출력 전 의무
```

### §UE-16.2 5-Level Rhyme Hierarchy

```
Level 1 — Perfect Rhyme (완벽):
- love / above / dove
- 효과: closed / resolved
- 자리: Chorus 끝 (메모러블)

Level 2 — Family Rhyme (가족):
- bag / back / nap
- 효과: 닫히는 듯 열린
- 자리: Verse → Pre-Chorus transition

Level 3 — Additive-Subtractive (추가-감소):
- mine / mind (+d)
- play / plays (+s)
- 효과: 흐름
- 자리: Verse 중간

Level 4 — Assonance (모음운):
- light / mine (i)
- bone / road (o)
- 효과: 진행감
- 자리: Verse 진행

Level 5 — Consonance (자음운):
- summer / never (r)
- mother / under (r)
- 효과: 가장 열린
- 자리: Verse 시작 (열린)
```

## §UE-23. 다언어 문화권 톤 → 한국어 변환 차단 풀바디

### §UE-23.1 운영자 직격 진단

운영자 발화:
> *"일본 문학톤을 좋아하는데 그걸 한국어 가사로 가져오려면 갑자기
>  번역투가 되어서 '발이 먼저 나가' 이딴 식으로 나온단 말이지."*

진단:
- 기존 §5 (번역투 차단)는 *영문 → 한국어* 7종 패턴만
- *일본어 / 라틴어 → 한국어* 패턴 부재
- 문화권 *톤은 살리고* / *번역투는 죽이는* 어법 부재
- 운율 등가 변환 어법 분산

### §UE-23.2 일본 문학톤 → 한국어 차단 어법

**일본어 어법 특성 → 직역 시 한국어 번역투:**

```
일본어 결: 신체 부위 주어 + 동사 (擬人法의 일종)
"足が先に出る" (발이 먼저 나간다)

❌ 직역: "발이 먼저 나가"
✅ 한국어 자연: "나도 모르게 발이 먼저"
✅ 한국어 시적: "걸음이 먼저 닿아"
✅ 한국어 함축: "발끝부터 너에게로"
```

**일본 문학 → 한국어 번역투 6대 패턴:**

#### 패턴 1: 신체 부위 주어화 (擬人法)
```
일본어: "心が叫ぶ" / "心が震える"
❌ 직역: "마음이 외친다 / 마음이 떨린다"
✅ 자연: "외치고 싶어 / 떨려와"
✅ 시적: "심장이 안다 / 마음 끝이 떨리고"
```

#### 패턴 2: 시간 명사 + 모호 동사
```
일본어: "時が止まる" / "時が流れる"
❌ 직역: "시간이 멈추다 / 시간이 흐른다"
✅ 자연: "멈춰 있는 / 흘러가는"
✅ 시적: "그 순간 / 그 자리에"
```

#### 패턴 3: 추상 명사 +する (동사화)
```
일본어: "存在する" / "実在する"
❌ 직역: "존재한다 / 실재한다"
✅ 자연: "있다 / 여기 있다"
✅ 시적: "남아있어 / 머물러"
```

#### 패턴 4: 모순 형용사 결합 (정지용 어법과 친화적)
```
일본어: "懐かしい寂しさ" / "甘い痛み"
❌ 직역: "그리운 외로움 / 달콤한 아픔"
✅ 한국 어법 (정지용 영향 활용): "외로운 황홀한"
✅ 자연: "그리워서 외로워" / "아파서 달콤해"
```

#### 패턴 5: 자연 의인화 (花が泣く 등)
```
일본어: "桜が泣く" / "雨が歌う"
❌ 직역: "벚꽃이 운다 / 비가 노래한다"
✅ 자연: "벚꽃이 흩날려 / 빗소리가 들려"
✅ 시적: "꽃잎 떨어지는 자리에 / 빗방울이 음을 그어"
```

#### 패턴 6: 부정형 강조 (Yorushika 결)
```
일본어: "言えない" / "戻れない"
❌ 직역: "말할 수 없다 / 돌아갈 수 없다"
✅ 자연: "말 못해 / 돌아갈 곳 없어"
✅ 시적: "한 마디도 / 닫혀버린 길"
```

### §UE-23.3 일본 문학톤 *유지하면서* 한국어 자연

운영자가 *일본 문학톤 좋아하는* 자리 — 톤은 *살리고* 번역투는 *죽이는*
어법:

**일본 문학톤 핵심 결:**
1. *모노 노 아와레 (物の哀れ)* — 사물의 정서, 덧없음
2. *유겐 (幽玄)* — 깊은 은유, 보이지 않는 결
3. *와비사비 (侘寂)* — 불완전한 아름다움
4. *키레지 (切れ字)* — 의도적 끊김, 여백
5. *교카 (狂歌)* — 우스꽝스러움 + 정서

**한국어로 매핑 (번역투 X):**

```
1. 모노 노 아와레 → 한국어 어법:
   "벚꽃이 진다" → "꽃잎이 떨어지는 자리"
   "여름 끝나" → "여름이 머문 자리"
   "비 그치고" → "비가 지나간 길"
   * 명사 결합 + 진행형 회피 = 한국어 자연

2. 유겐 → 한국어 어법:
   "雨の音" → "빗소리 사이로"
   "影の濃さ" → "그림자 깊은 곳에"
   * 직접 묘사 X / 간접 디테일

3. 와비사비 → 한국어 어법:
   "傷ついた花瓶" → "이가 빠진 도자기"
   "古い木の机" → "오래된 책상 모서리"
   * 구체 사물 + 시간 자국

4. 키레지 → 한국어 어법:
   일본어 や / かな / けり (끊김 조사)
   한국어 대응:
   - "..." / "—" / 한 박자 정지
   - 짧은 단어 끝: "그래"  "응"  "어"
   - 의문 끝 (의도적 미해결): "그랬을까"

5. 교카 → 한국어 어법:
   슬픔 + 우스꽝 결합
   "失恋して / 冷蔵庫を開ける"
   ❌ 직역: "실연해서 / 냉장고를 열다"
   ✅ 자연: "헤어지고 / 또 냉장고 열어"
   ✅ 시적 함축: "헤어진 다음 날 / 김치찌개"
```

### §UE-23.4 라틴 문화권 톤 → 한국어 차단 어법

**스페인어 어법 특성 → 직역 시 번역투:**

```
스페인어: 강한 감정 표현 + 신체 의인화
"Mi corazón está roto"
❌ 직역: "내 심장이 부서졌어"
✅ 자연: "마음이 깨졌어 / 무너졌어"
✅ 시적: "심장 한 조각이 빠진 채로"
```

**라틴 → 한국어 번역투 5대 패턴:**

#### 패턴 1: 소유격 강조 ("내 사랑 / 내 인생")
```
스페인어: "Mi amor" / "Mi vida"
❌ 직역: "내 사랑 / 내 인생"
✅ 자연: "사랑하는 사람 / 그 사람"
✅ 시적: "너 / 너 하나"
```

#### 패턴 2: 강한 감정 + 신체 ("내 영혼이 / 내 심장이")
```
스페인어: "Mi alma" / "Mi corazón"
❌ 직역: "내 영혼 / 내 심장"
✅ 자연: "마음 깊이 / 가슴 안에"
✅ 시적: "한복판 / 깊은 곳에"
```

#### 패턴 3: 영원 / 죽음 / 절대 ("eternamente / siempre")
```
스페인어: "Te amo eternamente"
❌ 직역: "너를 영원히 사랑해"
✅ 자연: "너를 끝까지 사랑해 / 영원히 너만"
✅ 시적: "오랜 시간이 지나도 너 / 한참을 지나도 너"
```

#### 패턴 4: 운명 / 별 / 천사 (라틴 종교 메타포)
```
스페인어: "Eres mi destino / mi ángel"
❌ 직역: "너는 내 운명 / 내 천사"
✅ 자연: "너는 어디든 함께 / 너 같은 사람"
✅ 시적: "너는 나의 답 / 너로 시작해"
```

#### 패턴 5: 도전 / 욕망 / 정복 (reggaeton 톤)
```
스페인어: "Te quiero conquistar"
❌ 직역: "너를 정복하고 싶어"
✅ 자연: "너만 갖고 싶어 / 너 하나만"
✅ 시적: "너만 / 너밖에"
```

### §UE-23.5 라틴 톤 *유지하면서* 한국어 자연

**라틴 톤 핵심 결:**
1. *Passion (파시온)* — 강한 감정, 직접 표현
2. *Romance (로만세)* — 낭만, 시적 비유
3. *Tragedia (트라헤디아)* — 비극, 운명
4. *Sensualidad (센수알리다드)* — 관능, 신체 의식
5. *Familia (파밀리아)* — 가족, 공동체

**한국어로 매핑:**

```
1. Passion → 한국어 어법:
   "Te necesito" → "너 없으면 안 돼"
   "Me muero por ti" → "너 때문에 미쳐"
   * 강한 감정 + 한국어 직설

2. Romance → 한국어 어법:
   "Bajo las estrellas" → "별이 깔린 / 별 아래"
   "Caminar contigo" → "너랑 걷는 / 너와 함께"
   * 구체 자연 + 함께 자리

3. Tragedia → 한국어 어법:
   "El destino nos separó" → "운명이 갈라놨어"
   * 운명 / 길 / 자리 어법

4. Sensualidad → 한국어 어법:
   "Tu piel contra la mía" → "네 손이 닿는 / 네 숨소리"
   * 신체 디테일 + 한국어 간접

5. Familia → 한국어 어법:
   "Mi familia siempre" → "우리 가족 / 우리 사람들"
   * 공동체 어법 유지
```

### §UE-23.6 일본/라틴 → 한국어 운율 등가 변환

#### 음절 매트릭스 변환

```
일본어 → 한국어 변환 시:

일본어 7-5조 (와카 / 하이쿠 결):
"夕焼け空に" (7 morae) "君の名前を" (7 morae)

한국어 등가 어법:
"노을 진 하늘에" (7 음절)
"너의 이름을" (5 음절)
* 모라 수 ≈ 한국어 음절 수 매칭

영어 → 한국어:
영어 8 syllables → 한국어 7-9 음절 (받침 고려)
영어 10 syllables → 한국어 8-10 음절

스페인어 → 한국어:
스페인어 음절 (vowel-rich) → 한국어 받침 적게
"Te quiero ver" (5 syllables) → "널 보고 싶어" (5 음절)
```

#### 모음 / 받침 매칭

```
원칙:
- 양성 모음 (ㅏ/ㅗ) ↔ a/o
- 음성 모음 (ㅓ/ㅜ/ㅡ/ㅣ) ↔ e/u/i

받침 stop (ㄱ/ㄷ/ㅂ) 회피 자리:
- 빠른 BPM
- Sustain 자리
- Vowel-rich 일본어/스페인어 등가

받침 liquid (ㄹ/ㅁ/ㄴ/ㅇ) 선호 자리:
- Sustain 자리
- 흐르는 결
- 일본어 / 스페인어 자연 매칭
```

## §UE-24. Show Don't Tell 한국어 어법 풀바디 (07 §UE-11 확장)

기존 §UE-11이 *기본 원칙*. §UE-24는 *실전 풀바디 예시*.

### §UE-24.1 Verb Wattage 한국어 풀

```
0-10W (금지):
이다 / 있다 / 없다 / 되다

10-25W (피해):
가지다 / 갖다 / 두다 / 보다 / 듣다 / 하다

25-50W (보통):
가다 / 오다 / 만들다 / 찾다 / 만나다

50-100W (사용 권장):
걷다 / 달리다 / 쥐다 / 잡다 / 끌다 / 밀다 / 누르다

100-200W (강함):
움켜쥐다 / 흘끗 보다 / 기대다 / 끌어안다 / 떠밀다

200-500W (매우 강함):
부둥켜안다 / 찌푸리다 / 무너지다 / 떠밀다 / 무릎 꿇다

500-1000W (visceral):
짓밟다 / 찌르다 / 터지다 / 깨지다 / 부서지다

1000W+ (최강):
박살내다 / 폭발하다 / 산산조각 / 무너뜨리다
```

### §UE-24.2 Thought Verb 한국어 금지 풀

```
❌ 생각하다 → "기억나" / "잊지 못해"
❌ 알다 → 디테일로 보여줌
❌ 이해하다 → 행동으로 보여줌
❌ 깨닫다 → 모먼트 묘사
❌ 믿다 → 행동
❌ 원하다 → 디테일 ("너의 목소리만" / "그 자리만")
❌ 기억하다 → 구체 디테일
❌ 사랑하다 → 7-감각 디테일
❌ 그리워하다 → 빈 공간 / 잔재
❌ 후회하다 → 행동 묘사

대체 어법 (7-감각 디테일):
"그리워해" → "비어있는 컵 / 식어버린 커피 / 너의 의자"
"사랑해" → "네 손이 닿을 때마다 손바닥이 뜨거워지고"
"화났어" → "주먹이 떨려와 / 입이 마르고"
"슬퍼" → "눈이 따갑고 / 숨이 막혀와"
"기뻐" → "심장이 두 번씩 / 발이 가벼워져"
```

### §UE-24.3 메타포 신선화 한국어 풀

**Nick Cave 어법:**
> *"violent juxtaposition between two images that just don't belong
>  together can create a lot of tension"*

```
한국어 collision 어법:

일상 사물 + 추상 감정:
✅ "너는 내 책상 위의 늦은 커피"
✅ "너는 내 새벽 3시의 라디오"
✅ "너는 내 손목의 시계, 멈춰버린"
✅ "너는 내 방의 마지막 빛"

자연 + 도시:
✅ "너의 웃음은 한강 다리의 가로등"
✅ "너의 침묵은 지하철 마지막 차"
