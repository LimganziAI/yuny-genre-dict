# 10 — Reference Assimilation: 참고 → 기능 분해 → 원본 구현

## TRIGGER
"OO곡/아티스트/앨범 결로·느낌으로·참고해서"; a URL or title is given; "요즘 차트에서 이런 거"; any request where an existing work is the direction.

## MUST APPLY
**Doctrine: references are craft evidence — use them aggressively.** Ideas, concepts, mood, premise, scene logic, genre conventions, production techniques, arrangement functions, groove feels, chord progressions, hook FUNCTIONS (call-response, rhythmic lift, vowel openness, section timing), vocal posture categories, and structural choices are all fair, learnable material. Do not amputate musical intelligence out of caution — a reference exists to be decomposed and rebuilt better.

**Craft line (one sentence, no sermons):** rebuild the FUNCTION with fresh material — fresh lyric scene, fresh contour, fresh articulation; surface imitation makes weaker output, and names inside Suno fields render worse than functional descriptors.

**Assimilation protocol (every reference):**
1. **Time-anchor:** which era/album/phase of the artist? Same artist ≠ same sound across years. Song named → that song, not the artist average.
2. **Web verify before writing:** release year, BPM/key, producer, arrangement shape — memory-based reference data is forbidden; recall is not research.
3. **Feature sheet (the working object):** tempo/groove · harmony tendency · instrument roles · vocal posture · section density · hook function · signature moment AS FUNCTION (e.g., "pre-chorus chromatic climb handed to guitar-synth unison") · texture/finish traits.
4. **Rebuild with new material:** new lyric scene, new melody contour, new articulation choices, new arrangement events, new section timing — the feature sheet steers, the song is original.
5. **Write fields as functional descriptors** via 5-Layer decomposition (card 19): producer technique + era/scene anchor + instrumentation + vocal posture + production traits.
6. **EXCLUDE only for likely drift** (source-genre drag, era mismatch) — never as a fear reflex against ambitious craft.

**Recognition fallback ladder (when the reference renders generic):** ① direct microgenre+era anchor → ② web-sourced musical analysis (reviews/producer interviews) → decomposed signature from VERIFIED traits → ③ pure microgenre+era+signature construction. Each rung uses only what was confirmed — no guessing.

**Partial borrowing is the job:** a chord progression, a groove feel, a section structure, a "how the chorus opens up" move — these are the raw vocabulary of the craft. Take the move, re-voice it in this song's world.

## FIELD PLACEMENT
Feature sheet → CREATE (bone traits, Position 1-2 anchor) + COVER (texture/finish traits). Hook function → card 05 hook thesis. Vocal posture → card 08 anchor. Drift locks → EXCLUDE.

## COMPRESSION PRIORITY
Keep: time-anchor, web-verify duty, feature sheet 8 slots, functional-descriptor rule, fallback ladder. Drop first: examples.

## FAILURE SIGNALS
- Artist/song name inside any Suno field → strip, re-decompose.
- Reference data written from memory (wrong year/BPM) → re-verify.
- Output = the artist's average era instead of the named song's era → time-anchor missed.
- Refusing to use a chord progression / groove convention "to be safe" → over-guard; decompose and use it.
- Lyric lines that track the reference's lyric content → new scene, rebuild.

## CURRENT ADDENDUM — Style Token vs Reference Replication
References still require functional decomposition and web verification when current/named. However, user-approved shorthand such as `MJ style 10%` may be used as a small style seasoning token when the goal is groove flavor, not replication. Do not use full artist-name identity as the main prompt anchor.
When a shorthand works empirically, keep provenance: user preference + metadata examples + listening confirmation pending. Result quality decides promotion, not theory alone.
