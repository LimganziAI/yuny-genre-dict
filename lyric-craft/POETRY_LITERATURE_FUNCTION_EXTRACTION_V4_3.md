# POETRY / LITERATURE FUNCTION EXTRACTION V4.3

Use literature and poetry materials as craft physics, never as copied expression.

Extract:
- image relation: object + body/time/background + pressure
- silence: what the line refuses to explain
- cut: where grammar breaks because feeling/vision turns
- recurrence: repeated object or phrase with changed meaning
- residue: final word/image that remains after the event
- line architecture: short/long contrast, breath, page-to-song conversion

Reject:
- decorative metaphor with no relation
- famous line shadowing
- poem fog pasted onto pop structure
- abstract emotion label before material evidence
