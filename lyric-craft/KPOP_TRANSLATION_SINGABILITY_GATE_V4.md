# K-pop Translation and Singability Gate — V4

## Source basis
The uploaded K-pop lyric translation research emphasizes line/section alignment, singability, section-level semantic adaptation, and phoneme repetition as lyric-specific concerns.

## Runtime rule
When translating, adapting, or writing bilingual/K-pop-style lyrics:
- do not force literal line-by-line semantics
- preserve section-level meaning and emotional function
- treat syllable/breath count as musical constraint
- check phoneme/vowel repetition by section
- maintain repeated hooks when they carry musical identity
- allow semantic compression if singability improves

## Practical gates
1. Section semantic target: what must this section do?
2. Line breath target: how many mouth units can fit?
3. Repetition target: which section repeats more?
4. Vowel/coda target: what sound makes the hook work?
5. Language seam: where English/Korean changes, if any?
6. Listener coherence: does the section still make sense?

## Failure signs
- accurate translation but unsingable
- one line perfect, section incoherent
- bilingual drift inside a section
- too many hard codas on fast hook
- English hook kept only because it is English, not because it functions
