# KOREAN LYRIC MODE ROUTER V4.3

Purpose: prevent forcing one Korean lyric birth method onto every song.

## mode table
- conversational/narrative: pressure, ugly monologue, speech-act hook, V2 change, final defense shift.
- poetic/symbolic: object field, image relation, silence, refrain/return, cut/turn, residue.
- surreal/artful: internal rule, concrete anchor, recurrence, controlled estrangement, final rule-bend.
- chant/anthem: group mouth, command/claim, call-response, repeat dose, one semantic spike.
- vocable/phonetic: vowel map, consonant bite, groove cell, tiny meaning frame.
- bilingual: section-level semantics, one section one language, shared vowel seam, singability over literalness.
- theatrical/character: acting gesture, listener relation, staged timing, quotable mouth.
- minimal/fragment: subtraction, loaded object, silence, return with change.

## rule
A lyric mode may be mixed by section, but each section needs a declared job. Monologue is an engine, not a law.
