# KR Lyric Mode Router — V4 Final

## Purpose
Prevent YUNY from forcing every Korean lyric through one draft-origin method.

## Rule
Before writing a Korean lyric, choose a lyric mode.

## Modes

### conversational/narrative
Use for ordinary speech, confession, shame, comedy, self-defense, romance pressure, narrative scenes.
Engine: pressure lock → ugly monologue → speech-act hook → verse evidence → final shift.

### poetic/symbolic
Use for literary lyric, quiet image, object residue, symbolic relation.
Engine: image-system lock → object constellation → refrain/return → cut/turn → final residue.
Do not force ugly monologue if it flattens the poem.

### surreal/artful
Use for dream logic, estrangement, impossible scenes.
Engine: internal rule → concrete anchor → recurrence → one emotional readable thread.

### chant/anthem
Use for group hooks, dance chants, sports/party slogans.
Engine: sound cell → repeat dose → call-response → semantic spike.

### vocable/phonetic
Use for la-la, nonsense syllables, K-pop sound hooks.
Engine: vowel/coda map → groove grid → tiny semantic frame.

### bilingual
Use for Korean/English/other section maps.
Engine: section-level semantics, singability, shared vowel seam, language drift lockout.

### theatrical/character
Use for staged persona, dialogue, comedy mask, role voice.
Engine: character action, listener relation, quotable gesture, stage timing.

### minimal/fragment
Use for sparse lines, silence, single object, residue.
Engine: subtraction, micro-return, rest architecture, final object.

## Hard rule
Mode mismatch is upstream failure. Do not polish lines before correcting mode.

## Data use
- User corpus: taste and methods
- Literature/poetry: image relation and turn
- K-pop analytics: repetition/singability calibration
- Dialogue corpora: speech/register gates
- Translation datasets: section-level adaptation
