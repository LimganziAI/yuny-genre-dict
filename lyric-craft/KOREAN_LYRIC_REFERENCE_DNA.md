# KOREAN LYRIC REFERENCE DNA — 장르 10종 작사 유전자표
사용: 곡의 장르 family 확정 후 해당 1블록만 적용. 각 항목은 경향이지 공식이 아님 — off-center 채택 룰 유효. 원문 가사 복제 금지, 기능만.

## 1. 발라드
stance: 회상·후회·부재한 청자에게 / speech act: 자백·뒤늦은 인정·반문 / chorus: 사고의 정점 문장(소리보다 의미 하중), 저반복 / V2: 새 기억 각도·시제 이동(그때→지금) / final: 작은 항복 또는 수용 — 동일문+의미전환 강함 / bank: 방·계절·손·사물의 잔재 / 어미: -었지/-더라/-게/-니까 / 클리셰: 눈물·가슴·운명 직설 / AI실패: 감정 설명 만연체 / 수리: 감정명사→사물 행동, V2 새 노출.
## 2. 밴드·록
stance: 선언·질주·맞섬 / speech act: 결심·자기 명령·도발 / chorus: 동작 동사+한 이미지(빈 구호 금지) / V2: 장애물 구체화·속도 변화 / final: 선언의 그늘 1행 또는 더 큰 한 발 / bank: 거리·바람·엔진·신발·심박 / 어미: -자/-야/짧은 -어 / 클리셰: 불태워·끝까지 남발 / AI실패: 빈 앤섬(업리프트 클러스터) / 수리: 선언을 화자 전술로(무엇으로부터/무엇을 향해 명시).
## 3. 아이돌·댄스팝
stance: 직진 어필·자기 주장·밀당 / speech act: 명령·도발·콜앤리스폰스 / chorus: speech act+sound act(반복은 기능 — 후크 음절 설계) / V2: 입장 강화 또는 반전 신호 / final: 키 아닌 텍스처 리프트+1행 변이 / bank: 시선·폰·조명·거리 / 어미: -해/-줘/-니까, 의도된 EN 코드스위치 / 클리셰: 무의미 영어 훅 도피 / AI실패: 슬로건 복붙 반복 / 수리: 반복마다 사운드·섹션 기능 부여, EN은 화자 동기 있을 때만.
## 4. R&B
stance: 새벽·근거리·불확실 / speech act: 미완 고백·소프트 모순("가지 마, 는 아니고") / chorus: 짧은 구어+몸 감각, 미디엄 반복 / V2: 몸의 디테일 추가·관계 온도 변화 / final: 모순의 인정 / bank: 침대·불빛·숨·손끝·온도 / 어미: -인데/-잖아/말줄임 / 클리셰: 안개 같은 무드 명사 / AI실패: 증발형 분위기(사물 0) / 수리: 섹션당 구체 사물 1+촉각 행동 1.
## 5. 힙합
stance: 자기 서사·증명·관찰 / speech act: 플렉스·고발·서사 진술 / chorus: 리듬 훅(랩일 때만) / V2: 시점 전환·디테일 누적 / final: 펀치라인 회수 / bank: 동네·돈·시간·이름 / 어미: 종결 자유·체언 종결 / 클리셰: 번역투 스웨거 / AI실패: **sung곡에 힙합 밀도 이식 → V2 랩화** / 수리: sung 곡이면 이 블록 미적용 — sung-throughout 앵커+EXCLUDE rapping.
## 6. 인디·포크
stance: 관찰자·소시민·자기 농담 / speech act: 중얼거림·질문 종결·사소한 보고 / chorus: 평범 문장의 정확한 자리(폭발 불요) / V2: 카메라 한 칸 이동(창밖→방 안) / final: 같은 문장, 더 조용히 / bank: 골목·빨래·라면·버스·날씨 / 어미: -네/-려나/-거든 / 클리셰: 일기 산문화 / AI실패: 암호시 또는 일기 / 수리: 행=한 지각/한 행동, 같은 장면 세계 유지.
## 7. 트로트·성인가요
stance: 직접 호명·한·해학 / speech act: 부름·하소연·권주 / chorus: 고인지도 후크(아이고/그래요 류 추임 허용) / V2: 세월·장소 이동 / final: 꺾기 정점+체념 또는 신명 / bank: 정거장·소주·달·고향 / 어미: -요/-구려/-네요 / 클리셰: 의도 없는 신파 / AI실패: 젊은 컨셉에 트로트 어미 누출 / 수리: 컨셉이 young/modern이면 이 블록 차단+레지스터 리셋.
## 8. 시티팝·레트로
stance: 야간 드라이브·세련된 거리감 / speech act: 회상 어필·쿨한 미련 / chorus: 레가토 모음 훅·도시 사물 1 / V2: 장소 이동(도로→옥상) / final: 페이드 감성, 사물로 닫기 / bank: 네온 금지 대체 — 가로등·라디오·창문·강변 / 어미: -해요/-죠 혼용 가능(세련 거리감) / 클리셰: 도시 야경 일반론 / AI실패: 분위기만 있고 사람 없음 / 수리: 운전·정차·신호 같은 행동 비트 주입.
## 9. 여름송
stance: 현재형 들뜸·즉흥 / speech act: 제안·감탄·장난 / chorus: 개음절 고반복+의성 허용(vocable 모드 연계) / V2: 시간 경과(낮→밤) / final: 하루의 끝 이미지 / bank: 바다·얼음·선풍기·샌들·골목 그늘 / 어미: -자/-야/-네 / 클리셰: 파도·태양 일반론 / AI실패: 계절 의인화 남발 / 수리: 의인화→화자 지각으로("여름이 부른다"→"매미 소리에 멈췄어").
## 10. 귀여운 자기합리화·캐릭터 인접
stance: 변명하는 1인칭·들킴 직전 / speech act: 합리화·최소화·유예(self_rationalization_bank) / chorus: 변명 완문장+균열 1 / V2: 변명이 길어짐(전술 닳음) / final: 작은 항복("…맞아, 먹고 싶었어" 형) / bank: 디저트·영수증·거울·알람 / 어미: -지 뭐/-잖아/-는 척 / 클리셰: 무근거 깜찍 의성어 / AI실패: 유아어 추락 또는 설교 반전 / 수리: 화자 나이 고정+합리화 문법 유지, 반전은 항복 1행으로만.
