# KOREAN POETIC EXPRESSION DNA — 시/문학 기능의 작사 변환
원문 복제 금지 — 기능만. 문학성 = 추상어가 아니라 **정확성**이다.

## 10 기능
1. **시적 압축**: 조사 삭제가 아니라 *장면 선택* — 열 가지 중 가장 일하는 한 장면만 남긴다. "많이 힘들었고 외로웠고" → "불 켜둔 채 잤어".
2. **생략의 시학**: 한국어는 주어·목적어 생략이 시가 된다 — 단 문맥이 메울 때만(G3). "누가/무엇을"이 2행 안에 복원 불가면 생략이 아니라 누락.
3. **Twist(마지막 행 반전)**: 행렬의 마지막에 앞 행들을 다시 읽게 만드는 한 칸("잘 지내냐고 묻길래 / 잘 지낸다고 했어 / 거짓말은 아니지 / 잘, 까진 아니어도").
4. **first image → final image echo**: 첫 행의 사물이 끝에서 상태 변화로 귀환(COMPLETION_ARC 연동).
5. **물성화**: 추상을 무게/온도/질감으로 — "미안함" → "데운 국이 식는 동안". 감정은 물리량을 입을 때 만져진다.
6. **장면의 물리량**: 숫자·거리·횟수가 실재감을 만든다 — "오래 기다렸어" → "마을버스 세 대를 보냈어". 단 물리량은 곡당 2-3개(전 행 숫자 = 장부).
7. **평범한 단어의 정확한 위치**: 좋은 단어 사냥 금지 — "두다/남다/식다/멈추다" 같은 평어가 정확한 자리에서 시가 된다. 자리 = 받기 규칙이 만든 맥락의 끝.
8. **과잉 수식 제거**: 행당 형용사 ≤1. 형용사 2개가 붙으면 명사가 약한 것 — 명사를 바꾼다("차가운 쓸쓸한 방" → "보일러 끈 방").
9. **시조식 전환(3장 구조)**: 제시(초장)-전개(중장)-**전환·종결(종장: 의외의 한 수)** — Bridge→Final 설계의 원형. 종장 첫 어절의 낙차("아서라/그런데/근데 왜")가 전환의 스위치.
10. **긴 호흡 서사**: 연결어미 체인(-는데/-다가/-길래)으로 한 생각을 3-4행에 끌고 가기 — 발라드·포크의 무기. 체인 끝은 반드시 단문 착지.

## 복용량 (장르 연동 — DNA표 참조)
발라드·인디 = 기능 1·4·5·7·10 진하게 / 댄스 = 3·6 절제 사용, 압축은 소리 우선 / 록 = 6·9 / 자기합리화 곡 = 3·twist가 항복 장치. **문학성을 추상어로 때우는 것**(사랑의 무게·시간의 강)은 기능 0개 — 전부 5·6으로 변환.
