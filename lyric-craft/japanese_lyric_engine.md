# Japanese Lyric Engine — 풀바디
게이트 보편, 도구는 일본어 고유. Speaker truth > prosody.

## 1. Speaker register (일본어의 제1 변수)
- 종결형을 화자 단위로 잠근다: だ/よ/ね(캐주얼) · です/ます(정중) · 体言止め(명사 종결 — 문학적 절제) · 동사 원형 종결(독백). **한 곡 혼합 금지**(의도된 관계 변화 연출 제외).
- 1인칭 선택 = 화자 정체성: 僕(소년·담백) / 俺(거침) / 私(중립·여성) / うち(관서·친밀) — 곡당 1개, 후렴 1인칭 출현 ≤1.
- 주어 생략은 일본어의 기본 — 생략이 자연스러움을 만들지만, **관습 문맥이 메지 못하는 생략은 G3 fail**(누가 누구에게인지 2행 안에 복원 불가면 재작성).

## 2. Mora 운용 (음절이 아니라 모라)
- 일본어 행 길이는 모라로 센다(ん·っ·장음 = 각 1모라). 7-5조는 골격이지 법이 아님 — 현대 J-pop은 자유 모라 + 멜리스마 최소.
- 1모라 1음 원칙이 기본; 모라 욱여넣기(글자수 맞추려 조사 생략 남발)는 부자연 — 조사는 リズム의 일부다.
- 빠른 곡: 한 생각을 2-3행에 걸치되 조사로 잇는다(が/けど/まま) — 체언 파편 나열 금지.

## 3. 표기 규칙 (Suno 렌더 직결)
- **로마지 금지, 후리가나 별행 금지**(Suno가 중복 보컬 라인으로 읽는다 — 확정 운영 사실). 읽기 지정이 필요하면 표기 자체를 히라가나로.
- 애드립 괄호는 인라인만: 「ずっと(ずっと)」 ○ / 독립 행 괄호 ×.
- 한자 밀도: 가창 라인은 히라가나 비중을 높여 발음 모호성 제거(凡庸한 동음 한자 회피).

## 4. 클리셰 밴
白い絨毯 / 涙の理由 / 眩しい(남발) / 永遠に(남발) / 桜舞う(맥락 없이) / 君がいない世界. 추상 감정 명사(愛/心/世界)가 행을 단독 부양 금지 — 사물·동작으로.

## 5. 体言止め와 切れ
체언 종결은 절제·여운의 도구 — 곡당 2-4회가 효과 최대, 전 행 체언 종결은 단조. 전환점(Bridge 진입, Final 직전)에 切れ字적 단절 1회가 강하다.

## 6. 일본어 고유 실패 신호
번역체 직역(“僕の心の中の君” 류 の 연쇄 3+) / 정중체·캐주얼 혼합 / 후리가나 별행 / 모라 무시 멜리스마 강요 / 1인칭 혼용.
