# 한국어 자기합리화 구문 은행 — 부정·욕망·변명 컨셉의 후렴 재료
용도: 욕망 부정/합리화/변명 컨셉의 후렴은 **실재하는 한국어 자기변명 구문**으로 쓴다. AI식 의인화("여름이 나를 불렀다")의 대체재. 그대로 복붙이 아니라 *문법 골격*을 빌려 곡의 사물로 채운다.

## 골격 8종 + 변주 예
| 골격 | 구문 패턴 | 예시(러닝/단맛 곡이라면) |
|---|---|---|
| 원인 전가 | ~서 그래 / ~라서 그런 거야 | 목말라서 그래 / 더워서 그런 거야 |
| 대체 선언 | 이건 그냥 ~ 대신이야 / ~일 뿐이야 | 이건 그냥 물 대신이야 / 얼음일 뿐이야 |
| 자격 논리 | ~했으니까 (뭐) | 오늘 뛰었으니까 뭐 / 십 키로 했으니까 |
| 최소화 | 한 ~은/정도는 ~지 | 한 모금은 마신 것도 아니지 / 이 정도는 괜찮지 |
| 부정 의문(자문) | ~는 것도 아니잖아 / ~한 것도 아닌데 | 시킨 것도 아니잖아 / 산 것도 아닌데 |
| 유예 | 오늘만 / 이번만 / 딱 한 번만 | 오늘만 보는 거야 / 딱 한 번만 |
| 제3자화 | 누가 봐도 ~잖아 / 다들 ~잖아 | 누가 봐도 그냥 물이잖아 |
| 번복 직전 | 아니 근데 / 그게 아니라 | 아니 근데 손이 먼저 갔어 |

## 운용 규칙
1. 후렴 = 골격 1개를 **완문장**으로(150+BPM이어도 토막 금지 — 한 문장을 2-3행에 걸친다).
2. 골격은 곡당 2-3종까지 — 전 골격 나열은 변명 카탈로그가 된다.
3. 합리화의 **균열을 한 군데** 심는다(번복 직전 골격, 또는 감각 디테일이 변명보다 한 박 먼저 나오는 배치) — 들킴의 복선.
4. 의인화 금지 재확인: 추상·계절·사물 주어가 화자를 動하게 하는 구문은 후렴 0, 벌스 ≤1.

## 화자 톤별 어미 결합
담담 독백형: ~서 그래/~거든/~잖아 · 직진형: ~야/~지 뭐 · 체념형: ~겠지/~려나 · 장난형: ~다? /~라니까. 화자 카드의 어미 팔레트 밖 결합 금지.
