# Spanish Lyric Engine — 풀바디
게이트 보편, 도구는 스페인어 고유. Speaker truth > prosody.

## 1. Speaker register — 지역 좌표 고정
- 화자 카드에 지역 1개 고정: 멕시코 / 카리브(푸에르토리코·도미니카) / 안데스 / 리오플라텐세(아르헨티나 vos) / 이베리아(스페인 vosotros). **pan-Latin 혼합 = 한 화자가 두 지역 사람이 되는 G1 fail.**
- tú/vos/usted 선택 = 관계 거리 — 곡당 1개. 레게톤·어반 = tú+카리브 어휘 기본, 발라다 = 보다 중립.
- 어휘 점검: ahorita/chévere/vale/che 같은 지역 마커는 좌표와 일치할 때만.

## 2. Sinalefa (모음 연결 — 스페인어 운율의 핵)
- 인접 모음은 가창에서 한 음절로 붙는다(te amo = 2음절 “tea-mo”). **음절 계산은 sinalefa 적용 후** — 적용 전 계산은 행이 길어 보이는 착시를 만든다.
- 의도적 hiato(끊어 부르기)는 강조 연출 1곡 1-2회.

## 3. Stress (강세 박자)
- 멜로디 스파이크 = 강세 음절. 스페인어 단어 강세는 규칙적(끝-2 기본, 악센트 표기 우선) — 강세 어긋난 배치는 즉시 들린다.
- 행 끝 단어의 강세 위치(aguda/llana/esdrújula)가 운의 단위 — llana 운(amára/cantára류)이 가장 가창 친화.

## 4. Rhyme — asonante 우선
스페인어는 모음 운(rima asonante: 마지막 강세 이후 모음만 일치)이 전통·현대 공용 기본값. consonante(완전 운) 강박은 어휘를 비튼다. 후렴 = asonante 축 1개(a-o / e-a 등).

## 5. Vowel strategy
열린 a/o가 늘임에 최강 — corazón/amor가 훅에 사는 이유(단, 이 두 단어 자체는 클리셰 경보 — 사물·동작으로 대체 시도 먼저). i/u 늘임은 가늘다.

## 6. 클리셰 밴
corazón roto(맥락 없이) / fuego en mi piel / bailando bajo la luna / mi vida entera / 영어 코드스위칭 남발(의도된 바이링궐 설계 제외).

## 7. 스페인어 고유 실패 신호
지역 혼합(vos+ahorita 동시) / sinalefa 미적용 음절 계산 / 강세 어긋난 훅 / 전 행 -ar 동사 원형 운 (게으른 운).
