# KOREAN METAPHOR ACTION ENGINE — 은유는 행동으로 산다
AI 은유의 정체: **이미지 명사를 호명만 반복**("우산… 우산은… 그 우산이"). 사람의 은유: 사물이 **일을 한다**. 변환 3단 = object → action → shift(body/spatial/temporal).

## 8유형 × 변환
| 유형 | AI 실패형 | 행동화 변환 |
|---|---|---|
| object | "낡은 우산 하나"(호명 반복) | 우산이 하는 일: "펴지다 멈칫해 / 살 하나가 굽었네" |
| action | "이별이 다가와"(추상 행위) | 화자의 손이 하는 일: "테이프를 반만 붙였어" |
| spatial | "마음의 거리"(관념 공간) | 실측 가능 공간: "한 정거장을 더 가 / 네 골목을 피해서" |
| temporal | "시간이 흘러"(일반론) | 시간의 물증: "유통기한이 두 번 지났더라" |
| body | "가슴이 아파"(명명) | 신체 오작동: "숟가락이 무겁네 / 손목부터 저려" |
| contradictory | "차가운 불꽃"(형용 모순 장식) | 행동 모순: "버리러 갔다가 / 닦아서 넣어놨어" |
| negative-space | "텅 빈 마음"(빈 것의 명명) | 부재의 물증: "신발장 한 칸이 / 계속 비어 있어 / 안 채우게 되더라" |
| refrain metaphor | 후렴마다 같은 이미지 호명 | 후렴마다 사물의 **상태 진행**: 1절 펴진다→2절 마른다→Final 접힌다(중심 은유 1개의 변주 관통) |

## 운용 규칙
1. 중심 은유 1개 + 보조 2-3 — 산탄 금지. 중심 은유는 곡 전체에서 상태가 **진행**한다(refrain metaphor 행).
2. 은유 도입 후 2행 안에 그 사물의 행동/변화가 나와야 한다 — 안 나오면 장식.
3. 직유(처럼/같이)는 곡당 ≤2, 입말로 자연스러운 것만("거짓말같이 멀쩡해" ○ / "수채화 같은 그리움" ×).
4. 신체화 우선순위: 손 > 시선 > 호흡 > 걸음 > 내장(가슴/심장 직설은 최후).
5. 모드 연동: poetic/surreal 모드에선 결합의 낯섦 허용↑ — 단 행동화 원칙은 유지(낯선 사물도 일을 해야 한다).

## 변환 데모 (나쁜 AI행 → 사람 평문 → 가사행)
"그리움의 조각들이 쌓여가" → (평문) "안 버린 게 자꾸 늘어. 영수증까지 못 버리겠더라" → (가사) "영수증도 못 버려 / 자꾸 쌓이기만 해".
