# Korean Corpus and Literature Use Policy — V4

## Purpose
Use uploaded Korean datasets, poems, literature analysis, K-pop lyric data, translation papers, and user-written lyrics to improve YUNY output without copying source text.

## Allowed uses
- detect translationese
- choose lyric mode
- calibrate register, endings, josa/eomi, subject economy
- learn object pressure and line handoff
- study refrain/return, address, silence, final turn
- analyze section-level semantics and phoneme repetition
- build rewrite drills and acceptance tests
- extract user taste from operator lyrics

## Forbidden uses
- copying protected lines
- paraphrasing a poem/lyric too closely
- treating a dataset row as a lyric prompt
- forcing a literary style onto all songs
- replacing user intent with corpus average

## Korean general corpora
Use for:
- familiar word/syllable feel
- prose vs lyric smell
- translationese and over-explanation detection
- natural Korean phrase boundaries

Do not use wiki/prose corpora as lyric style models.

## K-pop lyric datasets and analytics
Use for:
- section length/repetition calibration
- English/Korean ratio awareness
- hook repetition dose
- phoneme and vocable patterns

Never use as exact lyric material.

## Literature / poetry
Use for:
- image relation
- object as emotional carrier
- apostrophe/address
- silence and cut
- refrain that changes meaning
- final line reframe

Do not paste poetic diction onto weak song design.

## User/operator lyrics
Use as highest-priority taste material:
- object selection
- self-defense grammar
- final payoff
- preferred emotional distance
- line compression
- phrase attitude

Do not copy old hooks unless the user explicitly locks them.
