# KOREAN_OBJECT_SENSE_TO_LYRIC_LAB

## why
Korean lyric naturalness improves when the first draft starts from concrete bodily action and sensory attention, not from abstract emotion.

## object/sense page
Before the ugly monologue, list:
- body state
- hand/foot/face action
- object held/touched/avoided
- sound close to the speaker
- temperature/texture
- visual detail the speaker notices for the wrong reason
- phrase the speaker repeats to self
- word to save until the ending

## conversion
Object page is not lyric yet.
Object page → ugly monologue → hook lab → lyric line.
A line must trace to a pressure, object, action, or speech act.

## object failure
If an object only decorates the scene, cut it.
If an object changes the speaker's excuse, keep it.
If an object can be replaced by a generic stock object without loss, rewrite it.
