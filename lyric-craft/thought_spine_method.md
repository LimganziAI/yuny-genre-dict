# Thought-Spine Method — G2의 비교 객체 만들기

## 왜
사고 흐름(G2)은 "느낌"으로 평가하면 도장이 된다. 게이트는 비교 대상이 있어야 작동한다 — 스파인이 그 객체다. 스파인 없는 가사 작업은 재료 나열로 끝난다(C-20260611-01 #4).

## 작성법
1. 초안 전, 화자의 사고 흐름을 **화살표 5-7개**로 명문화한다. 각 화살표 = 마음의 한 번 움직임(행동/감각/생각/전환).
   예: 달린다 → 생각을 밀어낸다 → 단맛이 침입한다 → 갈증으로 합리화한다 → 감각이 구체화된다 → 들킨다.
2. 화살표 수 상한 7 — 8개 이상이면 곡이 아니라 단편소설이다. 하한 4 — 3개 이하면 후렴 반복을 못 견딘다.
3. **섹션 매핑**: V1=①② / Pre=③ / Chorus=④(스파인의 추력 화살표 — 보통 합리화·선언·전환점) / V2=③④ 변주 또는 ⑤ / Bridge=⑤ / Final+Outro=⑥(결말 화살표).
4. 후렴 화살표는 곡 전체에서 가장 반복 가능한 한 문장으로 압축 가능한 것이어야 한다.

## 게이트로 쓰는 법 (G2 판정)
- 매 행에 묻는다: **"이 행은 어느 화살표 위에 있는가?"** — 답이 없으면 그 행은 재료 나열, 컷.
- 행 순서가 화살표 순서를 거스르면(④ 합리화가 ③ 침입보다 먼저) 사고 인과 붕괴 — 재배치.
- 한 섹션이 화살표 3개 이상을 먹으면 과밀 — 분배 재설계.

## 자주 쓰는 스파인 골격 (장르 불문 변주 가능)
- **부정/합리화형**: 일상 → 억압 → 침입 → 합리화 → 구체화 → 들킴 (욕망·금지 소재)
- **이별 후 회복형**: 흔적 발견 → 회피 → 기억 역류 → 직면 → 정리 행동 → 한 발짝
- **고백 직전형**: 관찰 → 망설임 → 핑계 → 신호 오독/포착 → 결심 → 발화 직전 멈춤
- **자기확신형**: 의심의 소리 → 작은 증거 → 반박 → 가속 → 선언 → 선언의 그늘 한 줄(입체감)
- **그리움 담담형**: 사물 발견 → 습관의 잔재 → 시제 혼동 → 교정 → 수용 → 사물을 제자리에

## 금지
- 스파인을 가사에 그대로 받아쓰기(설명충) — 스파인은 지도지 본문이 아니다.
- 화살표를 감정 명사로 쓰기("슬픔→분노") — 화살표는 행동·감각·생각의 *움직임*이어야 한다.
