# LYRIC MODE LOCK — 8모드와 게이트 보정
대원칙: **가사에 절대 금지 표현은 없다. 있는 건 '선언 없는 드리프트'뿐이다.** 의인법·슬로건·추상 선언·난해 상징·소리 훅·영어 훅 — 전부 도구다. INTENT LOCK이 모드를 선언하면 합법, 기본 모드에서 선언 없이 새어 나오면 AI-드리프트로 잡는다. 모드는 곡당 1개 기본, 혼합은 섹션 단위로 LOCK에 명시.

## 모드별 스펙 (좋은 표현 / 실패 / truth 기준 / 이해 요구 / prosody·cue / 한국어 운용)

**1. conversational/narrative (기본)**
좋음: 실제 입말, 장면·행동 디테일, 자기합리화·반문 같은 살아있는 화행 / 실패: 번역투, 의미 없는 예쁜 말, 업리프트 클러스터, 재료 나열 / truth: 이 화자가 이 장면에서 실제로 할 말(speaker truth) / 이해: 첫 청취에 상황 파악 필수 / prosody·cue: 강박=내용어, [Singing:] 대화 톤 지정, 휴지=호흡 / 한국어: 어미 팔레트 2-3 고정, 조사 생략은 규칙적으로, 혼잣말 어미(~네/~더라/~잖아) 적극.

**2. poetic/symbolic**
좋음: 객관상관물 1개 관통, 감각 전이(공감각), 절제된 의인법 / 실패: 이미지 산탄 살포(체계 없는 은유 5종), 정보 0의 장식 / truth: 시적 화자의 어법으로 일관(song-world truth 허용) / 이해: 축자 해석 불요 — 정서+장면이 잡히면 통과 / prosody·cue: 행갈이=이미지 단위, [Held]가 은유 정점과 결합 / 한국어: 체언 종결·명사형 종결 허용↑, 어미 단조화 주의, 受動 회피는 유지.

**3. surreal/artful**
좋음: 이미지 군 3-4개의 일관 전개(이미지-논리 스파인), 낯선 결합이 정서를 운반 / 실패: 무작위 단어 나열, 체계 없는 난해(스파인 부재) / truth: 그 초현실 세계의 내적 일관(song-world truth) / 이해: **유예 가능** — 감각·정서의 일관 전달이 기준, 해석 강요 없음 / prosody·cue: 사운드가 의미를 멘다 — 모음 설계·반복이 닻, Tier-S 이벤트로 구조 명시(가사가 안 주는 지도를 편곡이 줌) / 한국어: 조어는 여전히 금지(낯섦은 *결합*에서, 단어 발명에서가 아님), 음감 우선 단어 선택.

**4. chant/anthem**
좋음: 따라 부를 수 있는 구호, 점층 반복, 군중 1인칭(우리) / 실패: 구호+서사 잡탕, 점층 없는 단순 반복 / truth: 군중 발화로서 진실(crowd truth) — 개인 디테일 불요 / 이해: 즉시 — 한 번 듣고 따라 외칠 수 있어야 / prosody·cue: 강박 정렬 최우선, ALL CAPS·(BGV) 콜앤리스폰스, [Harmony enters] 점층 / 한국어: 받침 적은 개음절 위주, 2-4음절 구호 단위, 어미 생략형(가자/하나로) 허용.

**5. vocable/phonetic (소리 훅)**
좋음: 모음 설계된 스캣(라/나/두 계열), 본훅과 호응하는 배치 / 실패: 자음 무거운 음절(읏/극), 의미 가사와 무관 충돌 / truth: 해당 구간 의미 게이트 면제 — 가창 쾌감이 진실 / 이해: 비요구 / prosody·cue: 멜로디 스파이크=열린 모음, 변주는 리듬·모음 교체 / 한국어: 늘임 ㅏ/ㅗ, 받침은 ㄴ/ㅁ/ㄹ까지, 곡당 1구간 기본(전곡 스캣은 별도 선언).

**6. bilingual/cross-language**
좋음: 언어 전환에 화자 동기(감정 도피·인용·코드스위칭 인물), 섹션=언어 단위 / 실패: 무동기 영어 훅 도피, 행 안 단어 단위 혼합 / truth: 전환 자체가 화자의 행위로 읽힘 / 이해: 양 언어 청자 각각 성립 / prosody·cue: 언어별 운율 도구 각자 적용(EN stress/KO 박), 전환점에 [Breath]나 드랍 / 한국어: 한국어 구간은 기본 모드 규칙 그대로.

**7. theatrical/character-driven**
좋음: 배역 음성(악역·내레이터·코러스), 장면 전환 대사체 / 실패: 배역 일관성 붕괴(중간에 화자 표류), 뮤지컬 톤+일상 톤 잡탕 / truth: 배역의 진실(character truth) — 화자 카드가 배역 시트가 됨 / 이해: 배역·상황이 1절 안에 성립 / prosody·cue: [Singing:]에 배역 음색 명시, 대사형 행은 리듬 자유도↑, Tier-S로 장면 전환 / 한국어: 배역별 어미 차별화가 곧 캐스팅(하오체/반말/극존대 활용 가능).

**8. minimal/fragment-based**
좋음: 의도된 파편 — 단어·구 단위가 여백과 함께 의미를 만듦, 반복이 구조 / 실패: 압축 실패의 변명으로서의 파편(스파인 없는 토막) / truth: 파편들이 한 장면·한 정서로 수렴 / 이해: 수렴점이 후렴까지 도달 / prosody·cue: 휴지가 제1악기 — [One-bar rest]·[Sudden drop] 적극, 행당 1-4음절 허용 / 한국어: 명사·동사 원형 중심, 조사 최소, 단 수렴 행 1개는 완문장.

## 운용 3규칙
1. **드리프트 공식**: 표현이 선언된 모드 밖이면 플래그, 안이면 도구. 같은 문장이 모드에 따라 합법/위반이 갈린다.
2. **모드 추정**: 운영자가 모드를 명시 안 하면 기본 모드 + 발화 단서로 추정(카드 02 표) — 질문 0개, 가정 1줄 표기.
3. **혼합 곡**: 섹션별 모드는 LOCK에 표로(예: V=conversational, Bridge=surreal, Post=vocable). 전환 섹션엔 Tier-S 이벤트 1개로 갈아타는 소리를 만든다.
