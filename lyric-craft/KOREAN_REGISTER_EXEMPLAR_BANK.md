# KOREAN REGISTER EXEMPLAR BANK — 레지스터별 원창작 예시 (모방 대상 · 표준 아님)
**경고**: 아래는 *기법 시연*이다. 어느 한 줄도 품질 천장이 아니며, 시스템 생성 결과를 여기 추가하지 말 것(자기표준화 금지). 표준은 화자 코퍼스 + 운영자 카탈로그 + 세계 작법의 교차.

## R1 서정 발라드 — 감정어 없이 동작으로
컵을 두 개 꺼냈다가 / 하나는 도로 넣었어
불 끄려다 그냥 뒀어 / 네가 어두운 걸 싫어했으니까
현관 센서등이 / 혼자 켜졌다 꺼지더라
→ 무브: 행동 우회 · 어미 온도(~어/~더라) · 사물(컵·센서등)이 정서를 진다.

## R2 스토리텔링 — 카메라 선행 + 보고체
밤 11시 분식집 / 셋째 칸에 앉았어
아주머니가 안 물어보고 / 그냥 곱빼기를 주더라
나는 그게 고마워서 / 국물만 자꾸 떠먹었어
→ 무브: 시간·장소 1행 → 행동만 · 감정은 동작(국물만 떠먹다)에 숨김.

## R3 댄스·훅 — 입의 쾌감 + 화행 1개
오늘은 내가 정해 (정해) / 오늘은 내가 정해 (정해)
묻지 말고 따라와 / 뒤는 내일의 내가 책임져
→ 무브: 반복 도스 + 갱창 (정해) + 화행=선언 1개 · 벌스 정보 최소.

## R4 코믹·캐릭터 — 진지한 논리 + 어미 변주 + 정적 펀치라인
계산은 끝났어 이미 / 칼로리는 디저트부터 빠지는 거니까
참는 게 더 손해야 / 스트레스가 살이라잖아
[One-bar rest]
…일단 한 입만.
→ 무브: 자기합리화 논리 성실 · 어미 변주(이미/거니까/손해야/잖아) · 정적 직후 붕괴.

## R5 문학·시적 — 스파인 1개 + 감각 정확 + 사물 회귀
유리컵에 물을 받아 두면 / 밤새 공기 방울이 벽에 붙어
아침에 보면 다 사라지고 없어 / 어디로 갔는지는 아무도 안 물어
나는 그 방울들이 / 내가 못 한 말 같았어
→ 무브: 사물(물방울) 스파인 · 산문 종결 회피 · 마지막 행이 앞을 재정의.
