# LYRIC FAILURE AUTOPSY — JP 곡 '숫자 역산 작사' 부검 (v4.5의 기원 사건)
한국어 부검(NERH)과 다른 사인 — 이번엔 **공정 자체가 산수가 됨**. 실제 추론 로그에서 확보한 스모킹건.

## 사인 1 — 숫자 역산 작사 (결정적)
로그 원문: `lyric.replace("ここから行ける\n[End]", "ここから行ける\n少し軽く笑える\n[End]")` → 2999자 → 부족 → `もう少し軽く笑える`로 재패딩 → 3001자 달성.
**행이 노래 때문이 아니라 산수 때문에 존재** — "3000-3600자 범위"를 채울 목표로 오독. 교정 = LENGTH LAW: 분량은 결과, 하한 없음, 상한 초과 시에만 우선순위 컷.

## 사인 2 — 일률 처방 (수정 축 오류)
"가사를 늘리라는 게 아니라 큐로 디테일하게" 지적 → 전 섹션 일률 컷(3005→2435). 품질 축 불만을 분량 축으로 수리. 교정 = REVISION AXIS LAW: 축 선판정 후 해당 축만.

## 사인 3 — 자기긍정 스톡 문구 연쇄 (JP 클리셰)
寂しさを責めないで / やさしいままでいたい / 泣かない理由じゃなくて笑える理由を / 明日へ歩いてみるよ — J-pop 표어 사전의 연쇄. 90행에 구체물 2개(거울·소매)뿐, 나머지 전부 추상 감정 진술 = 화자 없음. 교정 = 목소리 우선(코퍼스/시연 모방), 장면·사물·고유 화행으로.

## 사인 4 — 文末 단조 (어미 모노톤 JP판)
〜ないで/〜たい/〜いいな가 후렴·프리·파이널에 연쇄. 교정 = 어미/文末 분포 게이트(동일 文末 3연속 금지, 곡 전체 ≥5형).

## 메타 교훈
규칙을 늘릴수록 '규칙을 만족시키는 글'이 늘었다 — 게이트는 검사용이고 초안은 목소리로(WRITE-THEN-CHECK). 그리고 **분량·개수 같은 측정값은 절대 생성 목표로 번역되지 않는다.**
