# KOREAN LIVING SPEECH → LYRIC ENGINE (독백→채굴→조각 풀바디)
핵심: **줄을 쓰지 말고 사람을 받아써라. 좋은 가사는 작문이 아니라 도청이다.** 조건을 만족하는 행을 조립하면 그게 조립감이다 — 행은 화자의 실제 발화 흐름에서 잘라낸다.

## 1. 독백 패스 (S3a — 모든 정식 한국어 곡의 출발)
화자가 그 장면에서 실시간으로 중얼거리는 1인칭 독백 **15-25문장**을 받아쓴다.
- 허용(권장): 반말, 비문, 말 끊김, 자기 정정("아니 근데"), 짧은 문장 다수, 시제 혼용, 시시한 디테일.
- 금지: 은유 압박, 대구, 줄바꿈 리듬, 예쁜 단어 사냥.
- **가짜 독백 판정**: 문장을 그대로 가사로 붙여도 될 만큼 예쁘면 가짜다. 독백은 가사보다 못생겨야 정상 — 못생긴 데서 진짜 말이 나온다.

### 작동 예 (generic 컨셉: 헤어진 사람의 우산이 아직 현관에 있다, 비 오는 아침)
독백 발췌 12문장:
"비 온다. / 우산 있는데. 현관에. / 내 건 어디 갔지. / 아 맞다 회사에 두고 왔지. / 그냥 맞고 가? 좀 그런가. / 아니 우산이 무슨 죄야. / 쓰면 되지. 물건이잖아. / 근데 손잡이 잡으면 생각날 거 아냐. / 한 번만 쓰고 버리지 뭐. / …버리진 말고. / 아 늦었다. 그냥 쓴다. / 비 그치면 돌려줄게. 누구한테."

## 2. 후렴 채굴 (S3b — 후렴은 쓰는 게 아니라 캔다)
독백에서 화자가 **두 번 이상 맴돈 문장/거의 말한 문장** 5-7개 추출 → 채점(표: PHONETIC_BEAUTY) → 메인 1 + 예비 1.
예시 채굴: A"우산이 무슨 죄야"(원인 전가+제목성+ㅑ 열림) · B"쓰면 되지, 물건이잖아"(합리화 직격) · C"한 번만 쓰고 버리지 뭐"+"버리진 말고"(유예+균열 페어) · D"비 그치면 돌려줄게"(시간 지정, 수신자 부재의 그늘 — Final 변형 예약) · E"그냥 맞고 가"(약함).
→ 메인 A+B 결합, D를 Final/Outro로 예약, C를 V2 프리로. **균열을 한 군데 심는다** — 변명보다 감각이 한 박 먼저 나오는 배치.

## 3. 조각 (S4 — carving)
행은 독백 문장에서 잘라낸다. 규칙:
- **Traceability**: 모든 행에 출처 독백 문장이 있다. 출처 없는 신규 행은 행동/지각 비트로만, 전체 ≤30%.
- **받기 규칙 7수** — 다음 행은 앞 행에 대한 반응이어야 한다:
| 수 | 정의 | 예 (우산 곡) |
|---|---|---|
| 이어받기 | 같은 생각의 다음 칸 | 우산 있는데 → 현관에 |
| 뒤집기 | 방금 말 부정·번복 | 버리지 뭐 → 버리진 말고 |
| 회피 | 화제 돌리기(숨김 신호) | 손잡이 생각 → 아 늦었다 |
| 줌인 | 디테일로 파고들기 | 우산 → 손잡이의 온도 |
| 결과 | 그래서 몸이 한 일 | 늦었다 → 그냥 쓴다 |
| 자문 | 스스로 묻기 | 돌려줄게 → 누구한테 |
| 침묵 후 재개 | [Breath]/휴지 뒤 작은 말 | (쉼) → …비 냄새 같네 |
- **인접 교환 테스트**: 옆 행 둘을 바꿔도 무손실이면 받기 사망 — "같은 주제의 형제 행" 나열이 조립감의 정체다. 받기가 살아 있으면 순서가 못 바뀐다.
- 조각 예 (V1, 출처 표기): "현관에 우산 하나(←2) / 내 건 회사에 있고(←4) / 비는 그냥 오고(←1) / 나는 신발만 봐(신규·행동 비트)" — 받기: 줌인→회피→결과.

## 4. 입말 텍스처 패스 (S7 후반 — 교과서 문장을 사람 말로)
### 축약표 (서면→입말, 가창 라인 기본값)
것이→게 · 것은→건 · 것을→걸 · 하지는→하진 · 이것은→이건 · 그것이→그게 · ~하여→~해 · ~지요→~죠 · 너의→네 · 나의→내 · ~려고 해→~려고/~게.
### 작은 말 사전 (AI가 "무의미해서" 빼먹는 사람의 질감)
그냥(이유 없음의 고백) · 뭐(체념·축소) · 좀(완충) · 자꾸(반복의 무력감) · 괜히(후회 선반영) · 일부러(의도 노출) · 어차피(체념 논리) · 아직(미련) · 벌써(시간 충격) · 그러게(자기 동의).
운용: **1개/4-6행**, 한 행 2개 금지, 같은 작은 말 곡당 ≤2회. 0개면 교과서, 과다면 추임새 범벅.
### 망설임·수선 (곡당 1-2회 — 사람 냄새의 핵)
"아니 근데" / "그게 아니라" / 말줄임(…) / 자기 정정("좋아해— 좋아했어"). Bridge·고백 직전이 제자리.
### 구어 어순
조사 생략은 입말 패턴으로만("나 어제 거기 갔어" ○ / 무작위 생략 ×). 도치는 강조 1곡 1-2회("못 버리겠더라, 그건").

## 5. 사고 이동 5종 (행 단위 — "예쁜데 정지" 차단)
모든 행은 화자 머릿속을 한 칸 움직인다: **지각**(들린다/보인다) / **행동**(쥔다/지운다) / **생각**(인가/겠지) / **말걸기**(너는/있잖아) / **판단보류**(모르겠다/일단). 행 끝에서 "그래서 머릿속이 뭐가 달라졌지?"에 답이 없으면 장식 — 컷. 단 기능 행(장면 유지·호흡·받침대) 20-30%는 정상 — 전 행이 메시지면 그게 AI다.

## 6. 자가 점검 (이 엔진의 fail 신호)
독백 없이 행부터 / 독백이 이미 시적 / 고아 미문(출처 없음+예쁨) / 신규 행 30%+ / 인접 교환 무손실 / 작은 말 0 / 축약 0(것이·하지는 잔존) / 수선·망설임 0인 고백 곡.
