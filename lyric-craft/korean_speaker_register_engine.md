## 1. Speaker Card (가사 첫 줄보다 먼저 — 빈칸이면 작사 시작 금지)
```yaml
gender_ageband:        # 예: 남 20대 후반
social_position:       # 직장인/학생/백수/군인… 어휘장이 여기서 나온다
listener_relation:     # 거리(연인/전연인/짝사랑/자기 자신) + 권력(누가 아쉬운가)
address_term:          # 너/그대/이름/호칭 없음 — 곡당 1개 고정
speech_mode:           # 반말 독백/존댓말 고백/혼잣말/체념/농담 섞인 슬픔/냉소 (1-2개)
na_quota:              # "나" 총량 상한 (후렴 ≤1 포함, 곡 전체 권장 ≤4)
sentence_habit:        # 단문형(툭툭) vs 만연형(흘러감) — 호흡 설계와 직결
humor_allowance:       # 슬픈 곡에도 농담 한 스푼 허용? (운영자 취향: 슬픈 노래도 즐겁게)
```

## 2. 어미 팔레트 확장판 (곡당 1팔레트 — 본문은 팔레트+중립어미만)
| 팔레트 | 주력 어미 | 양념(≤2회) | 절대 금지 |
|---|---|---|---|
| 담담 독백 | -더라 / -더라고 / -지 / -잖아 / -거든 | -길래, -뿐인데, -다는 게 | -것이다, -였던 것 |
| 직진 고백 | -야 / -할게 / -줄래 / 짧은 -어 | -자, -까 | 만연체 전부 |
| 체념·자조 | -겠지 / -려나 / -나 봐 / -는데 뭐 | -다니까, 웃기지 | 과장 감탄 |
| 회상 | -었지 / -곤 했어 / -던 | -었나, -였을까 | 현재형 남발 |
| 취중·농담 섞인 슬픔 | -다?, -라니까, -긴 한데 | 반문 -잖아? | 신파 어미 |
공통 과잉 금지: -했어 3연속+ · -고 있었다 · -게 되었다 · 동일 어미 4연속 · 전 행 과거 서술 · 번역투 7패턴(카드 06).
어미 분포 점검: 한 섹션 8행이면 주력 4-5 / 중립 2-3 / 양념 ≤1.

## 3. Speaker Sample 10줄 프로토콜
본문 전, 이 화자가 **노래 밖에서** 이 상황을 말하는 일상 대사 10줄 생성(내부). 체크: ① 10줄이 같은 사람인가 ② 팔레트 어미가 자연스럽게 나오는가 ③ 여기서 건진 말맛 2-3개를 본문에 이식(예: "딸기를 시켰지, 내가" 같은 도치). 본문이 샘플보다 문어체로 굳으면 R2 실패 → 샘플 톤으로 끌어내린다.

## 4. 일상어·조어·메타 판정법 (R2 상세)
- 산문 판정: 행 끝이 -고 있었다/-한 것이다/-며 → 산문. 행이 두 절 이상 관계절로 꼬임 → 산문. 노래는 말이 아니라 발화다.
- 조어 판정: 그 결합을 검색했을 때 실사용 없음 + 처음 듣고 뜻이 한 번에 안 잡힘 → 조어("입안만 먼저 식어"). 신선함은 **익숙한 단어의 낯선 배치**로 만든다("스푼 두 개, 각을 맞췄어").
- 사물 주어 영어식 행동: "비가 나를 적셨다/시간이 나를 데려갔다" → 한국어는 사람이 겪는다("비에 젖었어").
- 메타어 리스트(본문 출입 금지): 간주 · 브릿지 · 후렴 · 벌스 · 장면 · 연출 · 클라이맥스 · 고조 · 전환 · 멜로디 · 박자. 전부 [ ] 큐의 영역.

## 5. 5-감사표 실행 기준
① 화자: 10줄 샘플과 동일 인물? 중간에 시인이 빙의하지 않았나 ② 어미: 팔레트 이탈 0, 과잉 0 ③ 은유: 중심 은유 1개가 V1→Final까지 형태를 바꾸며 관통하나(빙수=관계: 시킴→녹음→물→자국) — 새 은유 난입 금지 ④ 후렴: 한 호흡, 열린 모음 착지, 따라 부르고 싶은 말맛, 4-변주 설계 ⑤ 설명·메타 0: 감정 단어로 결론 내리는 행("슬펐다") 제거 — 사물이 결론을 낸다.

## 6. 장르별 한국어 가사 stance (요약)
인디 발라드 = 사물 디테일+체념 유머 / 록 = 동사 전진+짧은 행 / R&B = 모음 흐름+반복 변주 / 트로트 = 직설+한(恨) 어휘 허용 / 시티팝 = 시간·거리 이미지+영어 1-2 토큰 허용 / 댄스팝 = 훅 음절 경제 최우선. 상세 → genre-dictionary 해당 장르 카드.
