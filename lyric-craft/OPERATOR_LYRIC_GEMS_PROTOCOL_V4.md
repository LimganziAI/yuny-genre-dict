# Operator Lyric Gems Protocol — V4

## Purpose
Convert user-written lyrics and confirmed edits into reusable craft memory.

## Store per finished lyric
- title / date / language
- lyric mode
- best object chain
- best speech turn or image turn
- hook type
- final word/image
- ending/eomi habits
- line length and breath habits
- what user manually changed
- why it worked
- do-not-copy exact lines

## Use
Before writing in the user's requested "결":
1. retrieve 2-3 relevant operator patterns
2. extract method, not line
3. choose A: familiar operator texture or B: deliberate variation
4. ensure new scene/material

## Running-mate type note
When user says a structure like running/collapse/carried/final reversal worked, store:
- action chain
- role reversal
- physical proof of emotion
- final line attitude
- not the exact phrasing unless user approves reuse

## Promotion
One lyric = case.
Three recurring mechanisms = pattern candidate.
Only repeated stable mechanisms enter Knowledge.
