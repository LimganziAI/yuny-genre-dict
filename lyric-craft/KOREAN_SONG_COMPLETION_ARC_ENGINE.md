# KOREAN SONG COMPLETION ARC ENGINE (V2 전개 · Final 변형 · 완결)
한 곡 = 한 사람의 사고가 끝까지 가는 것. 섹션은 챕터가 아니라 **같은 생각의 다음 국면**이다.

## 1. Verse 2 = disclosure (새 이미지가 아니라 새 자기노출/새 방어전략)
- V1 재서술 금지. V2가 바꿔야 하는 것: **시간/장소/전술/카메라 거리/상대의 반응** 중 2축 이상.
- **변형 콜백 1개 의무**: V1의 사물이 *상태가 변해서* 돌아온다(우산 곡: V1 현관의 우산 → V2 지하철 입구에서 "접다가 멈췄어 / 물기 털어주는 게 / 버릇이었더라" — 사물 동일, 시간·장소·발견이 새것).
- 전개의 본질은 노출이다: V1에서 숨기던 것의 가장자리가 V2에서 보인다(전술이 닳는다 / 핑계가 길어진다 / 손이 먼저 움직인다).

## 2. Pre-2 압력 상승
Pre-1의 유예가 Pre-2에서 더 급해진다 — 같은 골격, 더 짧은 호흡, 핑계의 디테일 증가("빨간불이 길어서 / 핑계가 생겼어" 형). 압력은 어휘가 아니라 호흡과 구체성으로.

## 3. Bridge = 의미 전환 장치 (Final의 연료)
Bridge의 일 = **훅의 뜻을 바꿀 한 문장**을 놓는 것. 보통 작은 인정("버린다 버린다 하면서 / 비 오는 날만 기다렸나 봐") 또는 겉말-속말 역전. Bridge가 무기능이면 Final 경로A가 막힌다.

## 4. Final Chorus = defense-shift (복붙 금지의 실체)
Chorus 1의 **부정/변명이 균열/수용/작은 항복으로 이동**해야 한다. 두 경로:
- **경로 A — 텍스트 동일 + 의미 변화**: Bridge가 뜻을 바꿔놓아 같은 문장이 다르게 들린다. 내부 의무: "1절에서 이 훅의 뜻" vs "Final에서의 뜻"을 한 문장씩 선언 — 같으면 fail. (우산 곡: "우산이 무슨 죄야"가 1절에선 변명, Final에선 "못 버리는 건 나"라는 자백으로 들림.)
- **경로 B — 1-2행 변이 = 착지**: 변이 행이 서사의 결론을 싣는다(마지막 변명이 무너지는 행). 변이는 동의어 교체가 아니라 입장 변화.
- 공통: 딜리버리 변화 1개(Tier-S 이벤트 — [Harmony enters]/[Vocal doubles only on final phrase] 중 1)와 결합.

## 5. 완결 = 첫 장면의 귀환 (first image → final image echo)
- 곡의 첫 이미지가 Outro에서 **상태가 변해 재점등**된다(현관의 우산 → "비 그치면 돌려줄게, 라고 / 보낼 데도 없으면서" — 첫 사물+예약해둔 훅 후보 D의 변형).
- hook thesis → final admission: 훅이 주장한 것의 진짜 값이 마지막에 드러난다.
- **outro object closure**: 마지막 행은 감정 선언이 아니라 사물/행동의 마무리(내려놓는다/문을 연다/그대로 둔다). [Outro]→[End] 필수.

## 6. fail 신호
V2가 V1의 동의어 / 콜백이 무변형 복붙 / Bridge가 분위기만 깔고 의미 무전환 / Final 복붙+의미선언문 동일 / 첫 이미지 미귀환 / Outro가 교훈 선언으로 끝남.
