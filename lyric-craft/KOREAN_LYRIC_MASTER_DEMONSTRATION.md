# KOREAN LYRIC MASTER DEMONSTRATION — 클로드는 이렇게 쓴다 (모방 강제 문서)
**지위: 한국어 정식 가사 착수 시 의무 fetch. 초안은 규칙이 아니라 *이 문서의 목소리*를 모방해 쓴다.**
규칙 카드(05/06)는 초안을 *검사*하는 도구지 *생성*하는 도구가 아니다 — 규칙을 보면서 쓰면 규칙 맛이 나는 죽은 글이 나온다(네르 스무디 7연속 실패의 사인). 순서는 언제나: ①화자 코퍼스 적시기 → ②그 목소리로 막 쓰기 → ③그 다음에야 게이트.

## 실전 시연 — 네르 '딸기는 과일이잖아'가 만들어진 실제 순서

### 1. 화자 코퍼스부터 (이걸 안 한 게 7연속 실패의 근원)
"네르" 지명 즉시 기존 곡을 찾는다. 찾았더니 — **'한여름 밤의 악몽'이 이미 같은 컨셉 계열**(단 것 유혹과의 전쟁 비장극: "들키면 끝장이야, 숨을 참고 멈춰서 / 세상에서 가장 길고 위태로운 열 발자국"). '분명히 열대야 탓'은 핑계 화법 교본("열대야 탓 맞아, 분명히"). 이 순간 곡의 절반이 끝났다 — 발명이 아니라 **검증된 결의 계승**. 화자 코퍼스 없이 쓴 7개 버전이 전부 죽은 이유가 이거다.

### 2. 독백은 화자 목소리로 (예쁘게 쓰지 마라)
네르로 빙의해 빠르게 중얼거린다 — 네르는 느린 서정이 아니라 정보 질주다:
"어제 야식 오늘 다 갚는다. 숨 턱까지 차는데 기분 좋아, 이게 갚는 맛이지. 모퉁이 도는데 믹서기 소리. 아침 일곱 시에 누가 갈아. 딸기네. 안 봐, 나 심박수 관리 중이야. 근데 냄새가 심박수를 올리네. 보는 건 운동 방해 아니잖아. 컵에 물방울, 저건 그냥 물이야. 방금 300은 태웠어. 작은 사이즈면 거의 물이지. 딸기는 과일이고 과일은 권장 식품이야. …줄 서 있네 내가. 언제부터. 지갑은 또 언제 꺼냈대. 한입만 하고 버린다. 못 버리지, 알아. 달다."
못생겼다. 그래서 진짜다. **"아침은 얇은 유리처럼" 같은 문장이 독백에 나오면 화자가 아니라 작가가 말하는 것** — 즉시 폐기.

### 3. 훅은 캐는 것 — 채굴 채점
맴돈 문장: "딸기는 과일이잖아"(논리 붕괴의 정점·ㅏ랜딩·10음절 챈트) / "보는 건 0칼로리"(위트) / "방금 삼백은 태웠잖아"(거래) / "한입만 하고 버린다"(거짓말 — 브릿지 샤우트 예약) / "심박수 관리 중"(비장 콩트). 메인 = "아니 딸기는 과일이잖아" — 화자가 *지는 순간*의 항변이라 8연타가 가능(매 행 다른 합리화: 과일→칼로리→물→과학 — 사고가 한 칸씩 추락 = 반복인데 정지가 아님).

### 4. 조각 — 버린 결정이 곧 기술이다
- "딸기 스무디 사진이 나를 보고 웃어" 류 의인화 → 폐기. 네르는 사물을 *탓하지* 사물에게 말 걸지 않는다("열대야 탓 맞아"가 그 문법).
- "괜찮아 오늘은 괜찮아" 류 자기 위로 연쇄 → 폐기. 정보 0 — 네르는 멈춰서 위로하지 않는다.
- "손이 한 일을 나는 모르는 걸로 해" 채택 — 몸의 배신을 *판결문 화법*으로(네르의 단정성: "내가 정했으면 그게 맞는 거야" 계열).
- Final = "아니→그래" 한 글자 전환으로 항변이 항복이 됨 + "내일 십 키로 뛰면 되잖아"(거래의 완성 — defense-shift 경로B).

### 5. 그리드 vs 화자 결 — 화자가 이긴다
168 BPM 매트릭스는 5-7음절이지만 네르 실곡은 더블타임 위 8-13음절 질주('열대야 탓' 실측). **음절 규칙에 맞추려 행을 토막 내면 결이 죽는다**(실패 버전들이 전부 5-6음절 토막). 그리드는 화자 체질 안에서만 작동한다.

### 6. WRITE-THEN-CHECK (이 문서의 법)
초안 단계: 카드 05/06을 *보지 않는다*. 보는 것은 ①화자 코퍼스 ②이 시연 ③OPERATOR_LYRIC_GEMS. 초안 완료 후에야 게이트(받기/사고이동/번역투/검산)를 *검사*로 돌리고, 걸린 행만 화자 목소리로 수리. 게이트를 만족시키려고 쓰지 말 것 — 게이트는 거름망이지 펜이 아니다.

## 모방 프로토콜 (매 한국어 정식 곡)
1. 화자 코퍼스 fetch(캐릭터면 기존곡 2-3, 못 찾으면 사용자에게 경로 요청 — 추정 생성 금지) → 2. 결 공식 3줄(행 길이 체질/화행/어미) → 3. 그 목소리로 독백 15-25문장(못생기게) → 4. 채굴·조각(버린 결정 포함) → 5. 게이트는 마지막. **외국어(JA/EN/ES)도 동일 구조** — 언어 크래프트 카드는 검사용, 목소리는 코퍼스와 시연에서.

## 7. 시연자의 1차본 결함과 수리 — 어미 분포 (클로드 자가 부검, v4.5)
시연자도 틀렸다. '딸기는 과일이잖아' 1차 후렴은 '잖아' 8연발 — 화행(항변)은 정확했지만 어미가 단조해 기계 낭독처럼 들렸다. 운영자 지적이 맞다. **수리 원리: 챈트는 '같은 어미 반복'이 아니라 '앵커 고정 + 사이 변주'다.**
- 수리 전: 과일은 몸에 좋은 거잖아 / 방금 삼백은 태웠잖아 / 작은 컵은 거의 물이잖아 (…전부 잖아)
- 수리 후: 과일 먹고 살찐 사람 봤어? / 방금 삼백은 태우고 왔어 / 작은 컵은 그게 그냥 물이야 — 앵커(잖아)는 1·5행에만, 사이는 의문/단정/명사절단/~지/~니까로. 화행은 전 행 항변 유지.
교훈 두 개: ①게이트가 없으면 시연자도 빠진다 — 그래서 어미 분포 게이트가 기계 검사로 존재해야 한다(카드 06). ②수리는 어미만 갈았다 — 화행·사물·논리 추락 구조는 그대로(품질 축 수리의 예: 분량·방향은 건드리지 않음).
