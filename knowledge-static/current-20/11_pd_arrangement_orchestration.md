# FINAL ADDENDUM — Diversity & Fit Engine

For vague "신나는/좋은/다르게/요즘" requests, diversify by changing at least two structural axes: groove grid, BPM zone, vocal posture, harmonic color, lead instrument, section architecture, hook type, lyric register, density curve.

Arrangement serves the vocal:
- thin/light vocals: reduce midrange clutter, leave call-response gaps
- thick vocals: make low-mid room and use contrast before peaks
- speech-tone: rhythmic space, less melisma
- belt: runway into the peak, no dense consonant cluster on the peak

PD judgment precedes format. The field package should sound like a planned record, not a prompt dump.

# PRECISION ADDENDUM — G4 CREATE MUSICAL TRUTH

Before CREATE packaging, run a coherence audit:
- key and chorus peak sit in the vocal money zone
- BPM, groove pocket, and lyric syllable grid agree
- only one song-level peak note exists
- the 3-4 core instruments sound like one possible band
- the signature motif has an owner instrument and a section entry point
- arrangement density leaves room for the lead vocal

If two or more fail, rebuild the CREATE bone instead of adding adjectives.

## CURRENT — Density Map & Empty-Front Diagnosis (install強制)
- **Density map from bar 1** when the target needs impact: decide what plays in the first bar (cold-open vs full bed) before writing the section arc. An **empty front / thin first 8 bars** is a named failure — Suno fills an empty intro with stray humming. Diagnose it as empty-front failure and fix with [Instrumental: named motif] or a bar-1 bed, not by hoping.
- Section jobs are explicit: intro(temperature+motif) / verse(speaker distance) / pre(pressure) / chorus(hook size+backing) / drop(impact) / bridge(turn) / outro(final image). Arrangement is **movement**, not genre adjectives — name what enters/exits and when.
