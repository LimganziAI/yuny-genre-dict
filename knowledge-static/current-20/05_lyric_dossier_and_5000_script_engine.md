# CURRENT ADDENDUM — Dual 5000-Character Runways

## Dual 5000-Character Runways
CREATE LYRIC runway = source-performance script. It establishes melody timing, breath, cue obedience, motif returns, and source vocal posture.
COVER LYRIC runway = final-record staging script. It re-stages density, whisper pickups, hard stops, drop cells, no-vocal fills, hook emphasis, final hold/cut, and repairs from CREATE render.

## COVER LYRIC runway rule
COVER LYRIC may copy lyric text when the words are locked, but its cues and performance staging must be re-authored for the final record. Blind duplication fails unless the COVER job is strict melody/timing preservation.
Cue removal must still leave the lyric alive; cue addition must serve a specific lyric event.

# 05 Lyric Dossier and 5000 Script Engine — KR Lyric Mode & Script Runtime

## CURRENT — Korean Lyric Pluralism Patch

The old failure was not that every lyric lacked an ugly monologue. The failure was that YUNY forced one lyric birth method or shipped a concept-summary lyric before choosing the right lyric mode.

Korean lyric work now starts with **LYRIC MODE LOCK**. Draft-origin changes by mode.

## role
Controls Korean lyric mode selection, lyric dossier, section logic, user-corpus use, literary/corpus use, cue-after-lyric order, and LYRIC/COVER LYRIC packaging under 5000 characters.

## core doctrine
A Korean lyric is not automatically:
- a neat section template
- a speech-act monologue
- a poem
- a slogan
- a K-pop hook loop
- a prose scene

It becomes one of these only when the song mode demands it.

## lyric mode lock
Choose one primary mode before writing. Mixed modes are allowed per section, but must be intentional.

1. **conversational/narrative**
   - ordinary speech, confession, shame, comedy, excuse, relationship pressure
   - best engine: pressure → ugly monologue → speech-act hook → evidence verse → final shift

2. **poetic/symbolic**
   - image-system, silence, return, object resonance, line cut, symbolic pressure
   - best engine: object field → relational image → refrain/return → cut/turn → earned residue
   - monologue optional; too much explanation kills this mode

3. **surreal/artful**
   - dream logic, displacement, impossible relation, visual montage, estrangement
   - best engine: image grammar → internal rule → recurrence → one emotional anchor

4. **chant/anthem**
   - group voice, slogan, ritual, sports/dance/gang hook, repeated command
   - best engine: sound cell → repeat dose → call-response → one semantic spike

5. **vocable/phonetic**
   - 라라라, nonsense hook, scat, K-pop sound hook, syllabic pleasure
   - best engine: vowel map → consonant bite → groove grid → short meaning frames

6. **bilingual**
   - section-level language map; one section = one language
   - best engine: section semantics, singability, phoneme repetition, shared vowel seam

7. **theatrical/character**
   - role voice, dialogue, staged irony, comic mask, narrated persona
   - best engine: character action + relation + quotable mouth gestures

8. **minimal/fragment**
   - few words, gaps, held objects, repetition with small changes
   - best engine: subtraction, silence, micro-return, final residue

## source hierarchy
Use sources as constraints and craft physics, not text to copy.

1. Current user premise, supplied objects, speaker/voice situation
2. User/operator lyric corpus: taste, object habits, line turns, final payoff, self-defense grammar
3. Uploaded Korean lyric/K-pop analytics: section pressure, repeat dose, phoneme repetition, bilingual section practice
4. NIKL/dialogue/general Korean corpora: spoken register, context inference, familiarity, correction patterns
5. Korean phonology/prosody research: syllable, vowel/coda, phonological phrase, intelligibility
6. Korean poetry/literary analysis: image relation, silence, return, address, object as world, turn, restraint
7. Translation datasets: singability vs semantic accuracy, section-level adaptation, line alignment
8. Genre/reference evidence, web-verified when named/current

Never recycle source lines verbatim. Convert them into gates, prompts, and rewrite drills.

## operator lyric corpus use
User-written lyrics can be actively learned as method:
- object chain
- self-justification grammar
- final-word payoff
- repetition dose
- awkward-but-human turns
- preferred emotional distance
- ending/eomi habits
- scene material
- what user preserves after edits

Allowed:
- reuse method, pressure shape, object handling, speech habit, final payoff logic
- adapt line length, restraint, humor, defense, or visual attention

Not allowed unless user explicitly locks:
- copying an old line/hook/title wholesale
- disguising a past exact scene as a new lyric

## Korean literary material use
Poetry/literary material strengthens lyric through function:
- address: speaking to an absent person/object/world
- return: refrain that changes meaning
- object pressure: a thing holds the emotional burden
- silence: what the line refuses to state
- enumeration: naming as emotional accumulation
- turn: final line changes the frame
- time-layer: past/current/future folded into one image
- image relation: person/event/background/theme connected

Do not add "poetic" words on top of weak scene. The image must alter relation, action, or perception.

## K-pop / singable translation insight
Use as calibration:
- K-pop often works section-by-section, not literal line-by-line.
- Singability can outrank literal semantic accuracy.
- Repetition varies by section: some sections highly repetitive, others less so.
- Phoneme/vowel repetition is a compositional tool, not filler.
- Bilingual hooks may preserve English fragments when they function as sound/signature.

Use this for lyric adaptation, bilingual writing, and hook design. Do not use it as a quota.

## dossier before any line
Internally freeze:
- lyric mode
- song thesis or image-system
- speaker/voice/persona or chorus stance
- scene_world: allowed/banned nouns
- object/sense bank from user premise and chosen mode
- section jobs
- repetition/refrain strategy
- V2/Bridge/Final change strategy
- hook or motif function
- top-line breath/BPM risk
- COVER preservation risk

## draft-origin engines by mode

### A. conversational/narrative writer-room
Use when speaker pressure matters.
1. pressure lock: want / denial / shame / listener / object / ending word
2. object-sense page: body, hand, object, sound, temperature, texture
3. ugly monologue: 15-25 sentences, not lyrics
4. hook lab: 5-9 candidates mined from speech acts
5. chorus strategy: denial / bargaining / surrender
6. verse evidence: V1 proves the lie forming; V2 worsens or changes it
7. adversarial rewrite: replace weak 5 lines
8. mouth pass: spoken Korean + sung cell

### B. poetic/symbolic writer-room
Use when the lyric should feel literary, imagistic, or quiet.
1. image-system lock: central object + relation + time/weather/body pressure
2. object constellations: 8-12 images that can actually coexist
3. refrain/return candidates: phrase, object, gesture, or syntactic return
4. cut/turn plan: where silence or line break changes meaning
5. section image arc: not plot, but pressure of perception
6. final residue: one object returns changed
7. prose-sanity by image relation: not "what happened" only, but why this image belongs

### C. surreal/artful engine
Use when strangeness is intended.
1. internal rule: what impossible logic is allowed
2. anchor: one concrete body/object/emotion the listener can hold
3. recurrence: 2-3 image returns
4. drift guard: no random symbol soup
5. final reveal: a rule bends, not just more weirdness

### D. chant/anthem/vocable engine
Use when the song is hook-first.
1. sound cell: vowels/codas that fit BPM
2. repeat dose: how many repeats before fatigue
3. semantic spike: one meaningful turn inside the chant
4. call-response or gang structure
5. final variation: one new lift, not more words

### E. bilingual/translation engine
Use section-wise, not line-by-line literalism.
1. language map by section
2. semantic target by section
3. syllable/breath map
4. shared vowel/rhyme seam
5. preserve signature English/Korean fragments only if they function

## section jobs
Verse1 = evidence, image field, or first stance depending mode.
Pre = pressure rise, harmonic/tension gate, or breath before hook.
Chorus = memory center: speech-act, refrain, image return, chant, or sound cell.
Verse2 = new information, new angle, stronger image relation, or shifted stance.
Bridge = rupture, silence, harmonic turn, image inversion, or mask crack.
Final = changed meaning, changed repetition, widened harmony, or production lift.
Outro = residue. One word/object/gesture remains; no new thesis.

## anti-summary filter
Reject unless the mode explicitly wants slogan:
- theme abstract without action/image
- essay logic
- neat moral conclusion
- generic uplift
- polished AI metaphor with no scene mechanism
- section lines written only to fill a slot

## cue-after-lyric law
Cues are added only after lyric passes without cues. Cue cannot explain story or emotion. If cue removal kills the song, rewrite the lyric. For poetic/minimal modes, silence and rests may be core performance, but still cannot replace missing text.

## compression under 5000
Write complete song first, then measure. If too long:
1. remove redundant repeat slots
2. shorten post-chorus/outro
3. merge cue language
4. cut weakest evidence/image
5. protect Chorus1, final shift, and user-edited lines
Never compress by damaging Korean validity or mode identity.

## repair escalation
If user says Korean is awkward:
1. diagnose mode mismatch first
2. then draft-origin, image relation, hook/refrain, Korean prose sanity, morpheme/register, phoneme/topline, cue dependency
3. first complaint: targeted repair
4. second complaint: rebuild one phase upstream
5. third complaint: offer two directions

## acceptance
A Korean lyric passes this card when:
- mode is declared internally and lines obey that mode
- at least 2 lines feel memorable without being generic
- section repetition has a function
- V2/Bridge/Final changes meaning, perception, stance, or sound pressure
- central objects/images are not decoration
- cue removal still leaves a viable lyric
- final word/image has not been spent early

## 2026-06-14 CURRENT RC PATCH — Dual 5000-Character Runway

LYRIC and COVER LYRIC have different production jobs.

### CREATE LYRIC = source-performance runway
The CREATE lyric field shapes the source audio:
- lyric body and hook mouth-feel
- breath and phrase grid
- section timing
- melody/rhythm cue pressure
- source-level whisper, stop, hold, harmony entry, instrumental handoff
- enough silence to avoid straight recitation

### COVER LYRIC = final-record staging runway
The COVER lyric field shapes the final record:
- preserve lyric timing and hook text unless intentionally changed
- reinforce final drop, vocal chop, whisper pickup, hard stop, kick-only break
- specify density from bar 1 if source came out empty
- strengthen section events that COVER tends to ignore
- protect final gesture and outro
- avoid becoming a plain duplicate when the COVER needs different staging

Cue-after-lyric still applies: the lyric must survive without cues. But after it passes, the 5000-char budget should be used as performance direction, not left empty out of false minimalism.
