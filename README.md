# YUNY Genre Dictionary

This repository holds the YUNY genre dictionary only.

- **`23_GENRE_FULLBODY/`** — per-genre reference (overview, Suno prompt keywords,
  core characteristics, reference tracks), organized by category. This is the **only**
  data the YUNY Claude system fetches live (via raw.githubusercontent.com).

The rest of the YUNY system — router, lyric engines, character voice palette,
production loop, render simulation, output contract — lives in the Claude Project
knowledge and the system instruction, not in this repository.
