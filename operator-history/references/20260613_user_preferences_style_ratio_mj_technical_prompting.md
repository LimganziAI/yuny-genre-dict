# User Preferences — Style Ratio, MJ Style, Technical Prompting

Date: 2026-06-13
Status: user-confirmed preference note for future prompt/runtime patches.

## MJ style
User preference:
- `MJ style` can be used as a 10% flavor/seasoning term.
- The purpose is to add excitement/groove taste, not to imitate an artist identity.
- User sees this as lawful flavoring / style seasoning, not a problem.

Runtime interpretation:
- Use `MJ style 10%` or `MJ-style rhythmic pocket 10%` when it helps make the track more fun, syncopated, or danceable.
- Keep it as seasoning, not main vocal identity.
- Best functions: groove pocket, rhythmic articulation, clipped phrase endings, funk/bass feel, ad-lib energy.

## Percentage blend prompts
User preference:
- Use percentage ratios when blending genres or reference lanes.
- Especially useful when the user explicitly asks for a hybrid or when the prompt needs clear proportions.
- It is not absolute science, but user feels it often works better in Suno.

Runtime interpretation:
- Use ratios for CREATE when building a hybrid bone.
- Use ratios for COVER when transforming/reshaping a source into a new style or balancing old/new elements.
- Do not overuse ratios for very narrow intimate songs unless it clarifies the sound.

## Technical prompt language
User preference:
- User generally prefers technical descriptions.
- Code/progression, instrument articulation, frequency/stereo/mix corridor, and detailed Suno-engineering language are welcome.
- User explicitly requested this kind of technical/engineering knowledge before and feels it was underused.
- For upbeat/high-energy songs, preserve audio quality using technical mix and cover language.

Runtime interpretation:
- Default serious prompts should be technically dense, not vague.
- Use codes/progressions when useful.
- Use instrument articulation instead of simple instrument names.
- Use mix/quality stack more aggressively for cover outputs.
- For dense covers, technical language such as center vocal, stereo placement, frequency corridor, ducking, low-end/high-end control can be used.
- For intimate songs, translate technical goals into gentler language unless the mix is failing.
