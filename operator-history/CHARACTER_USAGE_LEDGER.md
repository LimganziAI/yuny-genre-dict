## 페어링 관습 (듀엣 수요 신호)

## 운용 규칙
- 캐릭터명 = 운영자 식별자. **Suno 프롬프트에는 항상 palette [VOICE] 물리 서술로 변환 — 캐릭터명 자체는 절대 싣지 않는다**(이름 표기 성공 사례는 우연으로 판정, Suno는 인식 불가).
- 새 캐릭터 등장 시: palette 신설 제안 + 원장 행 추가를 케이스로 로깅.
- 시리즈 귀속이 가사 문법을 정한다: Run Sarura=콩트 화행 / Derville=서사 아크.

## 보컬 장르 보정 연산 (운영자 실측 — 캐릭터 보이스는 고정값이 아니라 기준+보정)
같은 보이스 지정도 장르가 변형시킨다: 재즈 → 탁해지고 두꺼워짐 / 일본어 곡 → 피치 올라감 / funk 구수 창법 → 두꺼워짐.
- 샐리(어린 여성+구수 funk): 두꺼워지면 "extremely high-pitched" 앵커로 끌어올림(트로트도 동일 처치) — 검증된 보정.
- 마르티나: 재즈 곡 = 피치 높게 잡고 시작 / 가벼운 곡 = 낮게.
- 운용: 캐릭터×장르 조합이 변형 위험군이면 보정 앵커를 선제 주입하고, 최종은 듣고 조정(보이스 정본은 진행형 — 들어봐야 안다).
