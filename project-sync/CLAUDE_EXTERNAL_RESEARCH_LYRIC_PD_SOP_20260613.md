## 3. Critical user preferences

### Prompt density
Use BPM, key, chord/progression, range anchor, vocal acting, melody contour, instrument articulation, section arc, motif, production stack, stereo/frequency/vocal corridor language when useful.

### Percentage ratios
Use ratios when clarifying hybrid genre balance: primary 45-70%, secondary 20-35%, seasoning 5-15%. Do not overuse for narrow intimate songs.

### MJ style
`MJ style 10%` is user-approved flavor/seasoning for groove pocket, syncopation, clipped phrase endings, pop-funk bass, rhythmic ad-lib energy, and dance-pop polish. Do not make it main vocal identity.

### Technical mix language
For upbeat/high-energy songs, use compact mix control: lead vocal center-forward, vocal corridor protected, kick/bass separated, mono low end, smooth high-mid presence, controlled air, wide mono-compatible backing, transient punch preserved.

## 6. CREATE → COVER doctrine

COVER is not a new song prompt. COVER uses the CREATE audio output as source material.

CREATE supplies bone: microgenre/scene/era, BPM/feel, key/tonal color, vocal identity, melody contour, hook shape, section arc, 3-4 core instruments, motif.

COVER supplies final record: target function, preserve map, substitution map, section events, quality stack, final/outro protection, Audio Influence matched to intent.

COVER prompt order: target anchor → preserve map → substitution/refine map → vocal identity protection → section events → quality stack → final/outro preservation.

---

## 7. Lyric-to-cue performance grid

A fixed lyric is not yet a Suno script. After lyric lock: remove cues, confirm lyric lives, choose breath architecture, add cues where lyric events call for them, protect quoted asides/held words/radio effects/final image, confirm cues do not carry story.

Renderable devices: [One-bar rest], [Sudden drop], [Band drops out], [Drums cut], [Harmony enters], [Vocal doubles only on final phrase], [Instrumental: motif returns], [Whispered] only after silence and on a short line, [Held] only on a suitable final open vowel.

## 9. Feedback response rules

- Lyrics good but prompt/COVER failed: lock lyric, repair fields.
- Prompt lazy/short/generic: PROCESS + prompt density failure, rebuild from current lock.
- Vocal tone only: do not change melody/tempo/genre/arrangement; use melody firewall.
- Cover old/mono/buried/weak: use quality rescue.
- Cues weak: rebuild cue pass from lyric events, not cue spam.
- Same problem twice: move one phase upstream.
