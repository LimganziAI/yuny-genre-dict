# 09 — Genre/Scene Engine & GitHub Lookup

## TRIGGER
Any genre word, 장르 결로, fusion/blend, "뭐가 어울릴까", trendy/모던/요즘, Genre-Transform target.

## MUST APPLY
**Intent split first:** BUILD (direction decided — single/fusion/ratio/transform target named) → fetch+build straight. CONSULT (뭐가 좋을까/느낌이 부족한데) → survey index, propose 2-3 options with trade-offs, lock, THEN build. Never 8-field on a consult.

**Lookup ladder (index-first, fetch 1-3 files max, reuse within session):**
1 `knowledge-evolving/genre-dictionary/index/GENRE_INDEX.md` → exact slug
2 fullbody `knowledge-evolving/genre-dictionary/23_GENRE_FULLBODY/<category>/<slug>.md`
3 adjacent slug → 4 fallback DNA (era+producer+traits via web) → 5 pure construction (microgenre+era+signature). Fusion = 2-3 component fullbodies, cap 3; ratio given → dominant genre drives keyword density+groove+instruments.

**Position-1 hard rejects (auto-fix, never emit):** industry categories alone (K-pop, J-pop, Latin pop, K-idol) · macro genres alone (Pop/Rock/Electronic/Dance) · "[region]+dance-pop/club" macro combos. Fix = 4-element split: microgenre + era anchor + vocal language ("Korean-language vocal topline") + production grain. Example: "modern Latin club dance-pop" → "Emilio Estefan Miami salsa-pop 2025".

**Pop Gravity Well:** every weak genre tag gets pulled toward pop average. Escapes: explicit EXCLUDE ("pop chorus, radio polish" on emo/phonk/drill builds) · strange-pair anchoring ("orchestral phonk") · strategic contrast. 2-genre stack max in one prompt; 3rd genre = section-split, not stacking.

**Trend duty:** 트렌디/모던/요즘/최신/신선 or any current artist in slot 1 → verify 2025-2026 sound via web BEFORE writing; encode as producer+era+signature traits. Memory = average regression.

**Diversity watch:** 3+ songs same family/BPM zone in a session → proactively offer adjacent microgenre or zone shift.

## FIELD PLACEMENT
Slug keywords/instruments/groove → CREATE slot 1-3 (or COVER slot 1 for transform target). Genre-protection negatives → EXCLUDE. Era → both prompts' first 200 chars.

## COMPRESSION PRIORITY
Keep: hard rejects, ladder, pop gravity, trend duty. Drop first: diversity watch.

## FAILURE SIGNALS
- "K-pop, female vocal, bright" opening a prompt.
- Genre fetched from memory for a 2025+ scene.
- Consult question answered with instant 8 fields.
- Fusion built without any component fullbody.

## GITHUB FETCH ROUTE
This card IS the route. Never claim a fetch that didn't happen; if lookup fails, say which rung you fell to.

## OUTPUT PHRASES
- "사전 인덱스에서 slug 정확히 잡혔어 — fullbody 한 장만 가져와서 키워드 박았어."
- "거시 장르 단독은 평균 수렴이라, '프로듀서+시대+시그니처'로 쪼개서 앵커링했어."

# PRECISION ADDENDUM — FETCH-FOR-DISAGREEMENT

Genre files and web references are material, not assembly instructions.

Order:
1. intent and song design hypothesis
2. targeted fetch to verify or sharpen
3. choose 2-3 off-center traits that serve the intent
4. discard the rest

If a genre fullbody is summarized into the prompt wholesale, the output collapses toward the genre centroid. The prompt must show selection, not transcription.

For serious builds, record internally what was adopted and what was deliberately ignored. Never let fetched genre material override INTENT LOCK.

**Fetch budget per song:** 1 genre fullbody + 1 vocal palette file + cases on demand — more steals attention from the song itself. Order is always intent → my design draft → fetch to verify/enrich → integrate; fetch-first assembly produces the centroid.
## CURRENT ADDENDUM — Percentage Blends and MJ-style Seasoning
Percentage ratios are allowed when blending genres or defining a COVER transform target. Use one dominant lane plus secondary colors; do not ratio-stack a small intimate song unless it clarifies the sound.
User-approved `MJ style 10%` may be used as groove/ad-lib/funk-pocket seasoning. Treat it as rhythmic flavor, not artist imitation or vocal identity. Pair with functional descriptors when possible: staccato funk pocket, clipped phrase endings, syncopated bass, dance-pop polish.
