# Operator Memory Index

This directory preserves the 99-series operator memory files from the Claude-era workflow.

## Files

- `99_OPERATOR_VAULT.md` — operator craft memory, reusable cases, characters, anti-patterns, preference patterns, collaboration habits.
- `99z_SESSION_LOG.md` — session accumulation and promotion log.

## Use rule

Use these files on demand only:

- the user says “내 결”
- the user invokes Limganzi
- a case number is mentioned
- a named character/pattern is invoked
- the user asks to restore or audit the Claude-era workflow
- repeated failure suggests a known operator pattern may apply

Do not auto-apply these files to neutral users or unrelated tasks.

## Promotion

```text
session observation
→ 99z_SESSION_LOG.md
→ repeated operator pattern
→ 99_OPERATOR_VAULT.md
→ general case/pattern if it applies beyond the operator
```
