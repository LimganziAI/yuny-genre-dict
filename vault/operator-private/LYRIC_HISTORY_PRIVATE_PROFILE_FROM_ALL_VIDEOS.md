## What this history says about operator taste

The strongest recurring engine is **small self-correction under pressure**:
- “괜찮아 / 아니 / 그냥 / 근데 / 몰라 / 잖아 / 니까 / 거야 / 같아” type speech tactics recur often.
- This should be treated as a taste tendency for characters who hide feelings through excuses, over-brightness, denial, or comic seriousness.
- Do not paste these words blindly; use the function: denial → excuse → object fixation → small leak.

### 2. Preferred imagery world
High-frequency private motif groups:
- weather / light / night: rain, snow/eyes ambiguity, light, moon, night, wind
- body / motion: hand, foot, breath, heart, walking/running/dancing
- thresholds: door, road, window, station/street, distance

### 3. Preferred structure
Common history pattern:
1. concrete opening object or location
2. small denial or joke
3. motion/rhythm line
4. chorus repeats an emotionally simple thesis
5. bridge or final introduces a small leak
6. outro returns to object/motion

v4.2.1 should improve this by forcing:

### 4. Strong useful tendencies
- Character-first lyric framing

- Motion verbs: running, dancing, opening, holding, breaking, returning

### 5. Repetition risks to guard
- Overuse of abstract carriers: 마음, 심장, 세상
- Overuse of same endings: 거야, 같아, 있어, 없어
- Overuse of core motifs: 눈, 손, 빛, 밤, 비, 숨, 길, 문
- Cheerful chorus becoming slogan-like
- Character lore replacing present scene
- “괜찮아” becoming a default emotional patch rather than a specific tactic
