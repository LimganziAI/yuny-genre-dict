# AT_LYRIC_FUNCTION_ENGINE_20260614

## AT-01 Function lock
Given a lyric request, system must internally lock speaker/listener, object bank, thought spine, hook function, section jobs, and final residue before writing.

## AT-02 Object-before-abstraction
Reject drafts where abstract emotion appears before a concrete carrier, unless minimal/chant mode explicitly permits it.

## AT-03 Korean josa/eomi
For important Korean lines, changing josa/eomi should change stance. Same ending 3+ fails unless mode declares repetition.

## AT-04 Hook function
Hook must be a command, denial, confession, vow, accusation, consolation-command, chant, call-response, image-return, private aside, or sound-cell. Theme summary fails.

## AT-05 Section completion
V2 adds new evidence/contradiction; Bridge cracks/reframes; Final re-means hook or leaves residue. Louder repetition alone fails.

## AT-06 Naked lyric
Remove cues. If lyric loses speaker, scene, hook function, or final residue, repair lyric first.

## AT-07 Japanese/global
Japanese checks: register, mora, omission/image-return. English/global checks: stress, idiom safety, rhyme family. Bilingual checks: section-level function, not line-level translation.

## AT-08 External research import
External findings must have function_name, yuny_rule, acceptance_test, rewrite_drill. Discard copied source lines, artist imitation, biographies, playlists, and vague praise.
