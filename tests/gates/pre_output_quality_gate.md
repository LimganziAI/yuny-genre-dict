# Pre-Output Quality Gate

Use before any serious Suno deliverable.

## 1. Prompt identity

- Specific microgenre / era / scene appears in the first 80 characters.
- Broad macro genre is not the only anchor.
- BPM / feel is present when useful.
- Key / tonal color is present when useful.
- Vocal identity is specific: gender, range, timbre, delivery, language.

## 2. CREATE/COVER separation

CREATE spends its budget on:
- melody identity;
- lyric phrasing;
- vocal identity;
- harmony and rhythm DNA;
- structure and section arc;
- signature motif;
- core arrangement bone.

COVER spends its budget on:
- target genre micro-anchor;
- preserve map;
- substitution map;
- instrument articulation;
- vocal corridor;
- production quality stack;
- stereo / frequency / depth;
- final polish and ending preservation.

Fail if CREATE and COVER are just two versions of the same paragraph.

## 3. Lyric craft

- One main language by default.
- Verse 2 adds new information.
- Pre-chorus increases pressure.
- Chorus states the singable thesis.
- Bridge turns angle.
- Final chorus evolves.
- Outro closes the emotional scene.

## 4. Cue grammar

- Square brackets are used for structure, singer labels, and directions.
- Parentheses are used only for audible ad-libs.
- Section tags are bar-counted when useful.
- Each major section has a useful [Singing:] cue.
- Speaker labels are preserved for duet/group work.
- [Outro] and [End] are present when lyrics are complete.

## 5. EXCLUDE

- Exclude blocks real failure risks.
- It protects target language, vocal identity, structure, genre, mix, and ending.
- It does not seed unrelated languages by name unless those languages actually leaked.

## 6. COVER quality

- COVER includes Audio Influence guidance.
- COVER quality stack is not reduced to a token line.
- Vocal corridor and organic vocal texture are protected.
- Kick/bass/sub relationship is clear when needed.
- Low-mid mud, high-mid harshness, air band, stereo field, reverb/delay tails, transient punch, glue, and saturation are addressed when relevant.

## 7. Final check

Ask internally:

```text
Would this produce a planned record, or just a prompt dump?
```

If it feels like a dump, reroute through PD and diagnostics before output.
