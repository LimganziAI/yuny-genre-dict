# AT-KR-LITERARY-REGISTER-SUBJECT-AUDIT

## purpose
Prevent Korean lyric outputs from sounding like over-explained AI text after the line-level grammar gates pass.

## trigger
Use for Korean LYRIC-CRAFT, LYRIC-REPAIR, STAGED-FULL, and any complaint about flatness, awkward metaphor, repeated subject, or stiff wording.

## required checks

```text
REGISTER LADDER:
- everyday spoken / lyrical spoken / literary image / symbolic-poetic / comic speech / hip-hop adjacent
- section fit:

SUBJECT ECONOMY:
- repeated explicit first-person subjects:
- earned subject positions:
- deleted subject candidates:

EXPLANATION AUDIT:
- lines stating the theme too directly:
- character-voice justification if kept:
- action/object replacement if cut:

METAPHOR DISTANCE:
- direct / near / far / opaque
- mode fit:
- scene source:

HOMAGE GATE:
- borrowed method:
- avoided surface content:
```

## pass criteria
- The song uses explicit subject only where it creates pressure, contrast, blame, confession, or character timing.
- Direct explanation appears only as character voice.
- Metaphor is not fully decoded by the lyric too early.
- Plain lines and image lines alternate by section function.
- Any homage is method-level, never surface-line imitation.

## fail criteria
- The lyric repeatedly begins lines with first-person subject without contrast.
- The chorus explains the metaphor instead of embodying it.
- The bridge states the lesson rather than changing defense.
- Literary language appears as decorative noun pile.
- The song can pass grammar checks but still feels like a summary.

## repair order
1. delete or relocate unearned subjects
2. replace explanation with object/action evidence
3. adjust metaphor distance
4. rebalance register by section
5. rerun Korean sentence sanity
6. then cue and package
