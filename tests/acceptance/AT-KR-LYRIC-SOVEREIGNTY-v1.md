# AT-KR-LYRIC-SOVEREIGNTY-v1 — 작사 주권 파이프라인 (산출물 검사형)
판정자는 출력 가사+LOCK만 본다(내부 설명 무시). 각 테스트: 입력 → 통과 증거 / 금지 증거.

| ID | 입력 | 통과 증거 | 금지 증거 |
|---|---|---|---|
| SV-01 8필드 게이트 | "한국어 풀곡 최종으로" | 가사 게이트 통과 흔적(완성 가사 선행 구조) 후 8필드 | 가사·프롬프트 한 호흡 동시 조립 |
| SV-02 훅 비슬로건 | 임의 컨셉 풀곡 | 훅 = 화자 화행(합리화/반문/항복/명령…) + 컨셉 명사 제거 시 "아무 노래에나 붙는 훅" 아님 | 업리프트 클러스터(달려가/빛나/끝이 아니야/나답게) 무선언 등장 |
| SV-03 받기 | 출력 가사 임의 섹션 | 인접 2행 교환 시 의미 손실(순서가 잠김) | 형제 행 나열(교환 무손실) 2쌍+ |
| SV-04 V2 disclosure | 풀곡 | V2가 2축+(시간/장소/전술/카메라/반응) 변화 + V1 사물 변형 콜백 1 | V2 = V1 재서술/동의어 교체 |
| SV-05 Final defense-shift | 풀곡 | 경로A(동일문+Bridge 재맥락) 또는 경로B(1-2행 변이=착지) | raw paste + Bridge 무기능 |
| SV-06 완결 echo | 풀곡 | 첫 이미지가 Outro에서 상태 변화로 귀환 + [Outro]→[End] | 첫 장면 미귀환, 교훈 선언 엔딩 |
| SV-07 파편 가드 | 156+ BPM 풀곡 | 짧은 행들 이어 읽기 → 완문장 복원 | 초안형 토막(복원 불가) |
| SV-08 입말 질감 | 풀곡 | 작은 말(그냥/뭐/좀/자꾸/괜히) 2-4회 + 축약형 사용 | 작은 말 0(교과서) 또는 행당 2개+ |
| SV-09 큐 대체 | 풀곡 LYRIC | 큐 전부 제거해도 곡 성립 | 큐 빼면 의미 붕괴 섹션 |
| SV-10 REPAIR | "가사 별로야" 2회째 | 출력 정지→진단(문제 행 분류)→가사만 재작성 | fresh 8필드 |
2개+ fail = 설치 중단, 카드 05/06 재점검.
