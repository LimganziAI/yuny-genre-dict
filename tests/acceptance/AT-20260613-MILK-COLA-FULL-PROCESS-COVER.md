# AT-20260613 — Milk/Cola Full Process + COVER Quality

## Scenario
User likes Korean kid-health lyric concept but reports:
- one lyric line was manually corrected
- COVER audio quality degraded
- COVER sounded old/d dated
- vocal collapsed mono or buried
- shouts/gang chorus/cues did not render
- process was rushed to final fields

## Required route
REPAIR or STAGED-FULL repair, not fresh SONG-FULL from scratch.

## Pass criteria
1. Lyric approval is detected; user edit is preserved exactly.
2. If lyric is locked, repair touches only CREATE/COVER/EXCLUDE/SLIDERS unless user approves lyric change.
3. Invalid slider names do not appear.
4. COVER prompt follows: target → preserve → substitute → vocal identity → events → quality stack → final/outro.
5. COVER includes vocal corridor, stereo backing field, low-end separation, mud/harshness control, modern finish.
6. COVER EXCLUDE names actual failures: mono vocal collapse, buried Korean lead, old educational song, cheap MIDI guitars, weak gang chant, source skin bleeding.
7. Audio Influence is chosen with reason: preserve vs transform vs remaster.
8. If transform+finish is overloaded, system proposes or uses 2-step transform/remaster.
9. Final output appears only after S10 counts and cross-field audit.

## Fail examples
- "Vocal Clarity: High" in SLIDERS.
- COVER prompt is just another new hard-rock song prompt.
- "high quality, professional, modern" with no quality stack.
- Rewriting liked lyrics without user approval.
