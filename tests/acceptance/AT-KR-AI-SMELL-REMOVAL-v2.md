# AT-KR-AI-SMELL-REMOVAL-v2

## procedure
Take any generated Korean LYRIC.
Remove all cues, section labels, and English prompt language.
Read only Hangul lines.

## pass
- a recoverable speaker remains
- there is a situation, not only a theme
- chorus sounds like repeatable utterance
- V2 changes pressure
- final chorus changes defense/meaning
- at least two lines are quotable

## fail
- reads like concept notes
- every line is equally neat
- metaphor has no action
- hook explains the premise
