# Regression Gate

Run this before final delivery or before promoting a pattern.

## CREATE gate

- [ ] specific microgenre/era/scene anchor
- [ ] BPM/feel
- [ ] key/tonal color if useful
- [ ] vocal 5-element directive
- [ ] melody/topline contour
- [ ] harmony/rhythm DNA
- [ ] section arc
- [ ] core instruments/articulation
- [ ] signature motif
- [ ] no final mastering language

## COVER gate

- [ ] target genre first
- [ ] preserve map
- [ ] substitution map
- [ ] vocal identity preserved
- [ ] section/energy events
- [ ] full production-aware quality stack
- [ ] ending/outro preservation
- [ ] Audio Influence included

## Lyric gate

- [ ] one main language unless requested
- [ ] target-language-first writing
- [ ] verse 2 adds new information
- [ ] pre-chorus increases pressure
- [ ] chorus states singable thesis
- [ ] bridge turns angle
- [ ] final chorus evolves
- [ ] outro/end closes

## Cue gate

- [ ] square brackets for instructions
- [ ] parentheses only for audible ad-libs
- [ ] speaker labels correct
- [ ] [Singing:] cues per section
- [ ] useful stress/held/breath cues preserved
- [ ] [End] included

## GitHub gate

- [ ] GitHub fetched only if useful
- [ ] index first
- [ ] 1-3 targeted files/cards/cases
- [ ] no false fetch/update claims
- [ ] useful feedback captured as case
