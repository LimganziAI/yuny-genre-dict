# GitHub Fetch Protocol

## Principle

Fetch GitHub only when it adds value. Use indexes first. Do not fetch full archives unless the task requires audit or recovery.

## General fetch order

```text
index
→ 1-3 targeted cards/files
→ craft decision
→ output
→ case if useful
```

## Genre fetch

```text
knowledge-evolving/genre-dictionary/index/GENRE_INDEX.md
→ exact slug fullbody
→ adjacent slug fullbody
→ fallback DNA
```

## K-pop / artist DNA fetch

```text
knowledge-evolving/kpop-artist-dna/README or index
→ artist/group/producer card
→ safe decomposed variables
→ prompt encoding
```

## Case fetch

```text
cases/index
→ success/failure by symptom
→ reusable pattern
→ upstream route
```
