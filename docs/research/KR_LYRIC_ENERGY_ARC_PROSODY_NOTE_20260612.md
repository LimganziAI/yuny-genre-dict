# KR LYRIC ENERGY ARC PROSODY NOTE — 20260612

## goal
Add song-level intensity, line-ending cadence, and cue-feedback checks to Korean lyric runtime.

## core additions
- Map intensity before final lyric pass.
- Treat intensity as directness, object proximity, line length, repetition, melodic peak, harmony lift, cue event, or vocal distance.
- Check Korean line endings as hard stop, soft landing, open tail, unfinished tail, spoken turn, or chant anchor.
- After cue placement, revise only the line endings, vowels, breath length, or intensity points that no longer fit performance.
- Then reread the lyric without cues.

## section arc
Opening lands the scene. V1 shows behavior. Pre narrows pressure. Chorus holds hook identity. V2 adds angle. Bridge changes defense or strips the track. Final changes meaning or energy. Outro leaves object residue.

## pass rule
A lyric must distribute expression strength across the song. It should not stay at one emotional temperature from first line to outro.
