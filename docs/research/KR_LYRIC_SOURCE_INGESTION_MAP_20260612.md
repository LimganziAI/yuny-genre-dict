# KR_LYRIC_SOURCE_INGESTION_MAP_20260612

## purpose
This map records how uploaded source types are converted into runtime gates. It is not a bibliography for citation; it is an engineering map.

## Korean phonology / pronunciation
- 4.+2235932.pdf: Korean syllabification and prosodic phonology. Runtime use: line breaks and lyric phrases follow phonological/breath pressure, not only written syntax.
- 25_0103.pdf: Korean pronunciation education. Runtime use: intelligibility and mouthability are communication gates.
- 26347.pdf: Korean phoneme vocal features and popular music lyrics. Runtime use: vowel/coda placement and consonant bite are lyric-writing tools.
- 0012003141.pdf: Korean syllable frequency in everyday dialogue. Runtime use: conversational hooks prefer familiar syllable shapes unless character/genre requires stiffness.

## literature / poetry / culture
- 200000256201_20260612221017.pdf: Literature in Korean education. Runtime use: person/event/background/theme/cultural vocabulary must connect; image must live in scene.
- 20181119193816146585.pdf: Korean modern literary works selection. Runtime use: concrete literary experience and context matter more than abstract literary talk.
- ART001472484.pdf: Song and poem intertextuality. Runtime use: lyric must be language and sound at once; music cannot rescue dead text.

## AI / generation / prompt
- Fine-Tuning and Prompt Tuning of the Gemma2 Model...pdf: Korean-domain adaptation and prompt tuning. Runtime use: language/domain specialization needs both data and operational prompts.
- N0870320006.pdf: AI webnovel creation platform analysis. Runtime use: AI needs setting/social code/genre scaffolds; otherwise outputs flatten.
- 200000499755_20260612220149.pdf: GAN automatic composition. Runtime use: automatic music generation evaluation needs both quantitative and qualitative gates.

## corpora / code / datasets
- videos_basic_stats.csv, videos_titles_lyrics.csv: user/team lyric behavior and recent operator corpus. Runtime use: scene-specific line pressure and ending/repeat baseline.
- kpop-lyrics-analytics-main.zip, Kpop-lyric-datasets-main.zip: K-pop structure and repeat calibration. Runtime use: section/repeat calibration, not mimicry.
- lyrics-database-master.zip, lt_dataset-main.zip: broad lyric/translation resources. Runtime use: lyric form awareness and translationese risk.
- korean-parallel-corpora-master.zip: translation/parallel corpus. Runtime use: translationese warnings; do not let English logic drive Korean lyric.
- KoGPT2-FineTuning-master.zip, Korean lyric generator repos: AI-generation scaffolding examples. Runtime use: model outputs need gates, not trust.
- korean-hate-speech-master.zip: toxicity/social-language dataset. Runtime use only for safety/register awareness when relevant, not lyric style.

## non-use rule
Raw source lyrics and copyrighted text are not copied into generated lyrics. Only statistical tendencies, gates, and abstract rules are promoted.
