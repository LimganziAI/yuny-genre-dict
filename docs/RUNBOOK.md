# RUNBOOK — 최소 실행 절차 (강하고 짧게)

## SERIOUS FULL SONG ("최종/제대로/한 번에")
LOCK 동결+에코 1회(장면 허용/금지 명사·화자·보컬·장르·가사 모드·보존 대상) → 장르 fullbody 1 + 팔레트 [VOICE] 1 fetch(off-center 채택) → 화자 카드+샘플 10줄 → 스파인 5-7화살 → **후렴 plain draft 먼저** → STOP-1(G1+G2) → 전곡 → STOP-2(G3) → 압축+숨김 → STOP-C(재독) → 큐 패스(위계 준수+대체 테스트) → CREATE(G4: 머니존·그루브·피크 1·한 밴드·모티프 소유) → COVER(G5: 보존/치환/AI 무모순) → EXCLUDE/슬라이더 → 실측 → 8필드. 표면 = 에코 1회 + 8필드.

## SKETCH ("빨리/대충 한번")
LOCK 약식(에코 생략 가능, 가정 1줄) → 게이트 압축 실행(소거 아님) → Tight 프롬프트 → 1턴 8필드.

## LYRIC REPAIR ("가사 어색해/별로야")
새 8필드 금지. 문제 행 분류(화자/어미/흐름/이해/모드 위반) → 화자·스파인부터 재설계 → 가사만 재출력. 2회째 불만 = 전면 정지 → 진단 4행(타깃/원인/전략 1/바꿀 필드) 선행.

## COVER TRANSFORM ("장르 바꿔/멜로디 유지")
모드 a(refine)/b(transform) 판정 → G5 삼각 작성(보존 맵·치환 맵·AI 숫자 — 침묵 0) → 신곡 묘사 토큰 박리 → 음질 스택 → b모드면 베이스 음질은 CREATE 책임.

## REFERENCE REQUEST ("OO 결로")
시간 앵커(그 곡·그 시기) → 웹 검증(연도/BPM/프로듀서) → feature sheet 8슬롯 → 새 재료로 재구축 → 필드는 기능 디스크립터만.

## VOCAL FIT ("어떤 목소리/창법이 맞아?")
8필드 금지. posture 2-3안 + 캐스케이드(키→피크→음절 밀도→레지스터→편곡 밀도) + 추천 1 → 선택 후 SONG 진입.

## 화났을 때 / "또 이상해"
사과문 대신 진단 산출물 → 초안 폐기 선언(LOCK 제외) → 상류 재설계 1회 정조준. 재뽑기 양산 금지. 3회째 = 방향 2안 제시.

## 새 창 첫 메시지 (복붙)
```
이 곡은 STAGED다. INTENT LOCK(장면 허용/금지 명사·화자·보컬·장르·가사 모드·보존 대상)을 3-5줄로 에코하고 1회만 확인받아라.
보컬 시드는 [VOICE]만. 스파인→후렴 먼저→STOP-1→전곡→STOP-2→압축→STOP-C→큐(위계+대체 테스트)→CREATE(G4)→COVER(G5)→8필드.
게이트는 산출물+LOCK만 보고 행을 인용해 판정, PASS여도 최약 2행 내부 수선. 같은 게이트 2연속 fail이면 한 단계 위로.
게이트 트래픽 보고 금지 — 내가 보는 건 에코 1회와 8필드뿐.
```
