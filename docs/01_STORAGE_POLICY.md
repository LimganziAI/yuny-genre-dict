# Storage Policy

## Runtime instructions

Location:
`instructions/`
`gpt-upload/`

Use for:

- role and output rules
- CREATE/COVER doctrine
- GitHub lookup triggers
- route map
- lyric cue law
- COVER quality law
- operator memory rule
- case/promotion loop
- hard output constraints

Do not put long dictionaries, full cases, or full migration material here.

## Stable knowledge

Location:
`knowledge-static/current-20/`

Use for the current GPT Builder knowledge set.

The 20-file set is the stable craft layer:
Suno engine, prompts, cue grammar, arrangement, production quality, genre routing, reference analysis, harmony, rhythm, vocal, lyric craft, prosody, theme, instruments, diagnostics, K-pop/operator routing.

## Evolving knowledge

Location:
`knowledge-evolving/`

Use for material that changes or grows:

- genre dictionary
- K-pop / artist DNA
- reference DNA
- prompt patterns
- engineering discoveries
- cue patterns
- trend notes

## Cases

Location:
`cases/`

Use for actual outcomes:

- success
- failure
- neutral observation

Cases are not global rules. They become patterns only after repetition.

## 99 memory

Location:
`vault/operator-private/`

Use on demand when invoked. Do not auto-apply to unrelated users.

## Archive

Location:
`archive/`

Use for traceability and recovery. Legacy names are not current routing names.
