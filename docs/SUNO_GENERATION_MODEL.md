# Suno 생성 모델 — 시스템 설계의 물리 기반
라벨 규율: [공식]=Suno 문서 / [인터뷰]=창업자 공개 발언 / [연구]=공개 논문·업계 표준 / [가설]=운영 가설 / [커뮤]=커뮤니티 관찰. 내부 구조 단정 금지.

## 1. 계보와 표준 스택
Suno는 Bark(오디오를 토큰화해 자기지도 학습한 트랜스포머)에서 출발했고, "오디오의 토큰화"가 핵심 혁신이었다 [인터뷰]. 텍스트→음악 모델의 업계 표준 스택: **텍스트 인코더 → 토큰 시퀀스 모델(자기회귀 트랜스포머 또는 디퓨전) → 뉴럴 코덱 디코더**(오디오↔이산 토큰 압축·복원) [연구]. Suno는 상세 아키텍처 미공개 — 이하 함의는 전부 이 스택을 전제한 [연구-가설]이다.

## 2. 여섯 함의 → 시스템 구조
| 함의 | 시스템 구조로 |
|---|---|
| 생성 = 조건부 확률 시퀀스. 프롬프트는 명령이 아니라 분포를 기울이는 조건 | 1렌더 실패 ≠ 프롬프트 결함 — 2-3 재렌더 후 판정 (card 17 triage) |
| **가사만 거의 그대로 실현** — 보컬 토큰의 내용을 직접 정렬하는 유일한 입력 | 가사 최강 게이트 + 가사 별도 공정(LYRIC IS ITS OWN PROCESS) + 가사 실패에 랜덤 알리바이 금지 |
| 부정문은 조건 공간에서 약함 — 전용 필드만 빼기 방향으로 작동 [공식+커뮤] | positive = Style, 부정은 전부 EXCLUDE (card 16) |
| COVER = 오디오 조건 재렌더. 오디오 조건은 멜로디·구조·보컬 퍼포먼스(의미층) 보존이 우세 [공식 Covers 정의 정합]; Audio Influence = 오디오↔텍스트 조건 비율 [가설] | preserve는 오디오+숫자가 지키고, 변화는 텍스트가 만든다. **텍스트가 침묵한 영역은 타깃 장르 평균으로 채워진다** → preserve/substitution map 침묵 금지 (card 14 G5) |
| 2-pass 비대칭: CREATE가 못 만든 뼈는 COVER가 못 살린다; COVER가 망친 스킨은 CREATE 무손 수리 가능 | 진단 1차 질문 = "어느 패스의 결함인가" (card 17) |
| 토큰 모델은 학습 분포의 중심으로 끌린다 | 마이크로장르 앵커·EXCLUDE 차별화·삭제 패스가 작동하는 이유 — 그리고 fetch-first 조립이 centroid가 되는 이유 (card 09 off-center) |

## 3. CREATE/COVER 조건 구조 (t2i→i2i 비유는 80% 정확)
- **CREATE:** 텍스트(스타일 ≤1000자, 분포 기울임) + 가사 ≤5000자(내용 정렬 — 단어·발음·구조·큐가 직접 실현) + EXCLUDE(빼기) + 슬라이더 → 1차 곡.
- **COVER:** **1차 곡 오디오가 추가 조건**으로 들어가고(Audio Influence = 그 무게), 텍스트는 스킨·장르 전환·피니시를 만든다. 이미지 i2i와의 차이: 보존 대상이 픽셀 구도가 아니라 멜로디·구조·보컬 퍼포먼스라는 점.
- 운용 결론: 지킬 것은 preserve map에, 바꿀 것은 substitution map에, 음질은 quality stack에 — **셋 중 어디에도 없는 요소는 보호되지 않는다.**

## 4. 필드별 작동 가능성 요약
| 입력 | 작동 방식 (추정) | 운용 규칙 |
|---|---|---|
| Style 프롬프트 | 임베딩 조건 — 앞쪽 토큰 가중 높음 [커뮤] | Position 1 = 마이크로장르+era 앵커; 태그 덤프 금지(삭제 패스) |
| LYRIC 5000자 | 내용 정렬 — 텍스트가 곧 노래 | 게이트 최상위; [ ] 큐는 렌더 가능 device만 |
| EXCLUDE | 분포에서 빼기 [공식+커뮤] | 부정 전속 필드; 차별화 엔진(과잉은 음질 저하) |
| Weirdness | 탐색 온도 유사 [가설] | 40-50 안정 / 70+ 실험 |
| Style Influence | 텍스트 조건 비중 [가설] | 프롬프트 주도 70-85 / 가사 주도 40-50 |
| Audio Influence (COVER) | 오디오 조건 비중 [가설] | 멜로디 보존 60-75(기본 65) / 재해석 45-60 / DNA만 25-40 |

## 5. 검증 큐
모델 메이저 업데이트 시 [커뮤]·[가설] 항목 전수 재검(전례: inline 부정 파싱 변화). Suno v5.5의 My Taste는 과거 생성을 학습 → 구식 사운드 강화 리스크 — era 점프 곡에서는 EXCLUDE로 상쇄. 세부는 suno-render-behavior/ 참조.
