# Source-to-Runtime Mapping — v4.5 RC

## Source classes

### 1. User/team lyric corpus
Runtime use:
- taste profile
- repeated object families
- preferred hook behaviors
- ending image tendencies
- successful Suno prompt lineage
- operator-specific "결"

Forbidden:
- copying old hooks as new hooks unless the user explicitly requests self-reference.

### 2. Professional lyric / K-pop analytics
Runtime use:
- line/section/repetition priors
- hook dose and phoneme recurrence
- bilingual section logic
- section-wise meaning preservation over line-wise literalism
- chorus and post-chorus pressure

Forbidden:
- lyric phrase copying.

### 3. Poetry / literature / young poets / lectures
Runtime use:
- image as event, not decoration
- silence, cut, residue, return
- poetic/symbolic mode calibration
- speaker/person/background/theme integration
- metaphoric distance and object transformation

Important correction:
Poetic lyric mode does not always require ugly monologue. It may begin from image pressure, cut, object return, breath, and silence. The system must choose mode first.

### 4. NIKL / dialogue / everyday Korean corpora
Runtime use:
- josa/eomi acting
- subject deletion
- repair words
- spoken register
- translationese detection
- Korean sentence sanity

Forbidden:
- corpus sentence pasting.

### 5. Korean writing / correction / parallel corpora
Runtime use:
- translationese repair
- style-conversion drills
- prose-to-lyric compression
- formal vs spoken register routing

### 6. Music composition / MIDI / theory skills
Runtime use:
- key/chord/motif/contour coherence
- peak-note and vocal money zone checks
- instrument role and arrangement density
- topline singability

### 7. Suno metadata / render history
Runtime use:
- CREATE/COVER lineage
- prompt density evidence
- Audio Influence A/B notes
- cover failure diagnostics
- quality-stack refinement

### 8. Web/current references
Runtime use:
- current trend verification
- release/BPM/key/producer confirmation
- up-to-date model/platform behavior
- public docs

Rule:
Current/named references require web verification before writing. Memory-only current trend work fails.

## Runtime destination
Every source must land in one of:
- 05/06 lyric gates
- 08 cue/vocal pass
- 11/12/13 PD/topline/instrument pass
- 14/15/16 COVER quality and control pass
- 17 diagnostics
- 18 case/promotion loop
- 20 acceptance tests
- GitHub support docs/tests/tools
