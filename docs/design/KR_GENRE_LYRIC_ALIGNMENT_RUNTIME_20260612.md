## genre-to-lyric tendencies

### alternative-rnb / rnb / neo-soul
Lyric register: lyrical spoken, intimate, body/object detail.
Hook type: sentence contradiction or small admission.
Repeat dose: low-to-medium.
Line behavior: medium lines, breath-aware, soft endings.
Risk: overexplaining the metaphor.

### chamber-pop / baroque-pop / singer-songwriter
Lyric register: literary image plus plain speech.
Hook type: object-memory sentence.
Repeat dose: low.
Line behavior: longer thought lines, strong outro residue.
Risk: too much beautiful noun naming.

### k-pop / electropop / dance-pop adjacent
Lyric register: direct hook plus verse detail.
Hook type: chant, sentence hook, phonetic cell, or slogan.
Repeat dose: medium-to-high.
Line behavior: shorter cells, open vowels, strong section contrast.
Risk: generic slogan, English-phonetic drift, idol macro prompt.

### indie-rock / pop-punk / emo
Lyric register: direct spoken, attitude, concrete contradiction.
Hook type: shouted sentence or wound-as-joke.
Repeat dose: medium.
Line behavior: blunt endings and forward motion.
Risk: melodramatic stock pain words.

### hip-hop adjacent / jazz-rap / trap-soul
Lyric register: verb force, internal rhythm, but sung-mode guard when requested.
Hook type: attitude phrase, self-defense, repeated internal rhyme.
Repeat dose: medium.
Line behavior: dense consonants only if delivery can hold them.
Risk: verse drifts into rap when song should stay sung.

### ballad / soundtrack / quiet-storm
Lyric register: plain emotional clarity with one durable object.
Hook type: address or direct admission, softened by scene.
Repeat dose: low-to-medium.
Line behavior: longer breath, open endings, clear vowels.
Risk: essay summary and melodramatic string logic.

### house / uk-garage / amapiano / dance lanes
Lyric register: minimal, rhythmic, social, body-oriented.
Hook type: sound-cell or short speech act.
Repeat dose: high by design.
Line behavior: short cells, vowel bounce, fewer narrative details.
Risk: narrative overload.

## method
Pick one dominant genre slug and one lyric-register lane. If using fusion, the dominant genre drives lyric density and hook type; the second genre modifies sound or section contrast only.

## full-package gate
A strong 8-field package must show:
- CREATE bone and lyric register agree
- vocal posture and ending cadence agree
- groove pocket and syllable density agree
- hook type and repeat dose agree
- COVER preserves or transforms the right layer
- EXCLUDE blocks drift created by the chosen genre lane
