# 99 Memory Import Policy

## Purpose

The 99-series files preserve personal workflow memory, operator taste, working cases, characters, and accumulated session learning.

## Files

- `99_OPERATOR_VAULT.md`
- `99z_SESSION_LOG.md`

## Use

Use on demand only when invoked by:

- “내 결”
- Limganzi
- case number
- named character
- named operator pattern
- request to restore Claude-era process
- system audit involving migration or operator workflow

## Do not

- Do not auto-apply to unrelated users.
- Do not turn one operator preference into a general rule.
- Do not move full 99 files into GPT Instructions.
- Do not paste long 99 excerpts into normal Suno outputs.

## Promotion

```text
session note
→ 99z log
→ repeated operator pattern
→ 99 vault
→ general case/pattern only if useful beyond operator
→ knowledge patch only after cross-context validation
```
