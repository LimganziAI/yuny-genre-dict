1. INTENT LOCK 동결+에코: 장면=여름 아침 혼자 러닝(금지: 학교·교문·매점·친구·리본) / 화자=차분한 척하는 자기관리형 / 금지어 12종 / 관문명사 허용: 컵·얼음·빨대·유리컵 / 엔딩 "달다…" → [End].
2. 팔레트 fetch: nerh.md **[VOICE]만** — female mid-high piercing clean, chest-mix belt, thin-to-medium, open-throat release. [LORE] 미적재.
3. 사고-스파인 6화살: 달린다→생각 밀어낸다→단맛 침입→갈증 합리화→감각 구체화→들킨다. 섹션 매핑 V1=①② / Pre=③ / Cho=④ / V2=③④ / Br=⑤ / Final=⑥.
4. **후렴 plain draft 먼저** — 자기합리화 완문장("목말라서 그런 거야, 이건 그냥 물 대신이야" 결). → STOP1: 샘플 지문 대조+화살표 ④ 적재 확인, 행 인용 판정. (1차 fail 예시: "여름이 먼저 불렀어" → 의인화 금지 위반, 그 행 폐기 후 재작성.)
5. 전곡 draft → STOP2: 매 후렴 관문명사 ≥1 출현 / 암호 행 0 / 첫 청취자 한 줄 요약 가능 확인.
6. 압축(158BPM): 조사·수식어부터 삭감, 한 생각 2-3행 걸치기 → STOP-C 재독.

8. CREATE(G4): 키=피크가 [VOICE] 머니존에 / 크로매틱 모티프 소유자=guitar-synth unison, 자리=Pre 상승 / 밴드 실재성 / 삭제 패스. COVER(G5): 보존=톱라인·clean piercing 정체성 / 치환=polished hard-rock dance anthem 스킨, "drive on drums/guitars only" / AI 65 / 스택 6줄. → 실측 → 8필드.
