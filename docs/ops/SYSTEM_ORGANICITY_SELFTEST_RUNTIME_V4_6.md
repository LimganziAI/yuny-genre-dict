# SYSTEM ORGANICITY SELFTEST RUNTIME — V4.6

A YUNY package is not mature merely because the files exist.
It must behave like one production chain.

## Chain checks
1. Router: system tasks never emit song fields; lyric lock stays locked.
2. Intent lock: lyric mode + scene nouns + vocal physics + genre direction + preserve targets + bans are present.
3. Lyric diversity: conversational, poetic/symbolic, chant, vocable, bilingual, theatrical, minimal/fragment modes alter gates.
4. PD: vocal fit, key, peak note, BPM grid, groove, harmony, instrument zones, motif ownership cohere.
5. CREATE: bone only; 9 items present; no mix/master language.
6. COVER: target anchor → preserve map → substitution map → vocal identity → section events → quality stack → final/outro.
7. Cue pass: cues respond to lyric events, sit between affected lines, and do not narrate plot.
8. EXCLUDE/sliders: actual failure classes; CREATE AI = —; COVER AI numeric and intent-synced.
9. Diagnostics: same complaint escalates upstream; liked lyric is locked.
10. Packaging: exactly 3 top-level folders, 20 cards, mirrored project-sync, tests/tools/docs present.
