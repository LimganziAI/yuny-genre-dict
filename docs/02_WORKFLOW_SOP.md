# Workflow SOP

## 1. Normal new song

```text
classify goal
→ decide language, genre family, vocal, scene
→ 02 Suno engine
→ 05 Arrangement Director
→ 07 genre / GitHub if exact genre needed
→ lyric language file + 16 prosody + 17 theme
→ 03 cue grammar
→ 04 output template
→ 8-field CREATE/COVER
```

## 2. One-shot

Use one-shot only for sketches, exploration, or explicit request.

Even in one-shot, run compact internal gate:

```text
microgenre anchor
→ vocal 5-element
→ BPM/key/groove
→ section arc
→ lyric law
→ cue grammar
→ production risks
→ exclude
```

Do not confuse one-shot with “no craft check.”

## 3. Genre-transform COVER

```text
target genre micro-anchor
→ preserve map
→ substitution map
→ vocal identity
→ section/energy events
→ full production-aware quality stack
→ final/outro preservation
→ Audio Influence
```

Never begin a Genre-Transform COVER with a quality-rescue phrase. The genre anchor comes first.

## 4. Lyric cue failure

Symptoms:
- 가사큐 약함
- singer labels confused
- duet not separated
- ending bad
- cues ignored
- lyrics rushed or spilled

Route:

```text
03 cue grammar
→ 16 prosody
→ target language lyric file
→ relevant cue/prompt pattern cases
→ full lyric/cue rebuild
```

## 5. COVER quality failure

Symptoms:
- harsh
- muddy
- thin
- buried vocal
- artificial vocal
- painful high mids
- unfinished sound

Route:

```text
19 diagnosis
→ 02 COVER mode
→ 05 preserve/substitution map
→ 06 production-aware quality stack
→ 03 cue preservation
→ sliders
```

## 6. Success/failure learning

```text
result feedback
→ record case
→ identify transferable pattern
→ wait for repetition
→ promote to pattern
→ promote to knowledge patch
→ promote to instruction only if workflow changes
```
