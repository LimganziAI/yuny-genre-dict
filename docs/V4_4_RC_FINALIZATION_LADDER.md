# V4.4 RC Finalization Ladder

This file exists so RC packages do not get mistaken for final installs.

## Gates
1. **Instruction gate**: `1_PROJECT_INSTRUCTIONS/PROJECT_INSTRUCTIONS.txt` is under 8000 chars and includes honesty/RC language.
2. **Knowledge gate**: exactly 20 files in `2_KNOWLEDGE_FILES/`, numbered 01-20.
3. **Structure gate**: GitHub upload folder contains project-sync mirrors, tests, lyric-craft support, prompt-patterns, production-engineering, and suno-render-behavior.
4. **Creative gate**: Korean lyric mode pluralism works. The system can choose conversational, poetic/symbolic, chant/vocable, theatrical, bilingual, or minimal mode without forcing one birth process.
5. **Record gate**: Production Bible -> CREATE G4 -> COVER G5 -> EXCLUDE/sliders -> S10 counts.
6. **Cue gate**: every major cue has a trigger event and a render purpose.
7. **Quality gate**: serious COVER includes listener-heard 6-group quality stack.

If any gate is uncertain, the artifact is RC/back-up only.
