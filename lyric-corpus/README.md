# YUNY LYRIC CORPUS — `lyric-corpus/`

YUNY 가사 작문의 **참조 코퍼스**. 시스템(Claude Project)이 런타임에 raw GitHub로 *fetch*해서
DRAW 단계에서 먼저 참조한다 — 장르 사전(`23_GENRE_FULLBODY/`)과 *동일한 방식*.

## 어디에 올리나
이 `lyric-corpus/` 폴더를 레포 **`LimganziAI/yuny-genre-dict`** 루트에 그대로 업로드.
(레포는 **public** 유지 — raw fetch가 되려면 필수. ADD 모드: 기존 장르 사전·파일 건드리지 말 것.)

## 파일 (fetch 매니페스트)
시스템은 아래 경로를 fetch한다. 경로 = `raw.githubusercontent.com/LimganziAI/yuny-genre-dict/main/lyric-corpus/<파일>`

| 파일 | 내용 | 시스템 연동 |
|---|---|---|
| `01_yeoneo_collocation.md` | 연어·호응 사전(어휘적 연어 도메인별 + 부사↔서술어 호응 + 직역 블랙리스트) | 65 §1.5 (자연스러움 1차 근거) |
| `02_sentence_forms.md` | 종결어미(화행별) + 문장 형태 변주(여운/명사종결/도치/강조/수사의문) + Pattison 완급 | 63 §2.5 |
| `03_transfer_principles.md` | 전이 원리 카탈로그(정서/상황 → 거장 원리 → 이 곡 무브) | 74 §2.5 · 69 |

## 저작권 (반드시 지킬 선)
- **OK:** 연어/문법 같은 한국어 *사실* · 작법 *원리* · *본인(운영자)이 직접 쓴 분석* · 짧은 *원본* 예시 단편.
- **금지:** 타인 곡 *전체 가사 복제 저장*. (그건 품질에도 불필요 — 시스템은 단어가 아니라 *원리*를 배운다.)
- 위 3개 파일은 전부 이 선 안에서 작성됨(연어=사실 / 종결·전이 예시=원본 / 원리=일반 작법).

## 운영자가 더 추가할 때
- 형식은 각 파일 하단 "운영자 추가 가이드" 참고.
- (선택) 거장 사전 `69A~H` / `22_KPOP_ARTIST_DEEP_DIVES`를 여기로 옮기면 코어 ~26% 경량화 — 라우터(69_INDEX·23a)는
  시스템에 남기고 *본문만* 옮긴다. 옮긴 파일은 시스템 zip에서 빼고 이 레포에서 fetch.
- 새 파일 추가 시 이 README 매니페스트 표에 *경로 한 줄* 추가 → 나한테 "추가했어 + 경로" 알려주면 fetch에 반영.

## 업로드 후
나한테 "올렸어"라고만 하면, DRAW에서 이 경로들을 fetch해 연어·종결·전이 근거로 쓴다.
(레포·경로가 위와 다르면 그 경로만 알려줘.)
