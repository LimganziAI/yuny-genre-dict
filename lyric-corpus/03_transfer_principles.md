# 03. 전이 원리 카탈로그 (transfer principles — 거장의 *원리*를 이 곡의 *무브*로)
# YUNY 참조 코퍼스 · 시스템 74 §2.5 TRANSFER TARGET / 69 distill · UTF-8
# 본질: 거장 가사를 *베끼는* 게 아니라 그 *작동 원리*를 빼서 이 곡에 *다르게* 적용한다.
#       단어를 줍지 말고 메커니즘을 배운다. 아래 예시는 전부 원본(저작권 무관) — 원리 시연용.
# 사용: 청사진 정서/상황 → 해당 항목의 *원리*를 골라 → 이 곡의 구체 사물·장면으로 번역 → WRITE.

## 대원칙
- **추상 원리 → 구체 무브:** "거리를 둬서 더 아프게"(원리) → "이 곡에선 *남의 일처럼 3인칭으로 날 본다*"(무브).
- 원리는 전이되고, *표현은 매번 새로* 만든다(같은 사물·구문 재사용 금지).

## §A. 정서/상황 → 전이 가능한 크래프트 무브

### 이별 · 상실
- **원리: 감정을 사물의 상태로 옮긴다(객관적 상관물).** 슬픔을 말하지 말고 *식은 사물*로.
  무브 예) "두 잔 시킨 커피, 한 잔만 식어간다" — '외롭다' 없이 외로움.
- **원리: 부재를 '있던 자리'로 증명한다.** 없음을 *남은 흔적*으로.
  무브 예) "베개 한쪽만 눌려 있어" / "신발장에 빈칸 하나".

### 그리움
- **원리: 작은 감각 디테일 하나가 전체를 소환한다(스몰 디테일).** 거창한 말 대신 *한 점*.
  무브 예) "샴푸 냄새가 엘리베이터에 남아서" — 한 줄이 사람 전체를 부른다.
- **원리: 부르지만 답이 없음을 형태로(호명 + 침묵).** (응집 유형 ④)
  무브 예) "지금 뭐 해. // (대답이 없는 채로 다음 줄)".

### 후회 · 자책
- **원리: 화자가 *간접적으로* 자기를 드러낸다(극적 독백·Browning).** "미안해" 대신 *자꾸 변명/회피하는 말투*로 결함이 새어 나오게.
  무브 예) "난 그때 바빴어, 진짜였어, 어쩔 수 없었어" — 세 번 변명 = 안 미안한 척의 미안함.
- **원리: 시간을 도치해 현재에서 과거를 호명.** 후회는 *지금 서서 그때를 본다*.
  무브 예) "지금 와서, 그날의 내 등을 본다".

### 분노 · 저항 · 결의
- **원리: 절제와 단형이 폭발보다 세다(침묵의 무게).** 소리치지 말고 *짧게 끊어* 압력.
  무브 예) "됐어. // 더는 안 물어." (B-6 단편 + 닫힘 정당).
- **원리: 반복+미세 변주로 다짐을 조인다.** 같은 구를 조금씩 바꿔 의지를 누적(힙합/결의곡).

### 사랑 · 고백
- **원리: 직진술을 피하고 행동·감각으로(Show).** "사랑해" 대신 *몸의 언어*.
  무브 예) "네 보폭에 내 걸음을 맞추고 있더라".
- **원리: 작은 약속/사소한 일상으로 크기를 표현.** 거대한 맹세보다 *구체적 사소함*.
  무브 예) "네 우산을 항상 차에 둬".

### 회상 · 향수
- **원리: 한 장면을 현재시제로 *지금처럼* 재생(present-tense 의례·Culler).** 과거를 *불러와 현재로*.
  무브 예) "열일곱, 우리는 옥상에 있다" (시제로 시간을 무너뜨림).

### 체념 · 담담함
- **원리: 사실을 담담히 진술하는데 정서가 *밴다*(감정↔사실 왕복).** 감정 줄과 사실 줄을 번갈아.
  무브 예) [사실]"불은 껐어" → [내면]"근데 왜 더 환한 것 같지" → [사실]"신발을 신었어".

### 희망 · 위로
- **원리: 단정하지 말고 *열린 미래·조건형*으로 여지를 둔다(unstable 종결).**
  무브 예) "언젠가, 아주 천천히라도—" (말줄임 여운, B-1).

## §B. 비선형/문학 전개일 때 (응집 유형 ②)
- **원리: 시간순 대신 *중심 이미지/정서*가 묶는다(의식의 흐름·Eliot).** 추상↔구체 점프 허용, 단 *한 중심*으로 수렴.
  무브 예) 새벽 불면 — 천장 얼룩 → 옛 약속 → 다시 천장 (시간 아님, '잠 못 듦'이 중심).
