# 02. 종결·문장 형태 변주 사전 (sentence-ending & form variety)
# YUNY 참조 코퍼스 · 시스템 63 §2.5 operationalize · DRAW/WRITE에서 참조 · UTF-8
# 본질: AI 가사 최악의 습관 = *모든 줄이 닫힌 평서 종결*(~했어/~더라/~않아). 종결을 *형태로* 흔든다.
#       어미만이 아니라 *문장 골격*을 섞어라. 아래 예시는 전부 원본(저작권 무관) — 패턴 학습용.

## §A. 종결어미 — 화행별 (통일 깨는 재료)
같은 줄을 다른 화행으로 바꾸면 어미가 바뀐다. 한 곡에 화행을 섞어라.
- **단정·확신:** ~다 · ~지 · ~어/아 · ~ㄴ다 — "끝났어" "다 지나갔다"
- **관찰·서술:** ~더라 · ~던데 · ~고 있어 — "혼자 걷고 있더라"
- **깨달음·발견:** ~구나 · ~네 · ~었구나 · ~ㄴ걸 — "이게 끝이었구나" (~네는 식상하니 곡당 2회↓)
- **추측·여운:** ~ㄹ까 · ~ㄴ가 · ~겠지 · ~ㄴ듯 · ~ㄹ지도 — "돌아오지 않겠지"
- **청유·바람:** ~자 · ~을래 · ~기를 · ~어줘 — "부디 잘 지내기를"
- **영탄·감정:** ~구나 · ~다니 · ~ㄹ줄이야 — "네가 떠날 줄이야"

## §B. 문장 *형태* 변주 — 닫힌 평서 탈출 (핵심)
### B-1. 여운 / 열린 종결 (안 닫기 — 끝을 흐린다)
- 말줄임: "너는 아직도 거기—" / "괜찮다고 했는데…"
- 미완 연결어미로 멈춤(~ㄴ데/~지만/~다가 뒤를 비움): "다 잊은 줄 알았는데" / "잡으려 했지만"
- 관형형 멈춤(~던/~ㄴ): "둘이 걷던" / "네가 두고 간"
- 조건 던지고 안 받기: "네가 없으면," / "한 번만 더 본다면,"
→ *닫지 않는 게* 더 깊을 때가 많다(=불안정/여운, §D).

### B-2. 명사형 / 체언 종결 (동사로 안 닫고 사물·이미지로 멈춤)
- "텅 빈 컵 하나" / "꺼지지 않은 형광등" / "식어버린 커피, 두 잔" / "신발 한 짝"
→ 여운 + 선명. 한 절을 명사로 끊으면 카메라가 멈춘 느낌.

### B-3. 도치 (어순 뒤집어 강조·여운)
- "잠그고 나왔어, 두 번이나" (← 두 번이나 잠그고 나왔어)
- "보고 싶었어, 말은 못 했지만" / "남았더라, 네 자리만"
→ 단, 연어·자연 어순을 *깨지 않는 선*에서. 라임/운율 위해 말을 비틀지 마라(소리가 의미를 왜곡하면 실패).

### B-4. 강조·수사 구문 (닫힌 평서 SVO 반복 탈출)
- "단 한 번도 묻지 못했어" / "차라리 모르는 게 나았어" / "얼마나 불렀던지" / "그저 서 있을 뿐이야" / "이름조차 못 불러"

### B-5. 수사 의문 (답 안 하는 질문 = 여운)
- "이게 사랑이었을까" / "왜 하필 지금일까" / "내가 뭘 그리 잘못했나"

### B-6. 단편 / 호명 (절 아닌 조각)
- "겨울. 다시 겨울." / "너였다." / "아무도 없는 방." / "바람아." (호명·현재 의례형, 시스템 응집 유형 ④)

## §C. Pattison stable / unstable — 완급·여운 *설계* [근거: Pat Pattison]
종결 형태로 *해소(stable)*와 *여운(unstable)*을 의도적으로 배치한다. 곡이 전부 닫히면(stable만) 죽는다.
| | stable(안정·해소) | unstable(불안정·여운) |
|---|---|---|
| 종결 | 완결 평서(~다/~어) | 열린 종결·말줄임·의문(B-1/5) |
| 행 수 | 짝수 행(균형·멈춤) | 홀수 행(미결·앞으로) |
| 라인 길이 | 균일 | 들쭉(움직임·불안) |
| 라임 | 완전운/모음 완전 일치 | 슬랜트/모음운(58)·무운 |
- 절차: 섹션마다 "여긴 안정? 불안정?" 정하고 위 도구로 실현. Verse는 좀 바쁘게(unstable 多), 후렴은 단순·해소.
- ★라임은 의미를 섬긴다: 완전운 맞추려 *틀린 말 박지 마라*. 안 맞으면 슬랜트·모음운으로 *맞는 말*을 지킨다.

## §C-2. ★Suno 렌더 주의 — 형태 변주는 *불리는 줄*을 섬긴다 [가설 · 렌더로 검증]
종결·형태를 다양하게 해도 *Suno가 그대로 부르는지*는 별개다. 작문은 종이가 아니라 노래다.
- **여운/말줄임(…·—):** Suno가 *긴 휴지*로 부를 수 있다 → 의도면 OK, 아니면 [Pause] 큐로 명시(56/§8 연동).
- **도치:** 자연 어순을 너무 비틀면 멜로디 강세와 어긋나 *어색하게 들릴* 수 있다 → 핵심어가 강박에 오게(56 정합).
- **명사 종결:** 끝을 명사로 끊으면 *프레이즈가 짧게* 잘릴 수 있다 → 머니노트/sustain 자리면 열린 모음 명사로(56).
- **수사 의문:** 억양이 올라가게 부르는지 [가설] → 핵심 의문은 후렴/정점에 두고 컨투어로 받친다(57/§7).
→ 결론: 형태 변주는 *반드시 56 가창성·§8 큐와 함께* 검토. 렌더 후 이상하면 그 줄만 큐 보강(POST-RENDER).

## §D. 출력 점검 (WRITE 후)
- 한 곡 줄 종결을 훑어 *형태가 3종 이상* 섞였나? (여운/명사종결/도치/의문/강조 중)
- *닫힌 평서 연속 4행+* = 종결형 일변도 = 위 도구 하나로 깬다.
- 단, 화자·장르가 단호한 선언체(랩 디스·결의)면 닫힘 多 정당 — 상황이 결을 정한다.
