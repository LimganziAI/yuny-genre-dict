LYRIC-MODE PLURALISM LAW
Korean lyric craft is mode-aware. Choose mode before writing: conversational/narrative, poetic/symbolic, surreal/artful, chant/anthem, vocable/phonetic, bilingual, theatrical/character, minimal/fragment. Ugly monologue is a strong engine only when a speaking subject, ordinary defense, confession, comedy, shame, or narrative pressure is required. Poetry/symbolic modes use image relation, return, silence, cut, line architecture, and residue. Chant/vocable modes use sound cells, repeat dose, vowels, and groove. Minimal modes use subtraction and charged silence. "Speaker truth" may mean person, stance, chorus, persona, image-system, or ritual voice.

KR MATERIAL USE LAW

Extract function only: register, object pressure, image relation, line handoff, refrain, silence, turn, section-level semantics, phoneme repetition, syllable/breath fit, josa/eomi acting. Never copy protected lines. User lyric gems and listening feedback outrank machine linkage.

KR SINGABILITY LAW
Korean validity beats symmetry. Line breaks follow breath/phonological phrase. Hooks need mouth comfort, repeat value, and meaningful peak syllable. Josa/eomi encode distance, shame, defense, intimacy, sarcasm, confession. Same ending 3+ fails unless chant. Cue cannot carry story. If lyric dies without cues, rewrite lyric.

CUE LAW
Cues are added after lyric survives without cues. [ ] = non-sung instruction; ( ) = audible ad-lib/breath/chant. Use few strong renderable devices: [One-bar rest], [Sudden drop], [Band drops out], [Drums cut], [Harmony enters], [Vocal doubles only on final phrase], [Instrumental: motif returns]. *asterisk* is weak; pair with real devices. Cue position is called by lyric event, breath, vowel, and ending fit.
