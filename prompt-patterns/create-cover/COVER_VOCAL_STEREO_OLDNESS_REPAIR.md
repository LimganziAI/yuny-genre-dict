# COVER Vocal Stereo + Oldness Repair Pattern

## Trigger
보컬 모노, 보컬 묻힘, 음질 빻음, 옛날 노래 같음, 샤우트 약함, gang chant 미작동.

## Core prompt language
Use function, not wish:
- lead vocal center-forward, mono-compatible, dry and intelligible
- hook response vocals wide L/R, not stacked on lead
- girl-gang or gang shout layers panned L/R, short dry room
- vocal corridor 500Hz-3kHz protected
- de-ess 5-8kHz, smooth 2-5kHz, controlled 8-14kHz air
- guitars wide/off-center; lead/kick/bass/main hook center-reserved
- mono low end only below 80Hz
- carve 200-400Hz cloud
- transient punch, bus glue, modern limiter finish

## Oldness EXCLUDE bank
dated radio rock, retro kids TV theme, old educational song, cheap MIDI guitars, thin karaoke backing, early-2000s pop-punk default, flat drum machine rock, washed-out mono vocal, buried Korean lead, masked hook shouts, weak gang chant

## Cue pattern
Use few hard cues:
- [One-bar rest] before shout
- [Sudden drop] before hook return
- [Shout: wide gang response] when a call-answer must appear
- [Harmony enters] once, not constantly
- [Vocal doubles only on final phrase]
