# PP-001 — 한낮 밴드 결 앵커 (마이크로장르 전진 배치)
- 출처: F-001(daylight kindie cover 표류 — "K-pop" 류 거시어 선두 → 평균 아이돌 팝 회귀)
- 증상: 의도는 한낮 인디 밴드 팝인데 렌더가 generic K-pop/시티팝 평균으로 끌림.
- 패턴: **Position 1 = 마이크로장르+era+장면**을 한 호흡으로 — `2010s Korean indie band pop, sunlit weekday afternoon`처럼 시간대·질감 명사를 슬롯 1-2에 박는다. 거시어(K-pop, pop)는 단독 금지 — 수식 구조 안에서만.
- 보강: guitar-pop daylight 앵커(jangly clean electric, easy mid-tempo strum) + EXCLUDE: glossy idol pop sheen, EDM drop, stadium reverb.
- 검증: 렌더 첫 15초의 드럼·기타 질감이 데모/합주실 결이면 성공.
