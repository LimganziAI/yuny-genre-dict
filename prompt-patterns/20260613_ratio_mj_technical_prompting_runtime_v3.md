# Prompt Pattern V3 — Ratio, MJ-style Seasoning, Technical Suno Prompting

Date: 2026-06-13
Status: pattern-candidate, user-preference confirmed

## Trigger
Use when:
- user asks for hybrid genre blend
- user mentions MJ style, 신나게, funky, danceable, groove seasoning
- prompt feels too short/generic compared with v5.5 examples
- COVER needs energetic transform or high-quality rescue

## Percentage ratio rule
Use ratios when they clarify sound dominance:
- primary lane 45-70%
- secondary lane 20-35%
- seasoning lane 5-15%

Good examples:
- K-indie pop rock 45% / bright modern J-rock chorus engine 35% / MJ style 10-15% / subtle electronic texture 5%
- nu-disco 45% / J-electro 30% / dnb texture 15% / MJ style 10%

Do not use ratio stacks for narrow intimate songs unless the user asks or it solves ambiguity.

## MJ-style rule
`MJ style 10%` is allowed as user-approved seasoning.
Use it for:
- rhythmic pocket
- clipped phrase endings
- funk bass/groove articulation
- ad-lib energy
- dance-pop polish

Do not use it as:
- main vocal identity
- artist imitation
- replacement for actual groove/instrument language

## Technical prompt default
A serious prompt should include the technical values that matter:
- BPM and feel
- key or tonal color
- chord/progression or hook landing if important
- vocal range anchor and acting
- melody contour and one peak
- instrument articulation and role
- density curve
- quality/mix corridor in COVER

## COVER technical stack
For energetic covers, compact technical language is allowed:
- lead vocal center-forward
- vocal corridor protected
- kick/bass separated, mono low end
- smooth high-mid, controlled air
- wide but mono-compatible backing
- transient punch preserved

For intimate covers, translate to listener language unless mix defects repeat.

## Promotion rule
Dense prompt shape is not proof of success. Promote as gold only after user listening confirmation or repeated successful renders.
