# EX-06 — 악기 치환 맵 (transform 단골 경로)
| 소스 → 타깃 | 치환 라인 |
|---|---|
| 발라드 피아노 → 시티팝 | grand piano → electric piano comping + clean funk guitar |
| 어쿠스틱 → 신스팝 | strummed acoustic → plucky analog synth arp; brushed kit → tight drum machine, gated snare feel |
| 록 → R&B | crunchy guitars → muted guitar licks + sub-warm bass; rock kit → snap-transient kit, half-time pocket |
| 포크 → 댄스록 | fingerpicking → palm-muted eighth electric; upright bass → driving pick bass |
| 트랩 팝 → 밴드 팝 | 808 + hi-hat rolls → live punchy kit + round fingered bass |
- 규칙: 치환은 **역할 단위**(리듬 주도권/저음 기반/화성 패드/모티프 소유자)로 — 악기 이름 1:1 교환이 아니라 기능 이식. 모티프 소유자는 치환 후에도 반드시 재지정(G4-e).
