# EX-03 — [Singing:] 큐·디바이스 모범/반례
## 모범 (HOW만, 라인 사이 실배치)
1. `[Singing: relaxed chest-mix, close mic, conversational phrasing, slight smile, dry-forward]` — verse 앵커형.
2. `[Singing: clean piercing mid-high, open-throat release on line ends, riding straight eighths, no strain]` — 질주 후렴형.
3. 디바이스 배치: 프리코러스 마지막 행 뒤 `[Breath]` → 후렴 직전 `[Sudden drop, one bar]` → 파이널 진입 `[Lift: wider backing harmony enters]` → 엔딩 행 앞 `[Whispered]`(직전 1행 silence 확보).
4. `[Bridge — instruments speak: vocal rests 2 bars, guitar-synth motif foreground]` — 보컬 휴지의 구조화.
## 반례
1. `[Singing: like unsent words drifting through summer rain, her heart trembling]` — 서사·은유 큐 = 렌더 불가, WHAT 침범.
2. 섹션 끝에 디바이스 4개 연속 더미 `[Breath][Held][Falsetto][Ad-lib]` — 쿼터 게이밍, 실배치 아님.
3. 전 섹션 동일 큐 복붙 — 섹션 목적 분리 위반(에너지 곡선 사망).
