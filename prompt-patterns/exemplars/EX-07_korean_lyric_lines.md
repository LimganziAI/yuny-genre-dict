# EX-07 — 한국어 가사 행 모범/반례 (게이트 적용 예)
## 모범 (G1-G3 통과형 — 골격 예시, 실제 곡엔 그 곡의 사물로)
1. 합리화 후렴(완문장 2행 걸치기): `목말라서 그런 거야 / 이건 그냥 물 대신이야` — 사람 말+골격 1개+이어 읽기 복원.
2. 관문명사로 숨기기: `컵에 맺힌 물만 봤어 / 빨대는 안 꽂았어` — 직접명 0인데 상황 즉시 이해(부정 행동이 욕망을 노출).
3. 들킴: `근데 손이 먼저 갔더라` — 자기 보고형 어미, 의인화 0.
4. 담담 회상: `네가 쓰던 컵만 그대로네 / 버리진 못하겠더라` — 사물→행동→감정 우회.
## 반례 (어느 게이트에서 죽는가)
1. `여름이 먼저 나를 부른 거야` — 의인화 후렴(G1, AI-tell 1호).
2. `흰 것 아래 붉은 결 하나` — 전명사 추상+인간동사 0 = 암호(G3).
3. `숨 / 컵 / 분홍 / 달다` — 스파인 없는 재료 나열(G2).
4. `갈증의 색깔이 나를 적셨다` — ~의 직역+물주구문 이중 번역투(R2).
5. `사랑은 원래 그런 것이다` — 추상명사 단독 부양+산문 종결(R2).
