# Cue Event Placement Protocol V4.2

Cues answer lyric events.

## events
confession · denial · joke turn · hook entry · object return · bridge rupture · final changed line · outro residue

## devices
[Band drops out] before strongest confession
[One-bar rest] before comic reversal or shout
[Sudden drop] before hook return
[Harmony enters] after lead hook is established
[Vocal doubles only on final phrase] for final changed line
[Held] only on open-vowel endings

Delete any cue that can be moved elsewhere without changing function.
