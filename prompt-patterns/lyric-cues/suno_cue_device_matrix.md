# Suno Cue Device Matrix — CURRENT

## Strong structural devices
- [Sudden drop] — strongest before hook return or whispered pickup.
- [One-bar rest] — strongest before title/hook phrase.
- [Band drops out] — bridge reset, final pre-chorus reset.
- [Drums cut] — one-beat impact before vocal.
- [Kick-only break] — dance drop isolation.
- [Instrumental: motif returns] — lets arrangement speak.
- [Harmony enters] — only where harmony must appear.
- [Vocal doubles only on final phrase] — final emphasis without full chorus bloat.

## Conditional vocal devices
- [Whispered] — only after silence/drop, short phrase.
- [Held] — only on open-vowel ending, 1-2 times.
- ALL CAPS — 1-2 shouted words only.
- vowel stretch — for sustain hints.

## Weak typography
- *asterisk* and **bold** are not primary controls.
- Use them only to reinforce a structural cue.

## Sync rule
A cue naming an instrument/event must be backed by CREATE/COVER prompt vocabulary. If not, repair prompt and cue together.
