# Ratio / MJ-style / Technical Prompt Runtime — V4

## User-confirmed
- `MJ style 10%` may be used as groove seasoning.
- Percentage ratios are useful when blending genres or shaping COVER transforms.
- Technical prompt language is welcome, especially for energetic songs.

## Ratio rule
Use primary 45-70%, secondary 20-35%, seasoning 5-15%.
Use when it clarifies dominance.
Do not overuse on narrow intimate songs.

## MJ-style rule
Allowed as:
- `MJ style 10%`
- `MJ-style rhythmic pocket 10%`
- clipped phrase endings
- syncopated pop-funk bass
- danceable ad-lib energy

Do not use as main vocal identity or artist imitation.

## Technical prompt stack
For serious CREATE:
- BPM/feel
- key/tonal color
- progression/hook landing if useful
- range anchor
- vocal acting
- melody contour/peak
- instrument articulation
- motif owner
- section energy

For serious COVER:
- target anchor
- preserve map
- substitution/refine map
- vocal protection
- section events
- quality stack
- Audio Influence

## Failure
Prompt under 600 chars for a serious full song is suspicious unless deliberately minimal.
