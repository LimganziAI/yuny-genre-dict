# english_object_verb_rhyme_engine

## Register first
Choose one stance: conversational, literary, intimate run-on, raw punk, R&B fragment, country/plainspoken, indie observational.

## Drafting tools
- AID: Action + Imagery + Detail in verses.
- Verb wattage: replace is/get/go/make when a stronger verb sings.
- Object writing: line carries a sensory object before abstract feeling.
- Rhyme stability: perfect = closure; family/additive/assonance = unresolved motion.

## Anti-patterns
Avoid lazy rhymes: fire/desire, heart/apart, tonight/alright, rain/pain, cry/goodbye, love/above.
Avoid generic AI turns: shadows, echoes, neon, broken pieces, endless night unless re-grounded in concrete objects.

## Accent/diction
Accent is a decision. Unspecified accent becomes neutral/flavorless. Use one vocal anchor and one pronunciation override when diction matters.
