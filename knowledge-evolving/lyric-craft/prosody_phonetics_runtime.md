# prosody_phonetics_runtime

## Universal
The peak note belongs on a content word with a singable vowel. Particles, weak endings, and dense consonant clusters do not carry the peak.

## Korean
Use syllable count by BPM. Open vowels ㅏ/ㅗ/ㅓ stretch best. Heavy 받침 stays off long notes.

## English
Stress content words on strong beats. Connected-speech hazards should not pile up more than 3 per line.

## Japanese
Count mora. Long vowels, っ, ん each take time. Use mora groups that match the groove.

## Spanish
Count sinalefa. Stress class must land correctly; final aguda can make hook endings strong.
