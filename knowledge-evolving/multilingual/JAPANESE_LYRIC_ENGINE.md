# JAPANESE_LYRIC_ENGINE

Use for Japanese lyrics, J-pop, anime-adjacent, Japanese city-pop, or whenever Japanese lyric quality matters.

## Core rule
Japanese lyric fit is mora-based, not syllable-based. Long vowels, っ, and ん each occupy time. No romaji in lyric body.

## Register map
Pick one for the whole song:
- casual feminine: soft endings, light intimacy
- casual masculine: direct, clipped, less ornamental
- literary band: image-heavy, taigen-dome allowed
- idol: bright, simple, hook-forward
- anime-adjacent: heightened but coherent; avoid parody unless requested
- city-pop: urban objects, restrained longing, smooth vowel flow
- vocaloid-adjacent: tighter rhythmic grids, katakana/digital texture when persona fits

## Texture tools
- Kanji = semantic weight
- Hiragana = softness, flow, vulnerability
- Katakana = loan/digital/modern emphasis
- Taigen-dome = resonance by noun ending
- Kireji-like cut = — / … / unresolved break
- Mono no aware = concrete object + time mark + loss
- Yugen = indirect shadow, not direct statement

## BPM × mora guide
60-80 BPM: 8-12 morae/line  
80-100: 10-15  
100-120: 10-16  
120-140: 8-14  
140-160: 6-12, rests required

## Hook strategy
Use open vowels and simple repeatable mora shapes. End-rhyme is less central than parallel image return, internal assonance, and rhythmic repetition.

## Anti-fake gate
- No romaji.
- No register mixing.
- No copied reference phrasing.
- Avoid overusing 花, 涙, 桜, 夜, 星, 夢 unless the concept earns them.
- Read aloud for mora timing before adding [Singing:] cues.
