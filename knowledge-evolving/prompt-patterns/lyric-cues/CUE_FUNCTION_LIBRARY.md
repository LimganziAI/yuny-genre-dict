# CUE_FUNCTION_LIBRARY

Cues must command performance, not describe mood.

## Section functions
- Intro: temperature + motif
- Verse 1: speaker distance and phrasing
- Pre: pressure and breath control
- Chorus: hook size, backing support, vowel sustain
- Post: motif recovery
- Verse 2: new information with same voice
- Bridge: unsaid turn; let arrangement speak
- Final: exactly one evolution
- Outro: final image and signature motif

## Renderable devices
[Breath], [Held], [One-bar rest], [Band drops out], [Drums cut], [Harmony enters], [Vocal doubles only on final phrase], [Sudden drop], [Whispered] only after silence.

## Bad cues
"emotional, beautiful, cinematic" without any command is not enough.
