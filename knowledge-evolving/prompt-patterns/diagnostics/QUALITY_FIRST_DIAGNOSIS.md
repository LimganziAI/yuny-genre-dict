# QUALITY_FIRST_DIAGNOSIS

When output is bad, name the upstream cause before fixing.

## Categories
1 vocal fit mismatch
2 genre/groove mismatch
3 harmony/contour flatness
4 lyric speaker/register failure
5 prosody/rushing
6 arrangement density conflict
7 prompt overload
8 Suno randomness

## Rule
Two failures on the same issue means stop synonym patching. Fetch targeted fullbody/case memory and rebuild the cause.
