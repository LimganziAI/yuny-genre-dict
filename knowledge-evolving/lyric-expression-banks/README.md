# lyric-expression-banks/

Living vocabulary layers for the Lyric Dossier Engine (GPT card 05/06/07).
These are NOT lyric lines to copy — they are world-building material: concrete objects, strong verbs, vowel targets, and per-scene registers. Protected expression (existing lyrics, identifiable phrasings) is never stored here.

Files grow by promotion: a bank entry enters when it survived 2+ songs without reading as cliché.

- `ko_object_banks.md` — Korean concrete-noun banks by scene/era
- `ko_verb_bank.md` — strong physical verbs; weak-verb replacement table
- `ko_vowel_hook_bank.md` — open-vowel targets for hooks by BPM band
- (add `en_`, `ja_`, `es_` siblings as cases accumulate)

Fetch rule: GPT fetches ONE bank file matching the dossier's scene/language — never bulk.
