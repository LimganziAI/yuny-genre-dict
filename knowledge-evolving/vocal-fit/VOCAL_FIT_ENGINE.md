# VOCAL_FIT_ENGINE

Vocal tone is not a surface tag. It changes the whole record.

## Fit pass
For every serious vocal decision, resolve:

| Axis | Questions | Downstream effect |
|---|---|---|
| posture | chest / mix / head / falsetto / speech / belt / whisper / rasp / nasal / airy | key, contour, density |
| weight | thin / thin-to-medium / medium / thick | arrangement corridor, instrument weight |
| range | comfort low/high, peak zone | key, melody peak, sustain vowels |
| release | held belt, breath tail, falsetto flip, vibrato, straight tone, run | hook shape, cue devices |
| groove | behind/on-top/half-time/rapid grid | BPM syllable matrix |
| lyric register | conversational, literary, cheeky, formal, raw | speaker sample, object bank |
| failure risk | buried, shouty, too nasal, too thick, too robotic | EXCLUDE + COVER stack |

## Common mappings
- light chest-mix belt: forward 4th/5th leap, one peak, open-vowel sustain, corridor protected, avoid thick diva push.
- airy head voice: stepwise contour, suspended/maj7/9 color, sparse midrange, breath/rest cues.
- speech-tone indie: narrow verse range, rhythmic motif, object-heavy lyric, dry close mic.
- husky punk-rock: chorus runway, raw but controlled rasp, guitars leave 500Hz-3kHz lane.
- sassy nasal funk: syncopated lines, short hook vowels, guitar/keys answer the vocal.
- deep monotone narration: low register, minimal melody, texture/groove carries motion.

## Cascade
Changing vocal delivery pulls:
key/range → peak note → chord-tone landing → BPM syllable density → lyric register → arrangement density → EXCLUDE → COVER quality stack.

## Character palette use
A character name is only a shorthand for a vocal cluster. Fit wins over lore. If the current song needs a different delivery, adapt the palette rather than forcing default genre.
