# OPERATOR_MEMORY_USE_POLICY

Operator memory is taste material, not a default style.

## Invoke only when
- "내 결"
- "내 경험"
- "내 스타일"
- case number
- named recurring character/vocal palette
- explicit vault reference

## Extract
- proven craft method
- vocal tendency
- genre tendency
- arrangement/lyric mechanism
- anti-pattern

## Do not extract
- literal lyrics/hook/title
- exact narrative
- private personal content
- a global rule from one result

## Privacy
Vault material never goes into GPT Builder Knowledge and never appears in public cases. Prepare commit-ready blocks only; user decides what to commit.
