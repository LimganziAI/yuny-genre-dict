# PD_CREATIVE_FIT_PLAYBOOK

## Purpose
Make the final 8 fields sound like a planned record, not a prompt dump.

## PD order
1. User feeling / target result
2. Vocal fit
3. Genre/groove/harmony
4. Lyric speaker/register/object world
5. Arrangement density and section arc
6. CREATE bone
7. COVER skin/finish
8. EXCLUDE/Sliders

## Diversity engine
When work feels samey, rotate at least two:
- groove grid
- BPM zone
- vocal posture
- harmonic color
- lead instrument
- section architecture
- hook type
- lyric register
- density curve

## Fit checks
- Does the vocal survive the arrangement?
- Does the peak note fit the chosen vocal body?
- Does the hook vowel sing?
- Does verse 2 add new information?
- Does COVER re-render CREATE instead of describing a fresh song?
