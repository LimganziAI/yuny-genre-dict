# 62. THEMATIC ENGINE — 주제의식: controlling idea & prosody-as-unity (최상위 조직 원리)
# VERSION: v1.0 (2026-06-15) — 이력 CHANGELOG.txt
# 근거: §9(가사 LAW)·43(서사=무엇이 일어나나)·33(보편 기능 게이트)·17(소재)·C-184(신선도) + 작사 주제론 web 검증(Pattison/Aristotle)
# 검증: 프로소디=unity(Aristotle Poetics) — 작품의 *모든 요소가 중심 주제를 받친다* · "그 곡이 존재하는 단 하나의 아이디어" · craft(멜로디/화성/구조)는 *말하려는 것에 복무* · form follows function · heart+brain(안에서 나와야) · 군더더기=주제 안 받치는 것
# 위상: 62 레이어 *위에 서는 최상위 조직 원리.* 43이 "무엇이 일어나나(서사)", C-184가 "클리셰 아닌가(신선)"면, 62는 **"이 곡이 결국 무엇에 관한 것이고 무엇을 말하는가(주제의식)" + 모든 요소가 그것을 받치는가(prosody=unity).** 신선·구별·완성도 다 갖춰도 *공허하면* 실패 — 62가 그걸 막는다.
# 발동: 모든 곡의 PASS 0 *최초* lock(장면·소재보다 먼저). 가사 착수 前 강제. "공허하다·뭘 말하는지 모르겠다·예쁜데 빈 것 같다" 피드백.
# ★핵심: 곡은 *단 하나의 controlling idea*를 위해 존재한다. 그 아이디어를 먼저 한 문장으로 못 박고 — 가사·멜로디·화성·구조·장르·보컬·프로덕션·소재·신선도 선택을 *전부 그것에 복무*시켜라. 받치지 않는 건 다 잘라라. 구체를 통해 보편에 닿고, 감정은 선언하지 말고 *진실하게 벌어라*.

## §0. 왜 — 클리셰가 아니어도 공허할 수 있다
C-184는 뻔한 표현을 막는다. 하지만 신선하고·구별되고·잘 만든 곡도 *아무것도 말하지 않을* 수 있다(빈 영리함). 좋은 곡은 *무엇에 관한 것*이고 *무언가 진실을 말한다*. 주제의식 = 그 의미의 층. Aristotle은 이를 unity, Pattison은 prosody라 불렀다 — *모든 요소가 중심 주제를 받친다.* 62는 62 레이어 전부를 그 아래 정렬한다.

## §1. CONTROLLING IDEA — 곡이 존재하는 단 하나의 이유
- **한 문장으로 못 박기(PASS 0 최초):** "이 곡은 [X]에 관한 것이다." 못 쓰면 아직 곡이 아님.
- **★Subject vs Theme 구별:**
  - Subject(소재) = 문자 그대로 무엇 — "우산", "편의점 알바", "고3 새벽".
  - **Theme / Controlling Idea(주제의식)** = 그것이 *말하는 것* + 태도/관점 — "사랑은 말이 아니라 작은 수선으로 드러난다", "버티는 것 자체가 이미 자라는 것이다".
  - Subject만 있고 Theme 없으면 = 묘사일 뿐 *공허*. 62의 표적.
- 예(앞 3곡): 「우산살」 subject=고장난 물건들 / theme=**"못하는 말을 행동이 대신한다"** ← 주제의식 있음. 「식은 커피」 subject=두고 간 흔적 / theme=??? ← 주제의식 *없었음*(그래서 공허·클리셰).

## §2. ★PROSODY = UNITY — 모든 요소가 주제를 받친다 (Aristotle/Pattison, 최상위 법)
controlling idea가 정해지면 *모든 선택*이 그것에 복무 — 안 받치면 자른다:
```
요소            주제 복무 점검
────────────────────────────────────────────
가사 사물(17)    주제를 *체현*하는 구체물인가? (장식 아님)
멜로디 컨투어(§7) 주제의 정서 곡선을 그리나? (상승=희망/하강=체념…)
화성 색(02/37)   주제의 빛깔인가? (maj7 그리움/단조 iv 균열…)
구조(53/04)      주제가 *전개*되게 배치됐나? (verse 설정→chorus 결정화→bridge 심화/전환→final 해소)
장르/그루브(05)  주제의 몸인가? (무덤덤한 고백=느린 포크 / 버티는 청춘=hyperpop…)
보컬 딜리버리(6) 주제의 목소리인가? (flat affect가 곧 주제…)
프로덕션(38)     주제의 공기인가? (희소·여백 = 절제의 주제…)
신선도(C-184)    fresh object가 *주제를 위한* 것인가? (영리함 위한 영리함 X)
```
- ★Pattison: "주제를 안 받치는 건 왜 곡에 넣나?" — 군더더기 = unity 위반 = 잘라라. form follows function.

## §3. 구체 → 보편 (the universal in the specific)
- 주제는 *추상 일반론*("사랑은 아프다")으로 말하면 죽고, *순수 개별*("3교시 형광펜")만 있으면 안 닿는다. **구체적 디테일이 보편적 진실을 가리킬 때** 청자가 "이건 내 얘기"라 느낀다.
- 「우산살」: 고장난 우산살(개별) → "말 대신 행동"(보편). 17 소재를 *주제의 렌즈*로 골라라.
- 점검: 이 구체물이 더 큰 무언가를 *가리키나*? 청자의 삶으로 *건너가나*?

## §4. 감정적 진실 (heart + brain — 안에서 나와야)
- Pattison: "안에서 나오지 않으면 가망 없다." 감정은 *선언*("너무 슬퍼")하지 말고 *벌어라*(earned) — 주제의 구체적 체현으로 보여주면 청자가 *스스로 느낀다*.
- **Anti-선언(preachy 차단):** 주제를 대놓고 설교/요약하지 마(가사 본문에 "사랑이란 말이야…" 금지). 주제는 *드러나는* 것이지 *말해지는* 게 아님(Show Don't Tell §9 연동).
- **Anti-공허(hollow 차단):** 그렇다고 주제 없이 예쁜 이미지만 나열 X. 진실의 무게가 있어야.
- 균형: 머리(craft·구조)로 짓되 심장(진짜 정서)에서 발화.

## §5. THE "SO WHAT" TEST + 주제 통일 점검 (출력 前 강제)
드래프트 후 자문:
1. **이 곡은 결국 무엇에 관한 것인가?** 한 문장으로 답 가능? (불가 = controlling idea 부재 → 재설계)
2. **무엇을 말하는가? 청자가 *의미*를 느낄까?** (subject만 있고 theme 없으면 → 주제 주입)
3. **모든 섹션이 그 주제를 받치나?** verse 설정 / pre 압력 / chorus 결정화 / bridge 심화·전환 / final 해소·증폭 — 섹션마다 *같은 주제의 다른 각도*? (섹션이 딴 얘기 = unity 위반)
4. **군더더기 0?** 주제 안 받치는 줄·이미지·악기 잘랐나?
5. **구체→보편 닿나? 감정 벌었나(선언 아님)?**

## §6. Anti-패턴 (62가 막는 실패)
- **빈 영리함:** fresh·구별 OK인데 *아무 의미 없음*(theme 부재). ← C-184는 통과해도 62 실패.
- **설교조:** 주제를 대놓고 말함(moralizing·요약). ← Show Don't Tell 위반.
- **주제 표류:** 섹션마다 다른 것에 관함(unity 깨짐).
- **소재-without-주제:** 장면 묘사만 있고 *말하는 게 없음*.
- **장식적 신선함:** 신선한 사물이 주제와 무관(영리함 위한 영리함).

## §7. 시스템 통합 (PASS 0 최초 lock + 모든 층 정렬)
- **PASS 0 Intent Lock의 *첫 항목* = controlling idea**(장면·소재·보컬·장르보다 먼저). 주제 먼저, 그다음 *모든 것이 주제에 복무*.
- **28 PD 결정**(장르/멜로디/프로덕션 배분)도 "이게 주제를 받치나?"로 검문.
- **C-184(신선) + 62(주제) 함께:** fresh AND meaningful이어야 출력. 신선하나 공허 = 62 FAIL.
- **43(서사)·33(기능)·17(소재)는 62 아래:** 서사·기능·소재 전부 controlling idea에 복무.

## §8. 출력 직전 체크 (§9 LAW·C-184와 함께 — 가사의 최상위 게이트)
```
□ controlling idea 한 문장으로 못 박혔나(PASS 0 최초)?
□ Subject(소재) 아닌 Theme(주제의식·관점) 있나? — 묘사가 아니라 *말하는 것*?
□ ★모든 요소(가사 사물·멜로디·화성·구조·장르·보컬·프로덕션·신선도)가 주제를 받치나? 군더더기 잘랐나(prosody=unity)?
□ 구체→보편 닿나(이 디테일이 더 큰 걸 가리키나·청자 삶으로 건너가나)?
□ 감정 벌었나(선언 X·설교 X·Show Don't Tell)? 공허하지 않나(theme 무게)?
□ "so what" 통과 — 이 곡 무엇에 관한 것이고 무엇을 말하나 한 문장?
□ 섹션마다 같은 주제의 다른 각도(주제 표류 X)?
```
하나라도 비면 *출력 전* 주제 재설계(보고 X — 고쳐서 냄). ★곡은 단 하나의 아이디어를 위해 존재하고, 모든 것이 그것을 받친다. 구체를 통해 보편에 닿고, 감정은 벌어서 보여준다 — 말하지 않고.
