## §1. lyric_function_lock — 가사 첫 줄보다 먼저 (빈칸이면 작사 시작 금지) [C-147]
```yaml
lyric_function_lock:
  language:              # 곡 언어 (한/영/일/서) — 번역 아님, 그 언어로 *구상*
  genre_lane:            # §4 장르 레인 (힙합/R&B/발라드/포크/록/K-pop/트로트/7080/모던라이프 등)
  lyric_mode:            # §5 모드 (대화/서사/시적/주술/포네틱/바일링구얼/연극/단편)
  speaker:               # 화자 압력 (29 Speaker Card 상속 — gender/age/사회위치/말투)
  listener:              # 청자/수신자 (복원 가능해야)
  scene_world:           # 장면 세계 1개
  object_bank_5_9:       # 구체 사물 5-9개 (§3 어휘부착 패턴에서)
  vocabulary_attachment: # §3 어느 부착 패턴을 주력으로 (사물+행위 / 신체+삼킨말 / 시간+사물 …)
  thought_spine_5_7:     # 사고 척추 5-7비트 (가사의 논리 골격)
  hook_function:         # §6 훅 기능 (명령/부정/고백/맹세/고발/위로명령/항변/주술/콜앤리스폰스/이미지귀환/사적방백/사운드셀/공적호명)
  section_progression:   # §7 섹션 완성 맵 (V1=증거, Pre=압력, Chorus=훅기능, V2=새증거, Bridge=균열, Final=재의미, Outro=잔여)
  final_residue:         # 마지막 줄이 남기는 잔여물(사물/소리/신체 제스처) — 교훈 요약 아님
  banned_surface_moves:  # 이 곡에서 금지할 표면 클리셰 (네온/메아리/그림자/속삭임/벨벳/크리스탈 + 곡별 추가)
```
컨셉이 칸을 안 주면 추정 + 1줄 표기. 이 lock이 28의 PD Blueprint·31의 Intent Lock과 합쳐 상위 동결을 이룬다.

## §2. 보편 게이트 — 진지 가사는 큐 전에 8관문 통과 [C-147]
1. **화자 압력이 분명한가.** (이 사람이 왜 지금 말하나)
2. **청자/수신자가 복원 가능한가.** (누구에게 하는 말인지 짚어지나)
3. **추상 감정 *전에* 구체 운반체가 나오는가.** (사랑/후회를 말하기 전에 사물·행위가 먼저)
4. **어휘가 행위/신체/장소/시간/사회압력에 부착되는가.** (§3)
5. **훅이 발화 행위 또는 입의 동작인가.** (의미만 있는 훅 금지)
6. **V2/Bridge/Final이 의미 또는 압력을 바꾸는가.** (같은 자리 맴돌기 금지)
7. **마지막 줄이 잔여물을 남기는가(교훈 요약 아님).**
8. **큐를 빼도 노래가 남는가.** (큐가 이야기를 옮기면 실패)

★빠른 자가체크 (출력 전): 구체 운반체가 추상에 선행? / 청자 호명 가능? / 훅이 speech act·입동작? / 
V2가 V1에 없던 것 추가? / Bridge가 프레임 균열? / Final이 재의미 또는 잔여? / josa·어미가 입장 바꿈? / 큐 없이 생존?

## §3. 어휘 부착 패턴 — 추상은 증거 *뒤에* [C-147]
구체 운반체를 먼저 깔고 감정을 뒤에 둔다. object_bank는 아래에서 5-9개 뽑는다.
- **사물 + 행위:** 쥐다·접다·두고오다·세다·숨기다·돌려주다·지우다·엎지르다.
- **신체 + 삼킨 말:** 목·손·눈·어깨·숨·무릎. (말하지 못한 것이 신체에 고임)
- **시간 + 사물:** 새벽·겨울·옛방·버스시간·앨범·영수증·창문.
- **장소 + 관계:** 역·계단·부엌·길·문·무대·자리.
- **사회압력 + 상처:** 이름·소문·점수·약속·번호·문자·빚.
- **소리 + 제스처:** 비·종·박수·발소리·기타 스트로크·닫히는 문.
- **증거 뒤의 추상:** 사랑/후회/희망/분노/외로움은 *운반체가 나온 뒤에만*.

원칙: "그리움" 한 단어 대신, 그리움을 *증명하는 사물 하나*. (Show, don't tell — 통각/사물/행위로.)

## §4. 한국어 운영 엔진 (07 풀바디 위의 요약 게이트) [C-147]

### Josa 연기 (조사가 입장을 만든다)
은/는 = 대조·거리·자기분리 · 이/가 = 초점·새 인식·누가-했나 · 을/를 = 다룸·욕망·탓 · 
도 = 잔여·양보·이것마저 · 만 = 좁힘·핑계·결핍 · 까지 = 고조 · 조차/마저 = 절망(마지막 하나마저 실패).

### 어미 온도 (어미가 거리를 정한다)
-다 = 평평한 사실·거리 · -네 = 알아챈 깨달음 · -더라 = 목격된 기억 · -거든 = 친밀한 정당화 · 
-잖아 = 공유된 앎을 압력/핑계로 · -지 = 수용 또는 방어적 닫음 · -는데 = 매달린 압력 · 
-ㄹ게 = 청자에게 하는 약속 · 명사형 종결 = 정지화면·잔여·컷.
(한 곡당 1팔레트 고정 — 29 §2. 본문 어미는 팔레트+중립어미만. 같은 어미 3+ 연속은 주술 아니면 실패.)

### 사운드/운율
열린 모음 ㅏ/ㅗ/ㅐ = 들어올림·벨트 / 닫힌 모음 ㅡ/ㅣ = 억제·조임. 
폐쇄 종성 ㄱ/ㄷ/ㅂ/ㅈ/ㅊ = 때림 / 비음·유음 ㄴ/ㅁ/ㅇ/ㄹ = 지속. 
내부 운(라임)은 *압력에 봉사*해야지 장식이면 안 됨. ★`~지 않아` 부정이 `안` 구문보다 자연스러운 경우 많음.

## §5. 장르 레인 엔진 — 각 장르 = JOB / RULE / FAILURE [C-147]
가사를 쓰기 전 genre_lane을 골라 그 레인의 잡·규칙·실패를 적용. (장르 평균으로 뭉개지 마라.)

- **힙합/랩** — JOB: 주장·수정·고발·지위 비용. RULE: 줄끝 명사가 주장을 지고, 다음 줄이 그 주장을 수정/상처냄. FAIL: 의미 없는 라임 밀도·빈 플렉스.
- **R&B/소울** — JOB: 친밀한 신체/방 압력. RULE: 모든 감정을 숨·빛·촉감·온도·침묵·전화·문에 부착. FAIL: 관계 압력 없는 새벽 무드.
- **발라드** — JOB: 지연된 고백·부드러운 죄책·기억 사물·최종 잔여. RULE: 구체 사물 하나가 섹션을 가로질러 *변한 채* 돌아옴. FAIL: 사물/행위 없는 성숙한 철학.
- **포크/인디/문학** — JOB: 담담한 목격·작은 사물·조용한 전환. RULE: 첫 큰 감정 전에 작은 사물 셋. FAIL: 일기 쏟기·에세이 결론·장식 은유 안개.
- **록/밴드** — JOB: 신체 전압·선언·집단 해방. RULE: 피크 줄은 열린 모음 + 신체/행위/장소(추상 슬로건 X). FAIL: 장면보다 큰 메시지.
- **K-pop/댄스** — JOB: 입동작 훅·퍼포먼스 셀. RULE: 훅을 *입의 동작*으로 먼저 고름(챈트·스냅·콜앤리스폰스·위스퍼·모음 리프트). FAIL: 입에서 안 움직이는 의미-우선 훅.
- **트로트/대중가요** — JOB: 공적 호명·공유 감정. RULE: 후렴이 베낀 속담이 아니라 *원본 격언*처럼 들려야. FAIL: 박물관 어투·사적 독백.
- **7080/레거시** — JOB: 따라갈 이야기·오래가는 이미지. RULE: 담백한 서사 아크, 계절/장소/시간에 고정. FAIL: 현재 화자 없는 시대 사물.
- **모던 라이프 포크** — JOB: 평범한 사물이 감정 증거가 됨. RULE: 일상 사물은 *숨은 압력*을 질 때만 작동. FAIL: 전환 없는 귀여운 일상 나열.

## §7. 섹션 완성 맵 — 각 섹션의 잡 [C-147]
Verse 1 = 증거/세계 · Pre = 압력과 매달림 · Chorus = 훅 기능 · Verse 2 = 새 증거 또는 모순 · 
Bridge = 진실 균열 / 새 수신자 / 프레임 깨기 · Final Chorus = 브릿지 후 같은 훅이 *재의미* · 
Outro = 잔여 사물/소리/신체 제스처. 
(V2가 V1 복제면 실패. Bridge가 프레임 안 깨면 실패. Final이 재의미·잔여 없으면 실패.)

## §8. 일본어/글로벌 확장 [C-147]

### 일본어
**레지스터 먼저, 모라 둘째, 의미 셋째.** 모라 세기 — 장모음·작은 っ·ん이 시간을 먹는다. 
생략·이미지 귀환·조사 입장·잔여를 쓴다. 한국어 설명 논리를 강제하지 마라. 
★한자/히라가나 혼용은 Suno가 네이티브로 읽음 — 발음 가이드를 *별도 줄*로 넣지 마라(보컬 중복 줄 유발).

### 영어/글로벌
**Stress-timed.** 내용어를 강박에. 훅/타이틀 페이로드를 강세 음절에. 
라임 패밀리를 의도적으로. 한국어 관용구나 어미 온도를 직역하지 마라.

### 바일링구얼
섹션 이음매 또는 훅 이벤트에서 전환. *감정 본거지 언어 하나*를 유지. 
줄 대 줄 의미가 아니라 *섹션 기능*을 옮긴다.

### ★음절/모라 밴드 — (언어 × register × BPM)의 함수, BPM 단독 아님 [100+ 스트레스 캠페인 발견]

모라라 같은 줄도 더 길다. 플랫 cap을 강제하면 좋은 랩/일본어 가사를 잘못 깎는다.

(이건 §9.0의 CRAFT/REPAIR/LOCK/STAGED 4모드와 직교 — 4모드는 "작업 방식", 여기 8모드는 "가사 문체".)

## §10. 표준 법 — 어떤 한 곡도 표준이 아니다 [C-147 연동]
단 하나의 곡, 특히 시스템이 생성한 곡은 표준이 될 수 없다. 표준 = 관련될 때 교차한 소스: 
화자 코퍼스 · 운영자 카탈로그 · 레지스터 맞춘 세계 크래프트. 예시는 포맷 데모지 천장이 아니다. 
줄이 아니라 *방법*을 모방. 품질은 화자 진실 · 사운드로서의 가사 · 구체 이미지에서 온다.

**금지(독창성 보존):** 소스 가사 복제 · 유명 훅 · 식별 가능한 표현 · 아티스트명 필드 삽입 · 
소스 줄 저장 · AI 요약 · 스톡 메타포 · 예쁜 컨셉 나열 · 일반적 고양(generic uplift).

## §11. 5000-RUNWAY — 가사는 평문이 아니라 퍼포먼스 활주로 [C-147 연동]
LYRIC과 COVER LYRIC은 5000자 미만 퍼포먼스 활주로. 
- **CREATE LYRIC** = 소스 타이밍·호흡·멜로디/큐·모티프 거동을 짓는다.
- **COVER LYRIC** = 게으른 복붙 금지. 최종 밀도·위스퍼 픽업·하드 스톱·드롭 셀·무보컬 필·훅 강조·
  최종 홀드/컷·소스 렌더 교정을 *재스테이징*. 
유용한 퍼포먼스만 — 절대 패딩 금지. (활주로 밴드: 활성 작업 4,000-4,800자, 5,000 헤드룸.)
