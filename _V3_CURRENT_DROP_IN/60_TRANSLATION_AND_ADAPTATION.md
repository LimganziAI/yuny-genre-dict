# 60. TRANSLATION & ADAPTATION (번안) ENGINE — 외국곡을 한국으로, 어미가 자연히 따라온다
# VERSION: v1.0 (2026-06-15) — 이력 CHANGELOG.txt
# 근거: 54(어미·레지스터)·55(장르 보이스)·56(가창성)·58(한국어 사운드패터닝)·59(소스언어 운)·14(운율)·26/27/08(언어별)·§9(번역 등가) + 노래 번역학 web 검증(Peter Low Pentathlon)
# 검증: Pentathlon Principle(singability·sense·naturalness·rhythm·rhyme 균형, 절대 sacrosanct 없음) · 3유형(translation/adaptation/replacement) · 음절수=리듬 보존(멜로디 안 깨지면 가감 OK) · naturalness=자연 어순·레지스터(번역투 탈피) · "dancing in fetters" 재창조 · EN→KO 가창번역 실재
# 위상: §9의 "직역 X·의미/운율 등가" 한 줄을 *엔진화*. 외국곡(영/일/스페인)을 한국으로 *번안*하되 어미·레지스터가 자연히 따라오게 — 54·55·56·58·59를 묶는 적용층.
# 발동: "이 곡 번안"·"외국곡 한국어로"·"이 느낌 한국어 버전"·외국 레퍼런스를 한국어 가사로. 
# ★핵심: 번안 ≠ 직역. 외국곡을 한국어로 옮길 때 문법을 번역하면 번역투. *의미·정서·멜로디는 보존, 표현은 한국어로 재창조* — 그러면 어미는 번역되는 게 아니라 "이 장르·이 감정의 한국 화자라면 뭐라 할까"에서 *자연히 emerge*한다.

## §0. 왜 — 직역하면 번역투, 재창조하면 노래가 된다
외국곡 가사를 단어·문법 단위로 옮기면 어색·번역투(naturalness 실패, Low). 좋은 번안은 *제약 속 재창조*("dancing in fetters") — 기존 멜로디에 맞춰, 한국어로 자연스럽게, 의미·정서를 살려 *다시 쓴다*. §9의 한 줄을 60이 엔진으로 편다.

## §1. ★Pentathlon Principle — 5축 균형 (Peter Low, web)
번안은 5축을 *곡마다 가중 조절*하며 균형(절대 1축만 사수 X — 타협 여지 클수록 성공):
```
축              뜻                                  YUNY 연동
─────────────────────────────────────────────────────────────
Singability     기존 멜로디에 부를 수 있음(최우선)     56(모음-온-노트·정합체인)
Rhythm          멜로디 음절/모라 수·프레이징 보존      14·§5(음절) / 59(소스 모라/음절)
Naturalness     자연 어순·레지스터(번역투 탈피)        54·55(어미·장르 보이스) ★어미 여기서
Sense           원곡 의미·정서 재현                   의미 보존(직역 아닌 등가)
Rhyme           운(소스 각운→한국어 모음운/반복)       58·59 §5(효과 매핑)
```
- 가창 기반 우선순위(일 연구): rhythm > naturalness > sense > rhyme. **Singability가 목표**, 나머지는 그를 위한 수단.

## §2. 3유형 (Low) — 목적에 맞게 선택
- **Translation(번역):** 의미 충실, 가창성 약함 — 자막·이해용. (노래엔 부적합)
- **★Adaptation(번안):** 멜로디·문화·자연스러움에 맞춰 *재창조*. 어미가 따라옴. **곡 작업의 기본.**
- **Replacement(개사):** 같은 음악, *새 가사*(의미 안 옮김) — 원 의미가 한국어로 안 살 때.
- ★판정: 의미가 핵심이고 한국어로 살릴 수 있으면 번안 / 멜로디만 빌리고 새 이야기면 개사.

## §3. ★어미가 자연히 따라오는 메커니즘 (네가 말한 그것)
번역하면 어미가 안 따라온다. 번안하면 따라온다 — 이유:
1. 원문 문법을 *옮기지* 말고, *의미·정서*만 추출.
2. 그 의미를 **이 장르(55)의 한국 화자가 이 감정에서 할 법한 말**로 다시 쓴다.
3. 그러면 어미는 *번역의 산물*이 아니라 *그 화자·그 장르의 자연 발화*에서 emerge — 54(어미 함의)·55(장르 보이스)가 자동 적용.
- 예: 영어 "I will never let you go"를 직역 "나는 너를 절대 보내지 않을 거야"(번역투·음절 과다) → 번안: 장르가 발라드면 진솔 "절대, 널 안 놓을게"(~게 의지·56 열린모음 '게'…ㅔ) / R&B면 "널 못 보내, 절대" — *어미가 장르·화자에서 따라옴*.
- ★규율: 어미를 "어떻게 번역하지"가 아니라 "이 사람이 한국어로 어떻게 말하지"로 접근(54/55).

## §4. 워크플로 (번안 시 — 내부)
```
1. 소스 분석: 의미·정서 아크 / 멜로디 음절(or 모라)·프레이징 그리드(행별 음 수) / 소스 운법(59) / 훅 개념·핵심 이미지
2. 유형·가중 결정: 번안/개사(§2) + 이 곡 Pentathlon 가중(§1)
3. 한국어 재창조:
   - 멜로디 음 수에 한국어 음절 맞춤(음당 1음절, 멜로디 허용 시 ±, §5·14)
   - 자연 한국어 레지스터·어미(55 장르 보이스 + 54, ★어미는 emerge §3)
   - 한국어 운(58 모음운/반복 — 소스 각운 직역 X, 59 §5 효과 매핑)
   - 의미·정서·훅 기능 보존(직역 아닌 등가)
4. Singability 패스(56): 원 멜로디의 머니노트 자리에 열린 모음 개음절
5. Naturalness 패스(54/55): "한국인이 이 장르에서 이렇게 말하나?" 번역투 sweep
6. 사운드 패스(58): 소스 운 자리에 모음운/반복
7. 완결성·흐름(§9.5) 통독
```

## §5. 보존 vs 재창조
```
보존(원곡에서 가져옴)              재창조(한국어로 새로)
──────────────────────────────────────────────────────
멜로디 음 수·프레이징(리듬)         운(→한국어 모음운/반복 58)
정서 아크·곡의 감정 흐름            관용구·idiom(→한국어 관용)
훅 개념·제목 기능                   어미·레지스터(→장르 자연 한국어 54/55)
핵심 구체 이미지(옮겨지면)          문화 특정 레퍼런스(→한국 등가)
```
- ★음 수(리듬)는 보존이 강제(멜로디가 고정) — 단 Low: 멜로디 안 깨지는 자리는 음절 가감 허용.

## §6. 양방향 (한국어→외국어도 동일 원리 역방향)
- 한국어곡을 영/일/스페인으로: 같은 Pentathlon, 타깃 언어 리듬형(59)으로 — 영어면 강세-각운·강세 자리, 일본어면 모라 수·종조사(26), 스페인이면 음절+sinalefa+assonance(27). 타깃의 *자연 레지스터*로 재창조(번역투 역방향도 금지).

## §7. ★저작권·독창성 (시스템 LAW 준수 — 절대)
- **기존 저작권 곡의 가사를 번역·복제하지 않는다(번역 복제도 금지 — 헌법).** 60의 "번안"은 *원곡 가사를 그대로 옮기는 게 아니라*, 외국곡의 *장르·정서·구조·바이브*를 포착해 **새 한국어 가사를 창작**하거나, *운영자 본인 곡/라이선스 자료*를 언어 간 적응하는 것.
- 유명 hook·식별 가능 구절 재현 금지. 의미·기능을 *새 표현*으로 재창조(§3).
- 레퍼런스 곡은 13/§11처럼 *기능 분해* + 새 가사. 릴리즈 목적이면 권리 1줄 게이트(30).

## §8. 출력 직전 체크 (54/55/56/58/59/§9.5와 함께)
```
□ 직역 아닌 번안인가 — 문법 옮기지 않고 의미·정서 재창조(§0§3)?
□ Pentathlon 5축 균형(singability 우선, §1)? 유형 맞나(번안/개사 §2)?
□ ★어미가 장르·화자에서 emerge(번역 아님) — 54/55 적용(§3)?
□ 멜로디 음 수에 한국어 음절 맞춤(리듬 보존, §5)? 머니노트 열린모음(56)?
□ 한국어 운=모음운/반복(소스 각운 직역 X, 58/59 §5)?
□ Naturalness — 번역투 0, 한국인이 이 장르에서 이렇게 말하나(54/55)?
□ ★저작권 — 기존 가사 복제·번역복제 X, 새 한국어 창작(§7)?
```
하나라도 어긋나면 보강. ★번안은 번역이 아니라 재창조다 — 의미와 멜로디를 안고, 한국어로 다시 부르면, 어미는 따라온다.
