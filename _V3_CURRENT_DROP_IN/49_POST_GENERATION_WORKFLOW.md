# 49. POST-GENERATION WORKFLOW — 생성 후 워크플로 (Studio·Stems·섹션편집 순서)
# VERSION: v1.0 (2026-06-15) — 이력 CHANGELOG.txt
# 근거: 30(렌더제어)·§14(반복 워크플로)·36(출력계약)·§1(COVER 메커니즘) + 현행 Suno Studio/Stems/Editor web 검증(2026-06)
# 위상: YUNY는 *프롬프트(8필드) 생성* 시스템 — 이 레이어는 *생성 후 운영자가 Suno에서 하는 작업* 안내(30 렌더제어와 상보). 클로드가 실행 X, 운영자 가이드.
# 발동: "이 곡 어떻게 다듬어/스템 어떻게/섹션만 고치고싶어/DAW로 넘기려면"·생성 결과 후처리 질문.
# ★핵심: **작업 순서가 전부 — 섹션편집 → 스템분리 → 믹싱.** 되돌리기 금지. 강한 섹션은 *지키고* around 작업.

## §0. 원리 — 순서를 지키면 되돌릴 일이 없다
Suno Studio는 생성기를 *프로덕션 도구*로 만든다(섹션편집·12스템·믹싱). 단 **순서 위반 = 손실**: 스템 분리 *후*엔 개별 스템
재생성 불가("드럼만 다시" X). 그래서 *구조·가사를 먼저 확정*하고 스템을 뽑는다. 80% 조정은 Studio, 나머지 20%는 DAW로.

## §1. ★작업 순서 (Order of Operations — 외우면 안 헤맴)
```
Step 1  베이스 생성        8필드 프롬프트로 곡 생성(슬라이더 디폴트) — YUNY 산출물 투입
Step 2  섹션·가사 확정      ★스템 분리 *전에* Replace Section/Alternates로 구조·가사 완성
Step 3  스템 분리 + 믹싱    Extract Stems(최대 12) → Volume/Pan/EQ로 밸런스. Add Track로 새 악기 추가 가능
Step 4  Remove FX          리버브 등 제거 → 깨끗한 소스(자기 리버브 입히려면)
Step 5  WAV 추출           시간정렬 WAV 스템 export
Step 6  DAW 마무리          Logic/Ableton에서 EQ·컴프·리버브·마스터링으로 최종
```
- **분리 전 vs 후:** 전=구조/가사(전체 트랙 작업) / 후=개별 스템 Volume·Pan·EQ·mute·solo + Add Track 새 악기(단 *기존 스템 재생성 불가*).
- 규칙: **제자리 수리, 전체 재생성 금지**(troubleshoot in place).

## §2. ★컴포저 마인드셋 (강한 것을 지켜라)
- **강한 섹션을 계속 remake 하지 마 — 저장하고 *around* 작업.** 강한 후렴/훅/보컬 모먼트를 도박처럼 날리지 마.
- **로컬 실패 = Replace Section/Edit Lyrics**(작은 수정 = 곡 정체성 보존 확률↑). 한 섹션 흔들리면 *그 섹션만* 수리, 전체 리롤 X.
- **무엇을 사수할지 먼저 정해:** 훅 / 가사 / 보컬 톤 / 섹션 역할 / 편곡 / 타이밍 / export 타겟. "지킬 게 생긴 후에만 컨트롤."
- Replace/Remake/Extend/Regenerate = Suno가 *새 해석* 생성(생성기 정상 동작). Song Editor가 위험을 *선택 구간*으로 한정.

## §3. 도구별 용도 (실패 유형 → 도구, 30/46 연동)
```
상황                          도구
──────────────────────────────────────────────
한 섹션만 실패(나머지 양호)     Replace Section / Edit Lyrics (로컬)
한 섹션 여러 버전 보고싶다      Alternates (생성 후 best 선택)
브릿지·2절 추가               Extend (1-2바 in/out으로 매끈한 전이)
타이밍 조정                   Warp Markers (비파괴 — 재생성 불필요)
리버브 과다                   Remove FX (스템별 리버브/딜레이 제거)
편곡 이슈(mid 과다)           Suno에서 수정 후 export
톤/EQ 이슈                    스템 export → DAW에서 마무리
보컬만 분리(가라오케)          Vocals+Instrumental 빠른 분리
정밀 믹스                     12스템 멀티 추출
```

## §4. 스템 → DAW 파이프라인 (하이브리드 — 아이디어 스케치 + 최종 폴리시)
- 프로 패턴: Suno로 곡 아이디어 → *드럼을 자기 샘플로 교체*·베이스 재녹음 → AI 보컬·멜로딕 코어는 유지 → DAW에서 결합.
- export: 일관 sample rate/bit depth(UI 설정 매칭). 시간정렬 WAV라 DAW에서 바로 정렬.
- Studio = 중간 편집층(80% 처리) — 마스터링은 Ableton/Logic. Remove FX ≠ AI 탐지 시그니처 제거(별개).

## §5. 권리·릴리즈 (생성 전 계획 — 30 소스 게이트 연동)
- 무료 플랜 트랙 = 비상업 / Pro·Premier = 상업권(스트리밍 배포). **라이선스는 소급 안 됨** — 나중에 업글해도 과거 무료 트랙 전환 X.
- 릴리즈 목적이면 *생성 전*에 플랜·타임라인 계획. 레거시 모델(v3.5/v4) deprecate 전 스템 early export(§17 백업 권유).

## §6. 업로드 시딩 (Audio Influence 연동, §12)
- 보컬 리프·기타 훅·드럼 루프 업로드 → 모델이 *이어감*(제로에서 시작 X). 업로드도 *새 생성 결과*의 일부가 됨.
- Audio Influence 高 = 멜로디·타이밍·프레이징 강하게 따름 / 低 = 영감만. 섹션 맵 불명확하면 업로드가 혼란 증폭 → 맵 먼저.

## §7. YUNY 연동 (프롬프트 → 생성 → 후처리)
- YUNY 8필드 = Step 1 투입물. 후처리는 운영자 몫 — 이 레이어로 *안내*만(클로드 실행 X).
- COVER(§1) = 최종 음질 형태 → 생성 후 Remaster/Replace Section은 *그 위* 미세 조정(30 Cover↔Remaster 라우팅).
- 운영자가 "스템/Studio/섹션" 물으면 이 순서 안내. 곡 *프롬프트* 요청이면 평소대로 8필드(이 레이어 발동 X).

## §8. 출력 직전 체크 (운영자 후처리 안내 시)
```
□ 작업 순서 안내(섹션편집→스템분리→믹싱)? 분리 후 개별 스템 재생성 불가 고지?
□ 강한 섹션 사수(저장 후 around) 강조? 로컬 실패=Replace Section?
□ 실패 유형 → 도구 매칭(§3)? 전체 리롤 말림?
□ DAW 핸드오프면 일관 sample rate + Remove FX 안내?
□ 릴리즈면 플랜·권리·라이선스 비소급 고지?
□ 이건 *안내*지 클로드 실행이 아님(YUNY=프롬프트 생성)?
```
★생성 후 = 순서 지키고 강한 것 사수 — 제자리 수리, 전체 재생성 금지.
