# 위상: 29가 *화자가 누구냐(WHO)*면, 54는 그 화자가 *어떤 결의 말을 쓰는가* — 어미의 사회적 함의·의도적 비완결·사회방언. "객관적 한 명의 화자" 탈피 엔진.
# 발동: 가사 작성 시 항상(특히 페르소나 뚜렷·문학적 결·다국어·"한 명이 말하는 거 같다"). 29와 동시.
# ★핵심: 화자가 누구냐가 *어미·말줄임·발음*을 정한다. 어미는 중립이 아니라 *태도·관계·계층*을 실어 나른다. 같은 뜻도 화자 따라 다른 어미.

## §0. 왜 — 중립 화자는 실패다
가사가 "객관적 한 명의 내레이터"로 들리면 죽은 가사. 어미 하나가 화자의 *나이·성별·태도·관계·계층·시대*를 노출한다. 29(화자
카드)로 WHO를 정했으면, 54로 그 사람의 *말투의 결*을 입힌다 — 어미 함의, 맺을지 흐릴지(비완결), 어느 사회방언인지.

## §1. ★한국어 어미 함의·레지스터 맵 (web 검증 + 화용)
어미 = 정보구조 + 화자 태도. 페르소나와 *함의*가 맞아야 한다(충돌 시 재선택).
```
어미              함의·정보구조                        화자 태도 / 어울리는 페르소나          ★충돌 경고
──────────────────────────────────────────────────────────────────────────────────────
~잖아             청자가 안다고 *전제*(공유경험 환기)    친근·확신·당돌 ~ 반박·불만·비난        ★여리고 조심스런 페르소나=당돌/시비조로 튐.
                  / 신정보면 동의 유도                  (억양 의존)                          확신·친밀·약간 당돌한 화자에만.
~거든             「화자만 아는 것」 → 이유·배경 제시     약간 방어·해명·정보("실은 말이야")     새침·해명형. 담담한 관조엔 어색.
~더라             자기 과거 관찰의 *회상적 거리*          관조·아련·담담·거리감                  뜨거운 직접 고백엔 안 맞음(식어 보임).
~네               가벼운 깨달음·감탄                     순하고 부드러움                        냉소·강한 단정 화자엔 약함.
~지               부드러운 단정 / 동의 가정               다정·확신·살짝 가드(혼잣말 톤)         차가운 단언 필요할 땐 약할 수 있음.
~ㄹ걸 / ~ㄹ 텐데   후회·추측                              미련·아쉬움                            결심·단호 화자엔 모순.
~란 말이야/~라니까 강조·답답함 토로                       감정 격해짐·우기는·호소               차분·시크 화자엔 과함.
~다 (평서 단독)    객관·서술·*문어적 거리*                관찰자·시적·차가운 거리                따뜻 친밀 독백엔 거리감 큼.
~어/~아 (반말)     직접·담백·구어                         솔직·평범·친밀                        문어적 장중함엔 안 맞음.
체언 종결(명사로 끝) 압축·여운·툭 던짐("네 이름 석 자.")   시크·절제·시적                         설명조·수다 화자엔 안 맞음.
~게/~ㄹ게          화자 의지·약속                         결심·자기 다짐                         수동·관조 화자엔 약함.
고어/역할어        ~단다(모성·옛)·~노라(장중)·~다오(청)    옛/동화/장중/특정 캐릭터               현대 구어 화자엔 이질(의도 시만).
```
- ★규율: 어미 팔레트는 페르소나 *축*(아래 §3)에서 도출. 한 곡 1팔레트(29)지만, 그 팔레트 자체가 *그 사람*이어야. 무지성 ~잖아 남발 = 시비조 사고.

## §2. ★의도적 비완결·말줄임 (§9.5 완결 강박 보정)
완결이 *대다수*지만 전부는 아니다. 흐름·페르소나상 *안 맺는* 게 맞을 때:
- **언제:** 망설임 / 미완의 감정 / 말 못 함 / 차마 / 여운 / 시크하게 툭. (정점·전환·엔딩에서 1-2회가 효과적.)
- **도구:** 줄표(—)로 흐려짐 · 말줄임(…) · 어미/조사 생략(체언 종결) · 도치 · 미완 종결("그냥, 너를—" / "돌리다 말고").
- **★규율(미완성과 구분):** 비완결은 *의도*일 때만. 전체가 미완이면 미완성(실패). 곡 *전체 서사*는 닫히되(§9.5), *개별 줄*은 의도적으로 열어둘 수 있다. 의도 없는 흐림 = R2 실패.
- **§9.5 보정:** "완결 강박 금지 — 줄 단위 의도적 비완결은 흐름·화자에 복무하면 허용. 단 곡 전체 아크는 닫힘. 비완결 빈도는 페르소나가 정한다(시크/망설임 多, 단호/선언 少)."

## §3. ★페르소나 축 → 어미·말줄임 선택 (29 화자 카드 연동)
화자를 *축*으로 분해 → 어미 팔레트 + 비완결 빈도 + 문장 길이가 따라온다:
```
축                    값 예시                          → 어미/말줄임 경향
─────────────────────────────────────────────────────────────────────
나이/성별             10대 소녀 / 30대 남 / 노년        소녀: ~어·~네·말줄임多, ~잖아·~거든 회피
태도                  여림·당돌·관조·냉소·다정·체념      냉소: 체언종결·~지·~더라, 감탄 少 / 다정: ~지·~네
관계/지향             연인에게·자기독백·세상에 외침       독백: ~더라·~지(혼잣말) / 외침: ~란 말이야·느낌표
시대/계층             고전·현대·거리·문어                고전: 고어/역할어 / 거리: 비속·축약·체언종결
```
- 같은 사건도 화자 따라: (여린)"…너를 보냈어, 그냥." / (냉소)"보냈지. 별거 아냐 —" / (관조)"그렇게 보내더라, 나도." 
- 충돌 검사: 페르소나 ↔ 어미 함의(§1) mismatch → 재선택. (예: 체념한 화자에 ~란 말이야 = 모순.)

## §4. 일본어 종결·역할어 (26 연동)
- **終助詞(종조사):** わ(여성·부드러움/관서男 다름)·よ(단언·통고)·ね(동의 구함·공감)·の(여성·설명/의문)·ぞ・ぜ(男·거침)·かしら(女·의문)·さ(가벼운 단언)·だい/かい(친근 의문)·もん(변명·어리광).
- **役割語(역할어):** 화자 정체성을 어미가 *표지* — お嬢様(~ですわ/~してよ)·노인(~じゃ/~のう)·소년·武士·박사(~じゃ) 등. 캐릭터 = 역할어로 즉각 각인.
- **言いさし(iisashi·말끝 흐림):** 일본어는 〜けど/〜から/〜て 에서 *멈추는* 미완이 흔함 → 배려·여운·간접. 일본어 비완결은 자연스러움(§2).
- **1인칭이 화자 정함:** 私/わたくし(정중·여성)·僕(소년·부드러운 남)·俺(거친 남)·あたし(여성 구어)·うち(관서/소녀) — 26 연동.

## §5. 영어 레지스터·사회방언 (08 연동 — 정합·존중)
- **레지스터 축:** elite/literary(완전한 절·무축약·subjunctive·다음절) ↔ casual ↔ vernacular.
- **AAVE 특징(흑인 보컬/소울/힙합/R&B 정합 시):** habitual *be*(she be working)·copula drop(you crazy, we good)·*ain't*·*finna/gonna/wanna/tryna*·이중부정(don't need no)·g-dropping(-in')·*y'all*·완료 *done*(I done told you). → R&B·gospel·soul·hip-hop 진정성.
- **Southern/working-class:** ain't·y'all·reckon·g-dropping·dropped auxiliaries.
- **Elite/RP-adjacent:** full grammar·no contraction·literary diction·complex clause.
- ★규율: 사회방언은 *화자 정체성에 진정성 있을 때만*. 코스프레·캐리커처·비하·민스트럴 금지(존중·정확). 문법과 발음이 *한 화자*로 일치(§6).

## §6. 보컬 사회방언 → 딜리버리·발음 (06/46/35 연동)
누가 부르냐 → diction·accent·모음·리듬을 *가사 문법과 일치*시킨다:
```
화자 결            보컬 딜리버리 / 발음 (Suno 큐)
──────────────────────────────────────────────
엘리트/RP          crisp diction, rhotic OR RP-adjacent, controlled vibrato, clean consonants
AAVE/소울          melismatic runs, behind-the-beat phrasing, vowel-rich, relaxed consonants, gospel melisma
포크/rural         plain nasal twang, flat affect, conversational, slight drawl
거리/street        clipped percussive consonants, rhythmic talk-sing, front-of-beat
문어/시적(한)       또렷한 발성, 모음 길게, 절제된 비브라토
```
- ★일치 규율: 엘리트 *문법*에 street *발음* = 충돌(의도 아니면). 가사 어미·문법(§1/§5) ↔ 보컬 발음(이 표)을 한 사람으로 맞춰라. §6 accent 명시 + 이 사회방언 결.
