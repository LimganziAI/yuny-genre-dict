# 위상: 25가 *강세를 Suno가 듣게*면, 56은 *어느 모음을 정점에 놓을지(가창성) + 발음·강세·큐가 한 줄로 정합되는지*. 가사는 page가 아니라 *불렸을 때*로 판정된다.
# 발동: 가사 작성·수정 + 큐 주입 + 머니노트/벨트/sustain 설계 시. 25·47·§8과 동시.
# ★핵심: 한 음절이 어떤 음 위에서 *어떻게 들리는가*(열린/닫힌 모음) + *강세가 박에 맞는가* + *[Singing:] 큐가 그걸 지시하는가* — 셋이 어긋나면 싸운다. 발음·느낌·강세는 큐사인과 한 몸이다.

## §0. 왜 — 가사는 불렸을 때로 판정된다
종이에서 좋은 가사가 불리면 무너질 수 있다: 닫힌 모음이 belt 정점에 박히면 가수가 못 뻗고, 강세가 약박에 떨어지면 흐물대고, [Belted] 큐를 줘도 모음이 안 받쳐주면 헛돈다. 56은 *소리(모음)·강세(박)·큐([Singing:])·프롬프트(보컬 묘사)* 넷을 한 줄로 맞춘다.

## §1. ★모음-온-노트 — 정점엔 열린 모음 (web 검증)
가창 음향학: **열린 모음(혀 낮음)은 강하게·길게·높게 부르기 쉽고, 닫힌 모음(혀 높음)은 고음·지속에서 큰 수정이 필요**. 음향 시뮬: [ɑ](아)·[ɔ](오/어)는 belt 음역이 *옥타브*까지, [i](이)·[u](우)는 unmodified면 ~5도밖에 안 됨.
```
한국어 모음    IPA      가창성(정점/belt/sustain)         배치 원칙
──────────────────────────────────────────────────────────────────
ㅏ            a/ɑ      ★최상 — 가장 열림, belt·sustain 왕  머니노트·벨트·긴 음에 1순위
ㅗ            o/ɔ      ★상 — 따뜻·열림, belt 옥타브        머니노트·sustain 우수
ㅓ            ʌ/ɔ      상 — 열림, 강한 톤                  머니노트·belt 좋음
ㅐ/ㅔ          ɛ/e      중상 — 밝게 뻗음                    하이·밝은 정점
ㅜ            u        중하 — 닫힘, 어두움, 고음 어려움      정점 회피(수정 필요)
ㅡ            ɯ        하 — 닫힘·중립, 뻗기 약함            정점 회피
ㅣ            i        하 — 가장 닫힘, 고음belt 큰 수정      ★정점 회피(또는 ㅔ로 modify)
```
- ★작법: **머니노트·벨트·긴 sustain 음절은 열린 모음(ㅏㅗㅓ)으로 끝나게 설계.** 닫힌 모음(ㅣㅡㅜ)이 정점에 오면 → 어휘 재선택(같은 뜻 다른 끝모음) 또는 그 음절을 정점에서 비킴.
  - 예: 정점에 "끝**이**"(ㅣ) → 못 뻗음 → "끝까지"의 "지"도 ㅣ… → 정점 단어를 *열린 모음 종결*로("보**내**" ㅐ / "**가**" ㅏ / "그**대**여" 보다 "너**야**"). ★샘플 「그냥 보내」가 머니노트를 "보**내**"(ㅐ)·"달려**가**"(ㅏ)에 둔 건 이 원리.
- 영어/일본어: EN도 동일(belt엔 ah/oh; "luck"→"lock"식 modify). JP는 5모음 중 あ(a)·お(o) 정점 유리, い(i)·う(u) 회피.

## §2. ★Target Vowel & 자음 타이밍 (web 검증)
- **음은 *모음* 위에서 지속된다. 자음은 지속 불가**(공명 없음). → 긴 음·정점은 *모음*이 받는다.
- **자음은 박 *직전*에, 모음이 정박/정점에 떨어지게.** ("보내"를 다운비트에 → 'ㅂ'은 박 직전, '오'가 박에.) 합창 Target Vowel 원리와 동일.
- **받침(coda)·자음군은 sustain을 흐린다.** 정점 음절은 *개음절(CV, 받침 없음)*이 이상적 — "사~"(받침X)는 늘어나고 "삶"(ㄻ)은 안 늘어남(14 §2.3 연동). 받침 있는 단어를 정점에 둬야 하면 받침을 *다음 음절로 연음*시키거나(밤이→바미) 정점은 개음절로.
- **l/r·비음 종결 주의:** ㄹ 종결("살", "별")은 sustain이 자음으로 새어 약함 → 정점은 모음 종결 우선.

## §3. ★정합 체인 — 소리·강세·큐·프롬프트 한 줄로 (이 파일의 심장)
한 정점을 만들 때 네 층이 *모두 같은 것*을 말해야 한다:
```
① 가사(소리)      정점 음절 = 열린 모음 개음절 ("보내"의 '내' ㅐ)         ← §1·§2
② 강세(박)        그 음절 = 강박/다운비트, 멜로디 최고음                   ← 25 §2 / 14 §2.7
③ 큐([Singing:])  [Belted] 또는 [Held] 또는 늘림(보-내) 그 위치에          ← §8 / 25
④ 프롬프트(보컬)  "belted peak / soaring money note" 보컬 묘사에 명시       ← 47 §money note
```
- ★불일치 = 싸움(실패 패턴):
  - 닫힌 모음(ㅣ) + [Belted] → 큐는 belt 시키는데 모음이 안 뻗음 → 긴장·음이탈. (①↔③ 충돌)
  - 열린 모음인데 약박·중간음에 묻힘 + 큐 없음 → 좋은 모음 낭비. (①↔② 충돌)
  - 큐는 [Held]인데 받침 자음 종결 → 자음에서 끊김. (②↔① 충돌)
- ★작법 순서: 머니노트 *위치*(47) → 그 자리 가사를 *열린 개음절*로(§1§2) → 강세=강박 정렬(25) → [Belted]/[Held]/늘림 큐(§8) → 프롬프트에 'money note' 명시(47). 넷 다 맞으면 정점이 산다.

## §4. 호흡·프레이징 ↔ 행 길이
- **부를 수 있는 행 = 숨 쉴 수 있는 행.** 한 호흡에 안 들어가는 긴 행은 가수가 몰아쉼 → 흐트러짐. 긴 행엔 [Breath] 자리 명시(§8) 또는 행 분할.
- **장르 템포 ↔ 행 길이:** 빠른 댄스/EDM = 짧은 행·잦은 숨 / 발라드·R&B = 긴 레가토 행 가능하나 호흡 표시. (39 phrasing 연동.)
- **들숨이 정서:** [Breath] · [Gasp] · 행 사이 쉼표는 *지시*면 살고 남발이면 끊김(§8 device 규율).

## §5. Mondegreen — 잘못 들리는 가사 차단
- **동음·연음 오인:** 연음됐을 때 다른 단어로 들리는 조합 회피("내 안에"→"내 아네"?), 받침 연음이 엉뚱한 뜻 되는지 점검(46 연동).
- **자음군 뭉개짐:** 빠른 구간에 자음 많은 음절 연속 → Suno가 뭉갬 → 빠른 곳은 자음 적은 음절.
- ★점검: 정점·훅·핵심 라인은 *소리 내어(머릿속으로라도) 불러보고* 오인·뭉갬 없는지. 불렸을 때 기준(§0).

## §6. 프롬프트·큐 반영 (끝단)
- 머니노트: 프롬프트 `single belted peak / soaring money note on the title` + 가사 정점=열린개음절 + [Belted]/늘림 큐. (셋 정합 §3.)
- sustain 많은 R&B/소울: 프롬프트 `melismatic runs, long sustained vowels` + 가사 개음절多 + [Melisma]/늘림.
- 또렷해야 할 힙합/구호: 프롬프트 `crisp clear diction, percussive consonants` + 가사 자음 또렷 + 강세=강박.
- ★프롬프트가 가창을 *요구*하면 가사·큐가 그걸 *받쳐줘야* — 한쪽만 있으면 헛됨.

## §7. 출력 직전 체크 (25/47/§8과 함께)
```
□ 머니노트·벨트·긴 sustain 음절이 열린 모음(ㅏㅗㅓ) 개음절인가(§1§2)? 닫힌 모음 정점 없나?
□ 정점 음절 = 강박/최고음 정렬(§3 ②)? 자음은 박 직전, 모음이 박에?
□ [Singing:] 큐([Belted]/[Held]/늘림)가 그 위치에 있고 모음이 받쳐주나(§3 ③)? 충돌 없나?
□ 프롬프트 보컬 묘사가 정점/가창 방식을 명시하고 가사·큐와 정합(§3 ④/§6)?
□ 긴 행에 호흡 표시 or 분할(§4)? 장르 템포에 행 길이 맞나?
□ 핵심 라인 소리내어 점검 — 오인·자음 뭉갬(§5) 없나?
```
하나라도 어긋나면 보강 후 출력. ★발음·느낌·강세는 큐사인과 한 몸이다 — 정점에선 열린 모음이 박 위에서 큐의 부름을 받아야 노래가 산다.
