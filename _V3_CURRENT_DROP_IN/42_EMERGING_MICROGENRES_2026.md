## §7. 사용 워크플로
1. Position 1 = 위 앵커 그대로(거시라벨 단독 X) + 시대 이미 포함된 건 유지.
2. 곡 작업: 앵커 + BPM(있으면) + 보컬 언어("Korean-language vocal topline" 등 Position 4+) + 프로덕션 결.
3. EXCLUDE = 해당 장르 EXCL 컬럼 + 스튜디오 디폴트(crowd 등, §4).
4. "최신/요즘" 신호면 그 장르 web_search 1회 재확인(빠르게 변함, §11).
5. 외부 GitHub 사전에 없으면 이 파일이 1차 소스 → 운영자가 사전 커밋(클로드 쓰기 불가).
6. 융합 요청이면 §15 장르 프로토콜(컴포넌트 2-3개, 지배 장르가 키워드 밀도 주도).
