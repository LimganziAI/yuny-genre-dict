# 58. KOREAN SOUND-PATTERNING — 한국어 라임·모음운·받침 echo·운율 (영어식 아님)

# 근거: 25(가사 사운드·연음·딕션 — 본 파일은 *시적 운 장치*)·14(운율·음절)·07(한국어 가사)·47(훅 반복)·29(화자) + 한국어 라임론 web 검증(2026-06)
# 검증: ★한국어=음절박자·무강세 → 영어식 강세 라임 직이식 불가(나무위키) · 모음 라임(assonance chain)이 한국 힙합 주류(P-Type 다음절 모음운) · 두운/요운/각운 · 동어반복+음수율/음보율(UMC 학파, 모음라임=영어식이라 비판) · 라임은 철자 아닌 *소리* 기준
# 위상: 25가 *부를 때의 소리(연음·강세·RENDERS)*면, 58은 *의도적 운 장치로서의 사운드 패턴(모음운·받침운·반복·음보)*. 둘은 보완.
# 발동: 한국어 가사 작성·수정 시(특히 훅·랩·반복 자리). 25·47·14와 동시.
# ★핵심: 한국어 라임은 영어 라임이 아니다. 한국어는 *강세가 없는 음절박자어* — 영어식 어말 강세-각운을 그대로 욱여넣으면 억지·번역투. 한국어의 운은 *모음 반복(assonance)·받침 echo·동어반복·음수/음보 리듬*으로 짠다.

## §0. 왜 — 영어 라임을 한국어에 욱여넣으면 망한다
한국어는 음절박자·무강세라 영어의 stress-foot 각운이 직접 적용 안 된다(web 검증). "대충 소리 비슷"을 라임이라 부르며 억지 어순·억지 단어를 끼우면 번역투·부자연(R2 실패). 한국어 운은 *다른 도구*로 — 그 도구를 58이 준다.

## §1. ★모음 라임 (Vowel Assonance) — 한국어 운의 주력
한국 힙합·현대 가사의 핵심: *모음 시퀀스*를 반복(받침·자음 달라도 모음열이 같으면 운). 다음절일수록 정교.
- 원리: 음절들의 *모음*을 맞춘다. 예 — "남자답지 / 난 작았지 / 만 차갑지"(ㅏㅏㅏㅣ 계열) 식 모음열 반복.
- 작법: ① 핵심 줄의 *모음 시퀀스*를 타깃으로 잡고 ② 그 모음열에 맞는 단어·구를 찾아 다음 줄·내부에 배치 ③ 단음절 각운보다 *2-4음절 모음운*이 세련(multisyllabic).
- 받침은 달라도 됨(모음이 운의 중심) — 단 받침까지 맞으면(§2) 더 단단.
- ★억지 금지: 모음운 맞추려고 *어순 비틀거나 뜻 망가지면* 운을 포기(의미·자연스러움 우선, §8).

## §2. 받침 echo (Coda Consonant) — 모음운의 강화
- 어말·핵심 음절의 *받침*을 반복하면 단단함: ㅇ(밤·강·정)·ㄴ(눈·산·문)·ㄹ(별·길·물)·ㅁ(꿈·봄·맘).
- ★비음 받침(ㅇㄴㅁ)은 *부드럽게 이어지고 sustain 좋음*(56 연동) → 후렴·긴 음 자리. ㄱㄷㅂ(폐쇄) 받침은 또렷·끊김 → 리듬·랩 자리.
- 모음운(§1) + 받침 echo(§2)를 같이 맞추면 완전운에 가깝되, 한국어에선 *모음운만으로도* 충분히 운으로 들림.

## §3. 두운·요운·각운 + 동어반복 (위치별 운)
- **두운(머리운):** 행 앞을 맞춤 — 이적식 "*그대를* 만나고 / *그대를* 만나고 / *그대를* 안고서". 반복이 곧 운·기억성.
- **요운(가운데운):** 행 내부 음소 반복 — 내부 리듬·말맛.
- **각운(끝운):** 행 끝 모음열/받침 반복 — 한국어에선 어미가 반복되면 자연히 각운처럼 됨(단 어미 단조 주의 — 29 팔레트로 변별).
- **★동어반복(repetition):** 같은 단어·구를 반복하는 것 자체가 한국어의 유효한 운 장치(UMC 학파). 후렴 hook·앵커 구절에 강력(47). "대충 비슷한 소리" 억지보다 *깔끔한 반복*이 나을 때 많음.

## §4. 음수율·음보율 (Syllabic / Metrical Rhythm) — 강세 없는 한국어의 리듬
- 한국어 리듬감은 *음절 수 규칙성*과 *음보(끊어 읽는 마디)*에서 온다(영어 stress-foot 대신).
- **음수율:** 행마다 음절 수를 일정하게(또는 의도적 패턴) — 3·4조(시조), 7·5조 등 전통 + 현대는 BPM×음절(§5)에 맞춘 일관.
- **음보율:** 한 행을 2-3 음보로 끊어 읽는 규칙 ("그대를 / 만나고" = 2음보) → 멜로디 프레이징과 정렬.
- ★실전: 운(모음/받침)이 안 잡히는 자리는 *음수율·음보 규칙성*만으로도 리듬·통일감이 선다(UMC식). 운에 집착 말고 *입에 붙는 마디*를 우선.

## §5. 두 학파 → 장르별 운용
```
학파/도구                     강한 장르                  쓰임
──────────────────────────────────────────────────────────────
모음 라임(다음절 assonance)    힙합/랩/R&B               flow·기교·촘촘한 내부운
동어반복 + 음수/음보율         발라드/포크/팝/트로트       hook 반복·자연스런 리듬·기억성
두운(반복)                    팝/동요/응원/CCM           앵커 구절·구호·따라부르기
각운(어미/모음 완만)          발라드/인디                 행 끝 은은한 마무리(어미 변별 29)
```
- 장르가 운의 *밀도와 종류*를 정함: 랩 = 모음운 촘촘·다음절 / 발라드 = 반복+음보·운은 은은 / 팝 = hook 반복+가벼운 모음운.

## §6. 라임은 소리 기준 (철자 아님) — 연음 반영
- 받침 연음이 *실제 소리*를 바꾼다: "같이"→[가치], "굳이"→[구지], "밤이"→[바미]. 운은 *발음된 소리*로 판정(46/25 연동).
- → 종이에서 안 맞아 보여도 *불리면* 맞을 수 있고, 반대도 가능. 소리 내어(머릿속) 확인.

## §7. 멜로디·훅·Suno 연동
- **모음운·반복은 이어웜 강화**(47): 같은 모음/구의 반복이 hook을 각인. 후렴에 모음운 or 동어반복 1개+.
- **운 ↔ 프레이징 정렬:** 운 자리(행 끝/내부)가 멜로디 프레이징 끝과 맞으면 단단(14 음보 연동).
- **Suno:** 운은 가사 본문에 내장(별도 큐 불필요). 단 반복 hook은 [Chant]/반복 섹션으로, 모음운 촘촘한 랩은 flow 큐로.
- **받침 sustain(56):** 긴 음·정점 운 자리는 비음 받침/개음절로.

## §8. ★Anti-pattern (출력 前 차단)
- 영어식 강세-각운 욱여넣기 → 억지 어순·번역투. (한국어는 모음운·반복·음보, §0)
- 운 맞추려 뜻·자연스러움 훼손 → 운 포기(의미 우선).
- 어미만 반복해 각운 흉내 → 단조(29 어미 팔레트로 변별).
- "대충 비슷한 소리"를 라임이라 자위 → 모음열을 *실제로* 맞추거나 깔끔한 동어반복으로.

## §9. 출력 직전 체크 (25/14/47/29와 함께)
```
□ 한국어 운을 영어식으로 욱여넣지 않았나(모음운/반복/음보로 §0§1)?
□ 모음 라임 or 동어반복이 훅·핵심 자리에 1개+ (장르 밀도 §5)?
□ 운 맞추려 어순·뜻 훼손 없나(의미 우선 §8)?
□ 받침 echo가 sustain/리듬 자리에 맞나(비음=긴음, 폐쇄=리듬 §2/56)?
□ 음수율·음보 규칙성으로 리듬 통일(운 없는 자리도 §4)?
□ 운을 소리(연음)로 판정했나(철자 X §6)?
□ 어미 각운이 단조롭지 않나(29 팔레트 변별)?
```
하나라도 어긋나면 보강. ★한국어 운은 영어 운이 아니다 — 모음이 메아리치고, 받침이 울리고, 반복이 새겨지고, 음보가 박자를 잡는다. 억지 각운보다 자연스런 모음운·깔끔한 반복.
