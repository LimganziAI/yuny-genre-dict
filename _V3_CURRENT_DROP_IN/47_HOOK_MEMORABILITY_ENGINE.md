# 47. HOOK & MEMORABILITY ENGINE — 훅·기억성 (이어웜 설계 → Suno 실현)
# VERSION: v1.0 (2026-06-15) — 이력 CHANGELOG.txt
# 근거: §8(가사큐/훅)·§7(컨투어)·33(섹션기능 post-chorus)·40(그루브)·44(보컬감정)·§12(구조) + 현행 훅/이어웜 작곡학 web 검증(2026-06)
# 위상: 가사·멜로디 크래프트에 *기억성(catchiness) 설계*를 더함 — 반복·단순·대비·기대를 훅으로 엔지니어링.
# 발동: 곡 설계 시(특히 팝/댄스/후렴 중심)·"훅이 약해/안 박혀/밋밋해"·후렴 임팩트 요청.
# ★핵심: 기억성 = 뇌의 *패턴 인식*. 반복이 메커니즘, 단순+대비+기대-보상이 증폭기. 훅 = 박히도록 *설계된* 순간.

## §0. 왜 — 뇌는 패턴을 기억한다
멜로디/리듬/구절이 반복되면 뇌가 latch할 패턴이 생긴다(장기기억 인코딩). "맛깔난 반복"이 기억성을 만든다 — 단 단조로움
X. 핵심 요소를 *핵심 자리에* 반복하되 매번 *변형*으로 신선하게. §9(가사 작법)이 *무엇을 말하나*면, 47은 *어떻게 박히게 하나*.

## §1. 훅 유형 (한 곡에 여러 개 가능 — 레이어) + Suno 실현
```
훅 유형          정체                          Suno 실현
──────────────────────────────────────────────────────────
멜로딕 훅        기억되는 짧은 멜로디·리프        §7 컨투어("hook leaps to the 5th")+머니노트(§4)
리리컬 훅        짧은 반복 구절(가사)            짧은 후렴 구절 반복(Lyrics)+자기인용 콜아웃(§8)
리듬 훅          그루브·베이스라인·싱코페이션      40(그루브)+CREATE Style 리듬 디스크립터
보컬 훅/챈트     "oh-la-la" 류 챈트·vocal chop    §6/§8 (chant·vocal chops·adlib·[Stacked])
```
- ★다중 훅(Bad Romance 모델): 후렴 멜로딕 훅 + verse 훅("Love love love") + 챈트("oh-la-la") — 어느 하나로도 충분. 강곡은 *겹쳐* 박는다.
- 챈트 훅은 곡 일부만 있어도 됨 — 각 verse *앞에* 깔고, 끝에 *무반주로* 다시(설정→회수).

## §2. 반복 엔진 (맛깔나게, 단조 X)
- *가장 중요한 요소*를 구조 전반에 반복 → 박힌다. 단 매 반복 *리듬/프레이징 변형*으로 신선(무변형 복붙 = 지루).
- **배치:** 후렴(핵심) + verse 핵심 자리 + *pre-verse 셋업*(각 절 앞 훅 예고) + *엔딩 회수*(끝에 훅 단독).
- 반복-속-변형 = §5(Verse2≠Verse1, Final=변형)·§9.5 완결성과 연동.

## §3. 단순성 원리 (★훅은 의외로 단순하다)
- 짧은 구절·적은 단어·부르기 쉬움. 복잡한 언어 = 뇌가 디코딩에 애씀 → 즉각성 상실. 단순 프레이징이 멜로디에 감정 싣게 함.
- 대화체 수준(Suno도 단순 가사를 또렷이 부름, 46 연동). 후렴 = 한 줄 ×2 + 짧은 의미 줄 / 짧은 질문+답.

## §4. 대비 & 돌출 순간 (뇌는 대비를 기억)
- 곡 대부분이 한 결로 흐르면 *대비되는 순간*이 박힌다: 비트 앞선 가사 / 길게 늘인 음 / 다이내믹 급변 / 음역 도약.
- **머니노트:** 가장 높거나 강렬한 음 = 곡 감정 핵심, 보통 후렴에. → §7 단일 peak note(곡 1회) + 44 belt/cry로 실현.
  CAPS/[Held]로 표기(§8). "money note on '[word]', belted peak".

## §5. 기대 & 보상 (설정→지연→회수)
- 반복은 *기대*를 만든다 — 뇌가 멜로디 회귀를 예측 → 들릴 때 쾌감/보상. Pre-Chorus가 기대 빌드, 후렴이 보상.
- 훅을 *아꼈다* 풀기: 인트로에 살짝 → 후렴에서 만개 / 끝에 단독 회수. 43 서사(보류)와 연동.

## §6. 멜로딕 훅 구성 (콜앤리스폰스·컨투어·부르기 쉬움)
- **콜앤리스폰스:** 둘째 프레이즈가 첫째에 *답*(대조/보완) → 기억 쉬움. "first phrase answered by a contrasting second".
- **변별 컨투어:** 도약·기억되는 형태(§7) — 밋밋한 순차만으론 안 박힘. 단일 peak.
- **부르기 쉬움(pentatonic 안전망):** 부르기 쉬운 = 기억하기 쉬운. 복잡 음정 도약 남발 X.

## §7. 멜로디 + 가사 LOCK (둘 다 강해야)
- 멜로디 훌륭+가사 잊힘 = 이어웜 X / 가사 훌륭+멜로디 잊힘 = 임팩트 X. *둘 다* 강해야 박힌다.
- 작법: 강한 멜로디 컨투어 잡고 가사를 거기 맞춰(또는 역). §7 컨투어 + §9 가사 동기화.

## §8. Suno 실현 — 훅을 8필드에 엔지니어링
- **CREATE Style:** "hook leaps to the [interval] of [chord], money note on the peak, [리듬 훅 디스크립터]" — 멜로딕+리듬 훅 명시(§7/40).
- **CREATE Lyrics:** 짧은 반복 후렴 구절 + [Singing:] 훅 딜리버리(belt/chant) + 보컬 챈트/chop(§6/§8) + 머니노트 CAPS/[Held] + pre-verse 셋업 + 엔딩 단독 회수.
- **반복-속-변형:** 후렴마다 미세 변형(§5/§9.5), Final = 증폭. **대비 큐:** 돌출 순간 1개(늘인 음/다이내믹 급변, §4).
- COVER도 훅 동일 유지(throughout, §1) — Final Chorus·Outro에 훅 밀도 사수.
