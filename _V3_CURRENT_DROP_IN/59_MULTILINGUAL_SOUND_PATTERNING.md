# 59. MULTILINGUAL SOUND-PATTERNING — 영어·일본어·스페인어 운법 (58 한국어판의 병렬)
# VERSION: v1.0 (2026-06-15) — 이력 CHANGELOG.txt
# 근거: 58(한국어 사운드패터닝)·08(영어 가사)·26(일본어)·27(스페인어)·14(운율) + 운율론 web 검증(2026-06)
# 검증: 언어 리듬형→운법(stress→stress-meter/iambic, mora→haiku 5-7-5, syllable→음절meter) · 영어 라임=마지막 강세모음부터 · 일본어=모라(장음2·ん1·っ1)·약한 운전통 · 스페인 sinalefa(모음 elision)·assonance(모음만)/consonance(완전)·octosílabo
# 위상: 58이 한국어 운이면, 59는 *소스 언어(영/일/스페인) 운 구조* — 번안(60)이 "뭘 보존/변환할지" 알려면 필수. 4언어 사운드패터닝 완성.
# 발동: 비한국어 가사 작성(08/26/27) + 번안(60) 시 소스 분석. 
# ★핵심: 운법은 언어의 *리듬형*을 따른다 — 강세박자(영)는 강세-각운, 모라박자(일)는 모라meter·약한 운, 음절박자(한/스/불)는 음절meter·모음운. 한 언어의 운을 다른 언어에 *직이식*하면 깨진다(번안은 효과를 매핑, §5).

## §0. 왜 — 운은 언어 리듬형의 산물
영어 라임을 일본어에, 일본어 모라를 영어에 그대로 옮기면 부자연. 각 언어는 *제 리듬형*에서 운법을 발전시켰다(web). 번안(60)이 잘 되려면 *소스의 운 구조*를 알아야 — 그래야 그 효과를 한국어 도구(58)로 재창조한다.

## §1. ★리듬형 → 운법 (통합 원리)
```
리듬형           언어                  운법(versification)
──────────────────────────────────────────────────────────
강세박자(stress)  영어·독일어            강세-foot meter(iambic 등) + 강세-각운(마지막 강세모음부터)
모라박자(mora)    일본어                모라 meter(haiku 5-7-5) · 약한 운전통 · 7·5조
음절박자(syllable) 한국어·스페인어·불어   음절 meter(음절 수) + 모음 기반 운(assonance)
```
- → 한국어(58)·스페인어는 *친척*(음절박자·모음운). 영어는 강세-각운. 일본어는 모라·운 약함. 번안은 이 차이를 *건너* 효과를 옮긴다.

## §2. 영어 (English) — 강세 기반 운
- **라임 유형:** Perfect(완전: cat/hat)·Slant/Near/Half(불완전: shape/keep)·Internal(행 내부)·Multisyllabic(다음절: 힙합 핵심)·Eye(철자만, 소리 X — 피함). 라임은 *마지막 강세모음부터* 일치(fog/log, history/mystery).
- **스킴:** AABB(couplet)·ABAB(교차)·ABCB(ballad)·AAAA. 라임+강세 함께 간다(강세 자리에 라임).
- **장르별:** 랩=촘촘한 internal+multisyllabic / 팝=후렴 end-rhyme hook / 발라드=완만한 각운. 
- **장치:** alliteration(두운)·assonance(모음)·consonance(자음)·onomatopoeia.
- **Pat Pattison 5종 라임(08 연동):** Perfect/Family/Additive-Subtractive/Assonance/Consonance — 안정/불안정으로 prosody 조절.
- ★강세박자라 음절보다 *강세 패턴*이 리듬의 뼈대 → 강세 음절을 강박에(25 §2 EN).

## §3. 일본어 (Japanese) — 모라 기반, 운 약함
- **모라(拍)가 단위(음절 아님):** CV=1모라 / 장음=2(とう=to-u) / ん=1 / っ(촉음)=1. haiku 5-7-5·tanka 5-7-5-7-7 = *모라* 수.
- **★약한 운전통:** 일본어는 모음 종결이 5개로 제한적이라 각운이 *너무 쉬워* 시 전통에서 운을 거의 안 씀 → *모라 수 규칙성*과 *반복*, 7·5조(shichigochō)가 리듬의 핵심. (한국어 음수율과 유사하되 *모라* 단위.)
- **현대 J-pop/J-rap:** 라임을 *씀*(모음 기반 assonance, 한국어와 유사 + 영어 차용 라임). 단 *모라 수·프레이징*이 더 깊은 구조.
- **어말:** 종조사(よ/ね/わ/の)가 행 끝(54 §4) → 각운보다 종조사 리듬.
- ★작법(26 연동): 모라로 세고(음절 아님), 운보다 *모라 수·7·5 리듬·반복*, 종조사 어말.

## §4. 스페인어 (Spanish) — 음절 meter + 모음 운
- **음절 meter:** octosílabo(8)·endecasílabo(11)·alejandrino(14). 끝 강세로 보정: aguda(마지막강세)+1 / llana(끝2번째)0 / esdrújula(끝3번째)−1.
- **★Sinalefa:** 인접 단어의 모음이 만나면 *한 음절로* 합쳐 셈("te había"→teha). 음절 수 맞추는 핵심 도구. 반대=dialefa/hiato(분리), sinéresis(단어 내 모음 합침).
- **운 2종:** **Assonance(모음운)** — 마지막 강세모음부터 *모음만* 일치(유려·대화체·서사, 짝수행). **Consonance(자음운)** — 모음+자음 완전 일치. romance=짝수행 assonance.
- **장르(27 연동):** Latin은 clave 리듬 grounding + sinalefa로 음절 흐름 + assonance 자연. 레게톤/살사 흐름.
- ★작법: 음절 세고(sinalefa 적용), assonance 기본(완전운보다 자연), 강세 종결 규칙.

## §5. ★Cross-Language 효과 매핑 (번안 60의 핵심 도구)
운은 *메커니즘이 아니라 효과*를 옮긴다 — 소스 운법 → 한국어 도구(58):
```
소스(원곡)                    효과              → 한국어 재창조(58)
─────────────────────────────────────────────────────────────
영어 강세-각운(end rhyme)      행말 결속·기대보상  → 모음운(assonance) or 동어반복(58 §1/§3)
영어 multisyllabic(랩)        촘촘한 기교        → 다음절 모음운(58 §1)
일본어 모라 수·7·5            규칙적 리듬        → 음수율·음보율(58 §4)
일본어 반복                    각인              → 동어반복(58 §3)
스페인 assonance(모음운)       유려·자연         → 모음운(58 §1, 거의 1:1)
스페인 음절 meter+sinalefa    음절 흐름          → 음수율 + 연음(58 §4/§6)
공통: 라임은 소리 기준(철자 X) · 강한 단어 행말 · 의미 우선(억지 운 X)
```
- ★원칙: 소스의 *각운*을 한국어 각운으로 직역하려 들지 마라(번역투). 소스가 *준 효과*(결속/기교/규칙성/유려함)를 한국어의 *자연스런 도구*(모음운/반복/음보)로 다시 만든다.

## §6. 출력 직전 체크 (58/08/26/27/14와 함께)
```
□ 소스 언어 리듬형 식별(강세/모라/음절)? 그에 맞는 운법으로 분석(§1)?
□ 영어=강세-각운/multisyllabic(§2) · 일본어=모라 수·약한 운·종조사(§3) · 스페인=음절+sinalefa+assonance(§4) 정확?
□ 번안이면 소스 운법 → 효과 → 한국어 도구 매핑(§5, 직이식 X)?
□ 라임을 소리로 판정(철자 X)? 의미 우선(억지 운 X)?
```
하나라도 어긋나면 보강. ★운은 언어의 리듬형을 따른다 — 강세는 각운으로, 모라는 규칙으로, 음절은 모음으로 노래한다. 번안은 그 효과를 건너 옮긴다.
