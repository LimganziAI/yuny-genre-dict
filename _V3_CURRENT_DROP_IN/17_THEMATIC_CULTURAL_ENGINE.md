## VERSION 2.0 — WHAT CHANGED AND WHY

v1.0 was a workable Scene Dossier system. It produced concrete-noun
banks, action-verb banks, anchor objects, environment cues — but
lacked execution depth in three areas the 2026-05-22 session
diagnosis surfaced:

1. **No Object Writing protocol.** v1.0 collected scene material
   but had no daily *generative practice* — Pattison's 10-minute
   sensory exercise. Without it, scene material recycles from the
   same sources.
2. **No Persona-first decision tree.** K-Pop industry practice
   *requires* persona lock before lyric write. v1.0 had persona
   as one of many lenses, not the *first* decision.
3. **No Genre Narrativity calibration.** Academic research (Berkeley
   2024) shows narrativity rate varies hugely by genre. v1.0
   treated all genres equally for scene depth.

v2.0 keeps v1.0's five lenses (theme / register / genre / scene /
named work) and adds:

- **§9 Object Writing Protocol** — daily 7-sense practice
- **§10 Persona-First Decision Tree** — persona lock before all else
- **§11 Genre Narrativity Calibration** — scene depth dialed by genre
- **§12 Anchor Object Methodology** — single-object metaphor expansion

Design principle: this file is *upstream* of lyric craft. It does
not write lines. It produces *raw material* — banks of concrete
elements that 07/08 then compose into lines.

## SECTION 0. PURPOSE — WHY THIS FILE EXISTS

Bad AI lyric symptom: abstract emotion statements, generic imagery,
clichéd nouns. Root cause: writer reaches for the *first available
word*, which is the *statistically dominant* word — i.e., the
cliché.

This file's job: *load the bank with specific, lived-in material
before lyric writing begins*. When the lyric writer reaches for a
noun / verb / image, the bank has *better candidates than the
default*.

Pipeline:
```
Brief Lock (01 §7.3)
   ↓
17 Scene Dossier Generation (this file)
   ├─ Persona lock (§10)
   ├─ Narrativity calibration (§11)
   ├─ Object Writing pass (§9, optional but recommended)
   ├─ Five research lenses (§2)

   ↓

Output
```

## SECTION 2. THE FIVE RESEARCH LENSES

### 2.1 Theme

The *what* of the song. Extracted from Brief Lock §1.1 (Concept).

Types:
- **Emotional state**: heartbreak, exhilaration, grief, longing
- **Situation**: party, breakup, road trip, return home
- **Concept**: time, memory, identity, freedom
- **Story**: specific event, journey
- **Tribute**: dedication to person / place / event

Theme research:
- *What's the central question*? (every theme implies a question)
- *What contrasts / tensions* live inside it?
- *Whose experience* is this (persona, see §10)?

### 2.2 Semantic Fields

Groups of words that share meaning territory. A song with 5-6
*connected* semantic fields feels *unified*. Random jumps between
fields = AI soup.

Examples:
- "Summer rooftop" field: concrete, asphalt, heat, sun, AC unit,
  pigeon, shadow, water bottle, sneakers, fence
- "Late-night call" field: phone screen, lock screen, ringtone,
  silence, kitchen light, refrigerator hum, voicemail, time stamp,
  unread message
- "Empty apartment after breakup" field: empty closet, half-coffee
  in sink, dust on shelf, light through blinds, second pillow

Generate 5-6 fields per song. Check they *connect logically* — they
should belong to the same world.

### 2.3 Environment Cues

The *physical setting*. Concrete answer to: where does this song
happen?

Lock down:
- **Location**: city / neighborhood / room / outdoor / indoor
- **Time**: hour, season, era
- **Weather / ambient conditions**: rain, snow, heat, fluorescent
  light, neon, candlelight
- **Sensory environment**: noise level, smell, temperature, light
  quality
- **Solitude vs people**: alone / dyad / crowd / observed

Environment cues → directly become Imagery / Detail in AID (07 §7.4,
08 §4.2).

### 2.4 Concrete Noun Bank + Action Verb Bank

Two parallel banks per song:

#### Concrete noun bank (8-15 items)
- Specific objects from the scene
- *Named*, not abstract ("white lily" not "flower")
- Mix of: furniture, clothing, food/drink, technology, vehicles,
  places, body parts, weather elements

#### Action verb bank (8-15 items)
- Mid-to-high wattage (50-1000W, see 08 §5.1)
- Connected to scene
- Mix of: physical (walk, throw, lift), sensory (touch, smell),
  transformative (break, melt, fade), figurative (haunt, devour)

These banks are *drawn from* during line composition.

### 2.5 Named-Work Touchstones

When references help: songs, films, books, brands that anchor the
sensibility. See §5 for handling rules.

## SECTION 4. CULTURAL REGISTER LIBRARY

### 4.1 What register means

Register = the *social tone* of the language. Different from genre.
- Casual / intimate / informal
- Polite / professional / measured
- Formal / ceremonial / distant
- Slang / street / coded
- Archaic / literary / elevated
- Sarcastic / ironic / arch
- Childlike / playful / silly
- Vulnerable / confessional / quiet

### 4.2 Korean register-specific palette

| Register | 어미 / 어휘 결 | Use |
|---|---|---|
| 일상·친근 | ~야 / ~지 / ~네 / 일상 단어 | Pop main, K-indie |
| 정중 | ~요 / ~어요 / 격식 단어 | Ballad, OST |
| 격식 | ~ㅂ니다 / 한자어 | Ceremonial, formal |
| 시적 / 모던 | 어미 생략 / 명사 마감 | Modern K-Pop, indie |
| 향수 | ~었지 / ~았어 / 옛 단어 | Retro pop, ballad |
| 절박 / 격렬 | 단문 / 도치 / 외침 | Hip-hop, rock |
| 익살 | 의성어·의태어 / 감탄사 | Bubblegum, novelty |
| 거리 / 슬랭 | 신조어 / 음차 | K-Hip-Hop, urban |

### 4.3 English register-specific palette

| Register | Vocabulary / syntax | Use |
|---|---|---|
| Conversational | Contractions, simple words | Indie pop, folk |
| Confessional | First person, vulnerable | Singer-songwriter |
| Declarative | Strong statements, no hedging | Pop anthems |
| Poetic | Metaphor-dense, image-driven | Art-pop, indie |
| Hip-hop vernacular | AAVE markers, internal rhyme | Rap, R&B |
| Country narrative | Specific place / time / object | Country |
| Cinematic | Image-led, atmospheric | Synthwave, ambient |
| Ironic / detached | Wry observation | Indie rock, hyperpop |

### 4.4 Register-genre matching defaults

Genre → likely register:
- K-Pop main → mixed (cute / girl crush / dark depending on persona)
- K-Indie → confessional / poetic
- K-Ballad → 정중 / 시적
- K-Hip-Hop → 거리 / 슬랭
- US Pop → declarative / conversational
- US Country → narrative / specific
- US Indie → confessional / ironic
- US Hip-Hop → vernacular / declarative
- Synthwave → cinematic / detached
- Hyperpop → ironic / mixed

These are defaults, not rules. Persona (§10) overrides genre default.

### 4.5 Register consistency gate

Throughout one song:
- Verse 1 register = Chorus register (or deliberate contrast)
- Don't mix 격식 + 슬랭 unless persona is "professor who code-switches"
- Bridge can shift register *if* shift maps to emotional shift

## SECTION 5. NAMED-WORK REFERENCE HANDLING

### 5.1 When references help

- Establishing *sensibility* fast ("Like Mac DeMarco" → operator
  understands fingerstyle warmth, chorus pedal, lazy vocal)
- Communicating *era* ("80s synthwave Drive soundtrack")
- Naming *texture* ("Bjork-style strings")

### 5.2 Reference categories

- **Songs**: specific tracks
- **Albums**: cohesive collections
- **Artists**: career bodies
- **Films**: visual reference
- **Books / poetry**: literary reference
- **Brands / products**: object specificity
- **Places**: location specificity

### 5.3 Reference handling — Suno specifically

Suno blocks direct artist references in style box (most cases).
Workarounds:

- **Description over name**: "smoky lo-fi indie female vocal in the
  style of mid-2010s bedroom pop" (no artist name)
- **Era + genre**: "early 2010s indie folk" 
- **Specific elements**: "fingerstyle nylon string + half-time
  shuffle + close-mic vocal" — describes the *qualities*
- **Korean-bracketed name**: "NMIXX(엔믹스)" — sometimes passes
  filter, *operator-tested, not guaranteed*
- **Combined approach**: "K-pop hyperhook 40% + bubblegum 30% +
  brat 20% + chromatic 10%" — operator's % rule (see 09)

### 5.4 Lyric reference handling

In lyrics themselves:
- **Brand names**: usually OK in lyrics (Marlboros, Coca-Cola,
  Polaroid)
- **Place names**: usually OK (Houston, Seoul, Brooklyn)
- **Real people**: case-by-case — public figures in non-defamatory
  contexts usually OK, but operator should verify
- **Song titles / quotes from other songs**: ban unless parody /
  homage with permission

### 5.5 Reference fatigue

Don't pile references. 1-2 named touchstones per song. More =
operator's vision blurry, system confused.

## SECTION 9. OBJECT WRITING PROTOCOL (NEW v2.0)

### 9.1 What Object Writing is

Pat Pattison's daily 10-minute sensory exercise. Pick a random noun.
Write 10 minutes using all 7 senses. No editing, no metaphor
pressure — direct sensory description only.

Purpose: *load the writer's sensory bank* with specific, lived-in
material *before* you need it. When lyric writing demands a sensory
detail, the bank has options *better than the cliché default*.

### 9.2 The 7 senses (Pattison)

1. **Sight** — color, shape, light, movement, shadow
2. **Sound** — noise, silence, tone, rhythm, echo
3. **Smell** — scent, smoke, decay, freshness, food
4. **Taste** — sweet, salt, bitter, sour, umami, metal
5. **Touch** — temperature, texture, pressure, wet/dry, weight
6. **Organic** — heartbeat, breath, stomach, nausea, dizziness,
   thirst — *the body from inside*
7. **Kinesthetic** — body in space, balance, motion, reach,
   gravity, exertion — *the body in action*

Most beginners write sight + sound only. *Force the other 5*. Real
emotional power lives in organic and kinesthetic — these are the
senses that *root the listener in their own body*.

### 9.3 The 10-minute protocol

1. **Pick a random noun.** Open a book, point to a word. Roll a
   die for a list. Use §9.7 list.
2. **Set a 10-minute timer.**
3. **Write without stopping.** No editing, no second-guessing. If
   you stall, write "I'm stalling, what does the noun smell like?"
   and answer.
4. **Hit all 7 senses.** At minimum 1 sentence per sense.
5. **Resist metaphor.** Direct sensory description first. Metaphor
   can come later in lyric draft.
6. **Stop at timer.** Don't run over.
7. **Pause 5 minutes.** Walk away. Make tea. Don't read what you
   wrote.
8. **Return and mark.** Highlight the 3-5 strongest images. These
   go to the bank.

### 9.4 What "strongest image" means

Strong:
- Specific (named object, not generic)
- Sensory beyond sight (smell / touch / taste / organic / kinesthetic)
- Unexpected (not the first thing you'd write)
- *Could survive in a lyric line as-is*

Weak:
- Generic ("the room was warm")
- Sight-only when other senses available
- Cliché reach ("the sun was bright")
- Tells emotion ("I felt sad")

### 9.5 Example Object Writing session

Random noun: **버스 정류장 (bus stop)**

10-minute output:

**Sight**: 가로등 빛이 비닐 의자 위에 노랗게 흐른다. 시간표
종이가 가장자리부터 말려 있고, 누군가 매직으로 ✕ 표시를 해놨다.
바닥 타일 한 장이 깨져서 그 자리가 어두운 그림자다.

**Sound**: 멀리서 엔진이 오는 소리. 가까이서 누군가 껌 껍데기를
뜯는 소리. 신호등이 삑삑 — 시각장애인용 멜로디가 너무 크다.

**Smell**: 비 온 뒤 아스팔트. 어디선가 누군가의 담배 끝. 누군가의
빨래 향이 바람 결에 묻어온다.

**Taste**: 캔커피의 알루미늄 맛. 아침의 졸린 입안. 입술이 마르다.

**Touch**: 의자가 차다 — 청바지 너머로 다리에 닿는다. 종이가
약간 축축하다. 손이 시리다.

**Organic**: 늦었나, 숨이 가쁘다. 위가 비어 있다 — 아침 못 먹었다.

**Kinesthetic**: 버스가 모퉁이 돈다 — 발끝을 든다. 손을 든다.
가방끈을 다시 어깨에 올린다.

**Strongest images** (marked):
- 매직으로 ✕ 표시된 시간표
- 신호등 삑삑 멜로디
- 캔커피 알루미늄 맛
- 발끝 들고 손 들기

→ Goes to bank for next song.

### 9.6 Object Writing → Scene Dossier pipeline

After 7 days of daily practice:
- Concrete noun bank: 30-50 items
- Verb bank: 30-50 items
- Sense-specific banks: 20+ items per sense

When new song starts:
1. Pull from existing banks
2. Add 1 fresh Object Writing pass on song's anchor object (§12)
3. Combine for Dossier

This eliminates *reaching for cliché defaults*.

## SECTION 10. PERSONA-FIRST DECISION TREE (NEW v2.0)

### 10.1 Why persona first

K-Pop industry rule: *persona lock before any lyric write*. Same
applies broadly:
- Without persona, vocabulary drifts (격식 + 슬랭 mixed)
- Without persona, register inconsistent across sections
- Without persona, anchor object choice unmotivated
- Without persona, narrativity calibration random

Persona = *who is speaking*. Every other Dossier decision flows
from persona.

### 10.2 Persona dimensions

Lock down for each persona:

1. **Age range**: teen / 20s / 30s / 40s+ / ageless
2. **Gender / identity expression**: feminine / masculine /
   androgynous / fluid
3. **Social position**: rebel / insider / observer / outsider
4. **Emotional stance**: vulnerable / confident / detached / chaotic
5. **Relationship to listener**: confessional / direct address /
   broadcast / overheard
6. **Speech pattern**: clipped / fluid / formal / slangy / poetic

### 10.3 K-Pop persona archetypes (from 07 §13)

| Persona | Age | Stance | Speech | Use |
|---|---|---|---|---|
| Cute | Teen | Light, playful | Short, exclamatory | TWICE, ITZY early |
| Girl Crush | 20s | Confident | Declarative, command | LE SSERAFIM, BLACKPINK |
| Dark | 20s+ | Mysterious | Minor mode, restraint | Red Velvet, aespa dark |
| Boyish | Teen-20s | Self-affirming | Casual, slang OK | Stray Kids, NCT |
| Retro | Ageless | Polite nostalgia | 80s/90s vocabulary | NewJeans, IVE retro |
| Futuristic | Ageless | Abstract | Tech-adjacent, repetition | aespa Next Level |
| Antihero | 20s+ | Rebellious | Self-questioning | BLACKPINK, Charli XCX |
| Shy Romantic | Teen-20s | Vulnerable | Indirect, questioning | IU, OST balladeers |
| Troublemaker | Teen-20s | Chaotic | Playful destruction | hyperpop, brat |

### 10.4 Non-K-Pop persona archetypes

Western pop / indie / hip-hop personas (less codified, more open):

- **Confessional songwriter** (Phoebe Bridgers, Mitski lineage)
- **Heartbroken narrator** (country tradition, Adele)
- **Trickster / wordsmith** (Eminem, Kendrick narrator modes)
- **Existential observer** (LCD Soundsystem, The National)
- **Party hedonist** (party rap, festival EDM hook)
- **Lone romantic** (synthwave, Lana Del Rey, The Weeknd)
- **Vulnerable confessor** (Billie Eilish, indie pop)
- **Cosmic / detached** (Frank Ocean, Tame Impala)
- **Storyteller** (Bruce Springsteen, country narrative)

### 10.5 Persona decision tree

```
START
   ↓
Genre? (from Brief Lock)
   ↓
   ├─ K-Pop → §10.3 archetype menu
   ├─ K-Indie → §10.4 + Korean register adjustment
   ├─ Pop main → §10.4 menu
   ├─ Hip-Hop → §10.4 + narrative voice required
   ├─ Country → §10.4 + storyteller voice required
   ├─ Indie → §10.4 + confessional default
   └─ EDM / Dance → simplified persona (anthem, hedonist)
   ↓
Operator's brief? (vibe / mood)
   ↓
Adjust persona within genre archetype
   ↓

   ↓

```

## SECTION 11. GENRE NARRATIVITY CALIBRATION (NEW v2.0)

### 11.1 The academic finding

Berkeley + ACM 2024 large-scale studies:
- Hip-Hop / Rap: *highest* narrativity (detailed scene, characters,
  plot)
- Country: very high (Grammy nominees *more* narrative than
  non-nominees)
- Rock: increasing narrativity over time
- Pop: moderate narrativity, *faster plot progression*
- R&B / Soul: lower, mood-focused
- EDM / Dance: lowest, anthem-mode

### 11.2 Narrativity dial 0-10

Calibrate each song:

| Dial | Description | Genre default |
|---|---|---|
| 0-2 | Pure mood / anthem | EDM, ambient |
| 3-4 | Emotional snapshot | Synthwave, R&B mood |
| 5 | Balanced (some story, some mood) | Mainstream pop |
| 6-7 | Story-leaning | Indie folk, K-ballad |
| 8-9 | Story-dominant | Country, hip-hop |
| 10 | Pure narrative | Folk ballad, concept rap |

### 11.3 Dial → lyric implications

| Dial | Verse content | Chorus content | Scene depth |
|---|---|---|---|
| 0-2 | Vibe phrases | Mood anchor | Minimal scene |
| 3-4 | Sensory snippets | Emotional core | Light scene |
| 5 | Some narrative, some image | Hook-led | Moderate scene |
| 6-7 | Scene with action | Hook + reflection | Detailed scene |
| 8-9 | Story progression | Story payoff | Full scene + characters |
| 10 | Linear plot | Story climax | Multi-scene |

### 11.4 Narrativity signal words

To dial *up* narrativity, include:
- Specific time markers: "Tuesday night," "after the storm," "at 4 AM"
- Specific place names: "Houston," "the river road," "Bushwick"
- Specific characters: "the man at the bar," "my mother," "her brother"
- Action verbs: said, planned, took, threw, walked
- Cause-effect connectors: "so I," "then," "until," "but"

To dial *down* narrativity, lean into:
- Abstract emotion (still wrapped in image, but image is mood-based)
- Sense-only description (no characters, no actions)
- Repetitive hook
- Atmospheric placeholders

### 11.5 Operator brief → dial calibration

Operator phrases that signal high narrativity:
- "이야기 / 스토리 / 서사"
- "장면 / 영화 같은"
- "구체적 / 디테일"

Operator phrases that signal low narrativity:
- "분위기 / 무드 / vibe"
- "추상적 / abstract"
- "anthem / 댄스"

Operator phrases that signal moderate:
- Default — if not specified, set to 5

### 11.6 Anti-pattern: narrativity-genre mismatch

- Country song at dial 2 → feels empty (genre demands story)
- EDM at dial 9 → loses the hook (genre wants anthem)
- Hip-hop at dial 1 → wastes the genre's narrative power

Match dial to genre default unless deliberately subverting.

## SECTION 12. ANCHOR OBJECT METHODOLOGY (NEW v2.0)

### 12.1 What an anchor object is

A *single concrete object* that becomes the song's central image.
Not metaphor at the abstract level — a *thing* you can hold, see,
hear, that *physically* anchors the song.

Examples:
- The empty chair at the table
- The white lily on the grave
- The voicemail at 3 AM
- The streetlamp on the corner
- The Polaroid on the fridge
- 매직으로 ✕ 표시된 시간표
- 6시 옥상의 콘크리트
- 죽어버린 에어컨
- 캔커피의 알루미늄 맛

### 12.2 Why anchor object

Pattison's "one metaphor rule" applied to *objects*: pick one
concrete thing, let *all the song's emotional weight* attach to it.
The listener has a single visual / sensory hook to remember.

Without anchor object: emotions float, listener loses grip.
With anchor object: every emotion has a *place to land*.

### 12.3 Anchor object selection criteria

A good anchor object:
1. **Specific, named** (not "flower" but "white lily")
2. **Sensory** (you can describe via 5+ senses)
3. **Carries narrative potential** (suggests history, fate)
4. **Persona-appropriate** (this persona would notice / care)
5. **Genre-appropriate** (anchor object should fit genre register)
6. **Repeatable** (can recur across verses without feeling forced)

### 12.4 Anchor object expansion

Once selected, expand:
- **Verse 1**: introduce the object in scene
- **Pre-Chorus**: zoom in on the object
- **Chorus**: object becomes the emotional statement
- **Verse 2**: object in different time / context
- **Bridge**: object transformed / revealed
- **Final Chorus**: object as climax
- **Outro**: object's final position

### 12.5 Example anchor object lifecycle

Anchor: **죽어버린 에어컨 (the dead AC)**

- Verse 1: "6시 옥상 위에 에어컨이 죽었어 / 콘크리트가 햇빛에
  녹는다"
- Pre-Chorus: "이런 날엔 그냥 우주로 가버려도 좋겠어"
- Chorus: "태양아 안녕 / 잘 가렴 / 공룡도 빠이 했을걸"
- Verse 2: "에어컨 소리 없는 옥상은 너무 조용해 / 비둘기마저
  떠난 자리"
- Bridge: "그땐 몰랐어 / 마지막인 줄 / 에어컨이 마지막으로
  돌아간 날"
- Final Chorus: (same hook, deepened)
- Outro: "에어컨이 죽은 그 여름이었어"

→ Anchor (AC) holds entire song.

### 12.6 Anti-pattern: multiple anchors

If you find 2+ anchor objects competing:
- Pick one as primary
- Make others *supporting cast* — they exist in scene but don't
  carry weight
- Save unused anchors for next song

### 12.7 Anchor object review

Before Dossier locks:
- [ ] Single anchor identified
- [ ] Anchor passes 6-criteria check (§12.3)
- [ ] Anchor expansion plotted across sections (§12.4)
- [ ] No competing anchors
