# 발동: 바일링구얼 곡·"영어 후렴/한영 섞어/스페인어 훅"·K-pop 한영 혼용·크로스언어 라임.
# ★핵심: 코드스위칭은 *화용적 동기*(정체성·강조·친밀)지 장식이 아니다. 모국어=친밀/뉘앙스, 영어=강조/보편/모멘텀. Suno 안전 = *섹션 경계* 전환.

## §0. 원리 — 전환에는 이유가 있다
음악 코드스위칭은 *구어 문법 제약을 벗어나* 아티스트의 바일링구얼 정체성을 반영 — 무작위 X. 기능: 정체성 확인 / 인그룹 마커 /
스타일 / 외부 개방 / 강조. 핵심 패턴 = *섹션 경계 전환*(모국어 벌스=친밀·취약, 영어 후렴=강조·보편). §9 LAW의 바일링구얼 운율 prep 연동.

## §1. 배치 레벨 (섹션 / 줄 / 단어)
```
레벨        방식                              Suno 안전도
──────────────────────────────────────────────────────
섹션        벌스=언어A, 후렴=언어B            ★최안전(§12 격리 부합) — 디폴트 권장
줄          줄 단위 교차(콜앤리스폰스적)        중간(섹션 내 = 발음 표류 위험, §12)
단어        한 줄 안 코드믹스(크로스 라임)      위험 — Suno 발음 표류, *드물게* 통하는 자리만
```
- ★Suno 권장: **섹션 경계 전환이 디폴트.** 줄·단어 레벨은 §12 발음 표류 리스크 — 의도·효과 확실할 때만.

## §2. 기능적 동기 (왜 전환 — 동기 필수)
- **모국어 = 친밀·취약·텍스처·뉘앙스·무게.** 감정 코어·디테일. (BTS RM/Suga: 한국어=texture·nuance·weight, §9.)
- **영어 = 강조·보편·시적 어필·훅·모멘텀.** 후렴/훅에서 보편 호소. (BTS: English=momentum.)
- **전환 자체가 의미:** 정체성 확인 / 인그룹(아는 사람만) / 외부 개방(글로벌). 전환이 *서사·정서를 진전*시켜야(무동기 X).
- ★규율: "왜 여기서 언어가 바뀌나?" 답 못 하면 전환하지 마. 멋부림 X.

## §3. 씬·장르별 패턴
```
씬/장르       코드스위칭 패턴
──────────────────────────────────────────────
K-pop         영어를 훅/후렴/인트로에 차용 → *한국어 음운에 맞게 변형*(22). 한국어 벌스 + 영어 훅 다수
Latin pop      영어 벌스 → 스페인어 후렴(또는 역). Demi Lovato "Échame la Culpa"형(영벌스→스페인어후렴)
레게톤         크로스언어 워드플레이·라임(비음운 발음 매칭). 스페인어 베이스 + 영어 포인트
힙합           모국어 라임 + 영어 펀치라인/훅. 코드믹스 자연(씬 관습)
J-pop/시티팝    일본어 벌스 + 영어 후렴 구(레트로 결). 26 톤 유지
글로벌 팝       모국어 정서 코어 + 영어 보편 후렴(크로스오버 전략)
```

## §4. 크로스언어 라임·워드플레이 (고급)
- 두 언어 *사이* 라임(음운 매칭) — 예: 비로틱 발음으로 영어-스페인어 음 맞추기(Pitbull형). 14 운율 + 25 사운드 연동.
- 한 컨셉을 두 언어로 *대구*(같은 의미 다른 언어 = 강조). 단 Suno 발음 표류 주의 — 효과 확실할 때만.

## §5. Suno 실현 (46/§12 화해)
- **섹션 격리 유지(§12):** 한 섹션 = 한 언어. 비영어 섹션에 "all lyrics in [lang], no English" — 코드스위칭은 *섹션 경계에서만* 안전.
- **Style:** "bilingual, Korean verse, English chorus"(§12). 어느 언어가 어느 섹션인지 명시.
- **차용어 음운(46):** K-pop식 영어 차용은 *모국어 음운에 맞게* — 한글/가나로 쓰면 네이티브로 읽음, 별도 발음가이드 줄 X(46, 중복 보컬 방지).
- **줄·단어 코드믹스 최소:** §12 발음 표류 → 섹션 경계 우선. 정 필요하면 그 줄만 신중히.
- §9 LAW: 바일링구얼 곡은 *교차언어 운율 prep* 필수(각 언어 음절·라임 따로 설계).

## §6. 규율
- 전환은 *동기*(친밀↔강조, 정체성) — 무동기·멋부림 X. "왜 여기서?" 답 가능해야.
- 각 언어 *그 언어답게*(07/08/26/27 풀바디) — 영어 후렴도 번역투 X, 영어로 직접 구상.
- Suno 안전(섹션 격리) 우선 — 화려한 줄/단어 믹스보다 *효과적인 섹션 전환*.
- 모국어 = 정서 코어 사수(코드스위칭이 정서 흐름 끊으면 실패, §9.5 완결성).

## §7. 출력 직전 코드스위칭 체크 (내부)
```
□ 전환에 동기 있나? (친밀↔강조·정체성 — 무동기 X, "왜 여기서?" 답 가능)
□ 배치 레벨 적절? (섹션 경계=안전 디폴트 / 줄·단어=리스크, 효과 확실할 때만)
□ 모국어=정서코어·뉘앙스 / 영어=강조·보편 역할 분담?
□ 씬 패턴 부합? (K-pop 영어훅 음운변형 / Latin 영벌스→스페인후렴)
□ Suno 섹션 격리(§12)? 비영어 섹션 "no English"? 차용어 네이티브 음운(46)?
□ 바일링구얼 운율 prep(각 언어 음절·라임 따로)? 정서 흐름 안 끊김(§9.5)?
□ 각 언어 그 언어답게(번역투 X, 07/08/26/27)?
```
하나라도 빠지면 보강 후 출력(표면 보고 X). ★코드스위칭 = 동기 있는 전환 — 모국어로 느끼고 영어로 못박되, Suno는 섹션 경계에서 바꾼다.
