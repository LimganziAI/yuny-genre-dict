# 29. LYRIC SPEAKER ENGINE — 화자·말투·일상어·독창성 (한국어 중심)
# VERSION: v1.0 (2026-06-10) — 이력은 CHANGELOG.txt
# Scope: §9.0 모드 4종의 실행층. 07(작법 풀바디)·14(운율)·25(사운드)와 상보 —
#        07이 "어떻게 쓰는가"라면 29는 "누가 말하는가 + 무엇을 떨어뜨리는가".
# 발동: 한국어 가사 전 작업(차단 게이트) / 가사 불만 / "가사부터" / 운영자 가사 제공.

## §1. Speaker Card — 가사 첫 줄보다 먼저 (빈칸이면 작사 시작 금지)
```yaml
gender_ageband:      # 예: 남 20대 후반
social_position:     # 직장인/학생/백수/뮤지션… → 어휘장이 여기서 나온다
listener_relation:   # 거리(연인/전연인/짝사랑/자신) + 권력(누가 아쉬운가)
address_term:        # 너/그대/이름/호칭 없음 — 곡당 1개 고정
speech_mode:         # 반말 독백/존댓말 고백/혼잣말/체념/농담 섞인 슬픔/냉소 (1-2개)
na_quota:            # "나" 총량 상한 — 곡 전체 ≤4 권장, 후렴 ≤1 포함
sentence_habit:      # 단문형(툭툭) vs 만연형(흘러감) — 호흡 설계와 직결
humor_allowance:     # 슬픈 곡에도 농담 한 스푼? (운영자 결: 슬픈 노래도 즐겁게 — default ON)
```
컨셉이 화자를 안 주면 → 추정 + 1줄 표기("화자: 20대 후반 남, 담담 독백조로 추정 — 다르면 알려줘").

## §2. 어미 팔레트 — 곡당 1팔레트 고정, 본문 어미는 팔레트+중립어미만
| 팔레트 | 주력 어미 | 양념(곡당 ≤2회) | 절대 금지 |
|---|---|---|---|
| 담담 독백 | -더라 / -더라고 / -지 / -잖아 / -거든 | -길래, -뿐인데, -다는 게 | -것이다, -였던 것 |
| 직진 고백 | -야 / -할게 / -줄래 / 짧은 -어 | -자, -까 | 만연체 전부 |
| 체념·자조 | -겠지 / -려나 / -나 봐 / -는데 뭐 | -다니까, (웃기지) | 과장 감탄 |
| 회상 | -었지 / -곤 했어 / -던 | -었나, -였을까 | 현재형 남발 |
| 취중·농담 섞인 슬픔 | -다?, -라니까, -긴 한데 | 반문 -잖아? | 신파 어미 |
**공통 과잉 금지:** -했어 3연속+ · -고 있었다 · -것이다 · -게 되었다 · 동일 어미 4연속 · 전 행 과거 서술.
**분포 점검:** 한 섹션 8행 기준 주력 4-5 / 중립 2-3 / 양념 ≤1. 후렴은 팔레트 안에서 가장 부르기 쉬운 어미(열린 모음 착지)를 고른다 — 14·25 연동.

## §3. Speaker Sample 10줄 프로토콜 (본문 작성 前 내부 필수)
이 화자가 **노래 밖에서** 이 상황을 말하는 일상 대사 10줄을 먼저 생성한다(표면 출력 X).
체크 3: ① 10줄이 같은 사람인가 ② 팔레트 어미가 *자연스럽게* 나오는가 ③ 건진 말맛 2-3개를 본문에 이식할 것(도치 "딸기를 시켰지, 내가" / 자조 "웃기지" / 망설임 "…긴 한데").
본문이 샘플보다 문어체로 굳으면 R2 실패 → 샘플 톤으로 끌어내린다. **샘플 없이 쓴 한국어 가사 = 절차 위반.**

## §4. 일상어·조어·메타·산문 판정 (R2 게이트 — 매 행)
1. **실사용:** 실제 한국인이 입으로 쓰는 말인가? 의심되면 web_search로 용례 확인 — 용례 없으면 교체.
2. **가창성:** 소리내 읽었을 때 노래로 부를 수 있는가(14 BPM×음절 + 25 연음 연동).
3. **산문 판정:** 행 끝 -고 있었다/-한 것이다/-며 → 산문. 관계절 2겹+ → 산문. *노래는 글이 아니라 발화다.*
4. **조어 판정:** 그 결합의 실사용이 없고 + 처음 듣고 뜻이 한 번에 안 잡히면 조어("입안만 먼저 식어"). 신선함은 **익숙한 단어의 낯선 배치**로 만든다("스푼 두 개, 각을 맞췄어").
5. **사물 주어 영어식 행동 금지:** "비가 나를 적셨다/시간이 날 데려갔다" X → 사람이 겪는다("비에 젖었어").
6. **메타어 출입 금지(본문):** 간주 · 브릿지 · 후렴 · 벌스 · 장면 · 연출 · 클라이맥스 · 고조 · 전환 · 멜로디 · 박자 — 전부 [ ] 큐의 어휘. 화자가 "간주가 길어졌다"고 말하는 순간 곡이 무대 뒤를 들킨다.

## §5. 5-감사표 (출력 직전 내부 — 하나라도 fail이면 본문으로 회귀)
① **화자 일관성** — 샘플 10줄과 같은 사람인가, 중간에 시인이 빙의하지 않았나
② **어미 팔레트 일관성** — 이탈 0, 과잉 0(§2 분포)
③ **사물·은유 통일성** — 중심 은유 1개가 V1→Final까지 *형태를 바꾸며* 관통하나(예: 빙수=관계 — 시킴→녹음→물→자국). 새 은유 난입 금지
④ **후렴 가창성** — 한 호흡, 열린 모음 착지, 따라 부르고 싶은 말맛, 4-변주 설계(§9 LAW 훅 4결합)
⑤ **설명충·메타 제거** — 감정 단어로 결론 내는 행("슬펐다") 제거: *사물이 결론을 낸다.*

## §6. Expression Ledger — 곡간 수렴 차단 [C-139]
곡 완성 시 99z에 5축 1줄씩 기록:
```yaml
song_ref: / core_objects:(5-8) / emotion_verbs: / hook_structure:(한 줄)
ending_pattern:(팔레트+빈출 어미) / ending_image:
```
새 곡 초안 前 직전 3곡과 대조 — **어느 축이든 30%+ 겹치면 그 축 재작성, 엔딩 이미지 중복 0.**
같은 감정 동사("녹다")가 2곡 연속이면 3곡째 금지어. 곡마다 **fresh object bank**(그 곡 세계의 사물만, 17 Scene Dossier 연동) + **concept-cliché ban** 생성: 컨셉이 정해지면 그 컨셉의 상투구를 먼저 금지 리스트로 박는다(빙수 → 마음이 녹다/사랑이 녹다/눈물처럼/차가운 심장 — 물성으로만: 연유가 흐른다/스푼을 내려놓는다/자국이 남는다).

## §7. S0-S10 단계형 제작 (STAGED 모드 — 게이트는 단계지 체크리스트가 아니다)
| S | 내용 | 질문 | 8-필드 |
|---|---|---|---|
| 0 | 모드·리스크 락(§9.0) | 모드 모호 시 1회 | 금지 |
| 1 | Research Brief — 조사 항목 식별+웹(현행 어법/장면 어휘/장르 관습). *기억 회상은 리서치가 아니다* | 없음 | 금지 |
| 2 | Speaker Card+팔레트+object bank+샘플 10줄 (§1-3) | 화자 핵심 충돌 시 1회 | 금지 |
| 3 | Hook thesis + 곡형/BPM/음절 grid (04/05/14) | 추정+1줄 | 금지 |
| 4 | Draft — 곡 언어로, 섹션별(한 호흡 금지) | 없음 | 금지 |
| 5 | **R1** 의미·서사(아크/왜 지금/화자 동기, §9.5) | 서사 진짜 분기 1회 | 금지 |
| 6 | **R2** 언어·말투(§2·§4 sweep + 07 번역투) | 없음 | 금지 |
| 7 | **R3** 운율·가창(14 BPM×음절/peak/열린모음 + 25 + 소리내 읽기) | 없음 | 금지 |
| 8 | Cue pass(§8 — 가사 *동결 후* 별도 패스: 5+2층·device ≥4·휴지) | 없음 | **가사만 출력 가능 지점**(CRAFT 종료점) |
| 9 | CREATE/COVER 빌드(§1/§2/28/30) | 진짜 분기 2-3안만 | 금지 |
| 10 | EXCLUDE/Sliders + 정합성 감사 + 실측 | 없음 | **여기서만 8-필드** |
정합성 감사(S10): 가사↔CREATE 보컬 anchor 동기화 / 가사 이벤트 큐↔COVER substitution / 딜리버리↔EXCLUDE(rap lockout) / Sliders↔모드. 불일치 1개 = S9 회귀.
질문 총량 전 구간 ≤2회 — 남발도 결함, 질문 0으로 오답도 결함.
**LYRIC-REPAIR = S2-S8 루프만**(곡 빌드 회귀 금지). **LYRIC-LOCK = S8부터 시작**(가사 동결 — 본문 1글자 불변, 개선은 "수정 제안" 블록 분리).

## §8. 장르별 한국어 가사 stance (요약 — 상세는 장르사전)
인디 발라드=사물 디테일+체념 유머 / 록=동사 전진+짧은 행 / R&B=모음 흐름+반복 변주 / 트로트=직설+한(恨) 어휘 허용 / 시티팝=시간·거리 이미지(+영어 1-2 토큰 허용) / 댄스팝=훅 음절 경제 최우선 / 힙합 인접=딜리버리 의도 명시(§6 랩화 차단 연동).

## §9. 타 언어 연동 (영/일/스 — 08·26·27 보완 포인터)
- 영어(08): register 선결(구어 vs 문어), 클리셰 라임 확장 블랙리스트(fire/desire·tonight/alright·rain/pain·cry/goodbye·love/above), idiom은 실사용 검증만.
- 일본어(26): register map 곡당 1개(casual 男/女·문어·아이돌·밴드·시티팝), 조사 약박, 주어 생략 기본.
- 스페인어(27): aguda/llana/esdrújula 강세 + 지역 register 단일화(pan-Latin 혼합 = 즉시 가짜).
- **신규 언어 온보딩 템플릿:** prosody unit / register map / 관용표현 / 번역투 블랙리스트 / 라임 체계 / 훅 모음 / 문화 클리셰 가드 / 리서치 의무 / AT — 템플릿 미충족 언어는 출하 금지.
