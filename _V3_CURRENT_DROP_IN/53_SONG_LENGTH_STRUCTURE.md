# 위상: §5(지속→글자수)·§12(바카운트)에 *지속시간 → 구조 전략*을 더함 — 길이가 아크/섹션/훅배치를 바꾼다. §5와 상보(§5=분량, 53=구조).
# 발동: "숏폼/틱톡용/짧게/대서사/긴 곡"·릴리즈 플랫폼 명시·곡 길이 결정 시.
# ★핵심: 길이마다 *다른 구조 전략* — 마이크로(단일 훅 반복)·표준(3막 V-C-V-C-B-C)·대서사(다부). 현대는 훅을 앞으로(30-45초 내). "곡을 살리는 길이"가 정답.

## §0. 원리 — 길이는 구조를 정한다
플랫폼이 길이를, 길이가 구조를 정한다. 틱톡 15-30초 훅 / 스트리밍 2:30-3:30(스킵률↓) / 대서사 5-10분. 현대 청자는
*첫 15-30초*에 스킵 결정 → 훅 앞으로. 단 "곡을 살리는 길이가 정답" — 2분에 다 말하면 4분 반복보다 낫다(패딩 X).

## §1. 길이별 구조 전략 (★핵심)
```
타입          길이        구조 전략                                    훅 배치
──────────────────────────────────────────────────────────────────────
마이크로/숏폼  <2:00      ★단일 훅 1개를 변형 반복(다부 X). 루프·셰어     즉발(인트로 0-4바, 훅 ~10초)
              (틱톡)      가능한 단일 바이럴 모먼트. 인트로 거의 없음
표준          2:30-3:45  ★3막: Intro→V1→C→V2→C→Bridge→Final C→Outro    후렴 30-45초 내
              (스트리밍)   1막 도입·2막 심화·Bridge 피벗·Final 페이오프
대서사        5:00-10:+  다부 구성·솔로·확장 빌드·여러 섹션·키 전환.       여러 훅·점진 빌드
              (프로그/메탈) 테마 전개 시간. 50 에너지 아크 장대
```
- **3막 디테일(표준):** 1막(V-C)=세계 도입 / 2막(V-C)=심화 / **Bridge=피벗**(관점 전환·화성 변화·벌스가 못한 말) / Final C=Bridge 무게 얹어 폭발. ★Bridge가 좋은 팝과 위대한 팝을 가른다.
- **2막 지루함 방지:** V-C 두 번 반복 = autopilot 위험 → Bridge·키 전환·프로덕션 시프트·편곡 변화로 후반 살림.

## §2. 훅·인트로 배치 (현대 = 앞으로)
- **훅 앞으로:** 메인 훅 첫 30-45초 내(숏폼은 ~10초). 첫 15-30초에 스킵 결정 → 늦은 훅 = 이탈. 47 훅 연동.
- **인트로 규율:** 짧게(퍼블리셔도 첫 20초만 들음). 긴 인트로 = 카운터컬처. Suno V5 인트로 자동확장 경향 → [Short Instrumental Intro:2 bars] 또는 [Verse 1 8] 직접(§12). 클럽곡만 8바 리듬(DJ 믹스).
- **페이드아웃:** 현대는 거의 사라짐 → [Outro]/[End] 명확 마감(§12/§9.5).

## §3. 바 수학 (Suno 바카운트 산정, §12)
- 120 BPM 4/4: 16바 = 32초. 3분 곡 = 90바. 공식: (초×BPM)/(4×60)=바.
- 표준 바카운트: Intro 4-8 / Verse 16 / Chorus 8 / Bridge 8 / Outro. §12 [INTRO 4][VERSE 16][CHORUS 8] 태그.
- 랩=가사 담을 만큼 / EDM=빌드·드롭 담을 만큼. 길이 목표 → 바 배분 → §5 글자수 역산.

## §4. 장르 길이 경향
```
장르          기대 길이
──────────────────────────────────────────────
랩/트랩/드릴    2:00-2:30(리플레이 극대)
팝            2:30-3:30(후렴 빠르게)
R&B/발라드      3:00-4:00(정서 전개 시간)
EDM/댄스        3:00-4:00(빌드·드롭 사이클)
포크/싱송라이터  스토리텔링 시간(가변, 더 길게 OK)
메탈/프로그      에픽 다부(5분+)
시네마틱        장대 빌드(가변)
```
- **비트 스위치:** 프로덕션 전환(새 템포/키/비트)으로 곡을 반으로 — 구조적 피벗(힙합·실험 팝). 긴 곡 지루함 타개.

## §5. Suno·YUNY 연동 (§5/§12와 화해)
- **§5 글자수 매트릭스 = 분량 / 53 = 구조 전략.** 둘 같이: 길이 정함 → 53 구조 선택 → §5 글자수 → §12 바카운트.
- **마이크로:** 가사 짧게(§5 하한), 단일 훅 반복, [Short Intro]+즉발 후렴. Suno 1회 생성(1-4분).
- **대서사:** §5 4,800-5,000(대서사만), 다부, Extend로 확장(§14, 2-3회 max — 품질 degrade).
- **Style:** 길이·구조 결 1줄("concise 2-minute single-hook structure" / "full 3-act with bridge climax"). 50 에너지 아크 동기화.

## §6. 규율
- "곡을 살리는 길이" — 무작정 길게·짧게 X. 할 말 다 하면 멈춤(패딩·반복 채우기 = §5 위반).
- 숏폼이라고 대충 X(단일 훅이라도 47 완성도) / 대서사라고 늘어짐 X(50 아크·비트스위치로 텐션 유지).
- 릴리즈 플랫폼 명시되면 그 길이 타겟(틱톡 2분 이하 / 스트리밍 3분대). 미명시면 컨셉·장르 경향.

## §7. 출력 직전 길이·구조 체크 (내부)
```
□ 타겟 길이 정했나? (플랫폼/장르 경향 — 마이크로/표준/대서사)
□ 길이별 구조 전략 맞나? (마이크로=단일훅 반복 / 표준=3막 / 대서사=다부)
□ 훅 앞으로(30-45초, 숏폼 ~10초)? 인트로 짧게([Short Intro]/직접)?
□ 표준이면 Bridge 피벗 있나? 2막 autopilot 방지(키전환/프로덕션 시프트)?
□ 바카운트 산정(§12) + §5 글자수 정합?
□ 곡 끝 [Outro]/[End] 마감? 패딩·무의미 반복 X(살리는 길이)?
□ 50 에너지 아크·47 훅과 동기화?
```
하나라도 빠지면 보강 후 출력(표면 보고 X). ★길이가 구조를 정한다 — 마이크로는 단일 훅, 표준은 3막, 대서사는 다부. 훅은 앞으로, 곡을 살리는 길이로.
