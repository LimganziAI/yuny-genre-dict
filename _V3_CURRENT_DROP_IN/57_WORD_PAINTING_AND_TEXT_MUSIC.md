# 57. WORD PAINTING & TEXT–MUSIC DEPICTION — 음악이 가사 뜻을 그린다

# 검증: 음높이/컨투어(valley 저음·mountain 정점, Handel)·다이내믹(천둥 극단, Bohemian Rhapsody)·템포(Despacito "slowly" 감속)·화성 major↔minor(Hallelujah "minor fall/major lift", Cole Porter)·풀스톱(Britney "stops"에 정지)·편곡(MJ "change"에 전조)·의성(Riders on the Storm) + ★"stop에 stop"=진부 경고
# 위상: §7이 *컨투어를 어떻게 표기*면, 57은 *컨투어·화성·편곡·다이내믹을 가사 의미에 맞춰 무엇을 그릴지*. §7/40/44/50/56을 의미에 복무시키는 상위 의도.
# 발동: 가사·멜로디·편곡 설계 시(특히 정점·핵심어·전환). 음악쪽 표현력 핵심.
# ★핵심: 음악이 가사의 뜻을 *문자 그대로 그릴 수* 있다 — "올라가"에 상행, "혼자"에 희박, "멈춰"에 정지, 밝음↔어둠에 major↔minor. 단 *아무 단어나* 그리면 산만·유치 → 감정적으로 울리고 서사상 중요한 *핵심 순간*만.

## §0. 왜 — 음악과 뜻이 따로 놀면 평면적
컨투어·화성·다이내믹·편곡을 가사 의미와 *무관하게* 박으면 곡이 평면적. 반대로 핵심 단어의 뜻을 음악이 *그리면* 곡이 입체적·기억에 남음(이어웜 47 강화). 57은 그 매핑을 준다 — 단, 절제가 생명.

## §1. ★워드페인팅 유형 → Suno 큐 매핑 (의미를 음악으로)
```
가사 뜻               음악적 그림                                  Suno 큐 / 프롬프트
────────────────────────────────────────────────────────────────────────────────
위/하늘/날다/상승      멜로디 상행, 음역 ↑                          [Ascending melody] / 정점음 (§7)
아래/추락/가라앉다     멜로디 하행, 저음역                          [Descending melody] / 저음 (Friends in Low Places식)
멈춤/끝/정적/사라짐    밴드 정지·한 박 공백 (★"stop"은 진부 주의)   [Band drops out]/[Sudden Absolute Silence:1 bar] (§8)
느리게/천천히/영원     템포 늘어짐·음 길게(멜리스마)                [Held]/늘림(천-천-히) / half-time (Despacito식)
빠르게/달리다/쫓다     음 촘촘·당김음·러시감                        짧은 음절·syncopation (§40)
밝음/희망/사랑↔어둠/슬픔 화성 major↔minor 전환                      CREATE 화성 서술 "lifts to major on X / falls to minor on Y" (40)
변하다/돌아서다        전조(key change)·화성 급전                   CREATE "modulates up on the word change" (MJ식)
크다/분노/폭발/외침    다이내믹 ↑·belt·풀 편곡                       [Belted]+백킹 "+6dB, full band" (§6/50)
작다/속삭임/혼자/텅    다이내믹 ↓·희박 텍스처·솔로                   [Whispered]/[stripped back] "band drops to vocal only" (50/56)
함께/모두/가득        레이어 ↑·합창·풀 스택                        [Stacked]/[Gang vocals]/[Choir] (51)
원/돌다/맴돌다        순환 모티프·반복 프레이즈                     반복 hook·[circular motif] (JT "What Goes Around"식)
구체 사물 소리         편곡 사건으로 (★의성어 가사 금지 §8)         [Sound FX: …]/[side-stick knock] — 가사 (Bam!) X
```
- ★핵심어를 *정점·전환·제목*에 두고 그 위에 그림(56 정합체인과 결합: 그 음절은 열린 모음·강박·큐까지 정렬).

## §2. ★절제 규율 (이게 없으면 망함 — web 경고)
- **아무 단어나 그리지 마.** 모든 단어를 그리면 산만·유치(madrigalism 과잉). **곡당 1-3개**, *감정적으로 울리고 서사상 중요한* 순간(제목·전환·정점·핵심 이미지)만.
- **진부 회피:** "stop"에 정지, "high"에 고음 같은 *가장 뻔한* 직역은 과용됨 → 덜 뻔한 단어·더 미묘하게(화성 전환·텍스처 변화가 음높이 직역보다 세련). 의도적 클리셰는 이유 있을 때만.
- **서사에 복무:** 그림이 *gimmick*이 아니라 곡의 감정·이야기를 강화해야. 안 그러면 빼라.
- **섹션 정점과 결합:** 워드페인팅의 최대 효과 자리 = 후렴 머니노트·브릿지 전환(47/50)과 겹칠 때.

## §3. 8-필드 전반 반영 (한 단어를 4-5층이 같이 그림)
한 핵심어를 그릴 때 여러 층이 협력:
- **가사:** 그 단어를 정점/전환 위치에 + 열린 모음(56).
- **컨투어 큐:** [Ascending/Descending melody] (§7 3층).
- **CREATE 화성:** "lifts to major / modulates / chromatic fall on [word]" (40, 코드기호 X 서술).
- **[Singing:]/백킹:** 다이내믹·텍스처 사건([Belted]/[stripped]/[Band drops out]/[strings swell +6dB]).
- **프롬프트 무드:** 그 순간의 정서 어휘. → 다섯이 같은 의미를 그리면 그 순간이 *터진다*.

## §4. 언어 무관 + 한국어 예
- 한국어도 동일: 상승 "날아올라/올라가" → 상행 / 하강 "떨어져/주저앉아" → 하강 / 정지 "멈춰/끝났어" → 밴드 컷 / 희박 "혼자/텅 빈" → 솔로 / 확장 "다/모두/가득" → 스택 / 밝음↔어둠 "웃어↔무너져" → major↔minor.
- ★단어 선택은 *자연스럽고 울리는* 한국어로(억지 직역 X) — 절제 규율(§2) 동일.

## §5. 출력 직전 체크 (§7/40/50/56과 함께)
```
□ 핵심어(제목/전환/정점) 1-3개에 워드페인팅 적용? (전부 X — 절제 §2)
□ 진부한 직역("stop"정지 등) 회피 / 미묘함(화성·텍스처) 활용?
□ 그림이 서사·감정에 복무(gimmick X)?
□ 그 순간 4-5층 협력(가사 위치+컨투어+화성+다이내믹/텍스처+무드)?
□ 정점 워드페인팅이 56 정합체인(열린모음·강박·큐)과 겹치나?
□ 의성은 편곡 사건([Sound FX])으로(가사 의성어 X §8)?
```
하나라도 어긋나면 보강. ★음악이 뜻을 그리되, 절제가 세련을 만든다 — 모든 단어가 아니라 *그 한 단어*가 음악으로 살아날 때.
