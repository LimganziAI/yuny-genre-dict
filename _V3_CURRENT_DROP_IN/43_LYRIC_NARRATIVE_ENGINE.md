# 근거: 07/08/26/27(언어별 가사)·29(화자 엔진)·33(기능)·§9(작법)·§9.5(완결성) + 현행 서사 작사학 web 검증(2026-06)
# 위상: 가사 크래프트(WHO=29·WHAT=언어파일)에 *스토리를 어떻게 구축하나(HOW the story moves)*를 더함. §9.5(완결성 게이트=검사)와 구별 — 이건 *서사 구축 엔진*.
# 발동: 가사 설계 진입 시(특히 스토리텔링 곡)·"서사가 약해/그냥 감정 나열·전개가 없어"·관점/시점·반전·복선 발화.
# 핵심: 곡 = 3-5분 *미니 내러티브*. ★연구 검증 코어 arc = 서두 무대설정 → 플롯 꾸준히 전진 → *중간(브릿지 존)에서 인지 긴장 정점* → 해소(또는 의도적 비해소).

## §0. 왜 — 서사가 청자를 붙든다
감정 나열만 하면 곡이 평면. arc가 있으면 *계속 들을 이유*가 생긴다. 곡은 짧지만 책·영화와 같은 서사 구조를
따른다(N=12,280 가사 연구). 화자(29)가 *누구*라면, 서사는 그 화자가 *통과하는 이야기*다.

## §1. 서사 arc — 척추 (setup → conflict → resolution)
```
요소               기능                              곡 섹션 매핑(권장)
──────────────────────────────────────────────────────────────
Setup(무대설정)    화자·장면·일상 세계 확립           Verse 1 (+Intro)
Conflict(갈등)     중심 긴장·욕망·문제 도입           Chorus(중심 긴장) / Pre가 빌드
Escalation(고조)   복잡화·강화 — V2가 V1을 *심화*      Verse 2(≠V1, 전복/심화) → Pre 2
Peak(정점)         ★인지 긴장 최대 — 반전·고백·이해    Bridge(연구상 중간 정점 자리)
Resolution(해소)   변화된 귀결 / 의도적 비해소         Final Chorus(변형) → Outro
```
- **중심 생각은 *진화*한다(반복 X):** V2는 V1을 깊게·복잡하게(같은 말 반복 = 서사 정지). Final은 Chorus의 *재의미*(§9.5).
- **감정 고조 = 클라이맥스로:** 강약 매트릭스(§5)·편곡 레이어링(39)으로 구현.
- **해소 선택:** 깔끔한 해결 / 변화된 화자 / 의도적 미해결(여운). 컨셉이 정한다.

## §2. POV / 관점 — 모든 걸 바꾸는 레버 (★"무엇을 말하나"보다 "누가/어디서 말하나")
```
POV            효과                                예
──────────────────────────────────────────────────
1인칭(나)       고백·내면·직접 감정                  대부분의 발라드/팝 — 화자 직접
2인칭(너)       직접 호명 — 친밀(연인) 또는 비난(저격)  R&B 관능 / 이별 저격
3인칭(그/그녀)   관찰자·이야기·거리                   포크 발라드·서사곡(인물 묘사)
관점 전환        섹션 간 전환 = 깊이·반전              딜런식: verse 서사 → bridge에서 관점 전환
복화자(대화)     두 화자 주고받기                     듀엣/혼성(§6 보컬과 연동)
```
- POV는 컨셉마다 *선택*한다. 브릿지에서 전환(나→너, 현재→회상)하면 강력한 반전.

## §3. 시간 구조 (Temporal)
```
구조              무엇                              효과
──────────────────────────────────────────────────────
Linear(선형)      시간순 전개                        명료한 스토리(포크·컨트리)
In Medias Res     *사건 한복판*에서 시작 → V2가 배경    즉각 몰입·긴장(정점에서 열고 뒤에 설명)
Retrospective(회상) 지난 일을 현재에서 돌아봄           노스탤지어·발라드(시간의 무게)
Present-immediate  지금 일어나는 일(현재형)            긴박·생생(댄스·R&B 관능)
Frame(액자)        오프닝 이미지로 끝에 회귀(변화됨)    원형 완결·재의미(§9.5 연동)
```

## §4. 서사 구조 템플릿 (곡 섹션 매핑 — 골라 쓰는 뼈대)
```
Hero's Journey(변신 서사): V1=평범한 일상(보링한 직장/깨진 마음) → Pre/Chorus=모험의 부름(변화 욕망)
  → Bridge=시련(가장 힘든 순간) → Final Chorus=귀환(새 관점의 해소). 예: 아델 "Rolling in the Deep"
  (배신→분노/저항→독립 선언).
Freytag 5막: 도입(exposition)→상승(rising)→정점(climax=Bridge)→하강(falling)→대단원(denouement=Outro).
In Medias Res: 정점에서 열고(첫 줄=가장 극적 순간) → V2에서 배경 채움 → 다시 정점으로.
Vignette/스냅샷: arc 없이 *한 순간*을 깊이 파기(무드 곡·분위기 곡엔 유효 — 서사 강제 X).
Circular(원형): 시작한 자리에서 끝나되 *의미가 바뀜*(첫 줄 회귀, §2 Frame).
Two-hander(대화): 두 화자의 주고받음(듀엣 — 각 POV 교차).
```
→ 곡마다 *하나* 선택해 일관 유지. 매 곡 같은 구조 반복 = 전형성(다양화 §10).

## §5. 서사 장치 (Devices)
- **복선(Foreshadowing) = 가사 + ★음악 양쪽:** 가사로 힌트 + *음악적 복선*(Pre-Chorus가 잠깐 단조로 가서 Bridge의
  어두움을 예고 → Bridge에서 확장). §7 컨투어·§3 Modulation·40 화성과 연동.
- **정보 보류(Withholding):** 핵심을 Bridge/Final까지 아껴 *페이오프*. "누구에 대한 곡인지" 끝에 밝히기.
- **반전(Twist):** 초반에 *청자 모르게* 복선 심기 → 끝에서 뒤집기. (예: 사랑 노래인 줄 알았는데 이별/상실).
- **Show Don't Tell(§9):** 한 줄=1 이미지, 추상→구체 사물·신체.
- **구체 디테일:** 보편 감정을 *구체적 디테일*로(에드 시런 "Photograph"의 특정성). 일반론 X.
- **인물 구축:** 욕망 + 결함 + 특정성(딜런 "Hurricane"·스프링스틴 "Thunder Road"의 Mary). 화자 카드(29)와 연동.

## §6. 장르별 서사 경향 (연구 기반)
```
장르          서사 경향
──────────────────────────────────────────────────
Country/포크   상세한 장면 설정, 선형 스토리, 인물+장소 구체, 회상 빈번
Rap           조밀한 디테일, 1인칭, 높은 내적 갈등(braggadocio 또는 pain-narrative)
Pop           빠른 플롯 전개, 높은 내적 갈등, 감정 즉각성
R&B           친밀한 2인칭, 관능적 현재형, 분위기 우선
발라드         회상·감정 arc, 시간의 무게, 해소 또는 여운
인디/얼트       Vignette·내면, 비선형 허용, 모호한 해소
시네마틱        Frame·원형, 큰 정서 궤적, 정점 강조
```

## §7. 통합 (기존 시스템과 — 유기성)
- **29 화자 엔진 = WHO**(화자 카드·어미·POV 목소리) → **43 서사 = 그 화자가 통과하는 STORY**. 화자 먼저, 서사 얹기.
- **§9.5 완결성 게이트 = arc가 유지되나 *검사*** → **43 = arc를 *구축*.** 빌드(43) → 검사(§9.5).
- **음악적 복선·고조** = §7 컨투어 + §3 Modulation + 40 화성 + 39 편곡 레이어링(에너지 arc). 가사 정점 = 음악 정점 동기화.
- **POV·복화자** = §6 보컬 구성(듀엣/혼성 = two-hander 서사)과 연동.
- **시간 구조 Frame** = Outro 첫줄 회귀(§9.5 곡 끝 마감).

## §8. 서사 빌드 체크 (가사 착수 시, §9 LAW 안에서)
```
□ arc 골랐나? (setup→conflict→peak→resolution 또는 §4 구조 1종)
□ POV 정했나? (1/2/3인칭·전환 여부 — 컨셉 맞춤)
□ 시간 구조? (선형/in medias res/회상/현재/Frame)
□ V2가 V1을 *심화*하나(반복 X)? 중심 생각 진화?
□ 정점이 중간(Bridge)에 오나? 음악 정점과 동기화?
□ 복선·보류·반전 중 ≥1? (음악적 복선 포함)
□ 인물 구축(욕망+결함+특정성)? 화자 카드(29)와 일관?
□ 해소 선택(해결/변화/여운) 의도적인가?
□ 장르 서사 경향(§6) 반영? Vignette면 arc 강제 X?
```

## §9. 출력 직전 서사 체크 (내부, §9.5와 함께)
arc 일관·POV 일관·시간축 일관·V2 심화·정점 배치·인물 일관 — 하나라도 무너지면 보강 후 출력(표면 보고 X).
★Vignette/무드 곡은 arc 면제(단일 순간 심화가 목적). 서사를 *모든* 곡에 강제하지 마 — 컨셉이 정한다.
